# 夜班选题桌 · 独立美术交互样片

本目录是一条重新设计的探索路线。用户于 2026-09-07 明确同意从两张美术标杆和最终吸引力出发，不沿用旧三栏与逐组件制作流程。

## 本轮范围

- 一幅完整 ImageGen 母画承担桌面、地图、纸件、印刷物和所有材质。
- 浏览器只叠加真实中文、三张既有新闻母图、导航标记和交互状态，不重新绘制纸面。
- 同一组素材验证三地区选择、锁定地区预览、任务信息展开与入口反馈。
- 1920×1080 桌面演示；不覆盖旧界面，不接正式游戏，不声称 Godot 已落地。

## 美术依据

- `design/art-direction/references/clean-lowpoly-weekly-branch/benchmark-board-01.png`
- `design/art-direction/references/clean-lowpoly-weekly-branch/benchmark-board-02.png`
- 新闻图复用 `gd_project/Assets/prototypes/world_map_integrated/a_style_v2_runtime/` 的三张 1104×704 母图。

## 展示方式

用本机静态服务器打开 `index.html`。画面按整屏等比适配；建议使用 1920×1080。可点击底部来稿或地图编号切换地区，数字键 1–3 同样可用。任务信息可以原位展开；锁定地区可查看但不能进入。进入按钮只抵达样片入口反馈，不启动正式游戏。

## 诚实边界

母画原始尺寸是 1672×941，浏览器整体等比显示；不是原生 1920×1080 生图。照片在完整母画的轻微透视纸面上统一投影，三个地区使用完全相同的映射，原始内容均完整保留。没有重新生成状态专用缩略图。

本样片检验完整美术转成动态内容时能否保留效果，不代表最终美术验收或生产冻结。
