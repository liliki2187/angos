# 落地 Brief：全链 demo 高危五档结算退役

> 交接用实现说明，可直接交给执行 AI。设计决策：高危五档已于 2026-07-14 降级为备选点子（`docs/design-decisions/backlog-and-deferred.md` M4，原 B3）。
> 与重投 brief、暴露副轴 brief（`docs/plans/dice-reroll-review-points/`、`docs/plans/exposure-side-axis/`）相互独立；若同时实现，本 brief 是纯删除，无冲突。
> 本文分「已实测事实」与「待验证假设」。

## 1. 背景与目标

设计口径已定：非黑骰任务只看是否达标，黑骰任务用四档；五档（大成功 / 成功但反噬 / 部分成功 / 失败但有线索 / 大失败）降级为备查点子，不再是任何任务的结算方向。

**实测现状（2026-07-14 已核实）**：demo 里危险任务的主结算**已经**走达标口径（`applyStandardOutcome` 内含 `riskTier === "high"` 的重后果分支），五档只剩两个残留消费点：

1. `runMission` 里的 `mapHighRiskTier` 映射（对主流程基本是透传）；
2. 「再追一次」奖励环节（`shouldOfferPushBonus` / `resolvePushBonus`）：用五档 id 做触发门槛，并且内部还在用**旧苏丹式 split 检定**（`runSplitCheck`）跑追加判定——与当前角色骰主干双重脱节。

目标：把这两个残留连根摘除。「再追一次」按已采纳的 B1 定义（2026-05-06 修订：深度链终局前后进入黑骰任务的临时事件选择）属于**待重做**，本次先随五档一起下线旧实现，不做新版。

## 2. 硬约束

1. 纯删除 + 最小改动：不新增机制、不调整结算数值、不改判定弹窗与结算页布局。
2. **不改 `applyStandardOutcome`**：危险任务的达标口径与重后果分支（成功 Tier 3 素材 / 失败狂性+2 守序-1 弱线索）就是降级后的正式表达，原样保留。
3. **不删 `runSplitCheck` 函数本体**：`runMission` 的 else 分支（`useCharacterDice` 恒 true 的死分支）仍引用它，属另一层遗留，本次不扩大范围。
4. 不动 `world-mysteries-full-chain.html` 的废弃内联脚本副本（`data-obsolete-inline-script`）；改完把底部 `<script src>` 版本号更新为 `?v=20260714-five-tier-retired`。
5. 交付附 1–2 张真实浏览器截图（危险任务结算页 / 黑骰终局结算后不再弹「再追一次」）。
