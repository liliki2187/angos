# 区域任务配图抽象符号转换 Router Card

## 决策条

- **结论**：暂停整屏返工，先把卫星站、灯塔、厂房和天线城从低多边形微缩模型转换为四枚可独立印在暖纸上的编辑插画符号。
- **影响**：只验证对象—画法合同与黑色幽默关系，不改区域地图功能稿、任务状态、票据结构或整屏布局。
- **下一步**：V6 双 Agent 终审通过后交用户裁决；用户认可前不回填 A2.4、不拆资产、不进入 Godot。

## 路由

- 风险等级：`risky + experimental`
- 产物类型：`visual_style_reference`
- 输入失败样本：用户提供的四张具体低多边形建筑裁切
- 直接标杆：`benchmark-board-01.png`、`benchmark-board-02.png`
- 配色 / 场景上下文：区域地图 A2.4
- 设计顺序：`ui_designer` 定义四枚符号合同 → `ux_laoge` 检查 25% 与暖纸单卡 → 内置 `imagegen` 真实生成 → 双 Agent 终审

## 开放项

1. 四张配图的主剪影、辅助块、异常关系与内部大面。
2. 独立风格板上的暖灰纸面与深夜蓝灰编辑板。
3. 为 25% 可读性所需的对象比例与异常间距。

## 冻结项

- 四种任务对象身份：卫星站、灯塔、厂房、天线城。
- 区域地图 A2.2 / A2.4 的综合色彩家族。
- “真实编辑部认真处理荒谬事件”的成年冷面幽默。
- 正式区域地图的布局、文字、地图、状态、票据、条码与交互链。

## 停止条件

- 重新出现等距模型、完整地台、AO、接触阴影或零件清单。
- 只减少三角形数量，却仍靠真实建筑结构辨认。
- 四张图变成通用软件按钮或互相复用同一个卫星碟 / 光束模板。
- 异常关系必须依赖说明文字才能在 25% 下成立。
- 纸面滑向黄褐旧档案、羊皮纸、浮雕壁纸或连续花纹。
