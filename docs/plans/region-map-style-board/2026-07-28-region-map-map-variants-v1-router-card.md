# 区域地图中央地图变量 v1 Router Card

## 决策条

- **结论**：在已完成的区域地图风格板 v1 上，只替换中央地图内部的大面积配色与块面语言，横向生成 3 个候选。
- **影响**：验证“偏黄是否主要由地图陆地造成”，并比较夜蓝、冷青灰、铅蓝三种地图在同一外层编辑部界面里的综合色温与氛围。
- **下一步**：用户从 3 个候选中选择一条母方向；未选择前不进入完整界面、资产拆分或 runtime。

## 路由

- 风险等级：`risky + experimental`
- 产物类型：`visual_style_reference`
- 当前阶段：中央地图定向颜色 / 结构变量探索
- 真实生图：必须
- 必调角色：先 `ui_designer`，后 `ux_laoge`
- 美术指导：按 `clean low-poly weekly` 临时例外不自动调用

## 本轮唯一问题

在世界地图 A「夜班石板蓝」家族不变的前提下，中央区域地图换成什么主色与块面结构，既能消除卡其橄榄造成的综合色温偏黄，又不会跑成旅行地图、世界地图放大版、军事雷达或过度严肃的情报图。

## 可变范围

- 仅中央大地图纸内部的地图画面：
  - 水域 / 陆地 /高地的综合色块；
  - 大块面组织；
  - 岸线、交通骨架与异常圈注的视觉权重；
  - 地图内部至多一处轻量黑色幽默批注。

## 冻结范围

- 1672×941 画布与全部组件位置、尺寸、层级。
- 左侧事件票据、右侧 `CASE FILE`、底部日程 / 成本 / 后果 / 签批、`DAY 01` 硬件。
- 外层桌面、纸张、夹子、回形针、铅笔与所有现有文字。
- 海岸 / 河口的基本构图、事件坐标数量、事件 ID、`R-21` 选中位置与左票据到地图的选中链。

## 三个变量

1. `A1 夜蓝潮汐层`：潮湿夜班氛围上限。
2. `A2 冷青岩盘`：25% 地图 / 节点可读性的安全基准。
3. `A3 铅蓝剪报图`：真实编辑部剪报拟物上限。

## 停止条件

- 生成 3 张同母版独立候选及 25% 对照后停止。
- 不因某版局部跑偏继续无限生图。
- 用户未明确选择前，不登记正式采纳，不替换区域地图 v1，不升格生产候选。
