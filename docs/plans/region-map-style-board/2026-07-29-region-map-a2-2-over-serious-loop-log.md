# Loop Log：区域地图 A2.2 制度感压过趣味

日期：2026-07-29
触发来源：用户指出区域地图“稍微严肃了一点”，要求把趣味度拉到世界地图 A 附近。
产物类型：`loop_log`（审计记录，不是视觉候选）。

## 决策条

- **结论**：A2.2 的地图结构、配色和纸张校准继续有效，但趣味锚点数量与跨栏关系不足，整屏被案卷、表格和审批结构主导。
- **影响**：如果只加一张更夸张的贴纸，会把问题从“过于严肃”推向“卡通装饰”，仍然无法建立真实编辑部内的冷面怪新闻感。
- **下一步**：冻结 A2.2，只用三处不同媒介、同一案件的异常证据补足第二阅读层；完成世界 A 并排和 25% 验收后停下。

## 触发与归因

- **原始问题**：A2.2 解决了地图灰土和纸张偏暗，但与世界地图 A 并排时，趣味密度仍低一档。
- **失败归因**：本轮颜色 / 纸张单变量校准时过度冻结了叙事活性，只保留一个黄便签笑点；正确的制度层级因此成为唯一视觉主语。
- **复发判定**：命中 A268 已记录的“制度、审批和情报感压过好奇邀请感”同一家族，不新增错误家族。
- **错误修法保护**：不整体提亮、不扩张黄橙、不堆贴纸、不加卡通表情，也不复制世界地图的具体物件。

## 返工过程

1. UX 老哥将差距拆成“世界 A 约三层趣味、A2.2 只有一层”，要求主链首读不变。
2. UI Designer 将三处趣味统一成“方向错了 → 高度错了 → 目的地也错了”的同一事件链，并为每处绑定不同画法。
3. A2.3 首轮中，案卷高空鱼与票据水波成立，但黄便签把鱼形投影误生成独立人形，且 25% 趣味仍偏弱，故降级为诊断稿。
4. A2.4 删除误生人形，将同一枚锈红圈高空鱼同时放入左侧已选缩略图和右案卷照片，保留黄便签与票据水波。

## 复发保护

- 区域地图的趣味 Gate 不只数“有没有贴纸”，而检查至少两种媒介是否在讲同一宗异常。
- 25% 下先读任务链，再能指出至少两处怪异；反过来则说明趣味抢功能，完全看不见则说明制度感仍过强。
- 手绘、粗低多边形与机构印刷必须分别落在便签、证据图和票据上，不得全部变成同一套光滑图标。
- 无 mask 的生图编辑只能作为视觉参考；发生尺寸漂移时不得声称生产冻结。

## 沉淀判断

- **是否为单次 bug**：不是。
- **是否为可迁移错题**：是，属于 A268 同族复发。
- **设计决策修订**：追加到 A275；A2 结构与 A2.2 配色 / 纸张继续有效，A2.4 待用户确认趣味剂量。
- **GDD / 代码**：未改玩法规则、功能结构、Godot、atlas 或正式资产合同。

## 世界地图 A 并排后的再次复发（2026-07-29）

- **直接证据**：`image_gen/2026-07-28/region-map-map-variants-v1/51-world-a-region-photo-snapshot-side-by-side.png` 与 `52-world-a-region-photo-snapshot-side-by-side-25pct.png`。
- **用户判断**：区域界面相比世界地图 A 更严肃、更无趣。
- **结论**：判断成立。问题不只是色调偏冷或任务配图不够有趣，而是制度信息遍布全屏、趣味信号却集中在边角；当前区域页首先读成“异常事件派遣系统”，其次才读成“成年怪新闻编辑部的地方调查桌”。
- **合理职责差异**：区域页需要比世界页克制，必须保留三栏任务比较、地图节点、选中链、风险 / 成本和派遣 CTA；不能复制世界页的高密度自由拼贴、倾斜功能卡或散落道具。
- **当前设计失误**：
  1. 左卡、地图与右案卷各归各盒，同一异常没有形成跨媒介证据链。
  2. 右案卷大面积空横线和同构表单压过照片、标题与异常关系，内容高潮变成待填写模板。
  3. 横卡、矩形地图、矩形表单和底部三块形成连续正交框，缺少受控尺度跳变。
  4. 四张任务图共享相近冷灰天空、地平线和严肃建筑语法，案件差异只能靠文字。
  5. `FIELD DESK / CASE FILE / DISPATCH APPROVAL / CONSEQUENCE PREVIEW` 连续使用机构口吻，使记者、目击与怪新闻语气退场。
- **新的原型句**：区域页是一张正在被编辑部追踪的地方异常现场桌——三栏任务骨架＋每案一个异常色梗＋“左卡目击 → 地图定位 → 右案卷复核”的同源证据链＋一处选中案件内容高潮。
- **最高 ROI**：
  1. 先用 R-21 建一条完整三段证据链，不增加贴纸总数。
  2. 在既有右案卷槽位内装入真实摘要、两条短目击和一幅异常关系图，消除空模板。
  3. 四张任务图保持同一画法但分离地平线、明暗面积与异常强调色。
  4. 只在非交互装饰层制造一处裁切 / 轻叠压，外框与点击热区不动。
  5. 保留功能词，将非功能标题与辅助句分配给任务、目击和机构三种口吻。
- **Gate**：当前 `P0=0`，UX 诊断 `P1=4 / P2=2`；UI Designer 同意不推翻三栏，但必须先关闭三段趣味链、案卷层级与四图同调问题。A2.4 不再以“已有三处趣味锚点”视作趣味度通过。

## R-21 单案纵切片（2026-07-29）

- **真实生图素材**：`image_gen/2026-07-29/region-map-r21-vertical-slice-v1/01-r21-evidence-body-imagegen.png`。
- **整屏回填**：`image_gen/2026-07-29/region-map-r21-vertical-slice-v1/02-region-map-a2-r21-evidence-chain-preview.png`。
- **并排证据**：`03-world-a-region-r21-side-by-side.png` 与 `04-world-a-region-r21-side-by-side-25pct.png`。
- **本轮只开放的 ROI**：R-21 左卡照片的人工复核圈、地图到案卷的选中链延长、右案卷原有三块空表单正文；三栏、地图拓扑、任务位置、底部排期 / 成本 / 后果区和派遣按钮均保持不变。
- **内容层级修订**：
  1. `EVENT SUMMARY` 从空横线框变成紧凑的异常摘要节奏。
  2. `WITNESS REPORTS` 使用两张长短不一的证据票条，不再是第二块同构表格。
  3. `KNOWN PATTERNS` 使用“灯塔光束—高空鱼—潮位”的手绘关系图，不再是第三块待填写表单。
  4. 同一条高空鱼在左卡与右案卷照片中用同一锈红复核圈重复；地图只承担位置层，不额外塞入写实小景或贴纸。
- **自检结论**：相较 `45-region-map-a2-5-photo-snapshot-preview-v1.png`，右案卷的空模板感和连续正交框显著下降；25% 下 R-21 主链仍先读，鱼、票条和关系图作为二读成立。
- **仍未关闭**：本轮只验证一个案件；R-17 / R-34 / R-08 仍共享相近冷灰节奏，区域页整体仍比世界地图 A 更规整克制。不得把单案通过误报成整屏生产通过。
