# 区域任务配图抽象符号转换 Prompt 记录

## 输入角色

- 用户裁切：四张过于具体的低多边形微缩建筑，仅提供对象身份与失败证据。
- `benchmark-board-01.png`、`benchmark-board-02.png`：直接美术真值。
- 区域地图 A2.4：只提供深夜蓝灰、暖纸、冷青灰、橄榄与锈橙关系。

## 共同合同

- 每图只保留 `1` 个主剪影、`1–2` 个辅助块和 `1` 个异常关系。
- 主体约 `3–5` 个大面，总计不超过 `7–8` 个主要形状，只用 `3–4` 档离散明度。
- 插图直接印在暖灰纸面上；无照片框、地台、完整地面、接触阴影和 AO。
- 四图分别使用不同轮廓核：偏心大碟、竖向灯塔楔、宽扁厂房块、低锯齿城市色带。
- 25% 与独立暖纸单卡双测；先认对象，再发现一个不可能关系。

## 四个图形梗

1. **卫星站**：碟面朝右上，橄榄信号却从左侧进入碟背。
2. **灯塔**：灯束照向海面，鱼却悬在灯塔高处。
3. **厂房**：真实灰烟囱的扇形平面投影向右延伸，末端折起成为同形锈橙假烟囱。
4. **天线城**：低锯齿城市只保留一根向下弯的主天线，城内信号反向上行进入接收端。

## 迭代记录

### V1

- 首次把四个微缩建筑转换为四个大剪影。
- 问题：卫星仍有完整底座；厂房和天线城偏通用矢量图标。

### V2

- 删除卫星底座，给厂房与城市补宽大内部面，天线城去除模型感。
- 问题：厂房异常像普通橙色管道；天线城再次使用卫星碟；纸面偏黄并出现压花式连续花纹。

### V3

- 厂房建立连续折带，天线城改低头主杆，纸色转暖灰。
- 问题：纸面压花仍在。

### V4

- 单变量将四张纸收回安静暖灰无涂布区间，四枚图形冻结。
- UI Designer `PASS`；UX 老哥 `ITERATE`，认为厂房在无标题 25% 下仍像外接管道。

### V5

- 将厂房管道形折带改为从真实烟囱发出的扇形平面投影楔，末端接同形锈橙假烟囱。
- 问题：天线头被过度修成向下箭头，整版不采用。

### V6

- 保留 V5 厂房，恢复 V4 的低头天线城。
- 最终状态：UI Designer 与 UX 老哥均 `PASS`，`P0=0 / P1=0`；厂房橙色假烟囱稍强、天线末端略像吊钩为 P2 观察项。

### 用户回填复核

- V6 回填 A2.4 后，用户指出整体又显得太极简。
- V6 从待裁决候选降级为 `ICON / GRAPHIC ELEMENTS` 层下限反例；旧双审 PASS 只覆盖“摆脱微缩模型”，不覆盖“命中正确标杆颗粒度”。
- 下一轮不在 V6 上加噪点或随意增加零件，而从 `PHOTO & SNAPSHOT` 简化端重建：
  - 主体 `6–9` 个有意义结构块；
  - 环境 `2–4` 个宽大块；
  - `4–5` 档离散明度；
  - `3–4` 个综合色相组；
  - 留白 `20–35%`；
  - 单一异常占 `8–16%`。
- `COVER vignette` 只参考主体与环境互切；`ICON DESIGN / GRAPHIC ELEMENTS` 只作反例。

## 最终 V6 生成摘要

以 V5 为主板，仅把第四卡替换为 V4 的低头天线城：一条低锯齿城市色带、一根弯向城市的主天线、一条从城内向上进入接收端的断续橄榄信号。前三卡、暖灰纸面、深夜蓝灰底板、综合色盘和全部负空间保持不变。禁止箭头、插头、灯具、卫星碟、第二根天线、三角覆盖光束、三维模型、阴影和文字。

## 生成方式

- 六轮均使用 Codex 内置 `imagegen` 真实生成 / 编辑。
- 程序只负责复制工作区、源图并排、独立卡裁切和 25% 缩略，不替代美术生成。

## PHOTO & SNAPSHOT 再校准的 Prompt 结论

- 四联首轮补回现场后，画面会自然滑向完整低多边形景观；全局要求“减少约一半切面”则会把场所压成 ICON 背景。
- `主体 6–9 块 / 环境 2–4 块` 是父级与双 Agent 的验收口径，不再作为模型必须逐项数出的字面绘制命令。
- 只引用完整标杆板会同时放大 `COVER`、`PHOTO` 与 `GRAPHIC ELEMENTS` 三套语言；已制作 `47-region-photo-snapshot-focused-benchmark-reference.png`，只保留 `PHOTO & SNAPSHOT` 与少量主体—环境辅助。
- 单张大图不会自动提高质量：卫星单图试验放大成纪念碑式特写，因此后续仍以真实左卡尺寸的阅读结果判断，而不是以大图精致程度判断。
- 当前最近邻为 V2。下一轮 Prompt 只允许三个局部变量：删除卫星完整基地、让灯塔由海 / 岸裁断、把厂房弯管改为贴墙投影；天线城、综合色盘、天空层次和整体构图保持不变。
