# Loop Log：区域任务配图滑向低多边形微缩模型

日期：2026-07-29
触发来源：用户复核 A2.4 左侧四张任务配图，指出它们不够抽象概括；在标杆的多边形背景中尚可，单独置于票据上就显得写实。
产物类型：`loop_log`（审计记录，不是视觉候选）。

## 决策条

- **结论**：A2.4 的趣味关系与综合色盘继续保留，但四张任务配图的画法未通过；原“对象—画法合同 `pass_visual`”撤回。
- **影响**：四张图当前读成卫星站、灯塔、厂房和天线城的低多边形微缩建筑渲染，而不是标杆中的平面周刊图形。若直接扩展，会让同一界面内部再次出现“背景图形化、独立配图写实化”的风格断层。
- **下一步**：冻结票据、标签、条码和状态结构，只重画四张图像 ROI；先建立一张“具体模型 → 编辑符号”的四联转换板，用户通过后再回填整屏。

## 根因

1. **先建模、后低多边形**：保留了真实建筑比例、三维透视和大量零件，只是把材质分成多边形面。
2. **微缩地台语法**：四个主体都有完整地面、接触阴影和产品渲染式悬浮，像模型目录或策略游戏建筑图标。
3. **身份细节过量**：桁架、窗、台阶、栏杆、烟囱、天线和附属建筑共同解释对象，轮廓本身反而不够有力。
4. **连续空间明暗**：AO、渐进阴影和体积深度形成真实空间；标杆需要的是离散的平面明度块。
5. **载体差异未进入 Gate**：同样的具体对象嵌入大块多边形背景时会被背景吸收；独立放在暖纸票据上时，必须额外提高抽象度。此前只检查了“是否低多边形”，没有检查“脱离背景后是否仍是图形符号”。

## 下一轮画法合同

- 每张图只保留 `1` 个主剪影、`1–2` 个辅助块和 `1` 个异常关系。
- 主体使用约 `3–5` 个大面；特殊情况最多 `8` 个，不把三角面平均铺满对象。
- 使用正面或轻微三分之四海报视角；禁止等距微缩模型视角、完整地台和摄影景深。
- 明度只保留 `3–4` 档硬边色块；禁止 AO、体积光、连续渐变、金属高光与接触阴影。
- 禁止逐窗、楼梯、栏杆、桁架、线缆和成组烟囱；身份必须靠外轮廓而非零件清单成立。
- 暖纸只作为版式载体；插图本身应像印在纸上的平面图形，不像摆在纸上的三维模型。
- 25% 和“脱离背景白底裁切”双测：两种情况下都应先读成一个图形梗，不先读成具体建筑模型。

## 复发判定

- 命中既有 F9“低多边形碎片化 / 照片滤镜化”和支线规范 §3.1、§3.3 已记录错误；本次新增的是**独立纸面载体放大写实度**这一检查条件，不新增美术方向。
- A2.4 降级为 `direction_retained_component_illustration_rework_required`。
- 不改黑白功能结构、地图、纸张、标签、条码、趣味证据链、Godot 或正式资产合同。

## 用户复核后的二次修订：从模型摆到 ICON（2026-07-29）

- **触发**：用户把 V6 回填 A2.4 后明确指出“又有点太极简”，要求回到原标杆寻找合适的度。
- **结论撤回**：上述双 Agent `PASS` 只证明 V6 关闭了微缩模型、AO 和零件堆积，并不证明它位于正确的标杆图像层级。V6 与回填整屏降级为 `over_minimal_icon_layer_diagnostic`。
- **失败归因**：父级把“提高抽象概括”误做成“删除环境与场所信息”，从过写实端一次跨到 `ICON DESIGN / GRAPHIC ELEMENTS` 层；同属既有“大多边形被过度压平”错误家族，不是新方向。
- **标杆重新定位**：任务配图母图应落在 `PHOTO & SNAPSHOT` 的简化端；`COVER vignette` 只提供主体与环境互切的构图参考，`ICON DESIGN / GRAPHIC ELEMENTS` 只作过极简反例。
- **目标区间**：主体 `6–9` 个结构块、环境 `2–4` 个宽大块、`4–5` 档离散明度、`3–4` 个综合色相组、`20–35%` 留白、仅 `1` 个异常关系占 `8–16%`。
- **停止与下一步**：停止继续回填整屏。下一轮先生成四联 PHOTO 母图，并同时展示真实左卡 `1×` 与整屏 `25%`；三尺度共同通过后才能重开九处同源回填。
- **当前真值板**：`image_gen/2026-07-28/region-map-map-variants-v1/41-region-illustration-granularity-truth-board.png`。

## 三尺度实测后的第三次修订：中间档不能靠全局块数压缩（2026-07-29）

- **真实生图证据**：
  - `42-region-photo-snapshot-mothers-v1.png`：现场层级成立，但碎面、前景与建筑细节过多，仍偏低多边形写实。
  - `43-region-photo-snapshot-mothers-v2-broad-planes.png`：当前最接近目标区间；综合色盘、四图同族和异常关系基本成立，但卫星 / 灯塔仍有模型底座，厂房仍可能读成弯管，天线城零件略多。
  - `46-region-photo-snapshot-mothers-v3-over-minimal-diagnostic.png` 与 `48-region-photo-snapshot-mothers-v4-targeted-subtraction-diagnostic.png`：把“环境层”机械压成少量几何背景，再次滑向 ICON。
  - `49-region-photo-snapshot-mothers-v5-over-detailed-diagnostic.png`：只引用标杆照片后又滑向大量碎面、完整景观与严肃 COVER。
  - `50-region-photo-snapshot-satellite-anchor-over-monumental-diagnostic.png`：单图放大导致主体纪念碑化，不能作为后续统一锚点。
- **三尺度证据**：
  - `44-region-photo-snapshot-v2-three-scale-qa.png` 同时展示 V2 母图、真实左卡像素与整屏 `25%`。
  - `45-region-map-a2-5-photo-snapshot-preview-v1.png` 只替换左卡与右案卷照片槽；程序仅裁切、缩放、回填，未替代美术生成。
- **双 Agent 复核**：UI Designer 与 UX 老哥均为 `ITERATE`。共同 P1 为卫星 / 灯塔底座化、厂房主体与异常关系失焦、四图场景密度仍不完全同族；天线城可作为局部修正前的相对稳定项。
- **新根因**：把主体 / 环境块数作为生图字面命令会导致模型机械删空场所信息；直接引用标杆 PHOTO 又会把照片中的景观层次与碎面完整放大。数量合同只能用于验收，不能替代“同一周刊遗失照片”的视觉判断。
- **当前结论**：V2 是最近邻诊断稿，不是生产候选，也不恢复 `PASS`。下一轮不再整套左右摆动；以 V2 为视觉邻域，只局部处理卫星基地、灯塔岩台和厂房投影误读，天线城冻结，仍须重新经过真实左卡 `1×` 与整屏 `25%`。
