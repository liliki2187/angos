# 普通骰子重投与复核点交付清单

## 决策条

- **结论**：HTML 全链原型中的普通任务“保留已计入骰子、批量重投其余骰子”已通过本轮运行验收，可以进入玩家试玩与数值调参。
- **影响**：已验证交互、状态冻结、扣点、周重置、黑骰排除和桌面布局；不能据此声称 `2 点/周` 已完成平衡，也不代表 Godot 主干与黑骰规则已经同步。
- **下一步**：先用当前 `2 点/周` 试验参数收集重投频率、剩余点数和成功率，再决定是否转正或改表。

## 详情

- **一句话结论**：本轮把 A194 从已采纳规则落成可运行的 HTML 普通任务重投闭环，并补齐动态与静态证据；下一步应试玩，不应继续扩大到 Godot 或黑骰改造。
- **我实际做了什么**：加入每次判定首次免费、后续消耗 1 个周共享复核点的批量重投；已计入骰子保留，其余可重投角色骰和临时骰按点击瞬间快照重投；重投期间冻结全部骰子与提交操作；次周恢复至 2 点；同步事件检定 GDD、A194 和归档总集。
- **现在卡在哪里**：无工程阻断；只剩数值平衡和实际玩家理解成本需要试玩验证。
- **为什么不能跳过**：`2 点/周` 是试验参数，单次功能烟测不能替代跨周频率、胜率和资源焦虑测试。
- **下一步怎么验证**：记录每周判定次数、免费重投使用率、付费重投次数、周末剩余复核点与重投前后达标率；至少覆盖低骰池和高骰池。
- **本轮不要做**：不要把试验参数写成永久定值；不要把普通任务重投扩展到黑骰、道具骰、锁定骰或 `noReroll` 任务；不要声称 Godot 已实现。
