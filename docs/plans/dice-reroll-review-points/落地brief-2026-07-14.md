# 落地 Brief：判定弹窗加入「1 次免费重投 + 周共享复核点」

> 交接用实现说明，可直接交给执行 AI。设计决策已登记：`docs/design-decisions/core-mechanics.md` A194。
> 本文分「已实测事实」（本轮已读代码核实）与「待验证假设」（执行方开工先自查）。

## 1. 目标

在 HTML 全链 demo 的角色骰判定弹窗中加入掷后重投：

- 掷出停骰后，玩家可点「重投」：**所有未计入且未锁定的骰面一起重投**，旧点数作废；已计入骰面保持不变。
- **每次任务判定默认附带 1 次免费重投**；之后每次重投消耗 1 点**周共享复核点**（每周 2 点，周一重置，本周所有派遣共用）。
- 复核点耗尽且免费次数已用 → 只能提交当前结果。

## 2. 硬约束（仓库协作规则，必须遵守）

1. 只做局部嵌入：不重排判定弹窗三栏布局，不改其他界面、阶段切页或入口。
2. 玩家决策不自动推进：重投必须由明确按钮触发，无倒计时、无自动重投。
3. **黑骰任务（`mission.isBlackDiceTask`）不启用本功能**：330 公交有专属重投/提示设计（见 `design/gdd/black-dice-330-bus.md`），本次不要实现。
4. 交付必须附 1–3 张真实浏览器截图（改动点状态），说明用简体中文。
5. 不改动 `world-mysteries-full-chain.html` 里 `<script type="text/plain" data-obsolete-inline-script="true">` 的废弃内联脚本副本（约 8473 行起），它不参与运行。

## 6. 实现步骤

### 6.1 状态与常量

```js
const REVIEW_POINTS_PER_WEEK = 2;
// state 内新增：
reviewPoints: 2,
// nextWeek() 内新增（紧邻 pushBudgetWeekly 重置）：
state.reviewPoints = REVIEW_POINTS_PER_WEEK;
```

### 6.2 新函数：重投未计入骰

放在 `rollCharacterDice` 附近：

```js
function rerollUnselectedRolls(rolls, selectedIds) {
  const selected = new Set(selectedIds || []);
  const rerolledIds = [];
  (rolls || []).forEach((r) => {
    if (selected.has(r.id)) return;          // 已计入 = 保住
    if (r.locked || r.black) return;          // 锁定面 / 道具骰 / 黑骰不动
    if (r.kind !== "staff" && r.kind !== "tempStaff") return;
    const staff = findStaff(r.staffId);
    if (!staff) return;
    const faces = diceFacesForStaff(staff);
    const idx = Math.floor(Math.random() * Math.max(1, faces.length));
    r.faceIndex = idx;
    r.face = faces[idx] || blankFace();
    r.locked = !!(r.face && r.face.noReroll);
    rerolledIds.push(r.id);
  });
  return rerolledIds;
}
```

### 6.3 `renderCharacterRollsHtml` 扩展

新增 `options.rollingIds`（数组或 Set）：命中的骰按转动态渲染——

- `isRolling` 判定改为：`stage === "rolling" ? idx >= revealCount 原逻辑 : rollingIdSet.has(r.id)`；
- 转动骰 `data-dice-model-rolling="1"`、按钮 `disabled`、状态文案「重投中」。

### 6.4 `showDiceSelectionPopup` 内部

闭包新增：`let freeRerollUsed = false; let rerolling = false; let rerollingIds = [];`

**重投栏**（仅 `stage === "select"` 且 `!mission.isBlackDiceTask` 时渲染，插在「本轮骰面」section 内、骰格下方）：

```html
<div class="dice-reroll-bar">
  <button type="button" id="diceRerollBtn" ...>重投未计入骰面</button>
  <span class="dice-reroll-hint">…</span>
</div>
```

按钮三态（每次 `render()` 重算）：

| 条件 | 按钮文案 | hint 文案 | 可用 |
|------|---------|----------|------|
| `!freeRerollUsed` | `重投未计入骰面（本次免费）` | `已计入的骰面不受影响；重投后旧点数作废` | 是 |
| `freeRerollUsed && state.reviewPoints > 0` | `重投未计入骰面（消耗 1 复核点 · 余 ${state.reviewPoints}）` | `复核点每周重置，本周所有派遣共用` | 是 |
| `freeRerollUsed && state.reviewPoints <= 0` | `重投未计入骰面` | `复核点已用完 · 下周重置` | 否 |
| 无可重投骰（全部已计入 / 锁定 / 道具 / 黑骰） | 同上 | `没有可重投的骰面` | 否 |
| `rerolling === true` | `重投中…` | — | 否 |

**点击流程**（async）：

1. 计算 eligible（同 6.2 过滤条件）；空则 return。
2. `rerolling = true; rerollingIds = eligible; render();`（骰子进入转动态；同时禁用 `ok` / `cancel`）。
3. `await sleep(720);`
4. `rerollUnselectedRolls(rolls, selectedIds)`；若 `freeRerollUsed` 则 `state.reviewPoints -= 1`，否则 `freeRerollUsed = true`。
5. `rerolling = false; rerollingIds = []; render();`
6. `log(\`重投：${n} 颗骰面重新掷出（${免费 ? "本次免费" : \`消耗 1 复核点，余 ${state.reviewPoints}\`}）\`);`

**其他**：

- 重投后 `selectedIds` 保持不变，不自动重选推荐。
- `rerolling` 期间 `ok.disabled = true; cancel.disabled = true;`，结束后恢复。
- 摘要卡（`diceSelectSummaryHtml` 区域）旁不必改；复核点余量在重投栏 hint 已可见即可。低优先可选项：`tickHeader()` 的 `#dayLabel` 追加 `· 复核点 ${state.reviewPoints}/2`。

## 8. 验收清单

流程：浏览器打开 `world-mysteries-full-chain.html` → 进入本周 → 选区域 → 选任务 → 派人 → 推进天数至判定弹窗。

1. 停骰后出现重投栏；第一次重投免费，未计入骰变化、已计入骰不变。
2. 第二次重投扣 1 复核点，按钮文案余量正确；同日另一个任务的判定仍有自己的免费 1 次。
3. 复核点 0 且免费已用 → 按钮禁用，文案「复核点已用完 · 下周重置」。
4. 道具骰、`noReroll` 锁定面、黑骰不被重投；黑骰任务弹窗不显示重投栏。
5. 重投动画期间确认/推荐按钮禁用，无法双击连投。
6. `nextWeek()` 后复核点回到 2。
7. 结算页展示的骰面与弹窗最终状态一致（rolls 原地更新自然传导）。
8. 截图 1–3 张（免费态 / 耗点态 / 耗尽禁用态），中文说明交付。
