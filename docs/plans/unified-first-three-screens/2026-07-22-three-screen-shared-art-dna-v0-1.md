# 世界地图 / 区域地图 / 报刊填入共同美术 DNA v0.1

> 状态：`draft_pending_user_confirmation`  
> 日期：2026-07-22  
> 本轮范围：只提炼两张标杆的共同视觉语言，不生图、不修改功能稿、不进入资产化。  
> 真源：两张 `clean low-poly weekly` 标杆、三张黑白功能稿、支线风格规范与纸张材质合同。

## 1. 一句话内核

> **这是一个真实可代入的现代怪新闻编辑部：玩家在深海军蓝编辑台上翻地图、抽任务、移动稿件、拼报纸和签送印；所有物件用干净暖纸、活跃哑光色块与粗颗粒平面低多边形塑造，并由一套时髦的 WMW 品牌符号持续注入冷面黑色幽默。**

风格第一主语是“现代图形周刊”，不是低多边形游戏场景，也不是写实档案室。低多边形是删减现实信息并重建图形秩序的方法；纸张、文件夹、地图和照片只是承载这种方法的载体。

### 1.1 必须同时成立的两条体验轴

#### A. 代入感与氛围感：拟物的是编辑部工作现场

- 玩家第一眼应觉得自己坐在一个正在运转的编辑部工作台前，而不是打开一套抽象 UI 面板。
- 拟物感来自**物件身份、物理叠层和操作隐喻**：地图纸、地区文件夹、候选稿件、夹子、胶带、便签、校样、版位、印章、截止票、送印签批都有明确来源和用途。
- 氛围来自“工作正在发生”：纸件有前后遮挡、抽取 / 归位关系，选中项像被拿起或推到前面，待办、到期、空位与退稿在工作台上留下可见状态。
- 可以有轻微使用痕迹、错位、批注和印刷套色，但保持现代、干净、可工作；不能依赖污渍、泛黄、磨损或厚重写实材质制造真实感。
- **拟物的是语义和触感，不是摄影渲染。**仍然禁止写实光照、三维建模、AO、材质反射、景深和照片级细节。

#### B. 黑色幽默点缀：形成时髦、可复用的 WMW 品牌系统

- 黑色幽默不只藏在文案中，还要进入可跨三屏复用的图形品牌：WMW globe、眼形章、问号警示、异常分类徽记、不可能路线、荒诞审批章、编辑部禁令与带态度的贴纸。
- 幽默的机制是“严肃制度认真处理荒谬事件”，不是让异常主体做鬼脸。比如飞碟收到禁停罚单、无限折返路线被记为普通延误、明天的潮汐被盖上“已核实”章。
- “时髦”来自定制轮廓、粗细有变化的图形、轻微套印错位、非对称裁切、短促大标题和稳定色彩身份；不是通用软件 icon，也不是复古徽章大全。
- 当前共同风格板的工作密度建议为：每屏至少有 `1` 个清楚的品牌主锚点和 `2–4` 个第二阅读层的趣味符号。这个数量用于防止幽默再次被删空，最终以共同风格板观感为准。

## 2. 四个不能再混淆的边界

| 正确内核 | 容易误读成 | 一票否决表现 |
| --- | --- | --- |
| 现代编辑周刊拼贴 | 旧档案 / 侦探证据板 | 泛黄、脏边、厚卷宗、红线、黑色电影光照 |
| 平面裁纸式低多边形 | 写实模型加 low-poly 滤镜 | 均匀微三角、AO、写实体积光、材质反射、航拍 / GIS 质感 |
| 活跃且有面积主次的哑光色块 | 暗底加少量彩色按钮 | 橄榄黑或灰米吞掉全屏，颜色只存在于小状态点 |
| 成人编辑插画式荒诞 | 萌系怪谈贴纸或严肃军情软件 | 大量表情怪物、儿童绘本；或纯监控台、军事地图、SaaS 后台 |

## 3. 共同视觉 DNA

| 维度 | 共同规则 | 失败边界 |
| --- | --- | --- |
| 构图 | 正交功能骨架上叠加大小错落的出版物色块、局部裁切、窄边和硬边错位影；留白与彩色物件共同形成节奏 | 三栏全部由同形深色卡片填满；或把功能面做成倾斜桌面透视 |
| 色彩 | 深海军蓝只做负空间；暖纸、橄榄、钴蓝、青绿承担大面积中间调；芥末或锈红只选一组作小面积强调 | 全屏灰蓝 / 灰绿 / 米纸；多个强调色等权铺开；全局冷暗洗色 |
| 明度 | `3–5` 档离散平面明度：深底、暗彩、中彩、暖纸、窄高光 | 连续渐变、空气透视、柔和写实阴影、黑位压死 |
| 低多边形 | 先读完整剪影，再用 `3–8` 个结构体块组织对象；体块内只保留少量大小不均的邻色 / 明度大面 | Delaunay / Voronoi 式均匀网格、几十个小三角、碎玻璃纹理 |
| 图像 | 地图和报道图都像编辑部重新绘制的平面海报，不像照片、游戏截图或三维场景 | 城市逐窗、精确街网、建筑模型、电影构图、照片滤镜 |
| 材质 / 拟物 | 暖灰米纸、冷象牙窄边、轻微 print tooth、单层硬边错位影；通过纸件叠放、夹持、抽取、翻页、盖章和版位占用形成真实编辑部触感 | 厚纸板、卷边、折痕、污渍、泛黄、重颗粒、厚投影；或退化成没有物件身份的纯矩形面板 |
| 符号 / 品牌 | 正式文书使用 WMW 机构图形；贴纸使用一个有态度的主剪影加极少内部记号；globe / eye / question / abnormal seal 在三屏中形成可识别品牌家族 | 全部变成同线宽软件 icon、儿童贴纸或复古徽章大全；符号只出现一次、无法建立跨屏记忆 |
| 字体气质 | 大标题、明确字重差、短标签、出版编号和稳定基线；中文正文保持干净正交 | 满屏微小数据字、终端等宽字、复古打字机字、文字漂浮在图像上 |
| 情绪 | “混乱世界里的专业秩序”：成熟、神秘、清醒，偶尔出现一个安静的不可能点 | 惊悚、血腥、军情、政治监控、过度肃杀；或热闹卖萌、表情包化 |
| 细节密度 | 第一眼读大形和颜色，第二眼读任务关系，第三眼才看到编号、贴纸和印刷细节 | 第一眼先读小建筑、三角网、器材、噪点和装饰线 |

## 4. 共同颜色面积合同 v0.1

以下是下一张共同风格证明板的**工作目标**，不是从标杆逐像素反推的永久阈值：

- 深海军蓝负空间：约 `28–34%`。它负责安静和对比，不能吞掉整个界面。
- 暖纸 / 冷象牙中性面：约 `18–24%`。负责文字与出版物身份，不得全部变成灰米表单。
- 橄榄主色家族：约 `15–20%`。使用 `2–3` 档清洁相邻色，不做泥绿。
- 钴蓝 / 蓝灰主色家族：约 `12–18%`。承担另一组大面积色彩运动，不只用于 CTA。
- 青绿辅助家族：约 `8–14%`。连接地图、水域、照片和光源，但不能全屏青黑化。
- 芥末或锈红强调：合计约 `4–8%`。同一屏只允许一组明显强调色占上风；另一组退为极小状态提示。

硬规则：

1. 每个主区域至少有一块可在 25% 缩略图中看见的彩色中间调。
2. 颜色丰富来自大面积色块与同色系内部变化，不来自增加许多小彩点。
3. 三屏使用同一套颜色职责；可以因内容轻微改变局部分布，但不能一屏橄榄黑、一屏灰米、一屏蓝黑。
4. 深夜题材只允许作为少数异常重点图；其余报道图必须轮换橄榄、钴蓝、青绿、暖纸 / 芥末昼景。

## 5. 低多边形颗粒度合同

### 主体对象

- 先归并为 `3–8` 个结构体块，再在其中加入少量不等尺寸的大色面。
- 最大色面必须明显承担主体结构，不能所有切面尺寸相近。
- 多边形边界必须解释形体转折、地貌、光照或异常影响，不能只作为纹理。
- 缩到 25% 后，小色面若融成噪点，说明颗粒过细，应删除或并回大面。

### 场景与地图

- 世界地图先读大洲剪影、区域色带和少量路线；不读海岸微折线与三角网。
- 区域地图先读陆水关系、`4–6` 个次级地区、`2–3` 条主交通骨架与异常节点；不读逐栋建筑和街道网。
- 报道插图先读一个强主体、前中后关系与一个异常点；不读设备零件、逐窗建筑和真实材质。

### 统一禁项

`dense uniform triangulation / micro facets / photorealistic low-poly render / cinematic volumetric light / ambient occlusion / depth of field / detailed GIS / aerial city model`

## 6. 三屏“同族但不换皮”分工

| 界面 | 必须共享的画法 | 允许保留的页面个性 | 禁止滑向 |
| --- | --- | --- | --- |
| 世界地图 | 同一深底、纸材、色块尺度、插图画法、贴纸 / 图章与选中语法 | 全球尺度的大洲剪影、跨区路线、地区照片卡；构图最开阔 | 全球监控台、军事地图、卫星图、橄榄黑 GIS |
| 区域地图 | 同一颜色面积层级、平面剪影、纸边、pin、事件卡和图像扁平化方式 | 近尺度陆水关系、地区邻接、主路 / 河流、任务节点；空间关系最强 | 俯视三维岛城、城市模型、专业地图册、写实航拍 |
| 报刊填入 | 同一暖纸、色块、报道插图、标签 / 图章、硬边影与字体层级 | 双版阅读顺序、主副头版、栏网、候选报道与送印状态；出版感最强 | 暗色 SaaS 编辑器、图片画册、电影截图墙、旧报纸复古化 |

三屏统一性的判断不看“有没有同样的边框”，而看一张区域任务插图放进报刊版位、一张报刊报道图放进世界地图快照时，是否仍像同一位美术、同一本周刊、同一批印刷物。若互换后明显违和，说明图像引擎还没有统一。

## 7. 共同组件语法

- **背景**：同一深海军蓝哑光底，只有非常轻的网格 / 印刷压层，不做科技发光。
- **纸面**：同一暖灰米主纸与冷象牙窄边；可写面平静，边与影负责叠层。
- **选中态**：橄榄或钴蓝大色块底 + 清楚硬边轮廓 + 一枚状态记号；不用发光、霓虹描边或 3D bevel。
- **警告态**：低饱和锈红或芥末，只占小面积；不能让整屏变成红黑警报界面。
- **地图节点 / 图章**：一个粗剪影、少量内部记号、轻微手工偏心；不做完美同线宽 icon set。
- **报道图**：统一采用编辑部重绘的平面低多边形海报语法；不直接嵌入摄影或三维渲染。
- **硬边阴影**：每个物件只保留一层短距离错位影，方向统一；不用柔影堆叠模拟厚度。

## 8. 题材与气氛

共同叙事语气是：

> **工作人员在一个真实、正在运转的编辑部里，用严肃、专业、略显疲惫的出版流程处理荒诞异常；荒谬来自事件与制度的碰撞，并通过时髦的 WMW 品牌符号持续留下第二阅读层。**

- 卡通化体现在简化比例、强剪影和离散色面，不体现在萌化五官。
- 每个主要场景只保留一个核心冷面笑点，但界面层还应持续出现 `2–4` 个低强度品牌符号作为点缀；不能因为避免萌化而把幽默和品牌全部删空。
- 新怪谈只保留一个安静的不可能点，例如影子方向错误、路线折返到自身、远处物体轻微悬浮。
- 主体造型约八成可信、两成异常；不能把整屏变成怪物秀，也不能因“可信”恢复摄影写实。

## 9. 下一张共同风格证明板的内容

用户确认本文后，下一步仍不是三张完整界面，而是一张同画布共同验证板，至少包含：

1. 世界地图代表模块：大洲 / 路线 / 地区卡 / 快照。
2. 区域地图代表模块：陆水关系 / 次级地区 / 主路 / pin / 事件卡。
3. 报刊代表模块：主头版 / 普通报道 / 标签 / 空位警告。
4. 三屏共用的纸张、选中态、警告态、贴纸 / 图章和报道图处理样本。
5. 同一组颜色面积示意与 25% 缩略图。
6. 一条真实编辑部拟物链：地区文件夹被抽出 → 事件稿件被选中 → 稿件进入版位 → 空位阻断送印。
7. 一套跨三屏品牌符号小系统：至少包含 WMW 主标、globe / eye / question / abnormal seal 及两种冷面幽默应用。

只有以下条件全部通过，才进入三张 1920×1080 完整稿：

- 三组代表模块第一眼像同一套周刊资产。
- 三组都先读彩色大形与剪影，不先读三角网或写实场景。
- 三组颜色面积关系接近，不靠同一深色壳层假装统一。
- 三组纸张、影子、图章、图像和选中语法可以交叉复用。
- 用户明确确认共同风格证明板。

## 10. 最短执行口令

> **先做现代图形周刊，再做地图 / 报刊题材；先删写实信息，再用大块相邻色面重建；先用一张共同证明板锁定三屏画法，再分别套入各自黑白功能稿。**
