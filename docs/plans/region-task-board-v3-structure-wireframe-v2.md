# 地区任务台 v3.2 结构验证稿

日期：2026-06-18

本稿用于替换上一版结构验证稿中“孤立红块”和“底部长条过重”的问题。它仍然不是正式美术稿，而是给后续资产编辑、美术生成和 Godot 落地使用的结构真值。

## 本版修正

- 删除右侧详情和底部的孤立红色方块。红色只允许服务三类语义：主 CTA、截稿/危险、按钮状态。
- 底部长条从大面积模块压缩为 64-76px 的“本周行动回执 + 独立日程推进”。
- 左侧探索链任务必须有反馈：链轨、`续 1/4` 阶段章、选中高亮至少出现两项。
- 增加执行中队列承载位：只显示数量、到期提醒和可展开入口，不展示员工/骰池详情。
- 右侧详情增加“深度调查槽”和“阻断原因槽”，阻断原因贴近主 CTA。
- 中央地图继续保留原底图，只叠加 pin、selected、下一环 `?` 和短签。

## 功能分区

| 区域 | 职责 | 必须显示 | 不应显示 |
| --- | --- | --- | --- |
| 左侧任务索引 | 候选任务、选中态、探索链当前环、执行中摘要 | 任务名、耗时、需求、状态、`selected / chain-current / queued` | 完整任务叙事、员工、骰池 |
| 中央地图 | 空间锚点和链路位置 | pin、selected 圈、下一环 `?`、短签 | 常驻长任务名、完整规则 |
| 右侧任务详情 | 当前任务签批前复核 | 标题、摘要、需求、耗时、深度调查/截稿/危险、阻断原因、主 CTA | 候选列表、已派遣列表、长日志 |
| 底部回执 | 低权重周状态 | 剩余天数、当前地区、已选任务、签批后天数变化、执行中/到期计数 | 第二主 CTA、完整详情、行动日志 |
| 日程推进 | 独立系统动作 | `推进一天 / 结束探索周 / 结算中` | 与任务签批按钮混槽 |

## 探索链反馈契约

探索链任务的状态必须同步到四处：

- 左卡：`深度调查 · 当前环 1/4`、`续 1/4`、选中金框。
- 地图：当前环 pin 高亮，下一环只显示 `?`，不提前展示完整任务。
- 右详情：说明当前环目标、成功后揭示下一环、失败后保留/回退规则。
- CTA 附近：提示“签批不扣天数；派遣后预计占用 2 天”或阻断原因。

状态机：

`未显现 -> 当前环可执行 -> 当前环选中 -> 进入签批 -> 执行中 -> 结算 -> 旧环归档 -> 下一环显现 / 终局完结`

## 底部空间原则

底部默认只保留一条压缩回执：

`探索周 余 4天 · 北美禁区 · 已选 M330`

`签批后余 2天 · 本页不消耗天数`

若需要显示执行中状态，只显示：

`执行中 2 / 到期 1`

完整执行中队列、撤回、查看详情应放在可展开抽屉或进入对应已派遣任务，不常驻占用主舞台。
