# 任务派遣 / 签批外勤界面：V8.2 苏丹式部署结构稿

状态：`structure_wireframe`，不是高保真真实内容风格稿，也不是可拆资产母版。

定位：V8.2 用来修正 V8.1 的“中央骰池预备纸”问题。用户指出骰面 / 覆盖信息可以集成在角色卡牌里看，因此中央不再常驻展开骰池表、覆盖表或来源明细。本版学习《苏丹的游戏》的部署关系：`候选手牌池 -> 当前事件 / 任务承载 -> 投入卡牌 -> 右侧说明 / 最终确认`，但视觉包装仍是 Angus 的现代午夜编辑部外勤签批台，不学习宫廷皮肤或旧羊皮纸质感。

## 本版结构

1. **左侧任务卷宗**：只回答为什么派人，保留任务身份、简报和外勤目的，不承担签批复核。
2. **中央任务承载台**：把 `M330 末班车空白段` 作为当前事件 / 任务承载物。已选员工证卡和可选增援席直接压在任务纸上，形成“卡已投入任务”的读法。
3. **已选员工证卡**：卡内集成本次贡献章和小型骰面 chips，避免再在中央摊一张骰池 / 覆盖表。
4. **随队器材卡**：作为本次队伍的一部分写回中央任务台，显示辅助骰位、器材名和小型骰面 chips，不占人员槽，不另起大行。
5. **底部候选手牌抽屉**：默认一行，已选员工从候选池移出；器材手牌与候选员工同属供应层，悬停阶段再扩展更多候选。
6. **右侧签批票据**：唯一完整复核位，承载 `可签批 / 洞察 / 人脉 / 有效点 / 缺口 / 风险 / 耗时 / 本周 / 队伍 / 盖章派遣 · 2天`。

## 删除 / 降级

- 删除 V8 的高权重路线纸，不暗示游戏内存在路线规划、站点选择或路径分配。
- 删除 V8.1 的中央骰池预备纸，不把真实机制拆成中央常驻表。
- 删除中央伪状态块，例如 `需求已满足`、`待盖章`、`压力 +2`、`可签` 等与右侧票据同义的信息。
- 保留的空白纸层只做拟物桌面层次和 no-text 装饰，不承载动态字段。

## 交付前自检

1. 遮住右侧，只看中央：能读到谁被投入任务、是否还有可选增援、带了什么器材、卡片为什么大致可派。
2. 遮住中央，只看右侧：只剩最终签批复核和盖章 CTA，不再承担完整玩法解释。
3. 中央非角色 / 非器材 / 非候选 / 非任务短条块全部降级为背景纸层或装饰，不提供新功能。
4. 候选抽屉和器材手牌没有越出底部容器，避免重现“道具领用盘底线不一致”的问题。
