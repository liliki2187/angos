# 任务派遣 / 签批外勤界面：V10 编辑桌俯视牌桌结构稿

状态：`overreach_exploration / not-current-baseline`。这是为回应 V9 “旧骨架换皮”问题而出的整屏重构探索，但 2026-06-23 用户进一步纠正：左右两边栏目本身没问题，当前问题是中间部分空白不知道怎么填补。因此本稿不再作为当前推荐基准；后续应回到保留左右栏、只重构中间主舞台的方案。

> 修订：V10 的问题是把“中间主舞台空白”误扩大成“整屏骨架推翻”。可参考的只有“让当前队伍成为桌面主语”的意图，不继承顶部候选手牌、右下票据等整屏重排。

## 核心目标

V10 不继续沿用 `左任务 + 中央卡 + 右票据 + 底候选` 的四栏配置器。新的玩家动作流是：

> 从顶部候选手牌里抽人 -> 把当前任务案卷放在桌面中央 -> 把本次队伍和随队器材压到案卷桌面 -> 右下角盖章派遣。

这版优先解决“页面到底是什么”而不是解决美术完成度。第一眼应读作“主编的外勤签批桌”，不是后台审批表，也不是底部库存条驱动的配置页。

## 相对 V8.2 / V9 的结构变化

1. **取消左侧任务列**：任务信息不再占左栏，而是成为桌面中央的当前案卷。
2. **取消右侧整高签批票据**：复核与 CTA 压到右下角回执，不再整屏抢主语。
3. **取消底部候选库存条**：候选员工移到顶部证件夹 / 手牌层，符合“从手牌抽人投到任务”的部署语法。
4. **中央成为本次队伍桌面**：已选员工卡、空槽、随队器材和任务案卷共同组成当前派遣主体。
5. **保留拟物负空间**：中央留白用于桌面、纸层、路线暗线和卡片摆放关系，不再用复核表、状态块或新功能填满。

## Gate

- 遮住文案和材质后，整屏剪影必须明显不同于 V8.2 / V9。
- 候选层必须被读成“手牌 / 证件夹”，不是底部库存。
- 右下签批回执只做最终复核与盖章，不承接完整玩法解释。
- 中央所有高权重物件必须对应真实机制：任务案卷、已选角色、空槽、随队器材、候选手牌、签批动作。
- 若下一轮进入真实内容风格稿，应先让 UX 老哥、UI Designer、SIA 和像素艺术复审 V10 的结构，而不是直接用 V9 生图。

## 当前不足

- 这版仍是结构稿，卡片头像、纸张纹理、半调 / 套印、像素颗粒和字体融合都只是低保真占位。
- 顶部候选手牌容量、hover 展开方式和右下票据尺寸还需要下一轮细化。
- 中央桌面还需要美术指导把关，避免滑回普通办公桌或旧档案感。
