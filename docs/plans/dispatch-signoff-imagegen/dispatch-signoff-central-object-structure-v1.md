## 四区职责

1. 左侧任务卷宗栈：只回答「为什么要派」和「任务要什么」，包含任务身份、需求、风险、任务简报、本周状态。
2. 中央外勤地图签批板：作为主物件，承载当前队伍槽、随队器材，以及低权重校验章。
3. 右侧签批票据：唯一正式复核区，承载可签批结论、消耗、本周变化、队伍摘要和盖章派遣按钮。
4. 底部可选资源抽屉：只负责候选员工 / 器材检索与替换，默认一层可见，悬停再展开，不承担结果判断。

## 本轮结构决策

- 原「达标率 / 有效点 / 缺口」三个底部结果块不再作为独立功能区，合并为中央主板下沿的三个校验章。
- 右侧签批票据保留正式结果和行动，因此不会与中央校验章重复。
- 器材领用盘并入底部资源抽屉右侧小架，只显示默认短列表，不再形成额外底栏。
- 左侧本周状态与底部资源抽屉使用同一视觉底线，避免界面下边缘不一致。
- 所有功能框体保持正交矩形，后续可以按矩形安全区切图。

## 下一步

若这版结构成立，再把它推进到风格稿：在不改变四区职责和矩形边界的前提下，把中央主物件做成接近参考图的低多边形地图签批板，并把纸张、图钉、半调、套印作为结构语言，而不是额外装饰。
