## Agent 合并结论

- UX 老哥：核心主语应是“编辑部外勤桌面上的本次派遣案卷”。中央只承载 `人员席位 / 可选增援席 / 随队器材 / 路线底纸 / 局部贡献证据`；完整复核归右侧票据。
- UI Designer：16:9 结构改为左任务卷宗、中央外勤签派桌面、右签批票据、底部中央候选抽屉。底部抽屉不再跨入右侧票据。
- 像素艺术 / 美术指导：中央应是深蓝派遣桌垫 + 干净象牙纸 + 外勤证件卡 + 器材托盘 + 少量红青路线标注。不要旧档案泛黄、侦探证据墙、赛博面板或状态贴纸。
- SIA：Steam 第一眼必须从“条件达标审批 UI”转为“派遣编辑部外勤队”。人员卡和任务地图应成为最有吸引力的主画面，票据只是最终承诺。

## V8 结构

1. **左侧任务卷宗**：只回答为什么派人。保留任务名、地区、任务简报、外勤目的和风险钩子；不承载完整复核。
2. **中央外勤案卷桌面**：主舞台。上方任务短条，中央最大化 4 张已选外勤证 + 1 个低权重可选增援席，下方放随队器材托盘和路线纸。
3. **底部候选抽屉**：只服务中央组队。默认一行候选卡，已选角色从候选池移出；器材候选收在同一区域右侧小托盘，不跨进右侧票据。
4. **右侧签批回执**：唯一完整复核位。承载可签批状态、洞察 / 人脉 / 有效点 / 缺口 / 风险 / 耗时 / 本周 / 队伍和 `盖章派遣 · 2天` CTA。

## 必须保留

- 任务人员空槽：保留为 `可选增援席`，低权重纸质占位，不表现为必填阻断。
- 当前角色列表：中央第一视觉，卡片像外勤证 / 派遣卡。
- 随队器材：作为队伍附件托盘，写明 `1/1` 与补缺作用。
- 需求覆盖信息：只以角色卡贡献章、器材补缺标签、任务短条需求摘要表达，不独立成新系统。

## 必须删除 / 避免

- 中央完整复核表。
- 中央 `可签批 / 复核通过 / 压力 +2 / 缺口无 / 待盖章` 状态块。
- 覆盖矩阵、协同网络、队伍关系等第五功能区。
- 只为填空存在的便签、戳印、解释块。
- 底部候选栏跨入右侧票据区域。
- 倾斜动态文字面、泛黄旧档案、侦探红线墙、后台表格感。

## 进入真实内容风格稿前 Gate

1. 遮住右侧票据，只看中央 5 秒，必须能回答：谁去、带什么、去哪、为什么大致可派。
2. 遮住中央，只看右侧，必须只剩最终复核和盖章 CTA，而不是完整玩法解释。
3. 空槽必须读作可选增援，而不是缺人阻断。
4. 候选抽屉必须是供应层，不能和已选外勤队伍抢主语。
5. 所有承载动态文字 / 数字 / 头像 / 按钮的区域必须为正交矩形，并保留安全边距。
