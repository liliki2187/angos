# 任务派遣 / 签批外勤界面：外勤签派现场结构稿 V6

日期：2026-06-23

定位：V6 是对 V5 “中央需求核对面板过重”的回正稿。它把完整复核摘要合并进右侧签批票据，中央空间还给任务派遣、已选人员席位、候选人员抽屉、随队器材托盘和带任务痕迹的拟物桌面。

2026-06-23 追加修订：V6 只保留“完整复核摘要归右侧”的正确方向；其中中央下方 `需求已满足`、`压力 +2`、`待盖章`、路线说明等伪状态块仍与右侧复核票据重复，已被用户指出为无意义功能残留。后续 V7 不应继续保留这些缩小版复核块，应直接删除，把空间真正还给派遣人员、候选列表和拟物负空间。

## 用户反馈

用户指出 V5 中央底部“需求核对”功能仍可和右侧结合，中央不必为了填满而继续放复核面板，应把空间给任务派遣和人员列表，也允许画面中间更空、更拟物。

UX 老哥与 SIA 复审结论一致：V5 的需求核对内容正确，但横向大面板会把画面读成后台表格 / 系统配置页，削弱“玩家正在给队伍派外勤”的第一眼。V6 应减少一个系统面板，增加一个外勤签派现场。

## V6 修正

- 删除中央整块横向“需求核对”面板。
- 右侧票据新增完整复核清单：
  - 洞察 2/2
  - 人脉 2/2
  - 有效点 13/8
  - 缺口 无
  - 风险 压力 +2
  - 耗时 2 天
  - 本周 7 → 5
  - 队伍 4/5 + 器材 1
- 中央放大已选人员席位，角色卡内保留贡献章。
- 随队器材改成队伍下方器材托盘，只说明本次携带与补缺。
- 中央下半区保留拟物桌面 / 地图 / 路线 / 档案 / 便签 / 状态戳，作为任务派遣现场，不再作为表格复核区。
- 底部候选抽屉给更多人员卡面积，器材压缩为右侧小托盘。

## 自检 Gate

1. **A102 复核归位**：完整复核摘要必须在右侧票据，不得在中央形成第二张表。
2. **中央主语**：第一眼应读作“组队派外勤”，不是“看校验表”。
3. **局部证据**：中央仍需通过角色贡献章、器材补缺、任务短条和状态戳回答“为什么大致可签”。
4. **拟物留白**：中央允许留白，但必须绑定路线、档案、人员卡、器材托盘和盖章动线。
5. **候选优先**：释放出的高度优先给已选人员和候选人员，不要再用新面板填满。

## 后续基准

派遣签批台下一轮真实内容风格稿和资产化 UI 链路不再以 V6 的中央伪状态块为结构基准。V6 仅作为“复核摘要已右移，但中央仍残留重复复核标签”的过渡稿；V7 应删除中央 `需求已满足 / 压力 +2 / 待盖章` 等状态块，保留人员席位、空槽、器材托盘、候选抽屉和非功能性的拟物桌面 / 地图 / 档案负空间。
