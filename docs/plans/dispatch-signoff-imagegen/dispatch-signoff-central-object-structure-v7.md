# 任务派遣 / 签批外勤界面：删除伪状态块结构稿 V7

日期：2026-06-23

定位：V7 是对 V6 “中央仍残留伪状态块”的回正稿。它执行 A103：删除优先于换皮。中央不再用 `需求已满足`、`压力 +2`、`待盖章` 等同义状态块填补拟物空间，而是把完整复核只留在右侧票据。

## 用户反馈

用户指出 V6 中央下方的 `需求已满足`、`压力 +2`、`待盖章` 和路线说明等块与右侧复核票据仍然重合，没有足够功能意义。问题不是这些块的样式，而是它们本身不应该存在。

## V7 修正

- 删除中央所有与右侧复核票据同义的状态块。
- 中央只保留可操作或贴近操作对象的内容：
  - 任务短条
  - 已选人员席位
  - 空槽
  - 角色卡内贡献章
  - 随队器材托盘
  - 候选人员抽屉
- 中央下半区只作为拟物桌面 / 地图 / 档案 / 路线空间，不再承载复核结论。
- 右侧票据保留唯一完整复核清单和盖章 CTA。

## 自检 Gate

1. **删除测试**：中央任意状态块删掉后，如果派遣操作链不断裂，就不应保留。
2. **同义检查**：右侧已经表达的 `需求 / 有效点 / 缺口 / 风险 / 耗时 / 是否可签`，中央不得再用便签、戳印、短条复述。
3. **中央对象检查**：中央只给人员、空槽、器材、候选、任务短条和非功能拟物空间。
4. **负空间检查**：地图、纸片、路线可留空；不要用状态标签填满。
5. **父级整合检查**：agent 或规则要求“删除重复”时，不得折中成“缩小重复”。

## 当前基准

派遣签批台下一轮真实内容风格稿和资产化 UI 链路以 V7 为当前结构基准：中央是外勤签派现场与拟物桌面，右侧是唯一复核票据，底部是候选人员抽屉，左侧是任务卷宗。
