# 地区任务台 v3.4 真实内容填充稿

日期：2026-06-18

本稿承接 v3.2 / v3.3 结构验证稿，按用户反馈进一步调整：

- 底部中段不再显示重复的“签批后余 2 天 / 本页不消耗天数”。
- 该槽位改为“地区特殊事件 / 全局 buff-debuff”显示。
- 深度链下的具体任务点选入口放回地图上，接近网页版深链展开语法。
- 左侧任务卡只承担索引、选中反馈、链状态同步，不作为深链具体环节的主点选入口。
- 右侧主文本框扩大，承载摘要、目标、需求和耗时。
- 深度链身份槽从大框压缩为短状态槽，只显示当前环和下一步。
- 底部“推进一天”从普通小按钮升级为独立全局日程按钮，不复用任务 CTA 语法。

## 底部中段职责

底部中段改为地区特殊事件，例如：

`地区事件：军方封锁 · 本区对手骰+1`

它用于显示本区或全局当前正在影响探索选择的 buff/debuff，可替换为：

- `地区事件：军方封锁 · 本区对手骰+1`
- `全局debuff：热线被监听 · 洞察检定-1`
- `全局buff：匿名爆料潮 · 线索调查+1`
- `地区事件：目击者噤声 · 红色截稿倒计时-1`

该槽位只显示一条当前最重要事件，不展开解释。完整解释应在右侧详情、hover 或事件日志中查看。

## 深度链点选职责

深度链具体环节必须在地图上点选：

- 地图当前环卡：可点击，例如 `1/4 M330 空白段`。
- 地图下一环卡：不可点击，只显示 `2/4 下一环 ? / 未揭示`。
- 地图链线：连接当前环和下一环，表达连续调查关系。
- 左卡：只显示 `深度调查链 · 地图点选当前环 1/4`，同步 selected / queued / chain 状态。

这样可以保留网页版已有习惯：深链是地图上的连续节点，不是左侧列表里的普通任务按钮。

## 右侧详情 v3.4 职责

- 标题槽：只显示当前选中对象标题。
- 主文本槽：作为右栏主体阅读区，承载摘要、目标、需求、耗时。
- 深度链短槽：仅在深链任务出现，用紫色短票据显示 `深度调查 · 当前环 1/4` 和一句结果提示。
- 可带回 / 风险：保持紧凑，贴近签批前判断。
- 阻断 / 签批提示：贴近 `进入派遣签批`，只说明当前任务能否进入签批。
- `推进一天` 不属于右侧任务详情，属于底部日程条。

## v3.6 动作分离修订

用户确认的最新方向是：任务级签批动作与全局日程推进必须在空间、材质和交互状态上分离，避免玩家本来只想进入派遣签批，却误点成推进一天。

- `进入派遣签批` 是当前选中任务的主 CTA，只能出现在右侧任务详情纸面的签批区内。
- `推进一天` 是全局日程动作，只能出现在底部全局日程条内，不得放在右侧任务 CTA 的正下方、同一视觉延长线上或相邻热区内。
- 两个动作不得复用同一红色签批按钮语法；`推进一天` 使用深青黑 / 金色日程按钮、日历或翻页图标，读作全局时间推进。
- `推进一天` 点击后优先进入确认态，例如 `确认推进？ / 再次点击执行`；在有可派遣任务、临近截稿或执行中任务时，不允许单击立即推进。
- 资产合同中应拆出 `task_dispatch_cta` 与 `advance_day_button` 两套独立 atlas / hit rect / state matrix，不允许共用底图或共享点击区域。

## 后续落地注意

- 地图深链卡必须是独立可交互组件或状态层，不能烘焙在地图底图里。
- 左卡选中深链时，应只把地图对应链卡高亮，不直接进入派遣。
- 点击地图当前环卡后，右侧详情切换到该环任务，再由右侧主 CTA 进入派遣签批。
- 下一环 `?` 点击时只提示“完成当前环后揭示”，不能进入派遣。
- 地区事件槽如果可 hover，应显示影响范围、持续时间和来源；默认态只显示一句短文案。
