# Loop Log：clean low-poly 区域任务台的美术指导路由误判

## 决策条

- **结论**：父级把基于旧像素 / 半调坐标系的 `angus_art_director` 自动接入两张 clean low-poly 新标杆支线，属于 agent 路由误判；本轮已在生图前停止。
- **影响**：若继续，它可能把大块低多边形、干净现代周刊和轻纸品重新拉回旧像素、重半调与旧印刷语法，污染 prompt 和验收标准。
- **下一步**：仅从 clean low-poly weekly 支线暂时剔除该 agent；保留 UI Designer、UX 老哥与父级直接标杆复审，不生成新图，等用户继续指令。

## 详情

- **一句话结论**：问题不是 agent 能力不足，而是训练真值与当前任务真值不一致，不能让它担任这条支线的主风格裁判。
- **我实际处理了什么**：已定位并展示两张正确标杆；在用户叫停后中断 `ui_designer` 与 `angus_art_director`，没有调用生图模型，没有生成或落地风格稿。
- **问题卡在哪里**：`angus_art_director` 的启动壳明确自称 Pixel Art / Art Director；技能又把像素颗粒、半调和套印结构设为生成后硬检查，而新标杆规范明确强调它不同于此前像素与重半调方向。
- **为什么会发生**：父级机械执行了“视觉任务默认交美术指导”的全局规则，没有先检查 reviewer 的真值源是否覆盖当前支线。
- **下一步怎么防**：先做“任务真值源 ↔ reviewer 真值源”适配检查；两者冲突时不自动调用 reviewer，改用支线直接标杆 Gate。
- **本轮不要继续做**：不继续生图，不让旧像素语言补写本次 prompt，不把任何未生成产物称为风格候选。

- **本轮处理**：停止并修订支线路由。
- **最小下一步**：用户确认后，由 UI Designer → UX 老哥 → 父级直接标杆 Gate → 真实生图继续。
