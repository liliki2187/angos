# Loop Log：符号语言被生成为完整矢量 icon

## 决策条

- **结论**：v4 的场景和地图方向有进展，但符号区仍把标杆的编辑部记号统一成了清晰、完整、同线宽的标准图标库。
- **影响**：globe、eye、问号、loop、地图节点和误归档纸条虽然语义正确，却丢失手绘、剪贴、套印与纸面结构色块的高级质感，继续放大只会得到更完整的行政视觉系统。
- **下一步**：暂停整张元素板，先制作独立符号 / 纸面材质母板。2026-07-13 经用户复审，制作轴已由“三种视觉方言”修订为“手稿 / 正式文书 / 符号贴纸三种生产来源与载体”。

## 标杆复盘

- 标杆不全是手绘：`eye / hand / doodle / question` 偏手绘；`grid / globe / orbit / CD segment` 偏技术线图；`TOP SECRET / WMW / badge` 偏贴纸字标。
- 三类的共同点不是统一线宽，而是结构删减、轻微不完整、载体差异、一至两色印刷、硬边套印和大小不均的纸面色块。
- 纸面高级感来自哑光基色上的 `2–4` 个低对比结构面，不来自污渍、泛黄、噪声、折痕或磨损。

## 当前偏差

- v4 底部 globe、问号三角、eye 和 loop 都闭合、居中、对称、同线宽，像成熟 icon set。
- 地图节点使用完全一致的三角标记，缺少标杆里不同来源记号的拼贴感。
- `MISFILED DEPARTMENT` 使用完整标题、复选框和说明字段，过度解释语义，读成行政表单而不是编辑部临时标记。
- 纸片有轻纹理，但缺少作为结构语言的明确大色块；视觉变化更多来自纸纹而不是底版分面。

## 防复发

- 一个符号只允许一个主轮廓和 `0–3` 个内部记号，通常不超过两层嵌套；删除装饰刻度、重复环、完整网格和说明性小字。
- 每批必须同时出现手稿、正式文书与贴纸，但禁止跨载体复用：手绘只进入便签 / 方格纸 / 独立批注层；文件夹 / 光盘 / 报刊基础层只使用正体字与机构图形；贴纸必须保留独立模切边和贴附关系。
- 先做去纹理复核：去掉纸纹后仍有结构色块与受控不完整，才算通过。
- 先做纯黑轮廓复核：至少一半符号无需内部细节和文字也能识别。
- “手绘”通过线宽、断口、偏心和越界实现，禁止仅加随机抖动、脏边或噪声。
