# Loop Log：平面内容的生产来源与载体错配

## 决策条

- **结论**：上一版母板的根因不是手绘质量不足，而是把手稿、正式文书与贴纸误当成可跨载体任意复用的三种画法。
- **影响**：个人草绘被直接印在文件夹上，机构文书失去专业秩序；贴纸也不再是独立态度层。标杆中“混乱世界对照冷静系统”的张力因此消失。
- **下一步**：母板按生产来源重新分为“手稿 / 工作便签、正式文书 / 机构输出、符号化贴纸”，并增加一个三层组合样例验证载体边界。

## 根因

- 先按“手绘、技术线、贴纸字标”归纳视觉特征，却没有先问谁画、为什么画、印在哪一层。
- 将“标杆不全是手绘”错误外推为“技术线或手绘记号都可以直印文件夹”，忽略了专业文件夹自身属于机构输出。
- 只检查图形复杂度和纸面色块，没有设置来源 Gate、载体白名单和物理叠层 Gate。

## 标杆中的三种来源

1. **手稿 / 工作便签**：记者或编辑的临时猜测。载体为便利贴、方格纸、散页批注；粗线与细线都可，允许箭头、问号、断口和未完成结构。
2. **正式文书 / 机构输出**：出版、归档或技术系统的可信信息。载体为报刊、文件夹、档案页、光盘、表格和正式地图；使用正体字、编号、网格、条码和规范图形，同时以大块邻色色面降低官僚感。
3. **符号化贴纸**：编辑部文化与快速分类。使用独立模切载体、白边 / 色边、一至两色粗图形、轻微套印和旋转，承担身份与冷面幽默。

## v1 具体偏差

- 钴蓝文件夹上的手绘 globe、橄榄文件夹上的手绘准星、青绿载体上的草绘轨道都把个人手稿语法并入了正式文书底层。
- “正式文书”未形成正体字、编号、秩序网格和清楚机构图形的独立分区。
- 贴纸虽有白边，但没有通过组合样例证明它与正式基底、手稿批注是三个后贴 / 后夹的物理层。

## 防复发 Gate

1. **来源 Gate**：每个元素先标注生产者与用途，再决定画法；无来源定义不得进入 prompt。
2. **载体 Gate**：手稿只进入便签、方格纸、散页或独立批注层；文件夹、光盘、报刊和正式表单基础层禁止个人手绘。
3. **叠层 Gate**：正式基底、贴纸、手稿必须通过纸边、遮挡、旋转、夹持 / 胶带关系保持可分离。
4. **转译 Gate**：同一 eye / globe 母题跨三类使用时必须分别重绘，不得复制后换载体。
5. **材质 Gate**：正式文书用 `2–4` 个结构色块软化制度感；禁止以手写化、污渍或泛黄制造“没那么严肃”。
