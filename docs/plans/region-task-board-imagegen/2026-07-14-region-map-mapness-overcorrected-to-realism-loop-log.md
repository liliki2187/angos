## 详情

- **一句话结论**：我在纠正“它不像地图”时，把目标错误替换成“更像真实地图”，洗掉了此前已经反复确认的支线风格主语。
- **我实际处理了什么**：提示词要求精确纽约关系、五区、水系、道路 / 铁路 / 桥梁、比例尺、图例和定位图，同时在末尾写了 `no GIS / no realism`。
- **问题卡在哪里**：模型优先执行了更具体、更可画的正向结构，最终生成精细海岸、密集街网、连续城市肌理和成套图册附件；负向词没有能力撤销前面的写实暗示。
- **为什么会复发**：这是 F6 的同一机制——每次只纠正一个显性维度，就把标杆其它轴抹掉。这次又叠加 F1：成图明显不像双标杆，我仍因“地图身份终于成立”而把它发送成候选。
- **下一步怎么防**：地图身份与支线风格必须分别验收；提示词先锁塑造语言，再用同一抽象度表达地图语义；生成后必须与两张原标杆并排判读。
- **本轮不要继续做**：不在当前写实底图上做 low-poly 滤镜、减街道、换色或加纸纹；这些都无法改变其专业 atlas 的底层主语。

## 提示词冲突复盘

| 原正向要求 | 实际把模型推向 | 正确替换 |
| --- | --- | --- |
| `recognizable / exact New York geography` | 精确海岸与真实城市定位 | `iconic simplified land-water relationship` |
| 五区、道路、铁路、桥梁、港口连接同时列全 | 密集 GIS / 交通图层 | `4–6 broad subregions + 2–3 major corridors` |
| 正式图例、比例尺、方向标、定位图成套出现 | 专业地图册 / 城市规划图 | 正体标题与边框为主，附件只选 `0–2` 个微型提示 |
| `no GIS / no realism` 放在末尾 | 弱负向词无法覆盖强正向结构 | 开头先锁现代编辑剪纸低多边形、大形概括与图形化地貌 |

## 正确的地图身份

地图感应来自以下极简空间骨架，而不是信息密度：

1. 一张矩形正式纸面与清楚视窗。
2. 一组概括但可辨的陆水 / 邻接关系。
3. `4–6` 个大尺度内部地区。
4. `3–5` 个图形化地貌 / 城市剪影。
5. `2–3` 条主交通走廊与少量地名 / 节点。

正式的是正体字、编号、边框和层级；地理内容本身仍必须是标杆式编辑插画：大剪影、少量中粗块面、有限冷色与受控省略。

## 复发保护

- **开工前**：把风格主语写在所有地理名词之前；禁止将 `accurate`、`exact geography`、`detailed roads`、`professional atlas`、`official cartography`、`locator map` 作为正向要求。
- **Mapness Gate**：遮掉文字和任务层后，仍能读成包含多个可达地区的区域地图。
- **直接标杆 Gate**：与两张 clean low-poly 标杆并排，检查大块面比例、线密度、材质是否连续写实，以及是否仍有现代编辑拼贴感。
- **一票否决**：出现密集街网、航拍式连续城市纹理、精确曲折海岸、成套图册附件，或第一眼像专业 atlas / 城市规划图，发送前直接判废。
