# Loop Log：区域地图碎面与整板颜色过载

## 决策条

- **结论**：v5 没有真正执行“大块低多边形”，而是在各地区均匀铺满小三角；同时把整套色票等权放大，地图失去标杆的秩序与高级感。
- **影响**：地图先读成程序化 low-poly / 彩色桌游行政区，不再是现代周刊编辑设计；文字、路线与地形也被碎面竞争。
- **下一步**：保留已通过的平面内容来源语言，只重做地图块面和整板配色；先过局部地图 Gate，再重出总风格板。

## 根因

- prompt 写了每区 `3–5` 个大色面，但没有阻断生成模型在其下继续铺几十个小三角。
- 将“中层活跃”误解成切面数量，把块面当纹理而不是地势 / 光照 / 异常结构。
- 将“色票丰富”误解成所有色相都应在同一地图里占大面积，没有规定主色、辅色、中性和强调色的面积层级。

## 标杆差异

- 标杆的低多边形面大小悬殊，少数主面承担体积和方向；当前地图三角尺寸近似，读成均匀滤镜。
- 标杆可以展示多枚色票，但单个主物件通常由一组相邻色支配；当前每个行政区使用独立强色，橄榄、青绿、紫、黄、红同时成为视觉主角。
- 标杆的纸面 / 场景保留安静色面承载文字和符号；当前路线与地区名被高频碎面包围。

## 防复发 Gate

1. **25% 块面 Gate**：每区只能先读到约 `3–5` 个主结构面；若仍先读到三角纹理，失败。
2. **尺度主次 Gate**：必须同时存在占区显著面积的主面与少量辅助面；等尺度三角镶嵌直接失败。
3. **语义 Gate**：每条主要分界线须对应地势、光照、气候或异常影响；无语义纹理线删除。
4. **颜色面积 Gate**：单板只允许两组相邻主色家族大面积出现，并从芥末 / 锈红中选择一个强调；紫、黄、红不得同时大面积并列。
5. **安静面 Gate**：文字与主路线附近必须有低变化色面，不允许细碎纹理穿过。
