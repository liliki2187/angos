# Loop Log：局部热点清障被整图重采样放大为地图重绘

## 决策条

- **结论**：本轮两次整图 image edit 均未达到“只清五热点”的要求；v2 降级为清障思路草稿，第二次拓扑漂移稿判废，停止继续整图重生。
- **影响**：A200 选定的第三案仍是唯一方向，但本轮没有得到可替换 `rt_map_base_clean` 的资产；继续追加整图 prompt 会反复洗掉已认可的陆水骨架。
- **下一步**：等待用户在“局部裁块生图后回贴”与“显式启用 CLI 掩膜编辑”之间裁决；未裁决前不做第三次整图生成。

## 根因

内置 imagegen 的整图编辑仍会对全画布重新采样。提示词虽然声明 `do not redraw`、固定五热点与不可变构图，但这些文字约束不能形成像素级冻结区；为了清除局部海岸 / 地标，模型同时重绘了森林规模、城市形状、多边形分面与东西岸线。问题不是提示词再加一条负面词就能解决，而是执行粒度与“掩膜外 1:1 保留”目标不匹配。

## 已试方案

1. **第一轮整图编辑（v2）**：NW 与中央热点得到明显清理，第三案第一眼身份仍在；但 SW / SE 高对比岸线和多条 `200×72` 标签走廊未通过，而且 UI / UX 对“是否已经改变冻结拓扑”产生分歧。ROI 外漂移探针显示，在“每像素 RGB 平均绝对差 > 24”的阈值下，约 `11.91%` 的 ROI 外像素仍发生显著变化，ROI 外平均绝对差为 `12.363`；因此父级按较严口径把它降级为 `no_text_style_draft`，不进入运行时。
2. **第二轮整图定向编辑**：只要求修 E / SW / SE，结果右侧水道、东部大陆轮廓与港湾关系被大幅重写，并把西南陆块底部的象牙色边框整段抹掉，明确违反 A200 的空间骨架与 A203 的连续边框不变量。该图仅保留在内置生图默认目录作为偏差输出，不复制进项目资产目录。
3. **止损判定**：同一“局部清障导致整图重采样”缺陷连续两轮未修复，命中 workflow harness §6.2；禁止继续用全图 img2img 追加第三轮 prompt。

## 结构性替代

### 方案 A：局部裁块生图后回贴（推荐，继续使用内置 imagegen）

- 从用户选定 v1 中按热点 / 标签走廊裁出带足量上下文的局部块；每块单独调用真实生图，只要求清理该块内结构。
- 程序只负责把通过复审的生图局部以羽化边缘合成回 v1，掩膜并集之外像素保持 `1:1`；它不程序绘画、不替代生图内容。
- 优点：不需要 CLI / API key，能把全局范围失控压缩到局部；代价是要检查接缝、块面尺度和纸纹连续性，可能需要 3–5 个局部候选。

### 方案 B：CLI 显式掩膜编辑

- 改用 imagegen 技能的 CLI fallback，以精确 mask 限定可变区域，掩膜外保持高保真。
- 优点：执行语义最接近需求；代价是用户必须明确授权切换 CLI 路线，环境需本地设置 `OPENAI_API_KEY`，且仍需验证模型是否严格服从 mask。

### 方案 C：保持 v1 仅作美术方向稿

- 不再为当前原图强行腾热点；A200 继续作为构图 / 风格真源，等正式运行时底图生产时以五热点合同从一开始重新生成。
- 优点：不破坏已选图；代价是本轮不产生可接入资产。

## 待裁决问题

推荐选择方案 A：它继续遵守“真实生图”规则，同时把程序限定为拼接与 QA。若用户更重视精确掩膜语义并愿意配置 CLI，则选择方案 B；若当前只需锁风格而不急于运行时落地，则选择方案 C。

## 复发与沉淀

- **触发来源**：父级截图复核 + UI / UX 生成后复审冲突 + 第二次生成拓扑漂移。
- **失败归因**：F3「范围失控」——局部热点修正被整图重采样放大为整体重做。
- **复发判定**：F3 至少第 `6` 次复发，最后复发日期更新为 2026-07-14。
- **本轮处理**：v2 降级、第二次生成判废、整图编辑路线停止，A200 选定方向不撤回。
- **复发保护**：局部视觉编辑若声明不可变区域，必须在生成前定义可变 ROI，并在生成后做全图前后对照；整图重采样不得再冒充局部修改。
- **防线升级**：F3 从“文档规则 + 交付前三问”升级到 `workflow-gates.yml` 的 trial `scope_invariant` gate；没有 ROI / 不变量证据时，只能交付为相似变体，不能声明局部编辑通过。
- **用户追加复核（2026-07-14）**：用户点名西南陆块底部边框消失。父级确认这不是刻意降权，而是模型把“岸线避开热点”误解为“删除岸线”。下一轮任何局部补丁必须同时检查边框的进入点、绕行段和接回点，不能只看 hotspot 中央是否变干净。
