## 直接标杆复核

### 通过项

- 周边 UI 已从原生程序面板转为统一的现代周刊纸品系统。
- 地图仍是第一视觉主语，左索引、右卷宗与底部日程没有压缩主舞台。
- 配色主要收束在深蓝、米白、橄榄、蓝绿与极少锈红，没有新增大面积紫色或亮色。
- 纸面主要依靠大色块、薄纸边和短硬阴影建立质感，没有依赖泛黄污渍或撕裂。
- 专业文书、手绘批注和模切符号的使用场景得到区分。
- `推进一天` 与派遣 CTA 保持空间和视觉语义分离。

### 当前仅作目标稿的原因

- 整屏稿中文字由生成模型近似绘制，只能判断层级与融合，不能作为真实字形证据。
- 生成模型无法保证中央地图像素级不变；正式实现继续复用已选地图原图。
- 左卡中的图形图标与卷宗装饰仍是气质占位，不能直接视为正式事件类型资产。
- 组件母板尚未完成透明切片、2x/3x 源尺寸、真实 `content_rects / no_text_rects`、状态几何全等、边缘残留扫描和 Godot 装配。
- 颜色尚未进入生产级 ROI / Lab 阈值合同，本轮只做直接标杆目检。
