# 区域任务台首轮视觉目标 Gate Router Card

## 任务

在已通过的 `runtime_skeleton / runtime_state_preview` 上，建立下一阶段的两项视觉裁决证据：

1. 无字组件与纸面材质母板；
2. 使用真实 `M330 selected` 状态的高完成度整屏目标稿。

## 产物类型

- 组件母板：`no-text style draft / component master board`
- 整屏目标稿：`filled-state visual target mock`

二者都不是 `no-text asset master`、atlas、运行底图或 `production_candidate`。

## 冻结项

- 1920×1080 五区职责和当前几何合同不变。
- 中央地图仍使用已选原图，生图不得成为地图生产源。
- 左卡、图钉、卷宗与 CTA 的动态字段仍由 Godot 渲染。
- 一个地区允许 0–N 个事件，固定热点表继续禁用。
- `推进一天` 继续禁用，不能因美术包装看起来可点击。

## 本轮判断

- 判断组件语言是否摆脱原生控件，同时没有滑向旧档案、复古招贴、写实探案或可爱怪谈。
- 判断整屏是否仍由地图主导，周边 UI 是否成为同一套现代神秘周刊物件系统。
- 不判断透明切片、九宫格、真实文字 bbox、状态几何全等或最终 atlas。

## 阻断条件

- 母板带真实动态文字、任务名或状态结论。
- 可写功能面倾斜或被装饰穿过。
- 周边 UI 仍像原生 Panel / SaaS 面板。
- 地图被重画、简化、缩小或被标签覆盖。
- 纸张依赖泛黄、污渍、撕裂制造复古感。
- 颜色、细碎多边形或装饰密度明显超过标杆。
