## 详情 / Human Brief

- **一句话结论**：复用已选地图底图，先拆掉旧整屏透明热点模型，用 Godot 原生节点证明动态事件点与真实任务数据可以闭环。
- **我实际做了什么**：读取玩法数据、现有区域页代码、旧 manifest、预落地评估和 UI / UX 结论；确认 `payload.nodes` 已提供 0–N 个任务与 `map_pos`。
- **现在卡在哪里**：独立“推进一天”没有玩法命令，底部日程本轮只能冻结几何并保持禁用。
- **为什么不能跳过**：若直接把按钮做成可点，会把“结束探索”或无效果操作冒充全局时间推进，造成实现与 GDD 漂移。
- **下一步怎么验证**：manifest 静态校验、组件 0 / 1 / N 测试、实际主流程截图、地图点切换动态演示。
- **本轮不要做**：不批量生图、不制作整屏 atlas、不启用推进一天、不宣称生产候选。

## 术语版 / Routing

- **任务一句话**：把区域任务台风格稿转成可替换、可测试的最小运行纵向切片。
- **任务类型**：UI / 代码 / 美术资产化 / 文档
- **风险等级**：risky
- **当前阶段**：运行实现
- **目标载体**：Godot / JSON 合同 / 截图 / GIF
- **本轮交付物类型**：implementation / delivery_manifest / screenshot
- **被路由对象类型**：runtime_skeleton / runtime_state_preview
- **本轮只验证**：真实 `nodes[]` 动态生成任务卡与图钉、同一 `task_id` 选中同步、右侧摘要容量、派遣 CTA 回调。
- **本轮不做**：最终纸面母版、最终图钉 sprite、推进一天玩法、所有分辨率与极端本地化。
- **本轮必读真源**：`docs/onboarding/ai-collaboration-guidance.md`、`docs/onboarding/ui-interaction-guidelines.md`、预落地评估、区域任务台资产化生产规格、当前 Godot 代码。
- **若进入下一步再读**：正式时间推进 GDD、最终资源导出规范。
- **必调 agent**：本轮消费前一环已经完成的 `ux_laoge` 与 `ui_designer` 结论，不重复发散。
- **明确不调的 agent 与原因**：`angus_art_director` 按 clean-lowpoly 临时例外剔除；冷备玩法 agent 未解冻，本轮不改玩法规则。
- **被路由对象允许下一步**：运行截图与状态闭环通过后，拆分纸面外壳 / 任务卡 / 图钉的资源母版。
- **被路由对象禁止跳到**：production_candidate、全量 atlas、推进一天可用态。
- **停止条件**：出现固定热点、卡片与图钉 ID 不一致、右栏摘要侵占 CTA、主流程无法进入派遣，立即停止并返工。

## 进入下一步前自问

- 当前验证对象是运行骨架，不是最终视觉稿。
- 必须保护：地图填满主舞台、右侧长摘要空间、左下推进位置、同一区域多个事件点。
- 本轮只接地图事件点—摘要—派遣，足以验证最危险的技术假设。
- “推进一天”缺玩法语义，保持禁用并明确记录，不擅自补规则。
