# Loop Log：区域任务元素板卡通强度过量

## 决策条

- **结论**：v1 从“过写实”纠偏到了“过卡通”，仍未对齐原始两张标杆。
- **影响**：若只把更多黑色幽默与新怪谈直接画成表情、怪物和贴纸梗，会让题材暗味反客为主，把克制的成人周刊风格变成怪谈漫画。
- **下一步**：先冻结文字强度方案；下一版以原标杆为八成主语，每个场景只保留一个安静的不可能点。

## 详情

- **触发来源**：用户复审。
- **当前产物**：`01-region-task-element-art-style-board-v1.png`。
- **失败归因**：为修复写实 / 探案偏差，把卡通、黑色幽默、符号化与新怪谈四项同时外显并拉高，形成纠偏过冲。
- **具体症状**：大笑脸怪物、独眼月亮、拟人图形、张嘴报纸、问号手与多枚强梗贴纸共同抢占主画风；场景不再只是“现实中有一处不对”，而是整个世界都主动表演怪异。
- **正确主次**：原标杆的现代周刊排版、克制低多边形插画、薄纸物件和哑光色块为主；荒诞关系为辅；表情化卡通最少。
- **产物处置**：降级为 `cartoon_overshoot_style_deviation_reference`，不作为下一轮正向参考输入。
- **沉淀位置**：A183 与 clean-lowpoly 支线规范 §3.2。

## 复发保护

- prompt 中不能把 `cartoon / black humor / symbolic / new weird` 并列成同权主风格词；先写原标杆图形语言，再把后三项写成 `subtle / restrained / one quiet anomaly per scene`。
- 放行前反问：遮掉异常细节后，底层物件与插画是否仍像原标杆；若只剩通用卡通板，失败。
- 任一场景最多一个叙事梗；任一贴纸不得靠可爱表情承担主要识别。
