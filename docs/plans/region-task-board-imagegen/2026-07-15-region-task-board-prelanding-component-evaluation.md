# 区域任务台风格稿落地前全组件评估

> 日期：2026-07-15
> 评估对象：`image_gen/2026-07-15/20260715-wmw-region-task-board-filled-style-v3.png`
> 冻结结构真源：`docs/prototypes/region-task-board-wireframe/` 与 A204、A208、A210
> 评估性质：资产生产前 Gate；本文件不授权批量生图、切图或 Godot 接入。
> 当前结论：**视觉方向通过；批量资产生产暂不放行。**

## 1. 一句话结论

这张风格稿已经足以证明区域任务台的整体气质和五秒操作链，但它是一张 `filled_state_visual_mock`，不是可直接裁切的生产母版。下一步应复用已经选定的地图原图，用 Godot 原生控件承担结构、文字、路线和状态，再只为少数纸面外壳、图钉母版与主按钮母版生产无字透明资产；必须先完成一条纵向切片，不能把整屏图直接拆成 atlas。

## 2. 评估依据与真源优先级

### 2.1 真源顺序

1. 玩法与交互真源：A204、A208、A210。
2. 1920×1080 几何真源：已确认的黑白功能结构框。
3. 地图视觉真源：`image_gen/2026-07-14/20260714-153016_wmw-region-map-landmark-rhythm-selected-v1-original.png`。
4. 风格真源：两张 clean low-poly weekly 标杆、支线风格规范、符号与纸面母板。
5. 当前完整风格稿：只证明组合气质、颜色关系和默认选中态，不证明坐标、裁切边界或交互状态。

### 2.2 当前风格稿的证据边界

- 实际位图为 `1672×941`，并非目标运行时 `1920×1080`。
- 它已烘焙文字、纸面阴影、相邻组件遮挡、选中标记和局部装饰，没有独立 alpha 层。
- 它可以证明：默认态、一个选中任务、左右联动的视觉层级和总体材质方向。
- 它不能证明：真实可写区、长文本、hover / pressed / disabled、0–N 图钉、标签避让、命中区、锚点或三档桌面分辨率。

几何叠加审计图：`docs/screenshots/2026-07-15-region-task-prelanding-audit/01-component-geometry-audit-overlay.png`。

## 6. UX 与交互合理性审计

### 6.1 已成立的操作链

玩家在五秒内能看出：左侧选任务 → 地图上找到同一事件 → 右侧阅读摘要和风险 → 点击右下派遣。当前 mock 中，橄榄绿选中卡、绿色图钉与右下 CTA 已形成一致的视觉链。

### 6.2 必须处理的问题

1. **幽灵任务点（P1）**：左侧只有 4 个可选任务和 1 个进行中条目，但地图上出现约 6 个任务式图钉。任何可交互图钉必须与左卡共享同一个 `task_id` 数据源；非任务地标禁止使用图钉、竖杆或同级描边。
2. **推进一天与派遣语法过近（P2）**：两者都使用粗重底板和向右箭头，容易被理解为同一类连续推进操作。推进一天改用日期、翻页或确认语法，不使用强右箭头；首次点击进入确认态。
3. **CTA 漂移（P2）**：风格稿里的派遣 CTA 偏高，右栏底部纸尾过大。正式版必须固定在 `[1512,916,356,112]`，摘要变长也不能把它顶走。
4. **摘要容量未验证**：316px 正文区在图上成立，但必须用真实中文 7 / 8 / 9 行压力文本验证；超过 9 行走“展开全文”，不缩字、不在框内出现默认滚动条。
5. **左侧外伸“当前”书签未冻结**：它容易造成额外裁切、越界和独立点击误解。正式选择态归入任务卡自身，不把外伸书签烘焙进左栏壳。

### 6.3 状态矩阵

| 对象 | 必须状态 | 当前风格稿已证明 | 仍需运行时证明 |
| --- | --- | --- | --- |
| 任务卡 | default / hover / selected / assigned / urgent / locked | default、selected | 其余 4 态及长标题 |
| 图钉 | default / hover / selected / assigned / urgent / cluster | default、selected | 其余 4 态、避让与聚合 |
| 派遣 CTA | default / hover / pressed / disabled / loading | default | 其余 4 态和阻断原因 |
| 推进一天 | default / hover / confirming / disabled | default | 确认态、禁用态、与 CTA 语法区分 |
| 摘要 | 7 行 / 8 行 / 9 行 / 展开全文 | 占位文字 | 全部真实中文状态 |

## 8. 生图、裁切与导出难度

### 8.1 不允许的做法

- 不从完整风格稿裁任务卡、dossier、CTA、日程条或带字图钉。
- 不让生图模型一次生成整套状态 atlas、精确中文、精确九宫格边界或成套命中区。
- 不把地图上的任务点和标签烘焙回底图。
- 不为 hover / selected / disabled 分别生成一张几何略有差异的新图。
- 不把当前无图层的 PNG 伪装成可恢复 PSD；`psd-to-godot-ui` 在没有 PSD / 分层源时不能恢复层级。

## 10. 代码与 manifest 前置阻断

1. **整屏图优先级阻断**：`WeeklyRunExplorePhase.gd` 的 `_apply_region_task_runtime_art()` 当前优先应用 `rt_artboard_full` 并提前返回。只把新资产放进目录不会显示，必须在纵向切片接入时调整优先级。
2. **旧状态 atlas 假设**：`WeeklyRunUiStyle.gd` 仍硬编码旧资产 ID 与多状态 atlas 读取。当前“一类一母版 + 运行时派生”需要新的 manifest v2 与样式入口。
3. **固定热点与 A204 冲突**：旧 `region_task_asset_manifest.json` 固定了五个 `hotspots`，甚至把“五个热点可点击”写成 QA case。正式版必须改为按事件数据动态生成 0–N 个坐标，同一区域允许多个任务。
4. **无组件合同**：当前不存在 `design/ui-contracts/region-task-board/`。在建立 visual / layout / clip / hit rect 与文本合同前，不得批量生产。
5. **`.gdignore` 说明**：现有自定义 loader 使用 `Image.load_from_file`，因此 `assetized/.gdignore` 并不会自动阻断当前文件加载；只有切换为 Godot 导入资源、Texture2D 或 tscn 依赖时，才需要同步移除或迁移。不得把它误判成当前唯一阻断。

## 11. 纵向切片顺序

1. 地图底图 + 共享 `task_id` 的动态事件图钉，验证 0 / 1 / N / 密集与聚合。
2. dossier 壳 + 7 / 8 / 9 行真实中文摘要 + 固定底部 CTA。
3. 左任务卡与地图、dossier 的同源选中联动。
4. 派遣 CTA 的 default / hover / pressed / disabled / loading。
5. 推进一天的 default / hover / confirming / disabled；使用日历 / 翻页语法，不使用强右箭头。
6. HUD 与日程条原生构造。
7. 纵向切片通过后，才允许批量生产剩余状态章、图标和同类实例。
