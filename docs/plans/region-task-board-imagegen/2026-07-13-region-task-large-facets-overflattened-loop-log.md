# Loop Log：把大多边形误做成极少纯色块与复古招贴

## 决策条

- **结论**：v3 成功避免写实细碎，却把“大块面”过度压成平面图标和纯色背景，丢失标杆的现代色块活跃度。
- **影响**：四张任务图变成居中黑剪影、复古大圆和公共信息标识；地图只剩平涂行政区，整体从现代神秘周刊滑向复古专业杂志 / 宣传招贴。
- **下一步**：恢复 v1 可取的中粗颗粒色块塑形与冷色变化，只替换可爱怪物等题材元素；地图采用宏观区域 + 区域内部大色面两级结构。

## 根因

- 把用户的“多边形大、不要碎”翻译成了“整张图只允许极少色块”，忽略“大块面仍可有大小、方向、明度和邻色色相变化”。
- prompt 同时使用 `few planes / posterized / black silhouette / official sign`，并大量指定芥末、橄榄、锈红、米纸，模型自然聚合为复古公共宣传画语言。
- 为增强符号化，把停车、信号和部门章放大成构图主角，黑色幽默从场景关系退化成复古路牌设计。
- 地图合同只有宏观区域数，没有规定每区内部的中层色块变化，导致纯扁平行政区填色。

## 标杆与用户样本重读

- v1 的可取之处不是笑脸怪物，而是同一场景内部仍有冷青、钴蓝、紫蓝、芥末等多档大色面共同塑形，快照之间昼夜和色相不同，画面有场景层次又没有回到摄影写实。
- 标杆纸品虽有周刊 / 档案语义，但深蓝负空间、冷色主导、清洁纸边、技术线条和错落拼贴让它保持现代；复古感只是一点材料暗示，不是总体年代风格。
- v3 的大圆日轮、居中剪影、粗边复古标识、卡其 / 土黄 / 褐红组合与四张同构编号卡，共同制造了“土”和“复古招贴”。

## 防复发

- “大多边形”改为**中粗颗粒**：结构体块少，但每个体块内部保留 `2–4` 个较大明度 / 邻色色面；整张快照允许约 `15–30` 个不均匀大中面。
- 色彩主运动由深海军蓝、钴蓝、青绿、紫蓝与清洁橄榄承担；芥末和锈红仅作局部强调，禁止卡其 / 土黄 / 褐红同时大面积占位。
- 黑色幽默先写进场景关系，章记 / 罚单 / 问号只作第二阅读层，不让复古标牌成为主体。
- 地图必须同时验收宏观区域可读性和区域内部色块活跃度；纯平行政区与细碎 GIS 两端都失败。
