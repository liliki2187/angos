# Loop Log：区域任务台未锁视觉基因就进入整屏界面

## 决策条

- **结论**：本轮应暂停整屏界面风格稿，先用元素美术风格板确认总体画风。
- **影响**：若继续让完整三栏界面同时承担结构、信息和美术探索，模型会被地图、任务卡、案卷等功能名词拉回写实探案语法，难以看清风格是否真的接近标杆。
- **下一步**：只参考两张标杆生成一张元素风格板；通过卡通、黑色幽默、符号化与新怪谈幻想四项复核后，再进入整屏界面。

## 详情

- **一句话结论**：问题不仅是上一稿画风跑偏，也包括过早选择了“整屏界面”这一验证产物。
- **我实际处理了什么**：此前直接生成了区域任务台 filled-state 稿，并在完整地图、四张任务卡与右侧详情中纠偏结构和材质。
- **问题卡在哪里**：完整界面会同时放大功能物件词、真实地图和证据照片语义；在视觉基因尚未锁定时，它不是最低成本、最高辨识度的风格验证载体。
- **为什么会复发**：把“世界地图界面的下一个界面”误当成必须先画完整 UI，没有先区分结构验证、元素风格验证和最终 filled-state 三种产物等级。
- **下一步怎么防**：凡新标杆与现有风格坐标系存在明显差异，先做元素美术风格板；风格板只验证色彩、造型、题材和图形语言，不带动态文字和完整交互布局。
- **本轮不要继续做**：不把上一版区域任务台作为正向图像参考；不在其上局部提亮、去灰或增加怪谈装饰。

## 术语版

- **触发来源**：用户反馈。
- **原始问题**：以两张 clean low-poly 标杆为主，探索区域选择后的任务界面风格。
- **当前产物类型**：由 `filled_state_text_mock` 回退到 `art_element_style_board / visual_style_reference`。
- **失败归因**：阶段 / 产物类型误判 + F1 验证等级冒充。
- **复发判定**：F1 第 ≥11 次；本次化身为“未锁视觉基因就用整屏界面承担风格验证”。
- **本轮处理**：停止整屏、生图对象降维、以标杆元素板重新验证。
- **最小下一步**：生成一张区域任务元素美术风格板并让用户判断总体风格。
- **不继续做什么**：不进入 UI 布局、Godot 资产化和动态文字合同。

## 复发保护

- 新标杆首次落地前先问：当前要验证的是视觉基因、布局读法，还是生产 filled-state；三者不得用同一产物互相冒充。
- 风格板通过前不输入上一轮跑偏整屏稿，避免写实 / 探案语言被图像参考继续放大。
- 放行时必须同时检查卡通、黑色幽默、符号化、新怪谈幻想四个主语，而不是只看低多边形和配色。

## 本轮结果

- **生成稿**：`docs/screenshots/2026-07-13-region-task-element-style-board/01-region-task-element-art-style-board-v1.png`。
- **初检结论**：四个题材主语均有可见证据：飞碟停车罚单与“周五 13 日截止”提供冷面黑色幽默；悬空纸洞列车、眼月天线和错误怪物影子提供新怪谈；地图、快照和贴纸均先读大剪影，未回到真实地图或证据摄影。
- **色彩旁证**：以同一脚本缩放采样，`benchmark-board-02` 平均饱和度约 `0.588`、低饱和像素约 `11.9%`；本稿约 `0.576` 与 `14.7%`，已明显脱离上一版整屏稿的灰暗区间。该数据只作旁证，不替代肉眼标杆对照。
- **用户复审**：未通过。用户指出整体卡通程度过量，要求重新参考原始风格稿并先收回到文字方案。
- **降级结论**：纸面颗粒与复古感不是当前首要矛盾；更大的偏差是把笑脸怪物、独眼月亮、拟人贴纸和连续视觉梗全部外显，画面因此读成怪谈漫画 / 卡通贴纸包。该稿改标为 `cartoon_overshoot_style_deviation_reference`，不得作为下一轮正向图像参考。
