# Loop Log：区域地图丢失地图对象身份

## 决策条

- **结论**：四案比较的是分面方式，但共用底座本身不是地图；它只是带河流、节点和路线的悬浮异形剪纸。
- **影响**：A / B / C / D 的差异没有决策价值，用户无法从中挑选区域地图语言；继续调色或块面只会把错误对象画得更精致。
- **下一步**：停止四案微调，先建立一个具有正式载体与五层地理语义的区域地图结构母版，再在母版上比较 `2–3` 种塑造方式。

## 根因

- 为了控制变量，让四案共用同一轮廓，却没有先验证这个轮廓与内容是否具备地图身份。
- 把河流、路线和节点当成“像地图”的充分条件，删掉了海陆 / 邻区上下文、内部地区、地貌、聚落和交通骨架。
- 让土地整块模切后悬浮在深色背景上，物理载体更像贴纸 / 徽章，而不是 A188 定义的正式文书地图。
- A190 的块面尺度和限色规则被错误地提前使用，导致对象语义尚未成立就开始风格分案。

## 正确结构

1. 正式矩形 / 展开式地图纸、标题、边框、方向标、比例尺、极简图例。
2. 海岸 / 湖泊 / 河谷 / 邻区边缘等地理上下文。
3. `4–6` 个内部次级地区与山地、森林、平原、城区、工业带。
4. 城镇、站点、地标及主路 / 铁路 / 航线形成的空间骨架。
5. 最后叠加任务路线、异常节点、独立贴纸和手写批注。

## 防复发 Gate

- 遮掉路线、任务节点和全部文字，仍必须被识别为区域地图。
- 去掉深色桌面背景，地图仍必须凭正式纸面载体与制图结构成立。
- 玩家应看见一个地区内部可去往的地点关系，而不是两个色块之间的三点连线。
- 任何风格分案前先只展示同一张无任务层地图底图；Mapness 未通过，禁止生成多方案。
