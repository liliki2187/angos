# RegionCard 精细水印偏离标杆复盘

- 日期：2026-09-04
- 触发：用户指出白色水印方案过于细节，不符合既有美术标杆。

## 误判

上一稿正确解决了空白表单感，却用精细地球浮雕填补右侧留白，把“完成构图”错误等同于“增加可识别图形”。结果重新引入机构徽章、公章和官僚文件感。

## 原因

- 没有坚持标杆的宽块面抽象程度。
- 把低对比误当成低细节；即使颜色很浅，精细大陆边界仍然是高信息密度元素。
- 用主题符号直接填空，而不是用色块、节奏和负形完成构图。

## 防复发规则

1. RegionCard 的无数据区不得使用可辨认大陆、经纬网、精细地球或机构徽章。
2. 右侧构图优先依靠三至五个宽色面、一个负形和最多一个粗线批注。
3. 判断细节度时检查轮廓节点和视觉焦点，不以透明度代替抽象度。
4. 任何装饰若在缩略图中成为照片之外的第二主视觉，必须降权或删除。

## 当前处置

新一轮生图已删除精细白色水印，改用宽块面；该结果仍需继续压低大型问号、短线和照片高度，暂不升格为资产候选。
