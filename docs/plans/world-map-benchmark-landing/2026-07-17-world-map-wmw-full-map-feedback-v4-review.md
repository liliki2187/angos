# WMW 完整地图与条件反馈 v4 双 Agent 复核

> 产物类型：`structure_wireframe_state_pair`；桌面 1920×1080。
> 当前 default 可成立；conditional 尚无运行时真实差量数据。

## UX 老哥复审正文

两条常驻“红线预警 / 深链动向”没有足够独立职责：左下日程器已经回答推进前会发生什么，右侧任务情报已经回答当前地区有哪些任务和风险。中央底部再次显示当前值，是第三处重复，并会被误读为两个可点击或独立系统入口。

推荐采用“A 默认 + B 条件覆盖”：

- 无事件时完全删除双条，地图扩为 `[426,96,924,936]`。
- 发生真实推进日、任务结算或地区解锁差量时，在地图内部覆盖 `[450,942,876,90]` 的单条“最近世界变化”。
- 回执只回答“刚才实际改变了什么”，不重复左下预计后果；数据为空时整个组件不渲染。
- 小型地图图例只有在永久编码确实被持续误读时才可重新评估，当前不需要。

P0：没有真实事件差量时不得伪造 conditional；现有双条不得继续作为常驻生产组件。P1：条件条不能改变地图尺寸、不能重复右侧任务和左侧日程、不能拆成两条。P2：无 `READ ONLY / NO HIT` 标签、无关闭 / 展开 / 轮播。

## UI Designer 复审正文

Default 精确规格：

- 地图 `[426,96,924,936]`，底边 `y=1032`；中栏底部 24px 安全边距。
- 三个 pin 与标签保持 v3 坐标，永久交互安全区为 `[450,120,876,798]`。
- `y=918–1032` 只能放海域、非关键地理轮廓或弱路线尾端，不得新增 pin / 标签 / hit。
- 左栏日程器、B2.12、右侧 A5.1-H、四任务列表和 CTA 全部保持 v3。

Conditional 精确规格：

- Overlay `[450,942,876,90]`；图标 `[462,956,40,40]`；眉题 `[518,950,180,24]`；主差量 `[518,978,518,30]`；对象 `[1056,950,246,24]`；数值变化 `[1056,978,246,30]`。
- 必须具备唯一事件 ID、合法 cause、before / after 和至少一个 changed field。
- 无关闭、展开、轮播、跳转或整条 hit；地图 Rect 在出现 / 消失前后完全不变。
- 当前 `world_receipts` 仅有固定计数句，不满足条件，default 必须无 Overlay。

## 父级合并

采用完整地图作为当前默认结构；条件回执只作为未来状态示意。没有遗留 agent 分歧。
