# 世界地图开放编辑材料式组件 brief v1

## 北极星

右侧不是一份已完成、待审批的公司报告，而是一包仍在被编辑的本期主报道材料。

整屏五秒首读：`三份地区线报 → 地图定位与证据 → 正在形成的本期主稿 → 进入地区采编`。

## 标杆文件语法

标杆采用 `一个综合色母件＋一张主要信息纸＋一张叙事照片＋一至两条短签 / 索引＋一次真实接触`。材料开放、局部遮挡、可继续加工；字段完整度和表格秩序只作为第三层收束。

## Dossier 重组

在冻结外矩形内按以下层级重做：

1. 钴蓝文件夹母体，顶部保留一个大标签耳。
2. 一至两张只露边的灰蓝 / 灰米 BackDecor，可轻倾 `1°–2°`。
3. 正交标题纸：地区名、短副标、一个小锈红校样章。
4. 正交同源新闻照片校样：完整 `69:44`，不裁切、不拉伸。
5. 正交编辑说明短签：一条新闻标题、两行摘要、一处极小校改记号。
6. 正交 Disclosure 索引条：标题、计数、唯一 `＋/－` 状态。
7. 一张正交编辑资料索引纸：四条编号、短标题、短 metadata、小状态签；只用不等长单线分隔。
8. 正交橄榄行动签：唯一 CTA，视觉像从底袋抽出，但 hit rect 不变。
9. 最多一枚顶夹和一片胶带 / 小回形针，均为 NO-HIT BackDecor。

## 必须删除的画法

- 完整四列表格、等高单元格和 Excel 式多列对齐。
- 无玩法真源的部门、人员、日期和 Field Unit 伪字段。
- `STATUS ACTIVE` 式企业状态框。
- 一张白纸收编标题、照片、Disclosure、任务和 CTA 的单一模板。
- 贯穿全页的连续外框、统一企业大写标签语气和标准全宽软件按钮。
- `+` 与展开条目同时可见的状态冲突。

## 其余区域

- 顶部刊头：主体冻结，只保留大刊名、WMW globe、ISSUE 小票的一体关系。
- 左卡：几何与同构冻结；局部减少完整描边，改读为从钴蓝 / 芥末 / 橄榄稿夹中露出的地区封面纸。
- 中央地图：深色底、综合色大陆、北美圈和 selected evidence 主体冻结；只修夹子 / 胶带是否真正压住两层。
- Schedule：功能冻结，外观改读为被左卡压住的 WEEK / DAY 被动回执。

## 第一眼失败条件

- 右栏仍是一张四面闭合的完整白表单。
- 仍能一眼看出四行等高表格。
- 只是在原公司报表上增加胶带、问号、手写批注或纸纹。
- 标题纸、照片校样、资料索引和行动签无法遮字分辨。
- 装饰物与 CTA 同样像按钮。
- 为衬托右栏再次把中央地图提白。

## 冻结边界

桌面 `1920×1080` 三栏、FrontCarrier `0°`、动态文字槽、状态语义、Disclosure、CTA / hit rect、三张 `1104×704 / 69:44` canonical 新闻图、Schedule passive 继续冻结。ISSUE exact rect 与地区卡 `2:1 / 86:41` 冲突继续未冻结。本 brief 不授权 atlas、manifest、Godot 或 `WeeklyRunGame`。
