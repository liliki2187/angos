## 目标

验证中央底部不常驻任何重复状态是否更合理，并为未来真实世界差量保留不改变布局的条件反馈形态。

## 用户硬约束

- 可以尝试删除红线 / 深链双条，也可以重新判断该区域真实用途。
- 不得为了填空新增没有系统依据的组件。
- 左右栏已成立结构不重排。

## 路由与范围

现有 UI 改进先由 UX 老哥比较删除、条件回执与其它候选，再由 UI Designer 给精确坐标。父级只生成两张 1920×1080 黑白结构态，不改运行时或正式合同。

## 输出

- Default：地图 `[426,96,924,936]`，无常驻底带。
