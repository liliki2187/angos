# 世界地图连续调色导致材质风格漂移 Loop Log

## 触发

2026-08-26，用户指出：近期世界地图与普通杂志配色稿虽然版面可讨论，但界面的质感、材质、细节与低多边形颗粒度均未贴近正式 `clean low-poly weekly` 标杆；整体仍显纯平，同时地区图片与小道具偏写实。

## 本轮结论

- 近期所有基于同一整屏底图的 `color-only edit`，统一降级为**综合色与构图诊断样本**。
- 这些图不得作为新的世界地图风格目标、资产真源或 Godot 落地依据。
- 当前三栏布局、功能矩形、图片比例、状态语义、Disclosure、CTA 与 hit rect 继续冻结；失败的是可见材质与绘制语言，不是功能骨架。

## 误判

在用户提出蓝色过亮、蓝绿不协调、灰土与官僚感等综合色反馈后，工作连续进入同一底图的重调色循环。该做法默认继承了底图已有的平面矩形、统一薄描边、普通 UI 投影、偏写实新闻图与细碎地图面，只改变色相、明度和纯度，无法修复正式标杆要求的实体出版物剪影、宽块面低多边形、纸层厚度、接触关系和印刷介质统一。

## 根因

1. 本地 sandbox 持续出现 `setup refresh helper_unknown_error`，正式 benchmark 原图没有直接送入后几轮图像模型；生成主要依赖文字描述，缺少像素级风格锚点。
2. 为保持综合色实验可比性，提示反复要求保留 95%–97% 原构图，客观上也保留了原底图的平面与写实偏差。
3. “功能承载面保持 0° 正交”被视觉执行误读为“功能承载面应是规整平色矩形”，忽略正交纸件仍可拥有切角、宽折面、纸边、后层与接触阴影。
4. “干净现代、不要旧纸噪点”只执行了删减，没有补回标杆中的宽块面浅折面、吸墨、轻微套印、厚卡侧边与材质差异。
5. 低多边形语言主要出现在地图和照片，且照片仍保留写实反射、细节和碎面；纸张、folio、口袋、胶带与夹子没有共享同一几何语言。

## 影响

- 近期综合色稿能够回答“哪组颜色更像杂志”，但不能回答“真实界面是否已接近正式美术标杆”。
- 若继续基于这些图返色或加小装饰，只会扩大视觉债务，并再次把局部改善误判为风格收敛。
- 暂不进入 atlas、manifest、Godot 或 `WeeklyRunGame`。

## 纠正路径

1. 停止对现有整屏底图继续 `color-only edit`。
2. 恢复 benchmark 原图直连后，以 `benchmark-board-01.png`、`benchmark-board-02.png`、已确认 Master Board 和冻结 wireframe／rect 合同共同作为输入，从空白可见表面重新生成。
3. 当前真实 UI 只提供几何与真实内容，不再作为风格正参考。
4. 重建约 60%–75% 可见画面：100% 地图美术、100% 三张 1104×704 地区母图、100% BackDecor、80%–100% FrontCarrier 可见材质、100% 接触阴影语言与简化接触物。
5. 先验证无字材质与母图语言，再叠加 Runtime 文字和精确功能槽；不得把动态文字烘焙进正式资产。
6. 重建后重新走 UX 诊断、UI Designer 复核和父级标杆并排验收。

## 下一轮硬门槛

- 正式 benchmark 原图必须实际进入生成或编辑上下文；仅有文字转述不得宣称完成直接标杆复审。
- 1920×1080 三栏、所有冻结尺寸、图片比例、动态文字槽、状态语义与 hit rect 保持 100% 不动。
- RegionCard 暖纸面仅使用约 3–5 个主要宽折面；138×88 图槽在缩小后仍依靠约 10–18 个主要色块识别主体。
- Dossier 414×264 母图以约 25–45 个大块表现，不使用写实水面、微型窗格和碎三角滤镜。
- 中央世界地图使用约 45–75 个主要陆地色面，不保留精细 GIS 海岸、国界、雷达、发光节点与密集等尺寸三角网。
- 关闭细纹后，仍能仅凭轮廓、厚度、透明度、综合色和接触关系区分薄纸、厚卡、照片、胶带与金属夹。
- 在 25% 缩放下，第一眼必须是实体周刊编辑部，不是软件面板；在 100% 下不得比正式 benchmark 更平或更写实。

## 2026-08-26 用户补充纠正：纸面几何不等于低多边形语言

用户确认重建方向可以继续，但指出两项新的误判风险：纸张仍显旧；纸面上的宽几何明暗容易被读成褶皱。此前“在纸张上补回宽块面浅折面”以及“RegionCard 暖纸面使用 3–5 个主要宽折面”的写法撤回，不能再作为下一轮门槛。

修订后的执行线：

1. 功能纸面使用当代、干净、新印的暖白无涂布纸，第一眼仍接近白纸，不得出现泛黄、棕灰、茶渍、脏边、旧档案或明显纤维摄影感。
2. 低多边形只能属于新闻图、地图、编辑插图、印刷色块和裁切轮廓，不能属于纸张受光；文字安全区禁止三角明暗、斜向折面与 origami 感。
3. 拟物感不靠褶皱，改由纸边、层厚、folio 侧边、插袋、露边、夹持、胶带和有原因的接触影建立。
4. 禁止纸褶后若退回“纯白矩形＋统一大投影”的程序卡片，同样判失败。
5. 下一张必须同时通过“新印纸感”和“非纯平实体接触”两项，任何一项缺失都不能升格为 filled-state visual target。
