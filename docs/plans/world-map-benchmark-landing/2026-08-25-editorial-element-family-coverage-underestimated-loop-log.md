# 编辑部元素家族覆盖度低估：复盘

## 触发

用户指出 A327 大风格稿虽然已比官僚机构更像编辑部，但元素仍显得偏少，可能不足以供全游戏界面持续取材。

## 误判

父级与生成后复审把“一个编辑工作台里已经出现很多物件”误判成“视觉语言类别已经足够”。实际 A327 的多数物件仍属于暖白矩形纸、照片和票签，只覆盖出版制作中段，没有覆盖全游戏需要的导航、状态、异常、进度、确认与结果反馈。

## 原因

- 用物件数量代替形态家族数量。
- 用同一场景的丰富度代替跨场景的状态覆盖度。
- 过度关注咖啡、剪刀、夹子等氛围物，忽略标杆中的彩色封套、成册物、透明媒介、多尺度品牌图形和制作状态变化。
- 生成后过早建议做减法，未先验证全游戏功能角色是否覆盖。

## 修正

- A327 降级为编辑制作中段生态参考。
- 新一轮先建立 16 个可复用元素家族，重点补承载、导航、状态、异常、进度和结果。
- 结合 benchmark-board-01/02 增加切角、插袋、书脊、成册、圆形与透明媒介、大综合色页和多尺度品牌章。
- 下一张扩展板必须展示同一物件从原稿到圈改、裁切、覆盖和校正后的状态变化，而不是继续增加零散小道具。

## 放行条件

只有扩展板同时覆盖“进入—选择—编辑—异常—进度—完成—回响”，并且模糊文字后仍不像组件目录或档案墙，才可重新判断其是否足够供全游戏界面取材。
