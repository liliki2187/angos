### 操作链判断

当前主要操作链清楚：

1. 用户在左栏浏览并选择地区。
2. 中栏同步定位地区、路线与区域缺口。
3. 右栏给出该地区的具体状态、任务情报和下一步行动。
4. 对已开放地区，用户通过唯一橄榄 CTA 进入地区任务台。
5. 对锁定地区，系统保留选择与查看能力，但阻止进入，并解释未开放状态与缺口。

这条链路的优点是“选择”和“进入”被分开：左栏负责换上下文，右栏负责执行进入。用户可以检查锁定地区，而不会把一次普通选择误当作立即跳转。

646 的任务披露属于右册内部的次级阅读链，不会打断“选地区—看差异—决定是否进入”的主链路。它没有改变左、中栏像素，说明展开行为的影响域控制正确。

三种颜色分别承担焦点、风险与禁用，没有出现同色多义。照片按地区固定，也避免了状态变化时地区身份漂移。

需保留边界判断：地图的低多边形、网格、点位和路线目前只能证明结构语言成立；像素颗粒、最终纹理、生产级地形辨识与细节密度不在本次通过范围内。

### 六、状态一致性复核

#### 左栏状态

选中、预警、锁定三态通过边框和内容状态共同表达，卡片尺寸、位置和照片身份不随状态跳变。状态差异明确，同时保持组件家族一致性。

#### 右册折叠态

正文维持折叠，仅保留必要信息和 CTA。信息密度符合右册作为披露面板而非任务总表的定位。当前唯一轻微问题是“减号”对折叠/展开关系的语义提示偏弱，但并未造成结构误判。

#### 右册展开态

展开只替换正文区域为两条任务并显示 `2/4`，标题、状态、CTA 和册体边界不发生无关变化。状态切换局部、稳定，不会让用户误以为进入了另一块界面。

`2/4` 能表达当前披露或完成数量，但“其余两项为何未出现”尚未被完全解释。这属于局部状态文案的 P2 风险，不影响展开结构成立。

#### 右册锁定态

锁定态包含：

- 标题槽空置。
- 照片槽为深色空白。
- 未开放文案。
- 禁用披露。
- 禁用 CTA。
- 红色或灰色状态印中的相应禁用表达。

锁定信息在文案、内容可见性和操作能力上保持一致，没有“文案说未开放但按钮仍可按”的矛盾。风险在于深色空白照片槽可能被部分用户理解为图片加载失败；这是状态感知问题，不是状态逻辑错误。

#### 0 天规则

0 天规则位于中栏当前地区摘要中，与选中地区上下文绑定，且没有被 CTA 或任务列表遮盖。其出现位置和职责一致，UX 操作链判断通过。
