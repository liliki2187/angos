## UX 老哥诊断正文

### 1. 总结论

上一张效果图修复了“左右下角裸空”这一层，但没有先补齐真实功能盘点。结果是：四个角看起来都有物件，物件却没有组成正确操作链。左下日期仍然只是读数；中下两张大纸没有决定价值；A5.1 又以展开态抢占注意力。

正确动作链应为：

`看周次与当前日 → 扫描地区状态 → 选择左卡或地图针脚 → 核对地图与右册同源 → 阅读地区说明 → 按需展开任务情报 → 选择进入地区任务台或推进到下一天 → 推进日后果确认 → 世界状态刷新`

两个末端动作必须明确分层：

- `进入地区任务台`：当前选区动作，页面跳转，进入不耗天；是全屏唯一最强 CTA。
- `推进到下一天`：全局周状态动作，会递减剩余天数、推进截止与结算；是左下独立的次级危险动作。

推进日第一击只进入确认态，第二击才执行。它不能与右侧 CTA 共用位置、橄榄色、右箭头或命中区；左下应是深海军蓝 / 金属日程器，右侧仍是橄榄主 CTA。

### 2. 当前功能错误

1. 缺少“推进到下一天”。
2. 缺少推进后的后果预览与确认态。
3. 中下两张纸件没有真实决策价值，属于大容器空填充。
4. A5.1 错误地默认展开；正确默认态应收起任务情报。
5. 页面身份条应保持低权重，只显示期号 / 周次；剩余天数不要在顶部和左下重复。

### 3. 位置与尺寸错误

- B2.12 在 1920×1080 的正确三卡坐标为 `[66,36,306,240]`、`[66,294,306,240]`、`[66,552,306,240]`；上一张生图没有锁定到这个尺度。
- 中下两张纸件不应继续做成大型空卡；`bottom_receipt_card` 按 1.5 倍应为 369×207。
- A5.1 应保持 `[1398,45,480,780]`；照片 `[1431,192,414,264]`；披露行 `[1425,630,426,66]`；主 CTA `[1425,711,426,75]`。
- 右下档案尾应是安静承托，上一张过于正面、过重，容易被读成第二功能面板。

### 5. P0 / P1 / P2

- **P0**：目标动作“推进到下一天”缺失；同时当前 gameplay 没有独立命令，若直接把按钮画成可执行，会形成视觉承诺 / runtime 事实冲突。
- **P1**：frozen 几何漂移；中下重复或空白；顶部与左下时间事实冲突；日程器被画成普通米色信息卡，危险动作辨识不足。
- **P2**：右侧档案尾过重，A5.1 展开态容易被误认为默认态。

### 6. 禁止项

- 不得继续做只读日期卡。
- 不得一击直接推进日。
- 独立推进日命令落地前，不得把运行图伪装成已可用。
- 推进日与进入地区不得共用 CTA 样式。
- 顶部不得重复剩余天数。
- 中下不得出现“当前选中摘要”“世界状态已同步”等同义回音。
- 不得拉伸 frozen class。
- 不得增加右侧第二功能面板、symbol strip、第四地区或第三张跨栏回执。

### UX 结论

保留三栏组合，但内部必须重构。先锁黑白结构稿，再生图；不允许模型自行补功能。

### 5. 中下内容与默认态

- 左回执为红线预警，右回执为深链动向；只有存在真实 payload 才显示。
- 两张回执都是只读，不承担地区进入、推进日或选择状态。
- 369×207 之外保留有意负空间，不再塞第三张卡。
- A5.1 默认 `collapsed`；展开态只作为另一个状态，不进入默认结构稿。

### 6. 黑白结构稿视觉规则

- 只用黑、白、灰和明暗填充表达层级，不使用正式纸张材质。
- 地图必须是可辨识的连续世界大陆剪影，不是随机漂浮多边形。
- 左下日程器用深色实底，与右侧橄榄 CTA 在后续风格稿中保持不同材质。
- 右下文件袋尾只负责承重，不出现文字、图标、箭头或 hover。
- 所有带文字 / 点击的面保持正交。

### 7. UI Designer 自检

- 三栏与主要矩形全部可直接做几何断言。
- 左下拥有推进日、确认入口与后果预览；右侧主 CTA 不被削弱。
- 右下不再是裸背景，也没有被误做成第二功能区。
- 生图重点风险：模型可能扩大左卡、把回执做成三张、把 A5.1 默认展开、重复天数或给右下加按钮；这些都应直接判失败。

## 父级冲突处理

两位评审只有一处轻微冲突：UI Designer 草案曾在顶部保留 `DAYS LEFT 07`，UX 要求剩余天数只有左下一个主人。父级采用 UX 方案，顶部最终只保留 `ISSUE 001 / WEEK 01`。

其余无冲突，合并结果为：

- 左下是可操作的全局日程器，不是只读日期卡。
- 推进日首次点击确认并预览后果；与右侧进入地区彻底分离。
- 中下只保留红线预警 / 深链动向两张真实回执。
- A5.1 默认收起，唯一最强 CTA 仍是进入地区任务台。
- 右下全高载体无文字、无命中区。
- 黑白结构稿先通过，真实生图只允许填充该结构。
