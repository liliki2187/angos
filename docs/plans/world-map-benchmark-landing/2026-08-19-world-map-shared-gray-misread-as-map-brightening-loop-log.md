# 世界地图综合色灰度被误读为地图提亮 Loop Log

结论：A314 的功能物件转译方向成立，但父级把用户要求的“综合色带共同灰度”误译成“抬高大面积地图与纸件明度”，导致中央深色地图被浅灰米纸替代。`03-functional-style-translation-imagegen-native.png` 降级为 `functional_mapping_valid / map_value_hierarchy_overcorrected`，不得继续作为综合色目标。

影响：左选—中定位—右确认、三卡同构、地图宽块、钴蓝 Dossier、唯一 CTA 与日程回执仍可保留；综合色与暗场比例不能保留。下一张只允许修正地图底色、综合色彩度 / 明度阶梯和整屏纸件面积，不重开结构、图槽、状态或交互职责。

下一步：恢复深海军蓝 / 深石板地图母场，让钴蓝、冷青、橄榄、芥末共享冷灰但保留色相；纸件重新降为少量对比面。先通过全屏暗部面积、地图裁切高亮面积与 benchmark 并排 Gate，再交用户判断。

## 触发

- **日期**：2026-08-19。
- **用户反馈**：“不用为了不灰土把地图改成白色。我说的是整体色彩的灰度，不是让你非要把深色底的地图调白。你再对比一下美术标杆，看看怎么调整。”
- **命中错误家族**：F6「题材元素 / 单一参数替代塑造语言」。本轮用“提亮中间调与增加冷灰纸”替代综合色共享灰桥，属于过度纠偏。
- **已有规则被忽略**：`design/art-direction/clean-lowpoly-weekly-branch-style-guide.md` 已明确写明“颜色靠色相区分，不靠整体提亮”以及“增加灰度不是添加灰色组件、棕色蒙版或整体降亮度”。本轮不是缺规则，而是生成与放行时没有把暗场比例绑定为 Gate。

| --- | ---: | ---: | ---: | ---: |
| benchmark 01 全屏 | 0.290 | 0.098 | 49.7% | 12.9% |
| benchmark 02 全屏 | 0.276 | 0.087 | 54.6% | 13.0% |
| A314 转译稿全屏 | 0.365 | 0.141 | 32.1% | 26.9% |

综合色泥化的问题原本来自色相失去身份与棕褐污染，不是暗地图本身。A314 却让灰米纸成为约三分之一的全屏第一面积，而 benchmark 的第一面积是深海军蓝 / 近黑负空间；材质层级因此被完全倒置。

## 根因

1. **把可见内容亮度追近 benchmark 当成主目标。** `visible-content V_mean` 没有区分深色地图、亮纸和综合色物件，导致通过扩大浅纸面积也能获得“数值接近”。
2. **没有对地图单独裁切。** 全屏综合色看似更清楚，但中央地图自身已有 `37.7%` 高亮像素，远离标杆暗场。
3. **把灰度理解成 value，而不是 chroma。** 正确目标是综合色共享低彩度冷石板灰桥；本轮却主要提升 value，并用大面积中性浅纸消除棕褐。
4. **prompt 同时要求“地图母纸”和“中间调提高 15%–20%”。** ImageGen 合理但错误地将中央对象生成为浅纸版样；父级未在交付前用暗场比例否决。

## 修正规则

- “增加灰度”只允许改变综合色的彩度、色相距离与共享灰桥，不自动改变背景 / 地图的明度身份。
- 深色地图是已认可不变量：底场保持深海军蓝 / 深石板蓝，不能为了去土改成白纸、浅米纸或大面积中性灰。
- 纸张只承担标题、简报、Dossier 与局部回执的对比；不能成为中央最大面积和全屏第一主色。
- 地图大陆继续使用钴蓝、冷青、灰橄榄、低彩芥末宽块，但落在深底上；不得退回单色灰团、GIS 微网或高饱和糖果色。
- 综合色校正优先降低彩度、减少红棕成分与统一黑 / 灰掺量；禁止用整体提亮、纯白边、奶油纸或扩大浅纸面积完成。

## 下一张 Gate

1. 全屏暗部 `V<0.17` 应恢复到约 `45%–55%`，高亮 `V>0.62` 不高于约 `12%–16%`；仅作概念 QA 区间，不是生产 token。
2. 中央地图第一眼必须是深海军蓝 / 深石板地图场，不是白纸地图；地图裁切高亮面积须明显低于 A314 的 `37.7%`。
3. 遮掉纸件后，钴蓝、冷青、橄榄、芥末仍能从深地图中辨认；若只剩灰蓝单色团，失败。
4. 左卡、Dossier 与 Schedule 的纸面允许保留，但不得继续提亮；纸张只作少量阅读对比。
5. 结构、图槽、Card / Beacon / Disclosure / CTA / Schedule 职责、功能面正交与 BackDecor 权限全部锁定。
6. 本轮只做 ImageGen 定点色彩 / 材质编辑，不整屏换构图，不进入 Godot、atlas、manifest 或 `WeeklyRunGame`。

这组结果证明：整屏 ImageGen 对 `5%–8%` 的纸面明度收束不稳定，会在“白纸过量”和“全屏关灯”之间摆动。当前必须止损：v4 只作为综合色与物件关系的用户判断候选；后续若用户认可方向，精确纸面值应进入分区遮罩 / role-based paper token 校准，不再用整屏随机重采样宣称精确校色。
