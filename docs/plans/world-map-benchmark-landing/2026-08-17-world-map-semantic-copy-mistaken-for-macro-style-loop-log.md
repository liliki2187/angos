# 世界地图把语义换皮误判为宏观风格重构 Loop Log

## 触发

2026-08-17 用户审阅世界地图品牌语义候选 02 后指出：几乎看不出区别，主要只是小批注装饰；真正需要的是组件样式、整屏氛围等大尺度风格变化。

## 错误结论

父级、UX 老哥和 UI Designer 曾把以下变化判为品牌方向通过：

- `REGION PITCHES / NEWS LEAD / 现场记录` 等周刊文案；
- selected / warning 分色；
- UFO 便签、标题批注和编辑意见；
- 中央标签从锁章改为来源签。

这些变化改善了“读完文字后的语义”，但没有改变缩略图先读到的最大形状。

## 根因

1. 评审先读了文字和批注，没有先做遮字剪影测试。
2. 仍把 A291 的“三张浅纸卡＋暗地图＋巨大白纸”宏观构图当成不可动视觉真值。
3. 把钴蓝、橄榄、芥末、锈红当作小状态色，而不是大中型组件主材。
4. 把“没有 SCP 文案和大锁”误当成“已经拥有怪新闻周刊风格”。
5. 对 `60%` 改造幅度按文字、便签和局部像素计算，而不是按遮字后仍可见的壳体、地图、综合色块和明度岛计算。

## 产物降级

- 原 `brand_direction_confirmation_ready` 结论撤回。
- 不从 02 回裁组件，不继续局部清稿，不进入 Godot、atlas 或 manifest。

## 纠偏

下一候选统一采用「夜班四色套印选题台」：

- 左侧三张白卡整体换成钴蓝、橄榄、芥末编辑夹；
- 中央深蓝 GIS 面板整体换成冷青 / 钴蓝世界套印版样；
- 右侧连续白 Dossier 换成双色主编稿夹；
- 左下白 Schedule 换成综合色实体截稿日历器；
- 局部冷青与暖黄明度岛进入大面积物件关系。

## 防复发 Gate

1. 遮掉所有文字、批注、便签与小于 `80×80px` 的装饰后再评审。
2. 旧新图缩至 `480×270` 并模糊，左 / 中 / 右三处必须强差异。
3. 近白纸全屏建议不超过 `28%`；综合色必须成为主物件，而非小状态点。
4. 中央大陆先读成 `4–6` 组宽块面，不得用均匀小三角制造伪低多边形。
5. 若主要改动仍可描述为“多了便签、批注、夹子、阴影或颜色点”，直接判失败。

## 当前结果

`01-night-press-color-key-desk-1920x1080.png` 已从空白画布生成。旧新 `480×270 + 12px blur` 粗测显示显著明度变化约 `43.7%`，左 / 中 / 右分别约 `29.9% / 35.7% / 71.0%`；双审确认宏观 Gate 通过。当前只升为 `macro_style_direction_candidate`，仍待用户视觉裁决；地图靶标 pin、工业设备壳、locked 静态语义和 Schedule 分层不得被漏带入下一阶段。
