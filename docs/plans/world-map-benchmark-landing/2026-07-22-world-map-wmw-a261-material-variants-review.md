# WMW A261 材质与情绪三方案复核

## 结论

三张均为完整 1920×1080 整屏，结构与资源容量可供用户直接比较。父级、UX 老哥与 UI Designer 的共同排序为：

1. **无涂布独立周刊**；
2. **当代布脊专题册**；
3. **细网丝印增刊**。

方案 1 是共同推荐的长期生产基线。方案 2、3 不是错误稿，但分别带来布纹缩放稳定性和丝网分区 / 防摩尔纹成本。

## 共同通过项

- 三栏关系、整屏对齐和 A 规格保持；
- 8 个经典矩形图位、完整日程、四任务、唯一 CTA 保持；
- 无异形图、标题压图、多照片拼贴、假文字或新增伪功能；
- 配色职责保持为 A258 方案 1；
- 未出现旧档案、军情警报、政治宣传画或儿童手账身份；
- 回形针、胶带、打孔和地图四角只读作静态装帧，后续不得设置热区或 hover。

## 逐案复核

| 方案 | 五秒身份 | UX | UI / 落地 | 结论 |
| --- | --- | --- | --- | --- |
| 1 无涂布独立周刊 | 当代成人怪新闻周刊 | `PASS`，P0=0 / P1=0 / P2=1 | `PASS`，P0=0 / P1=0 / P2=1；暖灰纸九宫格＋低对比纸齿贴图即可 | 共同首选 |
| 2 当代布脊专题册 | 可收藏的布装怪闻专题册 | `PASS`，P0=0 / P1=0 / P2=2 | `ITERATE`，P0=0 / P1=1 / P2=1；布纹需降对比并做多分辨率防摩尔纹 | 温暖备选 |
| 3 细网丝印增刊 | 图形更强的独立丝印增刊 | `PASS`，P0=0 / P1=0 / P2=2 | `ITERATE`，P0=0 / P1=2 / P2=0；需恢复严格色采样并用分区 mask 控制网点 | 实验上限 |

## 父级质检

- 首轮方案 3 因地图轮廓和故事图片漂移被交付前淘汰，没有混入最终文件。
- 最终三案左栏共轴、右栏矩形头图、四任务、日程和 CTA 均无明显漂移。
- 方案 1 最轻松、最不政治；方案 2 的材料差异最直观；方案 3 第一眼最鲜明，但与方案 1 的差异更多来自对比度与印刷感，生产风险最高。

## 最小后续修正

若选方案 1：只把长正文安全区纸纹对比再压低约 20%。

若选方案 2：布纹对比降低约 35–45%，删除左下第一枚打孔附近的小灰破损痕迹，并验证 1920 / 1600 / 1366 三档缩放。

若选方案 3：恢复 A258 方案 1 的严格颜色采样，网点仅进入非文字纸边、既有状态色块和底板，覆盖率约 6–8%，并验证三档分辨率防摩尔纹。

## 当前边界

三案仍是无真实中文的风格方向候选，不能据此验收真实文案容量、最终锁图标、hover / pressed、确认态或 runtime 状态。用户选择前不拆图、不制作 atlas、不改 Godot、runtime、正式合同、frozen compact A5.1、B2.12 或 GDD。
