# WMW v5 整页基础功能终审

## 结论

v5 的三栏职责、整页几何和 A233 / B 均通过；右侧“红线升温”不恢复。当前总判定为 **局部 FAIL**：不能原样冻结，但只需局部语义修正，不需要重新设计整页。

## 通过项

- 左栏选择 / 日程、中栏空间定位、右栏地区确认与进入动作的职责边界成立。
- 地区名在左卡、地图和右栏重复属于同步确认，不是无意义复读。
- `限时数量 → 具体任务截止` 的摘要—明细路径成立。
- 右侧状态章删除后没有出现功能空洞。
- “进入地区任务台”底锚且不消耗天数的动作范围成立。

## 冻结阻断

### P0-1｜推进一天的后果不真实

v5 写“剩余 6 天 · 红线 / 深链推进”和“第 0 天进入结算”。GDD 与数据真源表明：

- 深链只在对应任务成功后推进，不随自然日推进；
- 天数归零进入 `editorial`，不是直接进入结算；
- 当前 runtime 没有独立 `advance_day` 命令，v5 只能标记为 `TARGET_ONLY`。

v5.1 应保留日程器几何，删除泛化状态词，改成真实 default / confirming 差量。

### P0-2｜东亚“可用”与初始真值冲突

初始 `reputation = 45`，东亚需 `reputation >= 55` 或 `roswell_dossier`。因此 Week 1 / Day 1 默认样例中：

- 东亚左卡必须为锁定；
- 地图针必须同步锁定；
- 锁定地区允许选中预览缺口，但 CTA 必须禁用。

### P1-1｜任务统计与任务行分类不一致

v5 摘要为 `线索 2`，两条 `permanent` 任务却分别标为“常驻 / 线索”；meta 又使用非真源的“科学调查 / 热点调查 / 神秘调查”。正式内容映射是：

- `sci → 科学纪实`
- `pop → 大众热度`
- `occult → 神秘玄学`

UX 与 UI 在摘要词上存在一处分歧：UX 的最保守方案是继续沿用当前 `clue` 统计并把两行统一为“线索”；UI Designer 建议直接按 `node.kind` 改为 `常驻 2`，两行统一为“常驻”。父级不把这项术语变化自动当作既定裁决。建议 v5.1 使用 UI Designer 的 `常驻 2 · 限时 1 · 深链 1` 作为候选，因为它与 `permanent / temp / chain` 三种结构类型一一对应；用户确认前仍标为候选文案。

### P1-2｜地图虚线是无数据依据的关系

当前路线层按 `REGION_DATA` 数组顺序依次连线并闭环，没有 route / edge / adjacency 数据。它会被理解为旅行路线、解锁链或推进方向。v5.1 应删除；未来只有存在正式 edge 数据时才恢复。

### P1-3｜审计注释混入玩家层

- `LOW-FIDELITY`、A5.1-H、尺寸与安全边距可以留在独立审计层；
- v5 文件名已升版，但图内仍写 V4，需改为 `LOW-FIDELITY V5.1 · TARGET ONLY · 1920×1080`；
- `地区说明只回答为什么去。` 不是玩家文案，必须从正文删除。

### P1-4｜结构目标与 runtime 边界

A5.1-H 四行、任务截止 preview 和独立日推进仍未接入 runtime。v5.1 仍只能是 `structure_wireframe / TARGET_ONLY`，不能称为运行截图或已实现功能，也不能覆盖 compact A5.1 frozen 合同。
