用户确认把相邻的 `任务构成` 与 `任务情报` 合为一个可展开摘要，并把节省的高度交给地区描述。A5 因此显式升版合同，不在 A4 旧槽上跨区绘制：

- `decision_facts` 从父合同删除；
- `region_body` 从 `[22,288,276,54]` 扩为 `[22,288,276,90]`，净增 `36px@1x`；
- `mission_intel_button=[18,390,284,44]` 与 `primary_enter_cta=[18,444,284,50]` 坐标不动；
- 合并行在一个 hit rect 内显示文档图标、`任务情报`、类型计数与 chevron；
- A5 首版曾错误认定固定纸面没有列表余量，并据此制作左锚短抽屉；该容量判断与抽屉方案已被本页 §0 的用户后续裁决推翻。

- 光栅文字 bbox：`41/41` 通过。

## 5. 目检结论

- **Collapsed**：PASS。旧灰色事实条消失，地区描述成为连续的 90px 区域；合并摘要读作页内 disclosure，橄榄 CTA 仍是唯一实体按钮。
- **Expanded**：历史技术 PASS、交互方向 FAIL。三行抽屉曾做到无遮挡与状态同步，但用户已否决卡外承载方式；不得把“能运行”写成“视觉 / UX 通过”。
- **QA 绑定机制**：PASS。Godot 的文字与粉色 / 青色证据框共用同一组 `Rect2`，625 只在 624 展开基线上追加 QA，不重建第三份场景。
- **当前待定**：纸内固定高度原位切换与常驻两条预览二选一。正式字体、locked 文案与最终动画 easing 需在新方案选定后重做状态压力。

## 6. 过程纠偏

本轮及时拦下三项证据工具问题：半透明 carrier 结构线造成预乘差异、PIL 双绘制上下文破坏展开板、Godot 说明层覆盖抽屉首行。三项均修生成机制并重跑，没有放宽 gate，也没有挪动运行时文字来掩盖。

项目要求的 `ux_laoge` 与 `ui_designer` 调用本轮都在只读阶段长时间无返回，未产出可引用正文。父级按两份项目 SKILL 完成等价诊断与规格，未冒充子 agent 结论；父级复核为 `P0=0 / P1=0 / P2=1`，P2 即上述展开方向待裁决。
