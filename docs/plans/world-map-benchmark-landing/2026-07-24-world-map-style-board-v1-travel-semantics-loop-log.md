## Human Brief

- **一句话结论**：我把“地图感、轻松感、彩色丰富和探索欲”组合成了旅游视觉语法，却没有检查玩家看到后究竟想“出发去哪里”还是想“追哪条新闻”。
- **旅行语义来源**：晴朗蓝海、黄绿陆地、暖黄纸、橙色 pin、罗盘、虚线行程、灯塔 / 海岛 / 山峰明信片和整排圆章共同形成旅行社首读。
- **为什么黑色幽默没有救回来**：`ARRIVED BEFORE DEPARTURE` 与飞碟禁停虽有荒诞性，但都附着在旅行路线与纪念贴纸上，只被读成旅途彩蛋，没有成为值得报道的异常证据。
- **为什么不能简单变暗**：整体压暗只能把旅行社改成军情台；问题是语义和色彩关系，不是单纯曝光。
- **本轮保留什么**：世界地图主舞台、左卡三态、右 dossier、独立日程器、部分粗颗粒大形与 WMW 图形家族。
- **本轮撤回什么**：当前路线、pin、罗盘、风景快照、贴纸横排、连续晴朗蓝绿和旅行频道式命名。
