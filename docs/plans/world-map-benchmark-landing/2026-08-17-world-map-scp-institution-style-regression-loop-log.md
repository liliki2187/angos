# 世界地图真实 ImageGen 整屏回归 SCP 严肃机构感 Loop Log

## 触发

2026-08-17，用户复核 `image_gen/2026-08-14/world-map-real-imagegen-filled-state-preview-v1/06-final-direction-preview-1920x1080.png` 后指出：当前版本与 SCP 式严肃办公机构似乎没有拉开差距，并要求先分析、不立即继续改图。

该反馈不是新口味，直接复发命中 A256：WMW 世界地图应让玩家先感到“成年人认真编辑怪新闻”，不能先读成政治 / 国安 / 军情 / 全球异常管控。

## 预期与实际

- **预期**：在三栏与全部功能合同冻结的前提下，用真实 ImageGen 组件把当前画面从程序原型提升为具有时髦周刊编辑部、怪新闻翻阅欲与少量冷面幽默的完整 filled-state 方向预演。
- **实际**：纸张、夹具、衬板、照片框和接触阴影明显改善，但高权重对象仍按“权限目录 → 异常监控图 → CASE FILE 权威案卷”组织。材质来源问题关闭，品牌身份问题未关闭。

## 第一眼断裂

当前首读链：

`机构刊头 → 编号 / 锁定 / 权限 → 全球异常监控地图 → 红圈证据 → CASE FILE / 双章 → 进入受控任务`

目标首读链：

`本期周刊 → 三条不同怪新闻 → 编辑部取材 / 批注现场 → 当前主稿候选 → 进入地区采编`

操作链仍可完成，但玩家幻想从“这周又出了什么怪新闻”变成“我获准处理哪份异常档案”。

## 根因

1. **标杆权限混淆**：两张 clean-low-poly weekly benchmark 同时包含优秀的色板、纸品、低多边形和出版版式，也包含 `TOP SECRET / CONFIDENTIAL / CASE FILE / radar / target reticle`。上一轮把前者的表现真值和后者的秘密机构叙事一起继承，未把“怎么画”与“Angus 是谁”分开。
2. **A256 情绪 Gate 漏跑**：上一轮双审重点验证“是否摆脱 Pillow 程序感”“三栏是否安全”“纸物是否统一”，没有重新执行五秒品牌身份测试，因此把材质进步误扩大成视觉方向通过。
3. **制度语义跨栏重复**：左栏 Eye / 编号 / `REGION FILE` / 锁定章，中央 Eye / 大锁 / 网格 / 红色围捕圈，右栏 `CASE FILE` / 红章 / 校样章共同把限制、许可和归档推成全屏主叙事。
4. **中央主语仍是异常监控**：地图面积最大，新闻照片与 UFO 便签只是被圈选的证物附件，没有成为本周选题的编辑高潮。
5. **右栏物件身份过度权威**：厚纸堆、大夹子、`CASE FILE`、双章和大面积空表把 Dossier 读成最终案卷，而不是正在编辑的主稿候选 / 地区版样。
6. **趣味单点化**：唯一显著笑点是黄色 UFO 便签；它无法抵消遍布全屏的制度载体。增加更多零散贴纸也不能改变高权重对象关系。
7. **色彩只服务状态**：橄榄、锈红、暖白和冷蓝主要编码锁定、警戒、批准与档案，没有成为不同故事、栏目和媒介的内容节拍。

## 不是根因

- 三栏职责与 `1920×1080` 桌面结构；
- FrontCarrier、同源新闻图、动态槽、Disclosure、CTA 与 hit rect；
- 深海军蓝、暖白纸、橄榄、芥末、锈红的基础色组；
- 地图、夹子、文件夹、编号、锁这些单个元素；
- 成人、克制、不萌化的气质；
- WMW globe、中文刊名与 ISSUE 票签；
- 正交功能面和三张统一 RegionCard 规格。

问题不在是否存在机构感，而在机构感是否压过周刊感。目标顺序必须是：怪新闻第一、专业编辑部第二、机构制度第三。

## 本轮仍然提供的有效证据

- 真实 ImageGen 组件能够关闭“程序生成的粗糙纸框”问题；
- 三栏、同源图片、唯一 CTA 与状态语义可以继续冻结；
- 右栏纸层、左栏稿架和刊头材质仍可作为表现参考；
- A308 可保留为“材质已改善但身份仍错误”的诊断样本。

## 纠偏规则

1. 两张 benchmark 只冻结为表现层参考：色板、宽块面低多边形、纸品体积、夹具、照片、彩色文件夹、版式切割与完成度。
2. `TOP SECRET / CONFIDENTIAL / CASE FILE / radar / target reticle / secret archive` 只允许成为局部反差材料，不得控制跨栏叙事和玩家行动逻辑。
3. 未来整屏候选必须通过遮挡测试：遮住顶部刊名和单张 UFO 便签后，若仍可自然被叫作“异常管理局世界监控终端”，则直接判品牌身份失败。
4. 不以换色、增贴纸、加夹子、加纸层、去污渍、放大 Logo 或单改 `CASE FILE → NEWS LEAD` 冒充纠偏；这些只能改变表面，不能改变对象之间的权力关系。
5. 三栏功能合同可全冻，但至少需重做约 `60%` 的高权重可见身份层：左栏地区线报身份、中央选题编辑现场、右栏主稿候选身份，以及跨栏出版图形 / 批注 / 栏目色关系。
6. 下一张图生成前，必须先获得用户对品牌语义 brief 的确认；本轮不继续生图。
