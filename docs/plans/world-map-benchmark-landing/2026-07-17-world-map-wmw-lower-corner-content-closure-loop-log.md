1. 左栏第三张 B2.12 卡后直接结束，左下大块宿主底色被读成“卡栈还没装完”。

## 根因

### 1. 阶段混淆

把 `runtime_state_preview / structure_only` 的技术验收结果，误当成 `filled_state_text_mock` 的整屏构图结论。组件坐标、命中区、状态同步和唯一 CTA 可以同时正确，但整屏仍可能像未完成。

### 2. “不造假功能”被错误推导为“允许裸空角”

A221 正确禁止 symbol strip、第二 CTA、伪功能票据，却被进一步误读成 A5.1 下方只能保持裸背景。实际上右下可以用无文字、无交互、无状态的物理档案载体完成视觉闭合，不必新增游戏功能。

### 3. 评审尺度过窄

上一轮 UX / UI 复核重点检查三栏职责、状态同步、锁定边界和 CTA 层级，没有把“遮住文字后四角是否仍有承重”设为独立 Gate，导致 `P0=0 / P1=0` 对整屏完成度产生了错误背书。

### 4. 中下用大容器代替真实信息架构

为保留中央摘要职责，直接拉出一张大空框；没有按内容量反推容器高度，也没有把当前选区与全局更新拆成可扫读的小纸件。

## 修正方案

- 左下：只放真实、只读的全局周程；不新增第四地区，不默认生成“推进一天”按钮。
- 中下：删除巨型空框，改为两张止于中栏内的纸件——当前选区摘要与全局更新回执。
- 右下：A5.1 后方建立全高档案夹 / 背页 / 文件袋尾，整区 `NO_TEXT / NO_HIT`；不新增任何字段、按钮或第二 CTA。
- 中央地图：概念图必须一眼可辨为世界地图大陆剪影，不能继续用随机孤立多边形充当完整地图。
- A5.1：标题槽填入当前地区名，但 frozen 几何、披露结构与唯一橄榄 CTA 不变。

## 防复发 Gate

以后任何被称为“完整拼接 / 整屏效果 / filled mock”的 WMW 产物，除结构与交互 Gate 外必须补充：

1. `four_corner_content_closure`：四角不得出现紧邻组件断尾的大块裸宿主底色。
2. `masked_text_silhouette_check`：遮住全部文字后，左下、中下、右下仍能读出明确承重与连续底线。
3. `container_density_check`：大面积容器必须有与面积匹配的真实职责；低信息量内容不得占用大型空壳。
4. `visual_content_vs_game_function_check`：视觉载体延续不等于新功能；右下若仅为纸叠 / 背页，必须无文字、无箭头、无 hover、无 hit rect。
5. `artifact_type_label`：结构接线截图必须显式标注 `structure_wiring_evidence`；不得用它证明完整构图或生产美术通过。
