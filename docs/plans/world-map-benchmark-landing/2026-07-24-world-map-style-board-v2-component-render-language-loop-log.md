## 决策条

- **结论**：总体方向保留，但组件画法未通过；v2 降级为“方向成立、局部组件返工”，不得按当前图继续拆件或扩展其它界面。
- **影响**：旅行社语义已修正，三段阅读链和综合色彩仍有价值；但 UFO 贴纸、新闻图像、符号带与日程器来自不同渲染语言，继续沿用会把跨屏统一建立在错误组件母本上。
- **下一步**：冻结构图、地图、综合色盘和 `02` 同源关系，只对新闻图像、UFO 贴纸、底部符号试条、待核实框与日程器表面做局部重画。

## 触发记录

- **原始问题**：用户指出 `UFO NO PARKING` 不是手绘风；`LOCKED` 站台 / 时钟不是粗颗粒低多边形，并要求检查同类问题。
- **失败归因**：证据与美术执行失败。生成前只锁了综合色调、题材语义和大构图，没有给不同对象绑定唯一画法；生成后只检查了“是否摆脱旅行社”，没有逐组件核对手绘、粗颗粒低多边形、机构印刷与克制拟物是否串线。
- **复发判定**：命中既有 F6“题材元素替代塑造语言”第 8 次、F7“符号矢量化 / 过度完成”第 4 次、F9“低多边形碎片化 / 照片滤镜化”第 4 次；不是新家族。
- **本轮处理**：返工，但不继续生图。当前候选状态改为 `direction_retained_component_render_language_rework_required`。

## 同类扫描结果

### P1

1. `UFO NO PARKING`：飞碟完美对称、等粗描边、平滑矢量填色，读成商品贴纸；概念保留，画法重做。
2. `LOCKED` 站台 / 时钟：摄影透视、钟刻度、站牌和人物空间感过强；必须改为强剪影和 `3–8` 个结构体块。
3. `02` 无线电塔：背景已有大块低多边形，但塔身保留细桁架；左卡、中央照片与右栏主图必须改用同一份粗颗粒母图。
4. `DEFAULT` 悬浮建筑：异常概念成立，逐窗与建筑效果图细节需继续压缩。
5. 底部五枚符号：同尺寸、同线宽、等距排列，读成软件工具栏；需按机构章、异常分类、时间、待确认与信号来源拆分轮廓重量和载体。

### P2

1. 标准虚线框＋居中问号读成开发 placeholder，应改为明确的编辑批注纸、未确认剪影或圈注。
2. `DAY 1` 日程器的独立时间硬件身份成立，但高光、深 bevel、厚投影过于产品渲染；只压材质，不改变其物件身份。
