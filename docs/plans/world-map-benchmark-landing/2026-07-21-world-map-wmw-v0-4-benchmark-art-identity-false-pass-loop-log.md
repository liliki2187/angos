# WMW v0.4 标杆艺术身份误放行 Loop Log

## 触发

用户复核完整 1920×1080 v0.4 后明确裁决：“版面没问题，但是界面的美术效果和美术标杆相去甚远，效果不太好。”

这是艺术身份 Gate 的误判，不是一般的审美偏好分歧。上一轮 UI Designer 与 UX 老哥均给出 `PASS，P0/P1/P2=0`，但用户五秒观感直接否定候选与 benchmark 的同族关系。

## 影响

- v0.4 从 `ui_ux_pass_pending_user_art_direction_decision` 降级为 `rejected_by_user_art_identity_mismatch_layout_retained`。
- v0.4 的三栏版面、内容容量、文字安全区、阅读链和 `x=30,w=348` 左栏证据继续有效。
- v0.4 不再是视觉基准候选、拆件源、confirming 底图或 Godot 输入。
- 上一轮 UI / UX 美术 PASS 正式撤回；功能 UX 结论只在自己的范围内保留。

## 根因

### 1. 把风格拆成了错误的最小集合

制作 brief 只抓住“深蓝底、暖纸、橄榄、低多边形、薄描边”，没有把强刊头、品牌图形、现代编辑拼贴、照片纸、标签 / 贴纸、局部附着物和多色中间调视为不可缺失的共同系统。因此结果可以做到整齐，却不可能像 WMW benchmark。

### 2. Prompt 权限倒置

v0.3 功能骨架与旧 imagegen 源排在 benchmark 前面；benchmark 只被定义为“visual DNA”。模型优先复制了规整三栏 Dashboard 的壳体语法。

### 3. Hard negatives 切掉了身份载体

`no icons / office objects / folders / floating components` 本意是阻止假功能和无关物件，却把编辑拼贴、品牌符号、层叠纸边和附着关系整类删除。禁止项应该针对“照抄具体物件、无功能堆物、桌面透视与假控件”，不能禁止视觉语言本身。

### 4. 精确装配进一步抹平了关系设计

生成源只有 1672×941，随后按 rect 裁切 / 缩放到 1920×1080，并复用同一卡壳统一三张左卡。该流程保证几何，却放大了重复硬壳、相同米纸和标准按钮，使“统一”变成“模板化”。

### 5. 真实文字回填没有艺术字系统

Benchmark 的粗刊头、窄标签、期号、图章与图形符号共同建立出版物身份。v0.4 后置的是通用 UI 字体和细线层级；即使 bbox 全部安全，也只证明文字放得下。

### 6. Review Gate 只检查卫生，没有检查家族身份

上一轮检查了对齐、重复 carrier、裁切、阅读顺序、CTA 和职责闭合，却没有执行：

- benchmark 五秒同族识别；
- 去字 25% 品牌轮廓测试；
- 形状 / 色彩 / 材质 / 字体 / 图像 / 符号六维继承矩阵；
- “dashboard / 军事档案 / 策略 HUD”负面分类。

## 修复 Gate

### P0：五秒艺术身份

候选与 benchmark-board-01/02 并排，去除说明文字并缩至 25%。第一读法必须是“现代彩色神秘周刊编辑拼贴”，不能主要读成 dashboard、军事档案或策略 HUD。失败时直接停止，不进入文字、atlas 或 runtime。

### P1：六维继承

形状语言、色彩角色、纸 / 照片材质、品牌字体、异常选片、品牌符号六项分别给出 benchmark 证据；至少三类身份载体必须在整屏 25% 尺度可见，且左卡、地图、日程和右档案必须共享。

### P1：Prompt 权限

- benchmark 为艺术身份第一真值；
- v0.4 只提供 geometry / content mask；
- hard negatives 只禁止假功能、桌面透视、旧档案脏污、金属浮雕 / 发光 HUD、路线和 GIS，不再整类禁止贴纸、纸边、夹具和品牌图形；
- 禁止直接从 v0.4 Prompt 微调重试。

### P1：评审边界

UX 只放行玩家阅读与交互；UI Designer 只放行版式 / 组件设计；艺术身份必须由 benchmark 逐项对照独立放行。`functional PASS` 不得再写成 `art PASS`。

## 下一步边界

- 不重开三栏版面与 v0.4 rect。
- 本轮只完成分析，不生图、不改 Godot、不改正式合同。
- 下一产物仍是一张完整 1920×1080 默认态艺术方向稿，不交孤立组件。
- 下一张默认态通过用户美术裁决后，才补 confirming 与拆件链。
