# WMW A258 三方向完整整屏生产 brief

## 目标

按 A258 生成三套完整 1920×1080 风格候选：以 A「怪新闻头版」承担规则矩形图片槽、稳定标题区、较低素材数量和三栏职责；以 C「世界奇闻特刊」只提供更轻、更丰富、更不像军情的情绪目标。

本轮只供用户选择视觉身份，不是 runtime filled-state、正式母本、拆件、atlas 或组件合同升级。

## 输入图片角色

1. `wmw-adult-weird-weekly-01-news-frontpage-v0-2.png`：唯一 edit target，冻结完整功能骨架。
2. `wmw-adult-weird-weekly-03-world-oddities-special-v0-2.png`：只提供轻盈度、地区色差和奇闻情绪；禁止复制异形图片、标题压图、纯白纸或亮黄 CTA。
3. `benchmark-board-01-clean-reference.png`、`benchmark-board-02-clean-reference.png`：只提供 clean-lowpoly weekly 的纸张、块面、出版图形和克制办公物件语言。

## 三套共同 prompt

Use case 为 `ui-mockup`，资产类型为完整桌面 16:9 游戏 UI 风格编辑。三套均执行以下约束：

- 保留 edit target 的三栏宽度、间距、组件外轮廓和阅读顺序；
- 恰好 8 个经典矩形图片槽：左侧 3 张地区图、右侧 1 张专题图、四条任务各 1 张缩略图；
- 每槽只能有一张图；禁止图中图、叠照片、证据拼贴、异形裁切和标题压图；
- 保留完整日程容量、四条任务、第三条 deadline 和底部唯一 CTA；
- 北美卡、地图选区和右专题继续讲同一条雷达路牌故事；东亚和太平洋保留 locked 故事；
- 地图第一、右专题第二、日程次级；
- 所有真实文字区留空；禁止伪英文、乱码、数字、条码、假标题和假文字横线；
- 禁止政治策略、军情管控、情报 HUD、警察证据墙、周历、筛选器、图例、跑马灯、第二 CTA 和其他伪功能；
- 纸面保持现代暖灰，不得纯白、泛黄、脏旧、折皱或档案化；
- 照片和地图使用有主次的中粗低多边形块面，禁止均匀 Delaunay / Voronoi 碎三角滤镜。

## 生成和程序边界

- 三套均由 built-in imagegen 分别真实生成一次；不是程序调色。
- `compose_wmw_a258_variants_v0_1.py` 只做 16:9 尺寸归一化、拼版、哈希与基础图像审计；不重绘、不调色、不新增 UI。
- 三套生成源均为 1672×941，归一化输出为 1920×1080；宽高比偏差 `0.00094462`。

## 用户裁决边界

本轮只选择第一次打开页面时的身份感：轻奇闻特刊、可信怪新闻头版或午夜增刊。locked 最终图标、真实中文、deadline 文案、hover / pressed / 二次确认和 runtime 热区不在本轮裁决范围。
