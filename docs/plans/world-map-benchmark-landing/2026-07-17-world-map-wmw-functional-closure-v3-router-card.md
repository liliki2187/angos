# WMW 三栏职责闭合结构稿 v3 Router Card

> **中栏已被 A232 / v4 取代**：v3 左右职责闭合继续有效；中央常驻红线 / 深链双条退出默认宿主，地图改为 924×936。

## 目标

在不改变 WMW 三栏身份、B2.12、中央地图和右侧地区档案语义的前提下，消除左下与右下职责真空，产出严格 1920×1080 的黑白功能结构稿。

## 用户硬约束

- 左下和右下不得再出现大片空白。
- 中央地图与两条 450×90 紧凑世界回执保留。
- 以已经确定的组件形式为基础，不靠新增功能填空。
- 当前只交黑白结构稿，不继续有色整屏生图。

## 路由

现有 UI 改进按项目双 agent 规则先由 UX 老哥诊断，再由 UI Designer 给出精确坐标；父级合并后确定性绘制、像素核验并登记用户修订。

## 关键修订

- 左栏恢复 `[36,810,342,246]` 完整日程器，以当前日、推进确认、直接后果和到期提示收口到 `y=1056`。
- 中栏保持 `[426,96,924,822]` 地图及两条 `[450,90]` 紧凑回执。
- 删除右侧浅袋口、后页和无框空白；新建独立结构候选 `A5.1-H [1398,24,480,1032]`。
- A5.1-H 主交付态展开四条现有可见任务，`进入地区任务台` 固定为 `[1425,957,426,75]`，下方仅 24px 安全边距。
