## UX 独立复核

UX 回看 ingredient、source crop、`fit` 有效窗口和最终 100% 局部后撤回 PASS，结论 `ITERATE / P0=0 / P1=1 / P2=0`。前次只检查文字是否落在名义 carrier、是否存在旧接缝，没有检查真实色域、闭合轮廓和端帽完整性；并把意外直切边误读成了设计收口。

## UI 独立复核

UI Designer 复算 protected bbox 后撤回整屏 PASS，结论 `ITERATE / P0=0 / P1=1 / P2=1`。单层 footer 与无旧接缝仍是局部事实，但不能推出状态签完整。修正时保持现有几何，只允许改变第三卡 footer ROI；新的状态签应为闭合紧凑签体，最终右边距至少 8px，并按实际可见色域而非名义矩形居中文字。P2 仍是右栏 12px 摘要的未来 runtime 清晰度验证。

## 修正门槛

- 禁止继续对含 protected object 的 source crop 使用未审计的居中 `ImageOps.fit`。
