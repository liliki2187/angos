# Loop Log：右 dossier A5 证据层污染被测 UI

> **结论**：A5 首轮证据生成中出现三类“证据工具污染被测内容”：半透明 carrier 线导致像素真源不一致、PIL 旧绘制上下文破坏展开板、Godot 说明层压住抽屉首行。三项均在 finalize 前被父级自检拦下并重跑，问题版本不进入复审证据。
> **影响**：UI 结构本身没有因此改变，但未经修正的 621 / 624 / 627 会制造缺层、叠字或错误裁区，足以误导视觉裁决；不能用“文件生成成功、颜色数足够”替代内容目检。
> **下一步**：证据生成固定为“先完成所有 alpha 合成，再创建文字绘制上下文”；说明层始终位于产品层下方且退出产品 ROI；QA 只在已保存的 expanded 基线上原位加框；对照板必须使用产品 ROI 同尺度裁片。

## 触发与归因

- **触发来源**：父级逐张原图与放大裁片目检。
- **失败一**：carrier 的 1px 结构线使用半透明 alpha，压到不透明父壳后发生预乘变化，导致旧 facts 区残留比对出现 64px 差异。修正为不透明结构线，保持整块 carrier 真源一致；gate 未放宽。
- **失败二**：PIL 在 alpha 合成前后同时持有两套 `ImageDraw` 上下文，旧上下文把展开板大片区域覆盖回背景。修正为所有合成完成后只创建一个说明文字绘制上下文。
- **失败三**：Godot capture 先画产品抽屉、后画左侧说明文字，说明字形越过自身区域并压住抽屉首行。修正为说明层先画、dossier / drawer 后画；同时缩短说明文案并退出复审裁区。
- **QA 口径修正**：625 不再重建第三套场景；它只在 624 expanded 原场景上追加 overlay，并继续执行 baseline 缺失像素检查。
- **复发判定**：属于既有“证据层不能破坏或替代被测内容”错误家族，不新建视觉风格规则。

## 固化检查

1. Python 展开板必须与收起板共享同一产品图层构建函数；合成过程中不得保留旧 `ImageDraw` 引用。
2. Godot baseline / QA 共用同一场景；QA 只能加 overlay，禁止重新装配产品节点。
3. 复审板裁片先验证 ROI 内无说明文字、调试标签或其它面板残片，再进入同尺度拼板。
4. `文件存在 + 退出码 0 + 非黑 + 颜色多样性` 只说明截图可读；最终视觉结论仍需逐张内容目检。
