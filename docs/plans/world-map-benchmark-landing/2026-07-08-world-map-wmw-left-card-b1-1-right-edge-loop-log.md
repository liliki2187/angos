# Loop Log：left_region_card B1.1 右缘竖带漏判

日期：2026-07-08  
触发来源：用户复审截图圈出 B1.1 四状态右侧边缘仍有问题，并要求复盘。  
关联产物：406 / 411 / 412 / 414，B1.1 v0.9.3。

## 决策条

- **结论**：B1.1 视觉验收不通过；右侧边缘仍有竖向接缝 / 暗带 / 源裁片边缘残留。
- **影响**：411 manifest 里 `composite_cleanliness = pass` 是误判，B1.1 不能进入后续 class 生产方法确认。
- **下一步**：本轮先降级记录与复盘；下一轮若修，只做局部合成返工，并新增右缘 close-up gate。

## Human Brief

- **一句话结论**：我把“绿条残留”当成颜色阈值问题处理，却漏掉了非绿色的右缘竖向接缝；这说明先前 `composite_cleanliness` 的人工目检太粗。
- **实际处理过什么**：修掉了双地球、warning 双三角、上缘越界和饱和 greenish 残留；但没有清理 / 验收右侧低饱和竖带。
- **问题卡在哪里**：右缘区域介于合同 photo_slot 和卡壳边框之间，既不像典型照片溢出，也不被 greenish 阈值捕捉，所以被我误读成正常边框阴影。
- **为什么会复发**：我看的是缩略对比板和整卡运行截图，没有强制四状态右边缘 100% / 200% 裁切；同时把“全帧 greenish=0”错误扩展成“无视觉残留”。
- **下一步怎么防**：`composite_cleanliness` 必须拆成重复元素、槽外溢出、源图残留、边缘接缝四项；边缘接缝必须有局部裁切图，不能只靠整卡肉眼。
- **本轮不要继续做**：不继续批量生产其它 class，不宣称 B1.1 通过，不把 Godot 截图生成成功等同于视觉通过。

## Loop Detail

- **当前产物类型**：`vertical_slice_proof` 的失败候选。
- **失败归因**：验收对象误判 + gate 执行口径过窄。
- **复发判定**：属于“几何 / 统计 gate 不能替代内容目检”同族复发；上轮刚把 `composite_cleanliness` 写入文档，但这次证明仅写 gate 名称不够，必须要求可见局部证据。
- **本轮处理**：411 manifest 降级为 fail；STATUS 降级为 B1.1 不通过；复审文档追加用户复审修订。
- **最小下一步**：定义 B1.2 右缘 close-up gate 后再修合成。

## 沉淀判断

- **是否为单次 bug**：否。它是资产化 UI 程序合成验收口径问题。
- **是否为可迁移错题**：是。所有局部拼接 UI、atlas、状态皮肤、照片槽替换都会遇到同类边缘接缝。
- **写入 design-decisions / 采纳记录**：否。这不是用户采纳的新设计方向。
- **写入 onboarding hard rule**：需要补强既有条目，不另开新家族。
- **是否需要脚本 / gate 更新**：需要。下一轮应至少生成右缘局部 QA 图；若再次复发，再把右缘带状异常做成脚本检测。
