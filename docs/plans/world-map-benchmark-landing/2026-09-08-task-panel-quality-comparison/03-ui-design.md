# 传统路径第二步：UI Designer 方案原文

此稿基于共同题目与 UX 诊断完成，未收到父级独立分析。初稿之后，父级发现共同 brief 未显式写入上一轮“任务不能和纯信息一样，否则容易漏看”的用户原话，已补充并请 UI Designer 自主复核；这个输入遗漏属于父级，不据此判断角色能力高低。

## 初稿

UI设计师方案｜世界地图任务区与右栏

主推荐：把右栏做成“一张新闻来稿，末尾附调查摘要”。保留暖白主纸、蓝青背纸、夹子和蜜黄入口，让图片与新闻承担画面主角，任务文字延续纸面的阅读秩序。赞同 UX 的整合方向；折叠后入口是否移动，我建议直接保留固定位置，无须为这个可逆选择另设审批。

已实际查看局部图、整屏、长内容、折叠、锁定、空态、选定候选、两张标杆查看副本与两张母纸件，并查阅相关布局代码；未运行交互、制作或修改文件。

**右栏先建立一条连续的阅读路径。** 地区名降一级，成为来稿来源；新闻标题成为最强文字。图片从当前约 430 宽试增至约 500，与标题、正文、任务共享左边线和阅读宽度，继续完整等比显示。增加的高度从地区标题带、短新闻标题预留空槽和任务行冗余间距共同回收。新闻标题按实际一至两行占高，正文紧随，正文结束后再留明确段距进入任务区。这样洗衣店图片和“出现一片海”会成为同一个故事，而非上方一幅居中插图、下方几块文字。

**任务区改为纸上附栏。** 去掉浅青大底、深青满宽标题条和任务左竖线，只在新闻与任务之间留一条细墨线。标题行写“地区任务 · 4”，右侧明确显示“收起预览 −”；下一行保留“限时 1 · 线索 2 · 深链 1”，再接真实提醒。三个计数已经互斥，不改分类，也不把前两条包装成“推荐任务”。限时内容未必出现在预览里，所以总体提醒必须保留。

每项先排完整任务名，下一行紧跟“线索 · 调查耗时 2 天”；类型不再独占左列。名称与元信息间距小，两项之间间距明显更大。长标题允许两行，由实际文字高度推动元信息与下一项；类型、已有风险／追踪说明、剩余天数各守原有语义，不为画面补造截止时间。任务保持只读，不加卡片悬浮或箭头，避免暗示点击任务即可进入。

**资源分工也随之收敛。** `region-tag.png` 是带外缘的独立标签纸，本方案把它留给地图标签等物件，不再从局部取样染成两层任务面板。暖白主纸直接承载新闻和摘要；`action-paper.png` 继续承担入口。标杆值得继承的是“大图片、少量宽色块、清楚的叠放关系”，并非把每段文字都装成另一张纸。无需新增任务插图，现有同地区图片继续三处同源。

**入口固定，状态内容自然收束。** 收起后，任务标题、分类和提醒仍从正文下方连续排列；隐藏两项后留下暖白纸面，不保留空框，也不把说明孤零零放在中央。代价是折叠不会把空间转交其他内容，但入口稳定，画面重量仍会下降。锁定时在摘要位置紧接真实解锁条件，入口禁用；开放空态保留可进入状态及暂无任务说明。按钮和“进入不消耗天数”整体略上移，为纸边留足余量。

这属于中等成本的右栏布局重排：涉及文字测量、图片区尺寸、任务行高度与折叠热区，资源新增需求低。仍需看同尺寸默认与长内容成品，验证图片增大后是否挤压提醒、两行任务是否仍从容、折叠留白是否自然，并实测展开和入口。现有证据支持这个方向，尚不能证明成品一定更好。

## 补齐原始用户约束后的修订

UI设计师方案｜世界地图任务区与右栏修订

这条原始约束改变了任务区的处理：**“同暖白纸面＋单条细墨线”区分力度不足，我撤回这一局部建议。** 它能改善连贯性，却可能把任务重新压成新闻附注，削弱已经建立的任务识别。

修订为：在暖白来稿下半部放置**一张浅矿物青的任务附页**。它与新闻共享阅读边线，但以明确的底色和单一纸边形成独立物件；左上角用一小块较深矿物青页签承载“地区任务 · 4”，右侧写“收起预览 −”。页签只占标题的一部分，不恢复整条深色横栏。附页内部不再套框、加竖线或给每项另铺底。这样，远看能凭青色块找到任务，近看由标题、分类、提醒和成组条目完成阅读。

母件应提供平静可写区和一层清楚纸边，避免继续把同一标签局部染色拼成标题与底板。新闻图片仍是右栏最大的图像块，蜜黄仍强调进入操作；矿物青专门区分任务承载面，三者各有明确作用。

收起时附页缩至标题、分类和提醒所需高度，下面露出暖白主纸，CTA 保持固定。锁定与空态仍使用这张任务附页，按实际条件撑开内容，不以大片空底假装有任务。

新闻层级、图片同源、任务只读和文字按实际高度排布的建议继续成立。新增代价是一张适配任务内容的纸件及其高度调整。成品重点验证：玩家能否迅速找到任务，同时青色附页是否又抢过新闻；这两个要求必须在同一张整屏里共同成立。
