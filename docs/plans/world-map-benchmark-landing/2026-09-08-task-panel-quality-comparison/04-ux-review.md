# 传统路径第三步：UX 定向复核原文

UX老哥诊断｜世界地图任务区方案复核

修订方向兼顾了任务发现与整体组织：浅矿物青附页保留明确入口线索，局部页签替代满宽深条，任务仍可独立识别。此前撤回“同纸面单细线”源于父级补齐用户约束，不据此评价角色能力。本次仅为未制作成品的方案评审，尚未验证视觉效果。

需要收敛两处取舍：

- **内容高度优先于照片目标尺寸。** 约 500 宽只能作为试排值。双行新闻标题、双行提醒、两条双行任务与元信息必须共同放入固定 CTA 上方；若不足，应先回调照片尺寸和装饰间距，不能缩字或隐藏提醒。地区名可降级，但仍须清楚标识当前地区。
- **附页独立不等于条目可点击。** 折叠热区应对应标题行的明确操作，任务正文不增加按钮式边框、悬浮或箭头。类型与耗时贴近标题能改善归属；各条之间仍需留出明显间隔。

收起时附页减高、CTA 固定可以保留，新增的暖白留白需看整屏是否自然。锁定条件、开放空态应紧随摘要，保留各自入口状态。互斥分类与现有预览顺序已核实，无须再次请用户确认。

建议先验最拥挤长内容，再比较默认、折叠、锁定与空态；同时检查“任务容易找到”和“新闻仍有吸引力”，不能仅用无溢出判定完成。
