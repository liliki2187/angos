# WMW 左卡 B2.8 合同、风格与配料来源 Loop Log

> 日期：2026-07-10  
> 触发：用户连续指出 B2.7 的状态徽章贴边、字形截断与地球旧层残留，并明确要求先反思反复拼接失败的原因，再按结构方案修复。  
> 结论：B2.7 不是单一坐标错误，而是“错误合同被当成视觉真源 + 提取阶段被目标槽裁断 + 从压平图回采配料”三种边界错误叠加。

## 一、为什么反复修改仍然出错

1. **把合同一致误当成标杆一致**：旧合同 `action_badge` 只记录早期测量槽位，并未证明最终美术右留白。B2.7 对齐旧槽后，程序 gate 全过，视觉却比候选 B 向右偏约 11px。
2. **先用目标槽裁源，再检查目标槽**：四个状态字形提取 bbox 的左边都恰好是旧合同 `x=316`；形状在进入运行时之前已经被切断。后续 purity、居中和边界 gate 只能证明残片干净，不能追回缺失轮廓。
3. **配料来源仍是压平成品**：地球线稿本身已纯净，但照片从 428 atlas 裁出；428 已含旧地球 / 框体叠层，因此旧月牙沿照片层重新进入最终合成。
4. **gate 只证明内部自洽**：几何中心、色族、alpha 与非黑截图都可通过，却没有回答“视觉 gutter 是否像标杆”“源形状是否完整”“照片裁源是否完全位于纯场景内部”。
5. **来源文件正确不等于来源矩形纯净**：B2.8 首轮改用 396 后仍复用历史相对裁源坐标，三张照片带进右框。幸好配料关先出 510 并人工复核，正式 atlas 被阻断；这暴露出 provenance gate 还必须检查裁源 bbox 和边缘内容。
6. **非黑截图仍可能是局部残帧**：B2.8 最终巡检时，518 一度只绘制左侧 QA 脏区，标题或卡片片段随机缺失；文件存在、退出码 0、非黑与颜色多样性都能通过。根因是同一 SubViewport 的第二次增量重绘未稳定覆盖整张 render target。capture 已改为 normal / QA 各自使用新 SubViewport，并新增“QA 不得丢失 normal baseline 可见像素”的完整性探针。
7. **旧足迹退役仍然用了可见 inpaint**：B2.8 虽然不再保留旧 badge 像素，却调用 B2.7 的 `harmonic_inpaint()` 对旧八角足迹做 700 轮邻域扩散。新 badge 左移后只覆盖到约 `x374`，旧足迹仍延伸到 `x382`；右侧裸露扩散区形成四状态一致的纵向涂抹。`exact_legacy_pixels=0` 反而只证明像素被改写，完全不能证明底板纹理自然。

## 二、本轮止损修法

- 依据用户 A174 显式升合同到 `0.8.3`，只修订 `action_badge=[144,101,44,44]`；其它 frozen 字段不动。
- 以候选 B 标杆中心 `(166,123)` 和右视觉留白约 `16px` 为美术校准，B2.8 成品右留白为 `17px`。
- 完整字形先在候选 B 全徽章区域识别，再装入目标画布；禁止用目标合同矩形裁取源形状。
- 照片改用 396 的逐张实测绝对内容矩形，裁源必须在源照片内、位于源地球右侧、位于源框内侧；增加边缘长直框线扫描。
- 地球仅保留独立暖色线稿；照片、地球、框体、状态字形四个来源互不回采。
- 证据依赖顺序固定为：标杆位置对照 -> 纯配料板 -> atlas -> Python -> 16 点板 -> Godot。

## 三、新增防线

1. `state_badge_contract_and_style_alignment`：合同中心、外环中心与标杆视觉 gutter 一起验，不再只验合同自洽。
2. `runtime_icon_shape_completeness`：记录完整源 bbox、追回宽度、透明 padding 与 border touch；源提取独立于目标槽。
3. `photo_ingredient_overlay_contamination`：记录纯场景来源、绝对裁源 bbox、源照片 / 源地球实测 bbox、边缘浅色长直线和色键绿统计；压平 atlas 直接禁用。
4. `globe_linework_ingredient_purity`：地球贴片只能包含目标暖色线稿与抗锯齿 alpha。
5. 合同若与已采纳标杆冲突，执行方必须停下上报；经用户裁决后显式升版合同，禁止一边坚持旧合同一边在素材上补丁迁就。
6. `screenshot_content_validity` 增加 baseline 完整性：QA 可以新增 overlay，但采样点不得把 normal 的可见像素变成近黑；B2.8 阈值为 stride `4px`、缺失采样 `<=20`。
7. 退役结构足迹不得以 harmonic inpaint、模糊、扩散或生成色带作为最终可见底板；新组件没有覆盖的区域必须来自显式底板 / 边框配料，并做纹理连续性目检。程序 gate 必须统计“最终暴露的修补像素”，不能只统计旧像素是否消失。

## 四、回归结果

- 合同校验：四份 world-map class 合同与页面重叠检查全部 PASS。
- badge：1x 右视觉留白 `17px`；环 / 内芯中心误差 `<1px`。
- runtime icon：四状态最小 padding `4px`，border touch `0`，非目标像素 `0`。
- 照片：边缘浅色长直线最大 `1/5/0/0px`，阈值 `24px`；旧地球和源框不在裁源矩形内。
- 地球：opaque `1017`，非目标像素 `0`。
- Godot：4.6.2 windowed OpenGL3 生成 517/518，非黑且颜色多样性正常。
- Godot 局部残帧探针：最终 517/518 的 baseline 缺失采样为 `0`，阈值 `20`。
- 用户复审确认徽章右侧可见 harmonic inpaint 涂抹，B2.8 已降级为 `visual_fail_exposed_harmonic_inpaint`；程序通过不替代用户观感裁决。
