# WMW 左卡 B2.8 状态徽章与地球分层复审材料

> 版本：B2.8 / v0.9.14  
> 日期：2026-07-10  
> 当前状态：`visual_fail_exposed_harmonic_inpaint`，不是冻结生产资源。用户复审确认状态徽章右侧存在明显程序涂抹纹理。  
> 本轮范围：修正状态徽章视觉位置与完整字形，清除地球叠层来源；卡体尺寸、照片槽、文字槽、整卡 hit rect 与其它 class 均未改。

## 一、用户指出的三项缺陷

1. 欧洲灰域右下状态徽章贴近右框，破坏候选 B 标杆的视觉留白。
2. 靶心等运行时字形在提取时已被合同左界裁断，后续缩放只能得到“干净的残片”。
3. 地球线稿虽已独立，但照片仍从 428 压平 atlas 回采，照片里自带旧地球圆章下缘，最终形成第二个月牙层。

## 二、根因与结构修复

- B2.7 把旧冻结 `action_badge=[158,106,38,38]` 当成美术外环真源；该槽中心为 1x `(177,125)`，候选 B 标杆中心约为 `(166,123)`，因此“严格对齐合同”反而把徽章推向右框。
- 用户采纳 A174 后，`left_region_card` 合同显式升为 `0.8.3`，仅把 `action_badge` 修订为 `[144,101,44,44]`；卡体与其它 frozen 字段不变。
- B2.8 外环 2x bbox 为 `[290,204,374,288]`，中心约 `(331.65,245.43)`，距真实右框视觉留白为 1x `17px`，与候选 B 标杆约 `16px` 对齐。
- 四个状态字形改为先在候选 B 的完整徽章区域识别完整形状，再等比收进 `44x44` 透明画布；提取不依赖目标合同边界。四边最小透明 padding 为 `4px`，边界触碰像素均为 `0`。
- 照片不再从 428 或其它压平 atlas 裁取，改从 396 原始四场景的实测内容矩形取普通矩形配料；裁源始于旧地球 bbox 右侧并止于源卡框内侧。
- 地球只保留独立米白线稿 alpha 配料，非目标像素为 `0`；合成 z 序为“纯地区照片 -> 镂空壳与中性状态底盘 -> selected 光晕 -> 地球线稿 -> 运行时文字与状态字形”。

## 五、首轮配料关主动拦截

B2.8 第一次生成 510 时，selected / available / locked 的照片右端仍可见浅色源框线。原因是虽然来源已从 428 改为 396，但继续复用了 B1.1 的历史相对裁源坐标，三张裁源右界仍跨进 396 源卡框。该轮未进入正式 atlas：改为逐张实测绝对内容矩形，并增加边缘长直框线扫描后重跑。第二次 510 才作为冻结证据进入完整链。

## 六、协同评审意见

### UX 老哥

- P0：0。右下符号应是“地区状态徽章”，不是独立按钮；整张卡负责选择地区，右侧 dossier 主 CTA 才负责进入。
- P1：过度贴边和字形截断会降低状态可信度，并让徽章误读成独立小按钮。`selected / available / warning / locked` 必须分别表达当前选中、可选择、可选择但有风险、不可进入。
- 验收不能只看合同框命中；还要看视觉 gutter、图形完整性以及 warning / locked 的状态距离。

### UI Designer

- 候选 B 视觉中心约为 1x `(166,123)`；B2.7 依据旧合同落到约 `(177,125)`，水平向右偏约 `11px`。
- 旧合同证明的是当时的槽位记录，不证明最终美术位置正确；应显式升版合同，再让 Python / Godot 共享新锚点。
- 图标配料必须以完整源形状为起点，透明 padding 与外环光学内边距需要单独 gate。

### 美术指导

- 状态徽章需要恢复候选 B 的右侧呼吸空间，避免贴框形成“附着按钮”感；状态字形在内芯里应有完整轮廓和稳定光学留白。
- 地球应是纯线稿覆盖层；若背景需要颜色，应由下层地区照片提供，不能把旧圆盘或旧照片快照夹在地球配料中。
- 禁止继续从压平成品回采内容；照片、地球、框体和状态字形必须保持独立来源。

## 七、等待用户裁决

2026-07-10 用户复核 509 后指出四状态新徽章右侧均有纵向涂抹。代码与像素探针确认：B2.8 先用 `harmonic_inpaint()` 对旧徽章足迹做 700 轮邻域扩散，再把更靠左的新徽章覆盖其上；旧足迹右侧未被新底盘盖住的部分直接暴露。探针区域 `x374..382, y196..295` 中，旧足迹 mask 为 `576px`，新底盘仅覆盖 `177px`，裸露 harmonic inpaint 为 `399px`。这不是低多边形纹理或截图缩放，而是程序补丁痕迹。

B2.8 已降级为视觉失败；此前程序 gate 只证明旧语义像素被改写、几何位置和字形完整，没有验证“退役足迹的替代底板纹理是否自然连续”。下一轮必须从显式底板 / 右框配料重建该区域，禁止继续调 inpaint、扩大覆盖或用新色带遮住。
