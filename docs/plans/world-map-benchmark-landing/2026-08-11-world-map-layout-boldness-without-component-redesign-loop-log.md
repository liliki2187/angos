## 五个板块的真实缺口

1. **刊头**：仍是大标题、圆章和票签并排；需要重做成刊名、缩写、globe、期号、栏目引线、短色码与裁切标记组成的不对称出版品牌锁。
2. **地区卡**：仍是编号、缩略图、说明、右上状态的同模板列表；需要让 selected 成为展开的主选题封套，locked 成为压低的封存索引，并改变每态的字号、图文比例与状态位置。
3. **地图 / 证据层**：仍是世界地图、地名与 Eye pin 外加漂浮照片；需要让地区色块、异常快照、批注、状态章与选中关系共同组成编辑证据底板。
4. **Dossier**：仍是标题、状态、大图、正文、折叠行、CTA 的纵向表单；需要重做成本期地区头条首页，以出版版式组织异常命题、任务构成、情报披露与进入动作。
5. **Schedule / CTA**：仍是禁用表单卡和普通橄榄横条；需要分别重做成实体排期器 / 撕页日历与签批 / 频道切入物件，disabled 与 action 由物件构造表达，而不是继续依赖旧字段框。
