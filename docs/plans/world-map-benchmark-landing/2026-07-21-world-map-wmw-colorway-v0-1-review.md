# WMW 整屏配色方案 v0.1 复核

## 结论

四套候选均保留用户指定基底的三栏、全部框体、地图、照片裁切、pin、任务行、日程器与 CTA，并只改变语义颜色和既有表面印刷质感。用户复核后确认：这种受限变量实验无法改变整屏“全球异常管控 / 政治游戏”的体验承诺。四套已降级为诊断证据，不再进入用户配色裁决，也不能据此进入拆件或 runtime。

**2026-07-21 用户复核修订**：`rejected_by_user_serious_political_tone_diagnostic_only`。下一轮不再继续换色，应在保留功能布局的前提下解冻照片故事钩子、组件物件隐喻、出版图形、地区差异和受控非对称拼贴。

## 为什么现在给用户看

用户已认可当前版式，但认为此前美术效果与标杆差距较大，并要求先固定这张整屏，只探索有明显区分的配色与质感。此对照板用于选择下一轮正式美术方向，不用于复审功能、尺寸或布局。

## 用户需要判断

1. 哪一套最像 WMW 应长期使用的现代神秘周刊。
2. 哪一套与两张 benchmark 的色彩 / 印刷气质最同族。
3. 哪一套在地图、右档案和主 CTA 之间的层级最舒服。

## 父级目检

- A：暖纸与橄榄最接近当前 benchmark 主线，稳健但最接近基底原色。
- B：芥末黄与钴蓝互补最强，出版物与特刊感最明显；返修后第三任务左右两处均恢复唯一危险色。
- C：冷白与极地青最干净、现代，但要防止后续落地滑向工具软件。
- D：灰白、近黑与高色度酸绿对比最大，地下刊物感最强；返修后与 A 不再只是轻微橄榄差。

## 几何与差异审计

- 四张最终图均为 `1920×1080`。
- 与归一化基底比较，四张最佳边缘相关位移均为 `[0,0]`；未发现整屏平移。
- 零位边缘余弦相似度：A `0.9237`、B `0.9091`、C `0.9054`、D `0.9119`。
- 六个语义采样区的两两 RGB RMS 距离均不低于 `21.80`；不是四张轻微色温变化。
- 对照板为 `3840×2280`，每格嵌入完整 `1920×1080` 图，无裁切。

完整机器数据见 `wmw-colorway-v0-1-audit.json`。边缘相关只能发现全局位移或明显结构漂移，不替代人工版式目检。

## UI Designer 结论

首选 A「核心橄榄周刊」：它与 benchmark 的主色、纸张温度和 WMW 既有照片最兼容，图像污染与层级失衡风险最低。B / C / D 分别承担更活跃、更冷静和更实验的清晰备选。

## UX 老哥结论

四套必须保持地图第一、右档案第二；selected 与 CTA 同色族，locked 冷暗，左下日程次级，第三限时任务是唯一危险色。四套已按这些不变量生成；用户只需裁决视觉方向，不需重新判断功能布局。

## 边界

当前状态为 `rejected_by_user_serious_political_tone_diagnostic_only`。本轮停止继续生图；新的体验 brief 形成并由用户确认前，不生成正式有字整屏、confirming、拆件、atlas，不改 Godot、正式合同或 frozen compact A5.1。
