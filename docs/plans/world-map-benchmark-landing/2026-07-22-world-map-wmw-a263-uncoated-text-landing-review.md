## 为什么原双审假通过

- `safe_text()` 只验证 `text bbox ⊆ 作者定义的 safe rect`，没有验证 safe rect 属于真实可见载体。
- 来源差分为 0 只证明允许区外未变化，不证明允许区内补片层级、接缝和语义间距正确。
- 父级、UX 与 UI Designer 共享同一份 audit 和缩小整屏，没有建立独立 100% 局部裁切证据链。
- “任务情报”加粗后只复核了指定修改，没有扫描上下至少 100px 邻域，字号修正反而加剧了拥挤。

## 仍然有效的证据

- 方案 1 的三栏、八个矩形图槽、图片、地图、无涂布材料与配色方向未被误改。
- 默认态和确认态各有 38 条文字记录，均在作者定义的 safe rect 内；该事实只能标为合同框内含，不再标为视觉安全通过。
- 两态差异仍只位于日程允许区，允许区外差异为 0。
- Godot、正式合同与 atlas 未修改。
