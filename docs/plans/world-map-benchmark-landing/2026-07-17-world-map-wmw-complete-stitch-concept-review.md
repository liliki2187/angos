## UX 老哥诊断原文

### 1. 总结论

界面类型：地图 / 节点选择 + 当前地区详情。当前截图是 `runtime_state_preview`，但中央地图仍带有 `structure_only` 性质；用户现在要求的是可判断整屏构图的 `filled_state_text_mock`。

**当前问题不是“留白略多”，而是把组件级技术验收的留白，误当成了整屏视觉稿也可成立的留白。**

在独立宿主、frozen 坐标、点击范围和状态接线验收中，A5.1 下方没有功能可以是合理的；但当这张图作为“正确的大致拼接效果”展示时：

- 左栏内容在第三张卡后突然结束，左下角像组件未装完。
- 右栏 A5.1 在屏幕约四分之三高度处结束，右下角像画布漏出。
- 中下是一张面积很大的深色空框，不能把左右两处断口组织成完整底带。
- 三栏虽然技术上都存在，整屏剪影却不是一个闭合的出版工作台，而是“三组已挂载组件漂在测试底板上”。

这不是要求把空白全部塞满。正确方向是：**四角必须有视觉承重，模块必须对应真实职责；没有新机制的地方，用真实载体延续，不得伪造功能。**

玩家动作链应保持：

`① 看本周全局状态 → ② 扫左侧地区状态 → ③ 选择地区 → ④ 核对地图焦点与右册是否同源 → ⑤ 按需展开任务情报 → ⑥ 通过 A5.1 唯一 CTA 进入地区任务台`

现有唯一 CTA 和地区选择链没有被阻断，因此本轮 **P0 = 0**。但整屏呈现已明显误导用户对完成度的判断，属于必须在下一张拼接图中解决的 P1。

### 2. P0 / P1 / P2

#### P0

**P0 = 0。** 地区选择、地图选中、A5.1 当前地区详情与唯一 CTA 均可识别，没有看到不可逆误触、互相矛盾状态或第二个跨层动作。

#### P1-1｜四角断链

左下约四分之一栏高、右下约五分之一栏高没有任何承载关系；两处空白都紧邻已结束的功能组件，因而被读成缺件，不会被读成有意呼吸区。留白成立的前提是周围模块已经形成完整边界。这里边界本身没有闭合，效果不是“克制”减弱，而是反转成“尚未拼完”。

改进：增加左下真实周程模块和右册外载体延续；同时删除中下巨型空框，不额外增加同义状态卡。

#### P1-2｜中下空壳

中下区域面积接近一张大型功能面板，但实际只有地区名、一行说明和远端“0天”文本，信息密度与容器体量严重不匹配。应把大空框压缩为 2 个有真实职责的横向纸件：

- 当前选区摘要：地区名、当前状态、1 行地区钩子。
- 全局更新回执：仅展示已有的地区情报 / 档案更新 / 地区预警之一或两项。

最多两张，不生成第三张跨入右栏。

#### P1-3｜右册身份头缺失

当前截图右册标题槽明显为空，只剩状态章；照片内容虽与北美相符，但玩家必须跨越较大距离回看左卡或中央标签才能确认右册身份。A5.1 继续使用 frozen 标题槽，正常显示“北美禁区带”；只补运行时字段，不改组件内部几何。

#### P2

- 三栏底线失衡：左卡结束、中央空框、A5.1 页面结束分别落在三个高度，屏幕下缘没有共用节拍。
- 完成度语义未标明：结构宿主证据必须显式标为“结构接线 / 非完整视觉”；一旦称为“大致拼接效果”，就必须按整屏视觉闭合验收。

### 3. 左下、中下、右下职责

#### 左下：全局周程与时间动作

左下不是第四张虚构地区卡，而应承载现有全局周循环：当前第几天、剩余天数、本周阶段 / 截稿进度。若现行流程确有“推进一天”，其动作放在这里；如果本版不允许从世界地图推进一天，就只显示周程状态，不生成不可用按钮。

#### 中下：当前选区摘要 + 全局更新回执

中下属于中央栏，不属于右栏。左纸件承载当前选区摘要；右纸件承载真实存在的档案更新 / 地区预警 / 情报回执。它们是地图解释层，不是新的任务入口，不承担地区进入动作。

#### 右下：完成 A5.1 的物理载体，不新增功能区

右下真正职责是让 A5.1 读成嵌在完整档案夹 / 周刊册页载体里的当前地区决策容器。用背页、文件袋尾、低多边形纸叠、克制的彩色分页签延续到屏幕下缘。可保留无交互的期号、页码、归档刻度等固定印刷信息，但不能重复地区状态、任务数、风险或解锁条件。右下需要视觉内容，但不需要新增游戏功能。

### 4. 绝对不能用来填空的内容

- 不能增加虚构的第四张地区卡。
- 不能把 A5.1 已有状态、任务数、红线趋势、解锁条件再复制到右下。
- 不能增加外置 CTA、第二个“进入地区”按钮或新任务入口。
- 不能恢复 symbol strip、贴纸图标库存、手掌 / 眼睛 / 地球徽章陈列。
- 不能恢复 575 中旧版双动作行或顶部 QA 横幅。
- 不能把 30 的白色立体浮雕地图搬进来。
- 不能用“已选择”“本周可进入”“任务就绪”“风险已核对”等伪状态便签填空。
- 不能用三张或更多底部票据一路侵入右栏。
- 不能让右下纸叠具有按钮边框、hover 高光、箭头或 hit rect。
- 不能为了填满而放与游戏机制无关的路线规划、雷达控制台、图例面板或证据墙。
- 不能把三栏强行等高等宽做成后台 dashboard。

## UI Designer 复核原文

### 1. 方案结论

这版应定位为 **1920×1080 `filled_state_text_mock` 大致拼接效果**，不是新的整屏重设计，也不是 runtime 通过证据。

核心修正只有四件事：

1. 左下用真实全局周程模块闭合，不伪造第四地区。
2. 中下把巨型空壳改成两张真实纸件：当前选区摘要 + 全局更新回执。
3. 右下不增加新功能，而是用 A5.1 后方的全高档案夹、背页和文件袋尾补足物理载体；整块无文字、无按钮、无 hit rect。
4. 中央结构占位多边形必须替换成可辨识的世界地图剪影，保持 575 的深色低多边形语法，不照搬 30 的白色浮雕地图。

它解决的是“整屏四角与三栏底线闭合”。A5.1 的右栏独占职责不变，唯一最强动作仍是页内橄榄色 `进入地区任务台`。
