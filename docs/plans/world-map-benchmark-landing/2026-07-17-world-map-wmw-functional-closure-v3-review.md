## UX 老哥复审正文

### 结论

上一版不能继续生图。问题不是“留白不好看”，而是左、右两栏在内容结束后仍继续维持栏体，形成职责真空：左栏日程器结束后余 64px；右栏浅袋口结束后余 169px，并主动标成 `NO TEXT / NO HIT`。三栏底部必须分别由日程操作、地图状态、地区任务决策三种真实职责收口。

### 严重度

- **P0**：左右栏没有落到底边；右侧继续用 480×780 紧凑 A5.1 解决 1032px 完整栏位，组件规格与宿主规格不匹配；主交付态未使用既有任务情报展开能力。当前稿不可作为生图真源。
- **P1**：左下日程器不应无收益压缩；右侧不应再接第二块档案袋；默认态若收起并留空仍会形成空洞；CTA 必须固定到底部，不能随任务展开跳动。
- **P2**：删除结构稿中的 `UNFRAMED BREATH / NO TEXT / NO HIT` 辩护性说明；浅袋口完全删除；中央双回执无需扩大。

### UX 推荐结构

- 三栏：`[36,24,342,1032] / [402,24,972,1032] / [1398,24,480,1032]`。
- 左栏：三张 B2.12 不动；日程器恢复 `[36,810,342,246]`，包含当前日 / 剩余日、推进到下一天、直接后果与到期结算提示。
- 中栏：地图 `[426,96,924,822]`；回执 `[426,942,450,90] / [900,942,450,90]`。
- 右栏：删除浅袋口和无框背景；建立 A5.1-H `[1398,24,480,1032]`，任务内容区显示四条既有任务，CTA `[1425,957,426,75]`，下方仅 24px 安全边距。
- 主交付态使用 expanded；collapsed_summary 也必须占据同一 248px 内容区，CTA 坐标不变。

### UX 禁止项

不得再出现大面积占位说明、CTA 下档案袋 / 后页 / 抽屉、纯装饰填满、新增功能、第三回执、第四地区、重复天数、展开推动 CTA 位移或一击推进下一天。

## UI Designer 复审正文

### 对上一稿的明确纠正

1. “右下保留 169px 无框背景即可呼吸”是错误判断；这只是搬移空白。
2. 62px 浅文件袋仍是无功能装饰占位，本版完全删除。
3. 正确做法是保留 compact A5.1，同时建立显式 A5.1-H 派生规格，不拉伸旧组件。
4. 地图精确为 924×822、回执起点精确为 `y=942`。
5. 右栏新增高度只用于既有任务情报和底锚 CTA，不制造新模块。
