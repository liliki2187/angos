# RegionCard 右侧文字区误判为装饰区复盘

- 日期：2026-09-04
- 触发：用户指出右侧需要放文字，V3 背景过花。

## 误判

此前为了消除“空表单感”，把右侧当成纯装饰构图区，先后加入地球水印与宽块面。该判断忽略了这里实际承担动态文字，因此装饰即使风格正确，也会侵占可读性。

## 防复发规则

1. 在处理留白前先确认它是装饰静区还是动态内容槽。
2. 动态文字槽内，至少 80% 面积保持连续同色，色块边缘不得穿过文字行。
3. 状态、权限、任务与故事钩子分域承载，不用同义文案重复填满空间。
4. 合同字段语义变化必须升级版本，不得只在图片里悄悄塞字。

## 当前处置

- V4 已把色块退到最下缘，恢复安静文字底。
- V4 示例文案错误地重复了权限/门槛，只用于验证背景可读性，不作为内容层级目标。
