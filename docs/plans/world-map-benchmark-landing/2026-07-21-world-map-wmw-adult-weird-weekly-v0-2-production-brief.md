# WMW「成年怪新闻周刊」v0.2 整屏风格方向生产 brief

## 目的

本轮承接 A256，只解决一个问题：在不重开既有功能布局的前提下，把 WMW 世界地图从“全球异常管控 / 政治军情界面”转成“成年人认真编辑的怪异世界周刊”。

本轮是完整整屏风格方向裁决，不是正式母本、拆件、atlas、Godot 接入或组件合同升级。

## 用户意图真源

> 让玩家感觉自己正在翻开一份由成年人认真编辑的怪异世界周刊；每个地区都藏着一条值得点开的离奇故事，而不是在国家安全态势图上执行命令。

“更有趣、更丰富”不等于儿童卡通、糖果色、贴纸轰炸或无规则热闹，而是：

- 日常编辑部物件与荒诞调查内容产生冷面反差；
- 三个地区分别拥有可复述、可比较的怪故事；
- 纸张、照片、低多边形地图和出版图形属于同一套周刊视觉语言；
- 神秘感邀请玩家靠近，不以肃杀、危机管理或军事命令制造压力。

## 输入权限

- `wmw-layout-content-reference-clean.png`：只作为三栏职责、内容数量和宏观占位参考，不作为视觉皮肤。
- `benchmark-board-01-clean-reference.png`、`benchmark-board-02-clean-reference.png`：作为 clean-lowpoly weekly 的艺术风格参考。
- 三栏职责、地图第一、右档案第二、日程次级、四条任务、唯一 CTA、selected / locked / deadline 语义继续保留。
- 不生成可读假文字；全部文字区域保留为空白安全区，后续由真实运行时文案回填。

## 三个方向

### A｜怪新闻头版

把界面理解为一份成熟调查周刊的国际怪新闻头版：撕边纸、照片夹、克制的珊瑚色与蓝紫色状态色、较强新闻纪实感。目标是稳重可信，但不能回到国安态势图。

### B｜编辑部选题桌

把界面理解为编辑部正在比较三条怪异选题：文件夹、回形针、主照片与证据小照构成受控拼贴；中央地图保持主场，右侧是一张连续专题纸。目标是让玩家产生“这三件怪事我先追哪一件”的点击欲。

### C｜世界奇闻特刊

把界面理解为现代成年人奇闻特刊：更大胆的地区色块、更清楚的低多边形块面、更大留白与更强出版图形。目标是最大程度摆脱军情感，建立品牌辨识度。

## 统一故事钩子

为避免三张地区卡继续只像三个设施地点，本轮统一使用三个可复述故事原型：

1. 北美：荒漠公路出口牌每晚向西移动一英里；现场留下反复钉装的旧孔位与方向错误的影子，远处可见雷达球。
2. 东亚：封闭山中古塔每次航拍都会多出一段楼梯平台。
3. 太平洋：停用的气象站 / 传真设备仍会发送“明天失踪船只”的消息。

这些只是视觉叙事锚点，不在本轮写入 GDD 或 runtime。

## built-in imagegen prompt set

本轮使用内置 imagegen，先分别生成 A / B / C 完整无字整屏，再做一次定向编辑。三个 prompt 共享以下硬约束：

- 完整 desktop 16:9 game UI screenshot；
- 使用输入 1 的三栏职责和内容数量，使用输入 2 / 3 的 clean-lowpoly weekly 视觉语言；
- 中央地图为第一视觉，右侧专题为第二视觉，左下日程为次级；
- 三张地区卡必须分别表现上述三个故事；选中北美卡、地图选区和右侧大图必须讲同一件事；
- 右侧保留四条调查行、第三条独占危险色、底部唯一 CTA；
- 不生成政治、军事、国安、HUD、战争沙盘、儿童卡通、糖果色、贴纸轰炸或可读伪文字。

方向专属词：

- A：`adult investigative weird-news front page`、撕边米纸、照片夹、珊瑚选中色、克制新闻纪实。
- B：`adult editorial pitch desk`、文件夹与回形针、主照片加证据小照、纸层与夹具、冷面编辑部趣味。
- C：`adult world oddities special issue`、现代出版大色块、芥末黄选中色、蓝紫与青色地区差异、低多边形特刊。

定向编辑只修复首轮暴露的问题：恢复完整日程载体、恢复四条任务行、删除周历 / 检查表假功能、统一选中故事与右侧大图、把任务缩略图恢复为平面状态签，并保留各自既有风格。

## 程序职责

`compose_wmw_adult_weird_weekly_v0_2.py` 只对真实 imagegen 整屏进行：

- 分区裁切；
- 归位到同一宏观三栏；
- 归一化为 1920×1080；
- 生成一张完整对比板和 JSON 审计。

程序不重绘、不调色、不新增 UI 内容，也不以脚本图形冒充生图。

## 审阅边界

用户本轮只需判断：第一次打开世界地图时，玩家更应该感觉自己在阅读 A 怪新闻头版、在 B 编辑部桌上比较怪异选题，还是在翻开 C 世界奇闻特刊。

用户不需要再次判断三栏、任务数量或日程能否装下；任一方向被选中后，才会在同一方向内统一内部子槽、回填真实文字并再次做 1920×1080 完整整屏验收。
