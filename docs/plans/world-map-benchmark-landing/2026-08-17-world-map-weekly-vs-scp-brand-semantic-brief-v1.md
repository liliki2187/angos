# 世界地图「怪新闻周刊 vs SCP 异常机构」品牌语义 brief v1

## 产物边界

- 本文只定义下一张整屏方向稿应表达的品牌身份，不修改功能、布局、状态、图片规格或运行时。
- 当前状态：`semantic_layer_reference_only / macro_style_scope_superseded`。本文的品牌语义仍有效，但不能再充当整屏宏观风格 brief；组件家族、综合色块、地图载体和灯光范围已由 A309 重开。
- 用户确认前不继续生图，不进入组件拆分、透明化、量测、atlas、manifest、Godot 或 `WeeklyRunGame`。

## 北极星

> 玩家第一眼应觉得自己正在翻阅并选择一份由成年人认真编辑的怪新闻周刊；离奇故事是第一主语，专业编辑部是第二主语，机构制度只作为冷面反差的第三层收束。

错误首读：

`机构抬头 → 权限目录 → 异常监控 → 权威案卷 → 获准处理`

目标首读：

`本期周刊 → 三条怪新闻 → 编辑取材现场 → 当前主稿候选 → 进入地区采编`

## 参考图权限拆分

### 两张 clean-low-poly weekly benchmark 可以冻结的内容

- 深海军蓝主场及冷青、钴蓝、橄榄、芥末、暖白、锈红的综合色彩；
- 宽块面、低细节、抽象概括的 clean low-poly 图像；
- 现代纸品的体积、裁切边、夹具、照片、彩色文件夹和接触关系；
- 粗刊名、期号、版式切割、受控不对称和印刷错位；
- 高完成度办公物件与荒诞内容并置。

### 不能继续作为叙事身份真值的内容

- `TOP SECRET / CONFIDENTIAL / SECRET / CASE FILE` 作为核心主物件；
- 雷达、目标准星、监控室阵列和全球异常管理；
- 人员剪影、身份识别、收容编号和权限档案；
- Eye、锁、警戒三角作为跨屏主状态系统；
- `ARCHIVE / EVIDENCE / SECRET` 形成的机构分类逻辑。

这些元素最多只能出现为一处低权重反差材料，不能控制跨栏对象关系。

### A291 的权限

- 继续参考整体平衡、WMW 刊头锁组、约 `10%` 的纸层厚度、地图与编辑材料同场关系。
- 不自动继承 `EVIDENCE MAP`、大锁、证据圈选等机构语义。

## 五个高权重区域的身份转译

| 区域 | 当前 SCP 读法 | 目标周刊读法 | 继续冻结 |
| --- | --- | --- | --- |
| 顶部 | 组织门楣、工作站编号 | 本期期号、栏目与夜班编辑状态组成的刊头 | 刊名、WMW globe、ISSUE 槽位与顶部责任区 |
| 左栏 | Eye＋编号＋`REGION FILE`＋锁章的异常权限目录 | 三份来源不同、成熟度不同的地区线报 / 栏目简报 | 三卡规格、图片槽、动态文字、selected / locked 与命中区 |
| 中央 | 网格、Eye、大锁、红色围捕圈形成异常监控图 | 地图退为定位底板；照片、标题草案、取材纸条与主编批注组成本周选题现场 | 世界轮廓、地区锚点、选中关系与中央责任区 |

## 跨栏品牌语法

### 必须退到第二 / 第三层

- 锁定、权限、审批、归档、红色警戒和对象编号；
- Eye、锁章、同式红章与编号的跨栏重复；
- 监控网格、靶心圆环、围捕箭头和雷达式连接；
- 所有颜色只解释 selected / locked / deadline / CTA。

真实状态不删除，但每种状态只保留一个主要承载，其它位置改为低权重回执，不得让锁成为整屏 Logo。

### 必须进入第一层

- 每个地区各自可理解的异常主体与故事钩子；
- 地区线报来源、栏目归属或选题成熟度；
- 当前照片对应的标题草案、编辑批注或校样意见；
- 右栏当前主稿候选的出版身份；
- 一条栏目色签从左侧候选延伸到中央选中簇，再进入右侧主稿；
- 稿号、页码、栏目号、版位号等出版编号，而不是收容对象编号。

## 黑色幽默边界

- 幽默来自“普通办公秩序认真处理荒诞新闻”的关系，不来自贴纸数量。
- 高权重内容附近可有三类轻提示：标题草案的荒谬备选、照片边的主编批注、校样阶段的一句冷面意见。
- 不做儿童卡通、糖果色、贴纸轰炸、满屏怪物、笑话列表或大量问号。
- 单张 UFO 便签不能继续承担全部趣味；但也不能给每个锁旁边增加 UFO 或问号。

## 无效纠偏清单

- 只换色或整体提亮；
- 只把 `CASE FILE` 改为 `NEWS LEAD`；
- 增加更多纸层、夹子、胶带、印章和便签；
- 放大 WMW Logo；
- 在现有异常监控图上更换一张有趣照片；
- 增加更多幽默文字但不改变照片、地图和案卷之间的权力关系；
- 用不同小贴纸装饰仍然完全相同的 Eye—编号—锁—档案模板。

## 五秒身份 Gate

评审下一张完整整屏时执行：

1. 遮住顶部中文刊名、WMW globe 和黄色 UFO 便签。
2. 只看左卡、中央地图、右栏主物件及其对象关系。
3. 用一个名词描述画面。

- 若自然描述为“异常管理局 / 监控终端 / 秘密档案室”，判失败。
- 若自然描述为“怪新闻周刊编辑部 / 本周选题墙 / 主稿编辑桌”，才可继续审美术质量。

## 下一张图的最低改造幅度

不重开功能布局，但至少需要重做约 `60%` 的高权重可见身份层：

- 顶部品牌 `20–30%`；
- 左侧地区卡 `50–60%`；
- 中央地图可见层 `70–80%`；
- 右侧 Dossier 可见身份 `60–70%`；
- Schedule `30–40%`；
- 新建一套跨栏栏目色、校样批注与 WMW 出版图形关系。

上述比例是视觉重构范围估计，不是像素差异或功能改动指标。

## 当前推荐默认值

- 右栏主身份默认采用：`NEWS LEAD / 本期主稿候选`。
- `CASE FILE` 不作为主标题；若保留，只允许成为一处低权重、带冷面反差的编辑部内部分类字样。
- 中央默认采用“地图定位底板＋本周选题编辑簇”，不再使用红色围捕圈和大锁章。
- locked 的功能语义继续保留，但视觉作用从“禁止访问”改为“尚未拿到足够线报 / 仍可窥见故事钩子”。
- Schedule 只保留 `当前第 1 天` 与当前阶段说明；`最早截止：第4天`、`截稿倒计时7天`、`剩余7天` 均不得回流，地区紧迫性只使用正式任务摘要中的 `限时 1`。
