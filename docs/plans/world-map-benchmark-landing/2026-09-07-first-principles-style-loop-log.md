# 世界地图重新设计：构图变化不等于绘制语言到位

## 用户指出的问题

旧原型仍沿用过多旧组件骨架；新全幅地图稿虽改变构图，却把照片、地图与夹子画得过于细节写实，缺少两张原始美术标杆的大色块、低多边形概括、随性手绘和轻松幽默。

## 原因与本轮处理

此前把地图和纸物件的种类相似误认为风格继承，实际需要继承的是形状取舍与绘制方式。新构图只证明有不同布局，不证明材质与气质已达标。本轮以两张原标杆直接输入真实生图；第一张仅作构图草案，继续削减摄影细节、地图碎纹、旧纸质感、旅行装饰，并统一三个新闻图窗口的横向比例。

## 下次看图的判断依据

- 缩小仍能看清大形和主次，不依赖细碎纹理。
- 新闻主体靠少量宽面成立，不靠摄影式表面和密集细节。
- 小件有手绘取舍，不是精细办公用品模型。
- 幽默存在于异常主体、造型与物件组合，而不只是文案贴纸。
- 不用“重排布局了”“机器通过了”或“比上张好”代替用户对美术效果的确认。

本轮未进入 Godot，未覆盖旧原型；新图仍为视觉候选。

## 同日三栏转译复发

恢复原三栏功能后的第一轮整屏，再次把洗衣店、天文台与碟形天线画得过于写实，并把任务预览画成带方形图标的表格。说明功能字段增加时，仍容易回到现成办公组件和细节模拟。

第二轮继续直接引用用户选定 A 版，简化全部新闻主体、删除表格／任务方块图标与日历图标。该图仅作为软三栏视觉候选；地图配重、同源图片实际复用及动态文字仍待确认。功能回归不能成为降低画法标准的理由。
