# WMW「成年怪新闻周刊」v0.2 整屏风格方向复核

## 父级结论

三套完整整屏均已脱离纯政治 / 军情管控界面，并恢复左侧三卡、完整日程、中央地图、右侧四任务与唯一 CTA。三套可用于风格方向裁决，但尚不能作为正式整屏母本。

共同排序为 `B > C > A`。推荐用户选择 B「编辑部选题桌」作为下一轮正式风格方向；C 保留为情绪和品牌上限参考，A 保留为较严肃的新闻纪实对照。

## 结构回归

- 三套均保持地图第一、右专题第二、日程次级。
- 三套均有四条任务行和底部唯一 CTA。
- 首轮 B 的周历、C 的检查表假功能已经删除。
- 三套左下均恢复日期摘要、推进动作与两条后果信息的承载空间。
- 选中北美卡、地图选区和右侧大图已统一为同一个“弹孔路牌—雷达站”故事。
- 程序化裁切 / 归位未出现明显拉伸；当前不足来自内部子槽尚未统一，不来自合成事故。

## UX 老哥意见

UX 推荐 B。它最完整地形成“异样 → 好奇 → 比较证据 → 选择追查”的操作链，三条故事最容易复述，selected / locked 在左卡与地图之间也最一致。

A 的问题是第二条故事偏普通，且左侧 locked 语义弱于地图；C 的情绪承诺最好、最不像军情，但左卡小多边形容易被误读成选择控件，黄色 CTA 稍抢右专题。

UX 认为用户现在不需要重审三栏和容量，只需选择三种身份感：严肃怪新闻头版、编辑部选题桌、世界奇闻特刊。

## UI Designer 意见

UI 同样推荐 B，并认为三套均无明显 crop / fit 拉伸，但只可放行风格方向，不能升为正式母本。原因是三套的左卡内部图文分割、右档案标题 / 主图 / 正文高度仍不一致。

B 的办公物件 × 荒诞照片反差最自然，纸层、夹具与快照拼贴最接近 benchmark；下一轮只需统一内部子槽、补足日程四层承载、明确标题安全区，并把照片和地图进一步简化为有主次的大块面。

C 纸面过白、黄色 CTA 过亮，略像现代展览图册；A 仍偏严肃公路事件 / 情报档案，锈红 CTA 还会与截止警告争抢语义。

## 当前 Gate

状态：`art_direction_candidates_dual_reviewed_pending_user_choice`

1. 不再继续 A / B / C 三套整屏互跑；

3. 降低照片写实度和地图均匀三角网感，保留编辑部拼贴；
