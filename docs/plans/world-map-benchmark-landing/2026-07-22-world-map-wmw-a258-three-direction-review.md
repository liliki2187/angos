# WMW A258 三方向完整整屏复核

## 父级结论

三套均通过共同结构 Gate：同一 A 骨架、8 个经典矩形图槽、完整日程、四任务和唯一 CTA；无 B 式多照片拼贴、C 式异形图 / 标题压图、假文字或新增伪功能。

方案 1 和 2 可以交用户正式二选一；方案 3 可供选择，但 UX / UI 均建议把它视为更暗、更悬疑的边界对照，而非默认领先方案。

## 双审结果

| 方案 | 五秒身份感 | UX | UI | 当前用途 |
| --- | --- | --- | --- | --- |
| 1 浅靛鼠尾草 | 轻盈、克制的成年奇闻特刊 | `PASS`，首选 | `PASS`，第二 | 正式候选 |
| 2 暖纸柔珊瑚 | 可信、成熟但内容不对劲的怪新闻头版 | `PASS`，第二 | `PASS`，首选 | 正式候选 |
| 3 暮蓝陶土 | 有秘密调查气质的午夜增刊 | `ITERATE` | `ITERATE` | 深色边界样本 |

三套共同 `P0=0`。

## 方案 1

- 优点：最不像政治 / 军情；selected、locked、deadline 与 CTA 的色彩职责最干净；纸色明显比旧 A 轻。
- 风险：略偏冷静图鉴；地图内部小三角仍较均匀，东亚和太平洋的异常需要真实标题进一步明确。
- 后续最小修正：只简化地图主块面，给右纸面极轻暖灰偏移；不重生照片或组件。

## 方案 2

- 优点：最自然地实现“用 A 的生产骨架承载 C 的轻快邀请感”；暖纸、日光、柔珊瑚和低多边形照片最协调，成年怪新闻完成度最高。
- 风险：selected 珊瑚与第三任务 deadline 砖红缩小时可能混读；珊瑚大陆也可能让少数玩家联想到灾情态势。
- 后续最小修正：deadline 再深一档并只保留短边 / 短章；纸面高光压低一档；局部简化地图块面。

## 方案 3

- 优点：暮蓝、陶土和暮青 CTA 成熟统一，夜间特刊气质鲜明。
- 风险：重新接近夜间调查 / 情报档案；locked 容易像 disabled；照片暗部和写实光影削弱低多边形大块面。
- 若用户选择：必须抬高纸面与照片中间调、减少暗角、拉开 selected 与 deadline；不得改成霓虹或恐怖 UI。

## 共同未完成

- 左侧第二、第三卡已保留状态签位置，但尚未烘焙最终锁图标；作为风格候选可接受，作为 runtime filled-state 不通过。
- 当前无真实文字，因此还不能核验中文字号、任务名、截止文案和日程压力。
- 东亚与太平洋的怪事需要后续真实标题或单一异常锚点强化，不能靠增加小照片、贴纸或状态章完成。
