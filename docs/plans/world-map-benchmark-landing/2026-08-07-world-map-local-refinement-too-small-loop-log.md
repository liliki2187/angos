# 世界地图局部返修幅度不足 Loop Log

## 结论

本轮局部返修解决了证据簇遮挡、标签安全区、红线重复与纸层接触等工艺问题，但用户视觉 Gate 明确判定“改动不大”，未真正拉近真实界面与 A291 风格稿的整体距离。该预演不得继续升格或接入运行时。

## 这次错在

- **阶段误判**：用户要的是“先判断真实界面哪些部分效果糙”，后续继续的合理入口应是结合风格稿做整屏差距复盘；执行中却过早把诊断收敛成两个局部修补任务。
- **问题尺度误判**：把整体风格差距当成净距、阴影、断线等局部工艺问题；这些修改可以让画面更干净，却不会重建刊头品牌、左卡家族、色彩节拍和编辑部氛围。
- **Gate 误用**：UI / UX 的 P0/P1 清零只证明局部方案没有破坏功能与可读性，不能代替用户判断“是否真正像风格稿”。
- **交付叙述偏大**：将“局部视觉预演 PASS”置于第一屏，容易让人误以为整体风格问题已经收敛；实际仅关闭了局部合成缺口。

## 如何避免重复

1. 后续只要用户反馈“还是不像风格稿 / 改动太小 / 只是微调”，必须退回风格标杆与真实界面的整屏并排审查，禁止继续在当前局部上加码。
2. 风格差距审查必须同时覆盖：品牌刊头、综合色彩跨栏节拍、重复组件家族、中心主舞台语法、拟物接触、趣味符号；不得只列阴影、边距和线条。
3. UI / UX Gate 与用户视觉 Gate 分开记录：前者通过只能写“结构与局部工艺安全”，用户未确认前不得写“视觉方向已通过”。
4. 下一张候选必须是完整 `1920×1080` filled-state visual target，并与 A291 同尺寸并排；局部 crop 只能作为证据，不能作为主交付。
5. 继续冻结 A292 功能合同，避免把“需要更大美术变化”误翻译成结构、热区或图片比例重做。
