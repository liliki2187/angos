# WMW 完整整屏 Art Pass v0.4 复核

## 结论

- `artifact_type = fullscreen_art_pass_filled_state_mock`
- `state = default`
- `status = rejected_by_user_art_identity_mismatch_layout_retained`
- 用户版面裁决：通过，继续保留 v0.4 三栏与 rect。
- 用户美术方向裁决：否决，与 benchmark 相去甚远。
- UI Designer 修订终审：`FAIL，P0=1，P1=4，P2=0`
- UX 老哥修订终审：`FAIL，P0=1，P1=4，P2=0`

上一轮 UI / UX `PASS` 只证明布局完整、功能可读和拼装无明显错误，却被错误扩大成美术身份通过；该放行现已撤回。v0.4 只保留为 `filled-state functional assembly / layout-content evidence / art-identity deviation case`，不得升格为正式视觉基准。

## 用户否决后的核心诊断

- Benchmark 主语是现代彩色神秘周刊拼贴；v0.4 主语是灰暗军事档案 / 策略 HUD。
- Benchmark 以裁纸、照片纸、贴纸、标签、局部层叠和品牌图形建立组件身份；v0.4 以重复倒角硬壳、描边、内高光和标准按钮建立组件身份。
- Benchmark 的粗刊头、期号、图章与符号是艺术身份；v0.4 使用通用无衬线 UI 字体，只建立了信息层级。
- Benchmark 的低多边形主要服务异常选片和少量大色面；v0.4 将它均匀铺到地图、照片和面板，结果成为通用“低多边形皮肤”。
- v0.4 纸面中位约为 `#B29E85`，更偏棕档案纸；CTA 中位约为 `#3F452F`，比目标橄榄 `#6E8047` 更暗更灰。青绿 / 钴蓝 / 芥末等品牌中间调没有形成可见角色。
- Prompt 的 hard negatives 误删 `icons / office objects / folders / floating components`，把应该受控使用的编辑拼贴载体整体删除；同时又要求统一正交、安静空面，最终只剩规整 dashboard。

## 修订后 Gate

- P0：去文字并缩至 25% 后，五秒内仍必须首先读作与 benchmark 同族的“现代神秘周刊编辑拼贴”，不能读作 dashboard、军事档案或策略 HUD。
- P1：形状、色彩、材质、字体、证据快照和整屏节奏必须分别继承 benchmark；不能只在边角追加贴纸或纹理。
- 功能 UX PASS 与美术身份 PASS 分开记录；UI / UX 不得再用可读性和一致性代替艺术方向放行。

## 本轮解决的问题

1. 左栏四外壳统一为 `x=30,w=348,right=378,center=204`，三段垂直间距均为 18px；不再出现日程器与地区卡错轴，也不再整体过度内缩。
2. 三张地区卡共用同一套生成壳体、照片窗、Footer 和状态块结构，不再有第一张与两张 locked 卡尺寸 / 内距不一致。
3. 右档案只保留单层暖纸底、单外围线和单层阴影，不再有双轨、叠框或双照片。
4. 左下完整日程器继续独立承担当前日、剩余日与推进动作；右上“红线升温”状态章保持删除。
5. 中央地图仍是第一视觉中心，右档案第二，右下 CTA 是唯一最强动作；没有路线、世界新闻、筛选器或新增快捷按钮。
6. 生图负责卡框、按钮、纸面、切角、阴影与材质；程序只恢复精确 rect、真实照片与真实文字，未用纯色大矩形覆盖生成美术。

> 完整 1920×1080 整屏成立。左栏 x=30、w=348 的重量与边距合理，三张卡共用同一壳体、照片窗、Footer 和状态块，未见尺寸漂移或重复 carrier。卡框、按钮与暖纸材质已经摆脱程序矩形感，并与中央低多边形地图形成统一的 clean-lowpoly weekly 语言。右侧地区档案现为单层纸底、单外围线和单张照片，没有双轨、叠框或双照片。真实文字与生成材质结合稳定，正常比例下未见明显粗糙、错位、裁切或业余错误。地图仍是第一视觉中心，右档案第二，右下 CTA 是唯一最强动作。
