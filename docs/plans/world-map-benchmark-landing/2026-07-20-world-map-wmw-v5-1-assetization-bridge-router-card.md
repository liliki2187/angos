## Gate

1. A237 的 1920×1080 几何与文字不得漂移。
2. 每个区块必须标明：可复用资产、新无字资产、运行时层、禁止烘焙。
3. default / schedule-confirming 不得交换两张整组件或整屏位图。
4. 审计文字、尺寸线、TARGET_ONLY 标注不得进入发行资产。
5. 第一条纵向切片必须能验证当前最大未证风险，且不假装 runtime 功能已实现。
