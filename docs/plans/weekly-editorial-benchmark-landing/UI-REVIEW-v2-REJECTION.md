# 报刊编辑台视觉校正提案

稿件类型仍为 `filled_state_text_mock`，只验证构图、氛围与信息层级。

## 1. 上一稿的具体视觉误判

- 把标杆误读成“摊开的写实报纸界面”。暖白双页和签批纸占屏过大，深海军蓝退成窄边，丢掉标杆最重要的暗色编辑桌负空间。
- 第一视线落在超大中文标题，而不是异常主图；画面读成排版清楚的报纸，不是神秘周刊编辑部。
- 左侧六张等宽剪报全部展开，中央六版位又完整铺文，右侧再列数据，形成“三栏文字后台”。
- 顶部“当前拿起”横条是软件状态栏，不是职业物件；右侧签批纸像结算表，CTA 下方常驻说明进一步拖慢动作。
- 橄榄、钴蓝、芥黄只剩小标签；标杆中的文件夹、档案层、便签、胶带、CD、夹具等一级块面没有进入主构图。
- 图片虽使用低多边形，但数量、尺寸和明度接近，缺少“一张异常主图统治画面”的强弱节奏。

## 2. 新一轮 1920×1080 氛围优先构图

- 深海军蓝编辑桌：`x0 y0 w1920 h1080`，保持约 `46%–50%` 可见面积。
- 周刊品牌/期号窄标题：`x44 y28 w900 h94`，直接印在桌面或薄纸签上，不做全宽导航栏。
- 左侧重叠候选托盘：`x40 y150 w350 h850`；橄榄文件夹＋钴蓝档案层，只完整展开当前候选，其余仅露出彩色页签和标题首行。
- 当前拿起剪报：`x300 y620 w410 h190`，跨压左托盘与周刊边缘，形成“拿起→准备落版”的物理桥；删除顶部横条。
- 中央周刊：`x420 y130 w1010 h850`；头版异常主图 `x475 y220 w610 h390`，周刊品牌与主标题位于其上/左侧；其余 `2–3` 张次图分布在右页和下缘，六版位靠面积、页签与占用章识别。
- 右侧桌边复核件：`x1490 y250 w350 h510`；只留头版、预计传播、净收益、风险一行。
- 签批章/CTA：`x1515 y815 w315 h116`；独立锈红印刷票条，无常驻解释。

面积预算：异常图与次图约 `28%`；文件夹、剪报、周刊、便签、夹具等职业物件约 `35%`；动态文字约 `14%`；裸露海军蓝约 `46%`（允许物件重叠计算）。图像＋职业物件视觉面积至少为文字的四倍。

第一视线固定为：异常头版主图 → 周刊品牌/标题 → 跨边拿起剪报 → 锈红签批章。

## 3. 信息删减表

| 信息 | 默认同屏 | 渐进披露 |
| --- | --- | --- |
| 期号/阶段 | 保留一行 | 无 |
| 当前选中稿 | 标题＋一枚取向色签 | 摘要、精确标签、有效传播明细 |
| 六版位 | 保留占用/空位与短标题 | 稿件摘要、类型解释 |
| 头版定稿 | 保留 | 头版完整属性 |
| 预计传播、净收益 | 各一个数字 | 售出、订阅及计算明细 |
| 风险 | 一句“无冲突/存在冲突/硬禁令” | 疲劳、公开取向、空版长文 |
| 签批送印 | 只留动作本身 | 不设常驻说明 |
| 顶部拿起横条 | 删除 | 由跨边剪报承担 |
| 六张候选全文 | 删除 | 仅当前卡展开，其余托盘页签 |

## 4. 标杆色彩与物件转译

- `dark_board`：全屏主场，不做灰蓝面板。
- 橄榄：左候选文件夹、选中态和周刊分类页签，约主画面 `10%–12%`。
- 钴蓝：候选档案背层、右页次图承托，约 `7%–9%`。
- 芥黄：个人便签、当前拿起稿的临时批注，约 `2%–3%`。
- 暖灰/象牙：周刊与剪报可写面，控制在约 `25%–30%`，禁止铺满。
- 青绿：异常主图光束或冷色结构面。
- 锈红：风险章和唯一 CTA，低面积、高识别。

功能面保持 0°；轻微旋转只给背后文件夹、便签、照片和夹具。纸张薄、影子硬而窄，不表现厚旧案卷。

## 5. 下一张风格稿硬禁项

禁止全宽当前稿横条、巨型签批表、六张候选同时展开、六版位等权等图、白纸占屏过半、正文段落填满报纸、订阅数默认展示、CTA 常驻说明、SaaS 三栏卡片、泛黄旧纸、厚阴影、写实摄影、均匀细三角滤镜、所有功能面倾斜、用小色签冒充一级彩色物件。

## 6. 与 UX 的冲突

无实质冲突。唯一张力是“六版位必须同屏”与“减少文字密度”：设计侧建议保留六个明确版位轮廓、占用章和短标题，但不默认展开六篇摘要；完整内容通过聚焦版位后渐进披露。
