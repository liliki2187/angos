## 2. 静态刊头合同

- class：`edition_masthead`；尺寸 `1010×56`。
- 唯一职责：呈现《世界未解之谜周刊》的刊物身份与配色节奏。
- 固定元素：线描地球、中文刊名、`WORLD MYSTERY WEEKLY`、横线、橄榄绿 / 钴蓝 / 锈棕色块、`WMW` 字标。
- 禁止绑定：当前拿稿、稿件标题、稿件来源、风险、期号、取消操作。
- 禁止交互：`mouse_filter=IGNORE`；不得出现 Button、tooltip、hover、pressed、focus 或隐藏热区。

## 3. 拿稿与版位状态合同

- 当前拿稿身份只在候选卡显示 `已拿起`，并使用橄榄底、纸色粗边与形状差异；同一卡再次点击取消，`Esc` 是辅助取消路径。
- 从已占用版位拿稿时，原版位显示 `移动来源` 与钴蓝粗边；不再在远端重复来源长文案。
- 拿稿存在时，空位显示 `放入此处` 与橄榄粗边，其他已占用版位显示 `替换目标` 与纸色粗边；合法目标在非 hover 状态也必须可见。
- 投放、替换或取消后，`移动来源 / 放入此处 / 替换目标` 全部清除；静态刊头不发生任何变化。
- 两页始终读取同一份 `slot_assignment`；签批从双版常显进入右栏内联确认。

## 4. 页面与资产边界

- 左右页、主 / 副头版及四个普通版位继续沿用 v2 的几何与资源分级。
- `editorial-main-head-slot-base-v1.png` 继续以 `442×374` 运行，不因刊头改造缩放。
- 动态标题、元信息、状态和按钮仍由 Godot 绘制；本轮不新增报道图、整屏底图或批量插画。
- `held_article_bar` 合同退役，运行 payload 只保留 `held_article_id`，不再生成顶部显示专用的完整稿件副本。
