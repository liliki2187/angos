# 发刊编辑界面组件比例分类 v1

更新时间：2026-07-14

## 结论

本页采用唯一的“候选报道池 + 双版周刊常显 + 发刊复核”三栏结构。当前阶段不提供单版聚焦或上下文缩略页；资源投资按 S / A / B / C 分层，不把六个版位做成六张同等级插画。

| 组件类 | 参考尺寸 | 比例 | 档位 | 生产职责 |
| --- | ---: | ---: | --- | --- |
| `candidate_card` | 288×92 | 3.13:1 | C | 缩略图、短标题、来源与上版状态 |
| `main_page_shell` | 490×800 | 0.61:1 | A | 左页正交纸壳、书脊安全区与三槽承载 |
| `secondary_page_shell` | 490×800 | 0.61:1 | A | 右页正交纸壳、书脊安全区与三槽承载 |
| `main_head_slot` | 442×374 | 1.18:1 | S | 每期唯一主头版；最大图片和标题预算 |
| `secondary_head_slot` | 442×342 | 1.29:1 | A | 副头版；图像与标题权重低于主头版 |
| `standard_story_slot_compact` | 213×282 | 0.76:1 | B | 左页专题 A/B |
| `standard_story_slot_tall` | 213×314 | 0.68:1 | B | 右页内页 A/B |
| `edition_masthead` | 1010×56 | 18.04:1 | C | 静态刊物身份与配色节奏；不承载状态或交互 |
| `signoff_panel` | 360×920 | 0.39:1 | C | 整期结果、风险与唯一送印 CTA |
| `confirmation_plate` | 328×392 | 0.84:1 | C | 右栏内联确认，不遮挡双版 |

## 每期资产预算

- S：1 张主头版 clean-lowpoly 报道图。
- A：1 张副头版报道图；主副页面纸壳可长期复用。
- B：2–4 张常规报道图或证据快照；地图、波形、符号页均可计入。
- C：空位、阻断、投放、换稿、章、状态覆盖层与所有文字由确定性 UI 复用。

## 本轮停点

只制作并接入 `main_head_slot` 的无文字纸壳与 1 张 S 级报道图。其他类先锁合同，不批量生图。
