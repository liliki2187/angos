# 发刊编辑完整风格稿 A / B / C Router Card

## 目标

在物件化 v3.1 已通过的功能结构上，生成三张有真实选择价值的整屏美术候选。差异必须同时覆盖配色、材质和编辑部物件细节，不得只做同图换色。

## 共享硬锁

- `1920×1080` 正面桌面视角。
- 左侧八稿，第四稿为唯一抽出来源。
- 中间双页六槽，五篇已占用、右下唯一空槽。
- 右上头版为唯一悬停目标，只附着一个局部换稿签。
- 右侧为同一张连续证据链，下部只有一个锈色硬阻断和一个禁用 CTA。
- 同文章、同位置、同读序、同文字安全区。

## 三个分叉

- A 夜班印务室：冷钴蓝、精密套印、黑蓝印务夹板。
- B 现场回传编辑桌：青灰帆布、浅沙纸、照片角与蓝纸胶带。
- C 截稿校样台：橄榄批次架、暖纸、芥末校订条与签批耳片。

## Gate

三版均需通过 UI / UX 功能锁复核；转灰度后仍能看出材料和轮廓层级差异。任一版新增按钮、丢失空槽、改变文章或仅换色即判废。
