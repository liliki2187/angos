# 发刊编辑物件化完整风格稿 v3.1 Router Card

## 任务

在 v6 已冻结的功能区责任、数量与交互位置基础上，生成一张真正可供用户冻结美术身份的 `1920×1080` 整屏风格稿，不再沿用程序框体换肤。

## 真值顺序

1. 两张 `benchmark-board-01/02`：美术身份第一真值。
2. clean-lowpoly-weekly 支线规范与纸张材质合同：配色、块面、纸张与禁区。
3. v6：只提供三栏职责、双页六槽、5/6 状态、定向替换、证据链、硬阻断与唯一 CTA 的功能锚点。

## 执行链

现有 UI 改进按 `UX 诊断 → UI 设计 → 父级合并 → 真实生图 → UI / UX 生成后复审` 执行。clean-lowpoly-weekly 临时例外继续生效，不自动调用旧像素 / 半调坐标系的美术指导。

## Gate

- 遮掉文字并缩至 25%，五秒内先读出“八稿分拣架 → 展开双页校样报纸 → 连续签发夹板”。
- 画面为 5/6，只有一个空槽、一个来源、一个悬停目标、一个局部换稿签、一个硬阻断和一个禁用 CTA。
- 任一栏仍读作普通网页面板、中央仍读作六张网页卡、或右栏读作仪表盘，即判 FAIL。

## 边界

只生成低文字美术方向稿与审阅记录；不修改 Godot、组件合同、GDD 或正式报道资产。
