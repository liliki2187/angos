# 报刊编辑台 UI 设计评审稿

稿件类型：`filled_state_text_mock`，仅用于图文目标验收，不是生产底图或资源母版。

## 一句话目标

把“候选报道→六版位排版→后果复核→签批送印”收束成一眼可读的主编决策桌，让中央真实周刊成为绝对主物件。

## 1920×1080 六区坐标

1. 顶部期次栏：`x24 y20 w1872 h82`；期号、周次、编辑阶段。
2. 当前拿起稿短条：`x382 y112 w1100 h54`；显示标题、类型、公开取向、主话题、有效传播。
3. 左侧候选剪报架：`x24 y178 w338 h842`；六张稿件卡，纵向滚动。
4. 中央双页周刊：`x382 y178 w1094 h842`；占工作区约 58%，功能面全部 0°。
5. 右侧签批夹：`x1496 y178 w400 h686`；头版定稿、三项核心预期、风险与阻断。
6. 右下操作区：`x1496 y884 w400 h136`；局部“退稿/换稿”在上，唯一主 CTA“签批送印”`w352 h64`；“清空当前排版”移至左栏底部次操作。

## 六版位排布与内容

中央纸面 `x414 y206 w1030 h786`，中缝 `x920–938` 为 `no-text`：

- 头版头条 `x446 y302 w442 h330`：**M330末班车在不存在的站台停了三秒**；大幅车站异常图，最大标题。
- 头版次条 `x446 y652 w442 h146`：**51区夜班货车携带会呼吸的路牌**。
- 重点专题A `x446 y816 w442 h142`：**港口广播连续七晚播报明天的潮汐**。
- 重点专题B `x970 y302 w442 h248`：**罗斯威尔档案第十四页拒绝被复印**。
- 内页A `x970 y568 w442 h182`：**市政厅新增了一个不存在的影子部门**。
- 内页B `x970 y768 w442 h190`：**街区猫群一致拒绝经过蓝色电话亭**。

版位权重只靠面积和位置表达，不显示 `x1.00/base/comboRaw` 等开发词。每稿显示类型、公开取向、主话题、有效传播；取向/疲劳字段槽标“目标字段，待实现”。

## 状态矩阵

- `candidate`：暖灰剪报；可点击拿起。
- `lifted`：橄榄描边＋同色当前稿短条。
- `placed`：卡片降亮，写“已入：头版头条”。
- `placed-located`：候选卡与对应版位同步橄榄脉冲。
- `drop-target`：空版位钴蓝虚线；兼容拖拽。
- `occupied`：完整报道排版；点击可换稿/退稿。
- `warning`：窄锈红章，仅用于空版、疲劳、公开冲突。
- `blocked`：CTA 禁用并就地列出硬禁令。

点击链保持“选稿→点版位”；拖拽只是等价快捷方式。

## 文字安全区

所有动态文字遵循 `visible_color_module→carrier→inner→glyph_bbox`。纸边各留 20px，卡片内边 18px；标题最多 2 行、每行 16–18 汉字，摘要最多 2 行、省略号截断。中缝、纸边、夹子、折角、胶带、贴纸、印章和低多边形主图均为 `no-text`。右栏最长字段 14 字；CTA 固定“签批送印”，不缩字号。

## 生图关键约束

`modern graphic editorial collage, matte color-block UI, flat cut-paper low-poly poster, front-facing orthographic functional surfaces, thin crisp offset shadow`。

深海军蓝负空间，暖灰/象牙纸、橄榄、芥黄、钴蓝、青绿，锈红只作警示；异常图用 3–8 个大块面。禁止泛黄旧纸、厚案卷、脏污、写实摄影、密集三角、SaaS 白卡、斜置文字面。生图只负责无字结构与插图，中文必须后续控件回填。

## 三条风险

1. `required_slots_filled / hard ban / public_stance / stance_clash / fatigue` 当前 payload 未完整暴露，不能伪装成已实现。
2. 六篇长标题在 `1366×768` 下可能溢出，需真实中文压力测试。
3. 生成模型容易把正交纸面画斜或画成旧档案；右栏、CTA、中缝必须逐裁切叠线复核。
