## 3. 状态与误触合同

- `occupied`：报道图全亮；右下显示可交互 `↩`；点击整槽拿起稿件。
- `held_source`：报道图仍为 `Color.WHITE / alpha 1.0`；使用钴蓝外线、象牙内线与非交互 `来源` 徽记；退回按钮隐藏。
- `drop_target`：空位使用橄榄外线与非交互 `放入` 徽记；退回按钮隐藏。
- `replace_target`：占用目标使用象牙外线、橄榄内线与非交互 `替换` 徽记；报道图全亮；退回按钮隐藏。
- `blocked / disabled`：只有这两类允许降亮；确认层使用页面级冻结，版位不重复贴锁。
- 状态词不得拼进报道元信息；meta 只表达品质与标签。
- hover / pressed 不得给整张报道图铺色膜，只加强边线。

事件优先级：`return > slot_target`。两者不得在同一次点击中同时响应；拿稿存在时所有 return 必须隐藏。

## 4. 风格与资源边界

- 壳体是正交的现代周刊钴蓝印刷纸，不得滑向 SaaS 卡片、旧档案、泛黄报纸或厚重硬纸板。
- A02 报道图在缩略尺寸先读出“货车＋鼓起的空白路牌”，只使用中景与大色块；不靠放大后的机械细节、文字或写实摄影成立。
- 报道图的高亮面积保持克制，不使用贯穿画面的高亮光柱；双版并排时不得压过主头版。
- 壳、报道图、状态、文字和命中区分别生产；禁止为五态重复生图。
