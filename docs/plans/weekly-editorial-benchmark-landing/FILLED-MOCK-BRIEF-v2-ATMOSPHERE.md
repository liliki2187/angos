# 发刊编辑界面氛围优先风格稿 Brief v2

> **已废止（2026-07-14）**：该 Brief 把 v1 的“文字过载”单指标反向修正成“氛围优先”，但未冻结对象—状态—动作—后果的二维功能骨架；其中 `实体工作桌 / 俯拍 / 午夜灯光 / 纸张叠层` 等正向措辞还主动诱导了写实摄影桌面。不得继续用于整屏生图。

> 产物类型：`filled_state_text_mock`。只验证整屏氛围、标杆转译、图文主次与物件叙事；不是生产底图、切图源或 runtime 资产。

## 本轮纠偏目标

第一眼必须是“午夜神秘周刊编辑桌”，第二眼才读到“玩家正在把 M330 报道排进本期周刊并准备签批送印”。禁止再次用默认全显的功能字段证明界面可用。

## 视觉面积预算

- 深海军蓝编辑桌裸露面积：`46%–50%`。
- 暖灰 / 象牙可写纸面：`25%–30%`，不得成为全屏主色。
- 异常主图与次级快照：约 `28%`。
- 橄榄文件夹、钴蓝档案层、芥黄便签、夹具与介质等职业物件：约 `35%`，允许与其它层重叠计算。
- 动态文字视觉面积：约 `10%–14%`；图像与职业物件视觉面积至少是文字的 4 倍。

## 1920×1080 氛围优先构图

- 全屏是深海军蓝午夜编辑桌，不设全宽导航条或三栏面板边框。
- 左侧 `x≈40–390` 是重叠候选托盘：橄榄文件夹为一级大色块，后方露出钴蓝档案层；除当前稿外，其余候选只露出彩色页签、照片边和极短标题，不展开摘要。
- 当前拿起剪报约 `x≈300, y≈620, w≈410, h≈190`，跨压左托盘与中央周刊边缘，用抬升、夹子和窄硬阴影表达“正在拿起”，不使用顶部文字横条。
- 中央约 `x≈420–1430` 是打开的现代神秘周刊，但纸边薄、纸面不铺满。左页 / 主跨页由一张 M330 深夜站台低多边形异常图统治，主图约 `610×390`；大标题只有一处。
- 六版位仍可识别，但只通过面积、页签、占用章、短标题和 2–3 张次级缩略图表达；禁止六篇正文、六张等权配图和等权网格。
- 右侧约 `x≈1490–1840, y≈250–760` 是夹在桌边的小型复核件，只留头版、预计传播、净收益和一枚风险章；不做通高签批表。
- 右下 `x≈1515–1830, y≈815–931` 是唯一锈红 / 暖锈签批票条“签批送印”，无常驻解释。
- 无字氛围层可包含 1 张钴蓝照片套、1 枚青绿 CD / 磁盘、少量回形针、胶带和芥黄批注便签；必须有明确附着关系，不随机撒满。

## 默认可见文字

整屏最多 7–8 个独立文字簇：

1. `世界未解周刊`。
2. `第 1 周 · #001`。
3. `M330 末班车在不存在的站台停了三秒`。
4. 2–3 个极短次级报道标题或版位短签。
5. `预计传播 4,200`。
6. `净收益 +210`。
7. `风险：空位 1`，也可用图形章为主、短字为辅。
8. `签批送印`。

正文摘要、类型、取向、有效传播明细、订阅数、空版长文、疲劳解释、不可逆说明与开发字段全部不在默认画面出现。

## 标杆转译

- `benchmark-board-01.png`：控制暗色编辑部主场、错落物件密度、周刊封面冲击力、职业工具与硬窄阴影。
- `benchmark-board-02.png`：控制橄榄 / 钴蓝 / 芥黄 / 青绿大色块轮换、快照 / 文件夹 / CD / 便签 / 夹具的现代资产系统和中粗颗粒低多边形塑造。
- 只转译视觉语言，不照抄 style guide 的开发板式、英文标题或资产展示网格。

## 硬禁项

- 全宽“当前拿起”横条、全宽顶部导航、三栏 SaaS 面板。
- 巨型通高签批表、四项以上常驻数值、CTA 下方常驻说明。
- 六张候选同时展开、六篇摘要、六张等权配图、正文填满报纸。
- 白纸占屏过半、灰米色成为主色、橄榄 / 钴蓝 / 芥黄只做小标签。
- 传统旧报纸排版、泛黄档案、厚重案卷、污渍撕边、复古报社表单。
- 写实摄影、密集小三角滤镜、SaaS 卡片、网页、浏览器、终端霓虹。
- 所有物件规整平铺；功能文字面保持正交，但无字文件夹、照片、便签与夹具必须有错落、重叠和跨边。
- 随机贴纸、重复印章、无职责装饰、假字小段落、英文调试词和内部变量。

## 缩略图 Gate

25% 缩略图的第一视线必须依次落在：`异常头版主图 → 周刊品牌 / 标题 → 跨边拿起剪报 → 签批章`。若先看到表格、正文或大块米白纸面，直接判失败。
