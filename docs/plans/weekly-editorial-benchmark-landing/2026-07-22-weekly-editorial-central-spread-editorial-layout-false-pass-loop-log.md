# 发刊中央双版“纸张通过但报刊身份失败”｜Loop Log

## 结论

中央双版区域母件 v1 的纸张、书脊和报道图素材合格，但图文编排退化为“白纸上的六张图片”，没有形成现代周刊的版头、栏网、图文耦合和主副层级。撤回此前 UI / UX PASS；v1 降级为材质与合同几何证据，不得冻结或反向拆层。

## 影响

- 中央区域继续返工，左栏候选报道抽屉不启动。
- 当前六组 `headline / photo / meta` 合同坐标只证明几何可装配，不再作为编辑排版真值。
- 正式 Godot、组件合同、GDD 和 manifest 继续不动。

## 触发来源

2026-07-22 用户查看 v1 真实内容组合后指出：“文字和图版配合的很差，没有报刊的感觉，甚至没有之前程序版效果好”，要求先分析。

## 这次错在

1. 为避免文字与固定装饰叠化，把纸面清成几乎全空，同时没有用报刊自己的栏网、基线、版头和分隔规则接替旧程序框线的组织职责。
2. 把每组 `headline → photo → meta` 坐标命中当成图文关系成立；实际标题、图片和 meta 只是相邻，没有共享边线、栏宽、图注带或印务节点。
3. 主头版与副头版使用近乎同构的“大标题＋同宽横图”，玩家需要阅读“主版 / 副版”标签才能分辨层级。
4. UI Gate 收敛到合同几何、文字安全和折角冲突；UX Gate 收敛到可读性与中央焦点。两者都没有验证“不读标签是否仍有主副层级”和“中央首先是否被识别为报刊”。
5. 整屏未来态证明了中央最亮、最抢眼，却掩盖中央内部已经从报刊退化成画册。

## 复发判断

这是“局部素材 / safe-zone / 合同通过，被扩大解释成整体媒介与排版通过”的重复错误家族，与 A260 地区任务外围 UI、A263 WMW 真实中文假通过同族。仅补一句提醒不足，必须升级为独立硬 Gate 与人工目检项。

## 当前处理

- UX 重新诊断为 `P0 报刊媒介身份断裂`，撤回上一轮 PASS。
- UI Designer 复盘结论为“中央双版几何合格，但媒介排版 FAIL”。
- 当前 v1 只保留纸张 / 书脊 / 报道图材质和整体双页物件方向；统一空白纸面与六组内部排列不得作为拆图真源。

## 防复发

- 新增 `editorial_media_identity`：面向报纸、杂志、周刊校样等出版承载面，区域冻结前必须做去标签层级测试与媒介身份测试。
- **去标签层级测试**：隐藏“主版 / 副版 / 专题 / 内页”等显式等级标签，5 秒内仍能从面积、标题重量、跨栏和排版节奏看出 S / A / B。
- **媒介身份测试**：模糊报道图片后，中央仍应首先读成现代报刊 / 周刊校样，不能读成相册、作品集或 UI 卡片墙。
- 下一轮必须同时对照标杆、程序版结构和新稿；删除旧皮肤后必须明确由哪种报刊结构继续承担分组职责。

## 沉淀决定

- 用户否决与返工边界登记为 A264。
- 两项测试同步 `workflow-gates.yml`、`ui-geometry-and-text-safety-gates.md` 与资产化 UI 生产链。
- 本轮只完成诊断与防线修订，不生成新图、不修改正式实现。
