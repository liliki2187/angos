# 2026-07-14 发刊风格稿“功能全显吞噬包装”Loop Log

结论：首张已填稿效果图被用户明确拒绝，状态从 `style_candidate_partial` 降为 `rejected_by_user`。
影响：暂停生图、组件合同板、vertical slice 与运行时资产化；该图只能保留为偏差案例。
下一步：先重做氛围优先的稀疏信息风格稿，待用户确认后再恢复资产化链路。

## 1. 用户强反馈

用户指出：当前效果图包装效果太差、几乎全是文字，为功能性牺牲了效果、代入感和氛围感；风格与配色也和两张标杆图差距甚远。

这不是局部修色或文字润色问题，而是整屏视觉主语、默认信息层级和标杆转译同时失败。

## 2. 这次错在什么地方

### 2.1 把“真实内容压测”误做成“所有信息默认展开”

上一轮同时展开左侧六张候选的标题 / 摘要 / 图片 / 版位章、中央五篇报道的标题 / 摘要 / 图片，以及右侧发刊数值 / 空版说明 / 风险说明 / CTA。功能字段虽然齐全，但全屏形成二十余个文字簇，玩家第一眼只能扫描信息，无法先进入异常周刊编辑部的场景。

### 2.2 把标杆误读为纸张材质表，而不是面积与节奏合同

两张标杆的主语是深海军蓝环境、错落职业物件、橄榄 / 钴蓝 / 芥黄大色块和一张强异常图。上一稿却让暖白报纸与签批表成为面积主色，只把标杆颜色缩成小标签。物件语言从“文件夹、快照、介质、夹具构成的编辑桌”退化为“报纸、列表、表单三栏”。

### 2.3 正交安全规则被错误泛化

动态文字承载面 0° 是生产安全规则，不等于整屏所有物件都应规整铺平。上一轮为了安全区，连候选托盘、背景档案层、便签、照片和夹具都失去错落、重叠和跨边关系，氛围层被功能层的正交规则一并压平。

### 2.4 QA 只检查局部“有没有”，没有检查整体“像不像”

上一版 QA 把“中央周刊面积大、六版位可辨、功能面正交”列为通过，却没有把文字面积、纸面亮区占比、深色负空间和一级彩色物件面积设为前置门槛。更严重的是，首轮颜色回采已经显示暖纸与 CTA 偏差，仍错误保留 `style_candidate_partial`，相当于让局部功能通过掩盖整体美术失败。

## 3. 对照标杆的量化反证

基于三张整图统一缩放后的像素分布诊断：

| 指标 | 标杆 01 | 标杆 02 | 被拒候选 |
| --- | ---: | ---: | ---: |
| 深色区域占比 | 50.8% | 58.3% | 34.0% |
| 高亮区域占比 | 7.5% | 6.0% | 35.1% |
| 暖纸语义区域占比 | 11.8% | 12.4% | 41.5% |
| 橄榄语义区域占比 | 10.5% | 4.8% | 2.4% |

数值证明候选不是“颜色稍微不准”，而是面积配色关系整体反向：纸面亮区约为标杆的 4.7–5.9 倍，深色主场减少约 17–24 个百分点，橄榄色从一级物件退成小标签。

## 4. 被撤回的上一轮判断

- 撤回“每篇稿件的类型、取向、主话题、有效传播值必须同屏”。只展开当前选中稿。
- 撤回“传播、售出、净收益、订阅全部常驻”。默认只保留最能影响签批判断的两项。
- 撤回“右栏完整复核表常驻”。风险长文与不可逆说明进入确认态。
- 撤回“顶部当前拿起短条”。由实体剪报抬升、跨边和夹持关系表达。
- 撤回“中央周刊越大越能成为主物件”。主导权必须来自强异常图、图文节奏和物件关系，不得靠扩大米白纸面积。
- 撤回 `IMAGEGEN-QA-v1.md` 中对 clean-lowpoly 识别、旧档案回流、决策链和中央主权重的宽松“通过”。

## 5. 防复发 Gate（下一张风格稿前）

以下数值先作为内部预检目标，不替代用户视觉裁决：

- 深海军蓝可见面积目标 `46%–50%`；暖灰 / 象牙可写纸面控制在 `25%–30%`。
- 图像与职业物件视觉面积至少为动态文字面积的 2 倍；UI Designer 建议目标为 4 倍。
- 橄榄文件夹、钴蓝档案层、芥黄便签必须作为一级大色块出现，不能只做页签。
- 中央只保留 1 张强头版异常图与 2–3 张次级缩略图，不再把 5–6 张配图等权铺开。
- 默认信息只保留期号 / 阶段、当前稿、六版位占用、头版、传播、净收益、风险状态和唯一 CTA；其余进入选中、hover 或签批确认态。
- 交付前先做 25% 缩略图盲看：第一视线必须依次落在“异常主图 → 周刊品牌 / 标题 → 拿起剪报 → 签批章”，若先看到表格和正文即判失败。
- 颜色检查必须同时比较语义色值与整图面积比例；局部 token 接近不能覆盖全屏面积关系失败。

## 6. 当前停点

不继续生图，不建立该候选的组件 taxonomy，不制作 no-text 资产，不接 Godot。下一轮只重做一张氛围优先、默认信息显著删减的整屏风格稿；通过用户视觉确认后，再重新进入合同板与 vertical slice。
