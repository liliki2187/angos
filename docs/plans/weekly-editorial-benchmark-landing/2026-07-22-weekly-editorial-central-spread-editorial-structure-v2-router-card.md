# 发刊中央双版编辑结构稿 v2 Router Card

## 目标

针对中央双版 v1“纸张合格但报刊身份失败”的问题，在 `1040×920` 固定区域内只重建编辑排版骨架，验证现代异常周刊媒介身份、主副普通三级和图文耦合，不进入美术包装或资产拆分。

## 真值与边界

- 保留中央区域、左右页壳、书脊、六个版位外矩形、命中区和真实报道内容。
- 主头版 / 副头版使用横图；四个普通报道继续使用 `160×160` 正方形图片，遵守 A242 / A243。
- 解冻六个版位内部 headline / photo / meta 比例与排列、页头形式、栏线、图注带和印务信号。
- 不恢复闭合程序卡框，不做颜色、材质、按钮、状态或 Godot 实现。

## 单一路线

“打开的现代异常周刊校样”：以页头、开放式栏线、共同对齐轴和图注带组织连续纸面；主头版标题先行，副头版横图＋右侧窄文字列，左页普通位标题先行，右页普通位图片先行。

## Gate

- 去标签后仍能从面积、标题重量和排版关系分辨主头版 / 副头版 / 普通报道。
- 忽略或模糊报道图片后，仍首先读成现代周刊校样，不是相册、画册或 UI 卡片墙。
- 每篇报道的标题、图片和 meta 共享明确轴线与规则线。
- 四个普通图片全部为正方形；六个标题无溢出；浏览器错误 / 警告为零。
- UI Designer → UX 复审通过后才交用户裁决结构。
