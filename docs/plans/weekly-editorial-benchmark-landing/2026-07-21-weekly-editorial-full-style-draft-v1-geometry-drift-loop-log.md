# 发刊编辑完整风格稿 v1 几何漂移｜Loop Log

## 结论

首稿的 clean low-poly weekly 美术语言成立，但生成模型重新推导了整屏几何，不能作为“基于 v6 当前布局”的交付稿。

## 发现的问题

- 左右安全边距由约 80px 收缩到约 45px。
- 三栏宽度与双页、候选卡尺寸随之放大，无法与 v6 像素级叠合。
- 固定中文和动态正文出现生成式改写。

## 原因

首轮同时输入布局真值和两张复杂风格板，虽然 prompt 要求锁定结构，模型仍把任务理解为完整界面重绘，而不是原位视觉换肤。

## 修正

- v1 只保留为风格参考，不交给用户拍板。
- v2 使用 v6 作为唯一几何 / 文字真值，v1 只提供材质、配色和插画语言。
- 在 prompt 中明确 80px 安全边距、`320 / 1040 / 360` 三栏、20px 间距、`288×92` 候选卡和不可移动的双页 / 六槽。
- v2 经 UX、UI 与父级复审均通过。

## 后续保护

完整 UI 风格稿的首轮输出必须与布局真值叠合检查；几何漂移的图只能降级为风格灵感，不得因“看起来更漂亮”越过结构 Gate。
