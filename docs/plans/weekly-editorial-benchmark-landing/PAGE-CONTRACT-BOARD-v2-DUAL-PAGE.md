## 3. 交互与状态合同

- 当前只有 `dual_page` 与 `confirmation_frozen` 两种页面级状态。
- `focus_left / focus_right / context_thumbnail / focus_return` 不属于当前运行合同。
- 候选池、持稿条、两页与右栏始终同屏；放置、替换和退回候选只更新同一份 `slot_assignment`。
- 页眉不响应鼠标；点击页眉不得改变页面尺寸、候选栏可见性或 CTA 语义。
- `empty / occupied / held_source / drop_target / replace_target / blocked / disabled` 继续共享同一槽位几何。
- 签批从双版常显直接进入右栏内联确认；关闭确认返回同一双版排版现场。
