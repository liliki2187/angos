# 2026-07-14 发刊 v2“写实漂移 + 功能骨架消失”Loop Log

结论：v2 被用户明确拒绝；它只能作为氛围插画偏差案例，不能称为 UI 风格稿。
影响：停止第三次整屏生图；v1 / v2 均不得作为正向参考、组件母版或 runtime 底图。
下一步：先冻结可点击、可映射、可复核的二维功能骨架与六状态，再讨论标杆美术覆盖。

## 1. 用户强反馈

用户指出两个硬问题：第一，v2 的写实风格与标杆相去甚远，且这一类错误频繁发生；第二，即使是风格稿也必须具备功能性，而当前图完全无法使用。

## 2. v2 的双重失败

### 2.1 美术失败：低多边形只在插图里，整屏仍是摄影桌面

- 全局使用真实纸张厚度、金属夹高光、CD 反光、写实投影、电影式青光和俯拍透视，画面被读成摄影棚概念图。
- 标杆的现代平面周刊语言应由扁平大色块、薄纸边、图形化明暗与错落拼贴构成；v2 却用真实材质和光照制造体积。
- 橄榄文件夹、钴蓝档案、芥黄便签、CD 和回形针被照字面搬入，但没有转成游戏功能对象，只形成“标杆道具 cosplay”。
- 同样的色相经过重阴影、环境光遮蔽与真实材质后变得泥、暗、旧；因此局部 palette 接近也不能证明风格接近。

### 2.2 功能失败：可操作对象被画成场景装饰

- 候选池只剩一张完整剪报，其余文件夹没有候选身份、标题、已上版状态或选择入口。
- 当前剪报虽然跨边，但没有明确“已拿起”状态，也没有连接到中央某个可投放目标。
- 六版位消失；中央只是“一张主图 + 三张缩略图”的成品报纸，无法判断六个角色槽、占用、空位与当前目标。
- 放置、换稿、退稿没有任何入口或就近动作；玩家无法从静态图推断基本操作。
- 右侧只剩两个数字和空位 1，空位不对应具体版位，风险、阻断、立场冲突和同题疲劳都成为黑箱。
- `签批送印` 像桌面票根，缺少按钮热区、可用 / 阻断状态和确认关系。
- 中央周刊、复核件与 CTA 都有明显透视 / 倾斜，不具备稳定动态文字 carrier 和点击区域。

## 3. 为什么会频繁犯同类错误

### 3.1 每轮只追一个纠偏指标

v1 追求功能完整，结果文字过载；v2 把问题简化成“减少文字、增强氛围”，结果连对象—状态—动作—后果骨架一起删掉。没有一份冻结合同守住功能与美术的共同下限，两个指标只能像跷跷板来回摆。

### 3.2 提示词主动诱导写实

v2 Brief 与 prompt 使用了“实体工作桌、午夜氛围、俯拍、纸张叠层、夹具、CD、灯光”等语言，却没有把 `flat graphic 2D UI / no photographic material / no cinematic lighting / no physical depth` 提升为第一优先级。即使写了“no photorealistic office”，正向语义仍远强于负向限制，模型自然生成摄影式桌面。

### 3.3 继续让整屏生图承担不适合它的职责

整屏生图擅长整体气氛，不擅长稳定生成六个精确版位、可交互状态、动态文字 carrier、按钮热区与可逆操作链。父级仍试图让一次整屏生图同时解决 UI 几何、功能状态和美术包装，方法本身不稳定。

### 3.4 跳过资产化链的关键顺序

正确顺序应是：二维功能合同 → 六状态线框 → 无字组件 / 氛围资产 → 确定性装配 → 真实文字回填。v2 在没有冻结线框和组件合同的情况下，再次直接生成 filled-state 整屏图，重复了“让模型重新发明布局”的旧错。

## 4. 立即撤回的方法

- 不再以整屏生图作为下一版 UI 结构来源。
- 不再把“摆满标杆同款道具”视为标杆转译。
- 不再用 `physical desk / cinematic midnight / realistic paper layering` 作为 UI 主提示词。
- 不再为了减少文字而删除版位边界、状态、映射和可逆动作。
- 不再把有 CTA、有数字、有大报纸误判成“具有功能性”。

## 5. 下一轮 Hard Gate

第三版开始前必须先交付并通过一张无美术二维功能骨架：

```text
候选池 320        六版位周刊 1040                 复核 360
[当前已拿起]      头版①占用   次条②占用          头版：M330
稿件 B / C / D    专题③可投放 专题④占用          传播 / 净收益
已上版带章        内页⑤占用   内页⑥空位⚠         风险 / 阻断
                  [退稿] [换稿]                   [签批送印]
```

同时冻结六种静态可见状态：`未选 / 已拿起 / 可投放 / 已占用 / 空位 / 阻断`。任何风格稿都必须让陌生人仅凭静态截图说出：当前拿起哪篇、能放到哪里、哪个版位为空、如何换 / 退、送印前看什么、最终按钮在哪里。

美术覆盖只能改变颜色、材质、轮廓、插图和无字氛围层，不得改变三大区坐标、六版位关系、六状态语义和操作入口。

## 6. 正确生产分工

- **整屏生图**：只用于早期情绪 / 材质探索，不再直接充当 UI 母版。
- **组件生图**：生成无字橄榄文件夹、钴蓝档案层、周刊壳、剪报壳、签批票据、低多边形报道图等视觉配料。
- **确定性装配**：由 HTML / Godot / 可编辑二维稿锁定三大区、六版位、状态、文字 carrier、点击热区和真实内容回填。

只有确定性装配稿在功能上通过，且视觉配料经标杆对照通过，才能重新进入 filled-state 整屏验收。
