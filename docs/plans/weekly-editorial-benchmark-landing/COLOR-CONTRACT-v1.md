## 2. 使用规则

- 深海军蓝只做负空间，不用连续灰蓝面板铺满三栏。
- 候选剪报、双页周刊、签批单必须形成暖纸 / 橄榄 / 钴蓝 / 青绿的可区分中间色块。
- 红 / 锈色只给空版风险、冲突与“签批送印”主动作；不得把所有边框染红。
- 报道插图使用 3–8 个大块低多边形面，不做写实照片滤镜和密集三角网。
- 保持采样 palette 与 paper texture；几何和文字修复不得顺手全局重染。

## 3. 已知失败边界

- 泛黄旧档案、牛皮纸、脏旧报纸、厚重案卷。
- 全屏灰蓝 / 蓝绿黑，纸面比例被压暗。
- 过白粉笔纸、纯白表单和 SaaS 卡片。
- 鲜红 / 霓虹青铺满状态边框。
- 写实夜景照片、均匀 low-poly 三角滤镜、摄影噪声。

## 4. 通过阈值

- `dark_board / warning_rust / teal_blue`：`DeltaE00 <= 3.0` 且 `|dL| <= 2.5`。
- 纸面语义 ROI：`DeltaE00 <= 4.0` 且 `|dL| <= 2.5`。
- 整图平均亮度差 `<= 3.0`；暗部占比与纸面占比差 `<= 0.015`。
- 若候选构图导致语义面积不同，面积比例仅作诊断；不得为了追齐早期空板而删除真实内容。
