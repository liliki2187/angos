# 发刊中央双版区域母件 v1 Router Card

## 目标

在不拆层、不修改正式 Godot 的前提下，把已暂准的主头版语言扩成完整中央双版区域母件，并按当前合同回填六篇真实报道，验证组件组合与未来整屏是否同时成立。

## 真值

- 几何：`design/ui-contracts/weekly-editorial/` 中的主页面、副页面与六个版位合同。
- 功能结构：正式黑白结构稿 v4 / 视觉包装 v5 中央区域 `[420,96,1040,920]`。
- 美术第一真值：用户提供的图 2 物理周刊纸件。
- 配色：用户已选择的方案 1 钴蓝方向；中央亮纸、外围中深设备。
- 动态内容：现有六张正式语义报道图与对应标题 / meta。

## 允许范围

- 内置 imagegen 生成与定向编辑无字双版纸面母件、空白纸面和照片凹槽 / 蓝色折角配料。
- 程序只做真实生图母件缩放、真实生图配料裁切 / 重排、真实报道图回填、动态文字覆盖和未来态整屏位置合成。
- 未完成的左、右、顶栏只使用方案 1 风格稿代理，不显示旧程序皮肤作为美术证据。
- 不拆状态资产，不进入正式 Godot、组件合同升版、GDD 或正式 manifest。

## Gate

- 六组 `headline → photo → meta` 必须使用冻结合同矩形，不迁就生成图偶然几何。
- 主头版、副头版、普通报道维持三级视觉权重。
- 动态文字不得与蓝色折角、裁切标记或书脊叠化。
- 中央双页在 1920×1080 未来态整屏中仍是第一视觉锚点。
- UI Designer → UX 顺序复审通过后，才交给用户裁决区域；用户通过前不得反向拆层。
