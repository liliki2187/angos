# v2 风格稿功能性诊断原文

**产物类型：** `filled_state_text_mock`
**界面类型：** 排版 / 创作台
**优先评估：** 直接操纵、约束反馈、送印前决策完整性

结论：用户判断成立。这张图不是“功能弱”，而是核心编辑链已经断掉。它可以当氛围插画，不能作为可落地 UI 风格稿。

## 操作链复原

正确链路应为：

① 浏览候选池 → ② 选中一篇 → ③ 判断适合哪个版位 → ④ 放入版位 → ⑤ 换稿 / 退稿 → ⑥ 检查六版位与风险 → ⑦ 预览结果 → ⑧ 签批送印

当前静态图只能辨出“有一张剪报、中央有一期报纸、右侧有两个数字和送印票”。第①步只能看到一篇，不构成候选池；第②步没有明确选中态；第③至⑤步完全无从执行；第⑥步只知道“空位 1”，不知道空的是哪个版位、有什么代价；第⑦步缺风险、阻断、立场冲突和同题疲劳；第⑧步虽有 `签批送印`，却没有确认关系与不可逆提示。

### P0-1｜组版链消失

候选剪报与中央报纸之间只有空间重叠，没有“当前拿起稿件 → 可投放目标”的映射。中央页面看起来像已经出版的成品：没有六个版位边界，没有空槽、目标槽、占用槽，也看不出哪篇能移动。

直接操纵成立的前提，是对象、目标和状态同时可辨；本稿把功能物件都画成了场景装饰，效果不是更沉浸，而是反转成“看得见报社、做不了主编”。

### P0-2｜送印前决策黑箱

右侧只显示 `预计传播 4200 / 净收益 +210 / 空位 1`。玩家无法知道：

- 六个版位分别放了谁；
- 哪一个版位为空；
- 当前头版是谁、能否替换；
- 是否触发公开取向冲突或同题疲劳；
- 是否存在硬阻断；
- 点击送印后是否立即冻结。

因此签批不是一次有依据的决策，而是对一张漂亮成品图盲签。状态与操作暗示冲突，参考 case C-3-2、C-13-1。

### P1｜关键对象、状态与动作不可辨

- **候选池：** 只有一张完整剪报，其余是无语义文件夹；无法比较、滚动或区分已上版 / 未上版。
- **当前选稿：** 没有选中描边、抬升态、夹持态或连接目标。
- **六版位：** 实际只呈现“一张主图 + 三张缩略图”，不等于六个有角色差异的槽位。
- **放置 / 换稿 / 退稿：** 没有投放区、交换提示、移除入口或返回候选池的路径。
- **结果复核：** 两个数字有容器，但风险章与空位信息没有对应到具体稿件 / 版位。
- **CTA：** 锈红票据视觉突出，却像桌面道具，缺按钮热区、可用 / 阻断状态和确认层。

## 风格稿可以省略什么

可以省略：完整正文、非当前稿摘要、精确倍率、所有候选同时展开、hover 文案、动画时序、结算公式、最终确认弹窗的完整内容。

绝不能省略：候选池入口、当前选中稿、六个版位及角色差异、稿件到版位的映射、至少一个可投放目标态、换稿 / 退稿可逆性、空位对应位置、送印前风险 / 阻断、唯一主 CTA。

## 为什么从文字过载反摆到功能消失

上一轮把问题错误抽象成“文字太多”，于是按单一指标做减法；但真正该冻结的是“对象—状态—动作—后果”四层骨架。文字被删后，承载它们的版位边界、选中态、映射和操作暗示也一起被删了。随后又让生图模型自行组织界面，模型自然优先生成电影感桌面构图，而不是可操作的信息架构。

这也是频繁犯错的机制：每轮追一个视觉指标，没有先锁住二维功能合同，导致“功能完整”和“氛围强”像跷跷板来回摆。

## 下一轮必须先冻结的最小二维骨架

```text
┌ 候选池 320 ┐ ┌──────── 六版位周刊 1040 ────────┐ ┌ 复核 360 ┐
│ [当前选稿] │ │ 头版①〔占用〕  次条②〔占用〕      │ │ 头版：M330│
│ 稿件 B/C/D │ │ 专题③〔目标高亮〕专题④〔占用〕    │ │ 传播 / 净益│
│ 已上版带章 │ │ 内页⑤〔占用〕  内页⑥〔空位⚠〕    │ │ 风险 / 阻断│
│             │ │ [退稿] [换稿] ← 当前动作就近      │ │ [签批送印] │
└─────────────┘ └────────────────────────────────┘ └───────────┘
```

下一张必须固定展示一个操作瞬间：左侧一篇处于“已拿起”，中央某个版位处于“可投放目标”，其他五格明确显示占用 / 空位，右侧结果随当前悬停方案变化。美术只负责包裹这副骨架，不能再重新发明布局。

**Top 3：**

1. 冻结六版位、候选池和复核区的二维功能合同。
2. 冻结 `未选 / 已拿起 / 可投放 / 已占用 / 空位 / 阻断` 六种静态可见状态。
3. 先用无美术线框通过“候选→放置→退换→复核→送印”测试，再让低多边形标杆风格覆盖它。
