# 普通版位 B 级报道图纵向切片路由卡

## 决策条

- **结论**：只放行一张普通版位 B 级报道图进入真实运行预览，不批量生产其它专题图。
- **影响**：本轮可以验证小图可读性、紧凑 / 高版位裁切与文章 ID 绑定，但不能代表整套杂志资源已经完成。
- **下一步**：完成 `article_id=1003` 港口广播插图接入、三态截图和针对性回归后，停在用户视觉复核。

## 详情

- **一句话结论**：使用一个普通报道类型打通“真生图 → 母图裁切 → manifest → Godot → 截图”，保护现有双版、标题和换稿交互。
- **我实际做了什么**：定义单图构图 / 裁切合同，调用 UI Designer 与 UX 老哥顺序复核，然后只实现一个文章资源。
- **现在卡在哪里**：无工程阻断；最终风格与双版层级仍需用户看真实截图裁决。
- **为什么不能跳过**：若直接扩成四张，单图构图、亮度或小尺寸可读性出错会成倍返工。
- **下一步怎么验证**：看默认、单槽点击与拖拽 hover 三张 `1920×1080` Godot 截图，并检查 1003 在四个普通版位间移动时无文图残留。
- **本轮不要做**：不补第二张 B 图，不生成 C 级模块，不改变头版 / 副头版资源，不重做交互或页面布局。

## 路由

- **任务类型**：UI / 美术 / 代码 / 资产化工作流
- **风险等级**：risky
- **当前阶段**：运行实现 → 视觉验收
- **目标载体**：真实生图、Godot、截图、manifest
- **本轮交付物类型**：router_card / implementation / screenshot / delivery_manifest
- **被路由对象类型**：`runtime_state_preview`
- **本轮只验证**：一张 B 级普通报道图的构图、裁切、文章绑定、fallback 互斥和输入穿透。
- **本轮必读真源**：两张 clean low-poly weekly 标杆、支线风格规范、纸张 / 色彩 / 页面合同、普通版位 compact / tall 合同。
- **必调 agent**：`ui_designer` 先定构图与安全区，`ux_laoge` 后审小图可读性和交互风险。
- **明确不调的 agent 与原因**：按 clean low-poly weekly 临时例外不调用旧像素坐标系的 `angus_art_director`；本轮不涉及玩法、数值或系统架构。
- **允许下一步**：用户确认后继续下一张 B 级报道图，或只返修当前港口图。
- **禁止跳到**：批量专题图、C 级组件、整套生产真源。
- **停止条件**：真实三态截图、针对性测试与 Godot smoke 完成并交给用户复核。
