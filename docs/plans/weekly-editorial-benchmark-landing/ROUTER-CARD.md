# 报刊编辑台标杆落地 Router Card

## 决策条

- **结论**：用户已把当前范围收敛为“双版常显”，常驻教学 footer 与单版聚焦整组退役，Godot 只保留一个排版视图。
- **影响**：两页增高至 490×800，双版关系更完整；现有主头版 S 级壳保持原比例，未为布局调整重生或拉伸资产。
- **下一步**：以新的双版常显真实截图验收；通过后再扩副头版 A 类，不恢复隐藏聚焦分支。

## 路由

- **任务类型**：UI / 美术 / 生图 / Godot / 资产化
- **风险等级**：risky
- **当前阶段**：dual-page vertical slice candidate
- **目标载体**：Godot 1920×1080 desktop
- **已调 agent**：`ux_laoge` → `ui_designer`
- **clean-lowpoly 临时例外**：未调用旧像素 / 半调 `angus_art_director`；以两张 benchmark、支线规范、纸张 / 色彩合同、UI / UX 与父级逐项对照放行。
- **本轮允许**：删除常驻说明、退役聚焦状态、增高双版页面、更新确定性状态与文字层、输出真实运行截图。
- **本轮禁止**：用新模块填补 footer、保留不可达 focus 死分支、非等比拉伸主头版壳、整屏重生或批量生成插画。
- **停止条件**：页眉仍有按钮感、两页未同时可见、删除 footer 后留下无职责大空带、主头版资产被拉伸、Godot rect 偏离 v2 合同、GDD 规则被 UI 静默改写。
