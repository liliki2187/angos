# 二次 UX 诊断：当前报道版面效果稿

**产物类型：** `filled_state_text_mock`。本轮只判图文融合、信息密度、物件叙事和氛围，不替尚未实现的 runtime 状态背书。

## 结论

当前稿功能关系可辨，但体验判断失败：它把“必须可判断”误做成“所有事实默认展开”。结果是一张套了纸张皮肤的三栏信息页，而不是玩家沉浸其中的异常周刊编辑桌。用户指出“包装差、全是文字、为功能牺牲效果与氛围”成立，不能用信息完整为它辩护。

## 1. 功能信息为何吞掉氛围

左栏 6 张候选同时展示标题、摘要、图片和版位章；中央 5 篇报道同时展示标题、摘要和图片；右栏继续展开头版、4 个数值、空版说明、风险说明、CTA 与结果提示。全屏有二十余个可读文字簇，而且大多落在同样明亮的米白纸面上。

当所有物件都要求被阅读，物件就不再构成场景，只剩容器。玩家第一眼不是被异常头版吸引，而是在扫描库存、版位和表单。正文安全区虽然成立，氛围却被“每格都解释清楚”消耗殆尽。

## 2. 信息分层

### 默认必须同屏

- 本期期号与当前阶段，压成一处低权重标识。
- 当前选中的报道，以一张被拿起的实体剪报表达。
- 6 个版位的占用关系；只需用面积、图片、色签和空槽表达。
- 当前头版是谁。
- 送印前的三个判断：预计传播、净收益、是否有阻断 / 风险。
- 唯一主动作 `签批送印`。

### 只在选中、hover 或签批复核时展开

- 非当前候选的摘要、类型、取向、有效传播值。
- 非头版报道的正文摘要。
- 精确版位倍率、专题标签、下周订阅细项。
- 空版损失和风险的完整解释。
- “本期将冻结并进入结算”等不可逆说明；进入确认态后再显示。
- 清空排版工具；降级到周刊边缘工具区。

### 应图形化

- `5/6` 改为 6 枚页签 / 印刷格，其中一格为空。
- 风险改为一枚警告章；选中后展开原因。
- 公开取向改为色签 / 印章，不写成长句。
- 当前拿起状态用纸片抬升、夹子和投影表达，删除顶部文字横条。

## 3. 与标杆的断裂

- **视线节奏：** 标杆先读大标题或异常主图，再读文件夹、照片、光盘、便签等第二层物件；当前稿从左到右均匀铺满文字，没有“主视觉—停顿—细节”的节拍。
- **物件叙事：** 标杆靠重叠的文件夹、照片、介质、夹具和颜色层讲编辑部工作；当前是规整三栏，剪报架、周刊和签批纸只是三种面板外形。
- **图文占比：** 标杆以图像和物件为主，文字只承担品牌与短标签；当前正文密度反过来压过图片，低多边形图成为每格配图。
- **主物件沉浸：** 当前中央周刊面积大，但“面积大”不等于主物件成立。它内部被五篇同权内容切碎，缺少一张足够强的异常头版图。
- **配色：** 标杆的深海军蓝是主场，橄榄、钴蓝、芥黄、青绿形成大块物件轮换；当前大面积米白纸压过深色背景，颜色仅剩小标签和锈红按钮，远离标杆的多物件色彩节奏。

## 4. 给 UI Designer 的强制删减与布局约束

### 强制删除

- 删除非选中候选的全部摘要，只保留标题与主图。
- 删除中央除头版外的正文摘要；其余版位只留短标题或图形标记。
- 删除右栏空版和风险的常驻长段落。
- 删除顶部“当前拿起”文字横条。
- 删除 CTA 下方常驻不可逆说明。
- 删除重复期号、阶段和版位状态。
- 默认右栏只保留两项大数值与一枚风险 / 阻断章。

### 氛围优先布局

- 第一视线顺序固定为：**异常头版主图 → 周刊品牌 / 标题 → 被拿起剪报 → 签批章 / CTA**。
- 图像与职业物件的可见面积至少达到文字面积的两倍；深海军蓝必须继续是面积主场，米白纸不能成为全屏主色。
- 至少让橄榄文件夹、钴蓝档案层、芥黄便签三组大色块进入一级构图，不得只做小标签。
- 中央只保留一张强头版图和 2—3 个次级缩略图；禁止 5—6 张等权配图。
- 左侧改为重叠剪报托盘，只展开当前卡；右侧签批纸缩成夹在桌边的复核件，不做通高表单。
- 功能文字面仍须正交；斜放、重叠和夹具只进入 no-text 氛围层。
- 下一稿禁止继续用“缩小字体、缩短句子”解决；必须直接减少默认可见信息。

## 5. 撤回上一轮结论

以下上一轮意见应撤回或修订：

- 撤回“每篇稿件的类型、取向、主话题、有效传播值都必须同屏”的要求；改为只展开当前选中稿件。
- 撤回“预计扩散、售出、净收益、下周订阅三层全部常驻”；默认只留最能改变送印判断的两项，其余渐进披露。
- 撤回“右栏四组完整复核信息常驻”；风险解释与不可逆说明进入确认态。
- 撤回“当前拿起稿件使用顶部短条”；改为实体剪报抬升。
- 修订“中央报刊占主要工作区 52% 以上”：主物件应靠异常图、层次与场景关系主导，不靠扩大米白纸面积。

继续保留的结论只有：中央必须是真实周刊对象、送印必须明确确认、开发公式不得默认外露、状态不能只靠颜色。
