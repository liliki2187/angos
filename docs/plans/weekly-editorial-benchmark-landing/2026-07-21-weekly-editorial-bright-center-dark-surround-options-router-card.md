# 发刊编辑“亮报纸＋深色彩色外围”三方案 Router Card

## 目标

落实用户已经确认的明度关系：保留 B 的明亮杂志与阅读性，否决 B 的浅色外围，同时避免 A / C 的整屏过暗。

## 共享硬锁

- 中间双页保持全屏最亮区域，纸色、插画清晰度和双页完整性不得回退。
- 只分叉背景、刊头轨、左分拣架、右签发夹板和外围小色标。
- 三栏、8 篇候选、5/6、右下空槽、连续证据链、锈色硬阻断和唯一 CTA 保持一致。
- 不修改 Godot、组件合同、GDD 或正式报道资产。

## 三个分叉

- 方案 1：钴蓝印务机。最冷、最精密、现代设备感最强。
- 方案 2：深海青编辑台。最沉静、最中性，暖纸与冷色外围对比最柔和。
- 方案 3：橄榄蓝绿校样台。左右设备身份最鲜明，最接近标杆的橄榄 / 蓝绿 / 暖纸关系。

## Gate

中央报纸必须是绝对视觉焦点；外围不得重新泛白或压暗报纸；锈红只用于硬阻断。三版需保留足够的方向差异，供用户直接选择。
