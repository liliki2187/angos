# 发刊候选报道筛选 / 排序 v4 路由卡

## 决策条

- **结论**：删除名称搜索，只在左栏原有栏头高度内落地报道类型筛选与等级 / 获得时间排序。
- **影响**：候选稿变多后可用鼠标完成缩小范围与调整顺序；中间双页、右侧签发链、定向替换和唯一送印 CTA 不改。
- **下一步**：以 HTML 黑白结构稿 v4、真实截图和动态演示交给用户复核；本轮不进入 Godot，不升版组件合同。

## 路由

- **任务类型**：现有 UI 局部功能改进。
- **风险等级**：normal。
- **目标载体**：桌面 `1920×1080` HTML 黑白结构稿。
- **真值字段**：`recipe_type`、`quality`、`acquired_order`。
- **协作顺序**：先由 `ux_laoge` 诊断搜索输入负担、筛选 / 排序操作链与选稿隐藏风险；再由 `ui_designer` 收敛 `288×48` 栏头、两个 `44×44` 入口和浮层结构；父级合并并落地。
- **本轮只验证**：类型多选、四向排序、空结果恢复、已选稿隐藏保护，以及 8 / 12 条候选容量回归。
- **禁止跳到**：最终视觉包装、Godot 正式界面、`candidate_card` / `signoff_panel` 合同升版、GDD 规则歧义裁决。
- **停止条件**：真实截图、动态演示、自动审计与用户复核材料齐全。
