## 3. 状态与信息合同

`empty / occupied / held_source / drop_target / replace_target / blocked / disabled` 共享同一组件几何。状态只改变覆盖层、描边和小面积信号，不得移动内容槽或热区。

聚焦持稿条在 `heldArticleId != null` 时必须显示：`当前拿起 / 报道 ID / 短标题 / 来源位置 / 取消`。完整候选列表不在聚焦态恢复。

“退稿”统一改为“退回候选”。
