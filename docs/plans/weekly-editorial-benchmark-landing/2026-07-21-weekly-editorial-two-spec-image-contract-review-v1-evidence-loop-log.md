# 发刊报道图片两规格合同审阅板 v1｜证据 Loop Log

## 触发

第一次在本地浏览器中截图时，视口能力在目标页创建前设置，首个目标页仍以 `1280×720` 打开，只截到了结构板左上部分；该截图不具备交付资格。

随后首次完整截图又检测到右侧决策区与底部声明存在 `8px` 重叠。

## 原因

- 视口设置没有在目标页导航完成后重新应用并刷新。
- 右侧两张比例对照与三行冻结建议的总高度未给底部声明保留足够空间。

## 修正

- 在目标页已创建后重新设置 `1920×1080` 并刷新，先读取 `window.innerWidth / innerHeight`，确认正确后才保存截图。
- 缩短比例示意的垂直高度和决策行内边距，重新计算决策区与页脚边界。
- 覆盖无效截图，只保留最终 `1920×1080` 证据。

## 最终结果

- 视口：`1920×1080`
- 文档尺寸：`1920×1080`
- 双页与三审阅区：全部在视口内
- 决策区 / 页脚重叠：`0px`
- 浏览器错误 / 警告：`0`
