# Loop Log：常驻教学吞噬双版主舞台，聚焦范围进入过早

## 决策条

- **结论**：真实纵切片把辅助教学与单版聚焦当成当前必需结构，造成常驻说明占位和验证目标分散；本轮返工为唯一双版常显。
- **影响**：若只删文字不删状态机，会留下页眉幽灵入口、不可达 focus 状态和中央底部空带，继续削弱两张纵版的主体感。
- **下一步**：整组删除 footer / focus，并把“无教学 footer、无 ContextPageSwitch、页眉非按钮、双页 490×800 常显”写入自动交互审计。

## 详情

- **一句话结论**：这不是文案太长，而是把无需常驻的教学和暂不验证的交互做成了页面级正式结构；当前应返工并缩回双版常显。
- **我实际处理了什么**：删除底部 `1010×92` 说明模块、模式标签、页眉 `[聚焦]` 与按钮态、`focus_left / focus_right`、上下文缩略和返回总览分支；页面增高至 490×800。
- **问题卡在哪里**：此前只验证“双版＋聚焦能否共用状态”，没有先问聚焦是否是当前必要功能，也没有把 92px footer 的长期注意力成本与双版主体空间放在同一张账上。
- **为什么会复发**：同一错误家族此前已在发刊风格稿中表现为 CTA 下常驻说明、右栏完整复核常驻；本轮又以“教学安全”为理由回到中央 footer，属于“说明模块吞噬职业主舞台”的再次复发。
- **下一步怎么防**：防线从文档规则升级到运行测试；审计直接检查不存在 `ContextPageSwitch` / `OverviewFooter`，页眉类型不是 Button，两页在投放与确认后仍保持固定 rect。
- **本轮不要继续做**：不设计 footer 替代物，不把聚焦代码留作隐藏功能，不重生整屏，不拉伸既有主头版 S 级壳。

## 术语版

- **触发来源**：用户反馈 + 父级范围自检
- **原始问题**：常驻教学板无持续决策价值；单版放大分散当前双版验证目标。
- **当前产物类型**：`runtime_state_preview`
- **失败归因**：实现范围误判 + 信息层级误判
- **复发判定**：同族“说明常驻吞噬主舞台”再次复发；已有 UI 指南 §3、§12.5 和旧 Loop Log，禁止再只补一条泛化规则。
- **本轮处理**：返工
- **最小下一步**：双版常显真实截图与自动审计通过后交付。
- **不继续做什么**：不扩美术批次，不恢复 focus。

## 沉淀判断

- **是否为单次 bug**：否，是页面主语与辅助说明优先级的重复偏差。
- **是否为可迁移错题**：是；教学只在玩家必须凭它决策时常驻，否则应就地或按需出现。
- **写入 casebook**：不新增；现有 UI 指南已完整承载。
- **写入 design-decisions / 采纳记录**：是，修订 A202。
- **写入 onboarding hard rule**：否；`ui-interaction-guidelines.md` 已有“解释性文字只在必须凭它选择时出现”“旧说明回收检查”“拟物留白不得用伪状态块填充”，不重复落盘。
- **是否需要脚本 / gate 更新**：是，更新 Godot 交互审计。

## 复发保护

- 下次同类任务开工前必须检查：当前新增交互是否是本轮明确验证目标；任何常驻说明是否提供持续决策信息。
- 交付前必须检查：删除可见入口时同步删除状态、tooltip、hover / focus、测试与文档；主舞台释放空间不得被新说明块再次占用。

## 2026-07-15 同族修订：固定持稿条仍在占用杂志身份位

- **触发**：用户指出“当前拿起 / 来源 / 取消拿起”功能条似乎没用，更适合作为杂志标题装饰。
- **复盘**：上一轮虽然删除了底部教学模块，却默认保留了顶部远端状态条。它重复候选卡的选中状态和版位目标，还把双版正上方最适合建立刊物身份的横向空间占为操作说明，仍属于“辅助状态吞噬职业主舞台”的同一错误家族。
- **返工**：删除 `HeldArticleBar`、完整 `held_article` 显示 payload 和独立取消按钮；原位改为无交互 `EditionMasthead`。拿稿身份回候选卡，来源回原版位，合法投放 / 替换目标回各版位；同卡点击与 `Esc` 负责取消。
- **自动防线**：交互审计新增“不存在 `HeldArticleBar`、刊头无 Button 且 `mouse_filter=IGNORE`、正式刊名存在、同卡 / Esc 取消、来源唯一、目标非 hover 可见、投放后局部反馈清除”等检查。当前 25/25 通过。
- **不扩规则**：现有 UI 指南“一语义一处、功能信息只在改变决策时出现、装饰不得伪装交互”已能覆盖，不再新增重复 onboarding 条款。
