# 入门指引

当你需要在动手修改前先理解仓库结构时，从这里开始。

建议阅读顺序：

1. `repository-map.md`
2. `../README.md`
3. `git-collaboration.md`
4. `../technical-preferences.md`
5. `../../production/session-state/active.md`
6. `ai-collaboration-guidance.md`
7. 涉及已采纳 / 待定 / 设计历史时，先读 `../设计采纳记录.md`；按其中“跨分类检索保护”读取 `../design-decisions/` 对应分册
8. 涉及 UI / 交互 / 原型呈现时，再读 `ui-interaction-guidelines.md`
9. 涉及 PNG / 生图 / 拟物资产落地为可交互 UI 时，再读 `assetized-ui-production-chain.md`

如果之后还需要更深入的产品上下文：

- 玩法与范围：`../../design/gdd/`
- 架构决策：`../architecture/`
- 历史日志：`../dev-logs/`
