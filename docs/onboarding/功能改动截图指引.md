# 功能改动的真实图像证据

可见运行改动交付真实截图及简短说明；需要判断节奏、动作或反馈时给真实动图/视频。风格稿和合成图注明身份，不能冒充运行截图。文档工作无需游戏截图。

选择能说明本次变化的实际状态，默认桌面 16:9、1920×1080。状态或适配受影响才补对应尺寸与输入前后图；局部修改不固定遍历入口、操作和结算。保持当前用户已认可的整体优点。

发送前实际查看将交付的图像：新文案、选中状态、图文归属与争议处是否正确；像素非空、没有溢出或脚本通过都不能代替此判断。需要定位细节才补实际尺度裁图、前后对照或标注，放大图注明倍率。

对话直接展示 1–3 张关键图；更多证据按需给一个 Markdown/HTML 索引，附各自证明范围。仓库内相对链接便于迁移；对话图片用绝对路径，例如 `![说明](D:/angos/docs/screenshots/日期-主题/01.png)`。返工使用新文件名，避免缓存误认旧图。

无法获取证据时说明原因、已验证范围与替代方法，不声称视觉或动态通过。

## 截图保存

过程证据放 `docs/screenshots/日期-主题/`，默认被 Git 忽略；已跟踪历史图不做历史重写。长期标杆或当前规则不可缺的图需要纳入版本控制，在用户授权 Git 操作时按 [提交技能](../../skills/git-cloud-submit/SKILL.md) 处理。不要将忽略目录中的本机证据称作已同步，后续清理或外部归档也要保留可追溯来源。
