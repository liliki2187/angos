# 图像采集与查看方法（按需）

证据范围由 [截图指引](../功能改动截图指引.md) 决定；下面是可选方法，不要求每次执行全部命令或状态。

## HTML：真实渲染、入口与缓存

优先使用当前可用且获授权的浏览器工具或项目采集脚本。自行使用 Playwright/CDP 前确认环境允许；不因这里有方法就绕过工具权限。CDP 的相关能力是 Page.navigate、Runtime.evaluate、Emulation.setDeviceMetricsOverride 和 Page.captureScreenshot。

核对页面实际加载的脚本：历史全链 HTML 可能仍执行内联代码，改外部 JS 不一定生效；搜索页面的 script 引用再决定修改位置。若入口用版本参数管理缓存，更新真实入口的版本参数，采集专用 query 不能替代发布入口修复。

先采一张并确认改动确实出现，再扩展相关状态。等待目标状态而非固定 sleep；稳定随机内容或关闭无关遮挡应在隔离测试中处理，并说明注入/固定了什么。只有任务涉及弹层时才测其显示与关闭。

## Godot：真实尺寸与覆盖路径

使用当前项目入口或已有专用采集脚本；需要启动与节点接线检查时查 [运行 smoke](../../workflows/godot-agent-smoke.md)，需要其探索/派遣路径截图时查 [视觉 smoke](../../workflows/godot-visual-feedback-smoke.md)。这些脚本覆盖有限路径，不是所有页面固定前置。

检验输出 PNG 的实际像素尺寸和真实状态。窗口显示尺寸、逻辑 viewport 与 GPU 读回尺寸可能不同；缩小已有截图不能声称在较小窗口重新运行。修改共享显示方式时选择能暴露缩放风险的实际尺寸，无需让单处文案重复做全尺寸矩阵。

原生 Windows GUI 崩溃需查精确出错 EXE；console/headless 正常不能证明该 EXE 正常。相关命令见 [运行 smoke](../../workflows/godot-agent-smoke.md)。

## 黑区、裁图与展示

部分批量预览会显示同尺寸图像间的差分，未变化区可能呈黑色。怀疑黑帧时回读原 PNG 的 RGBA、非黑像素和变化范围，再单独查看或将关键状态并排；只凭差分预览不能判原文件损坏。

原截图与程序标注图分开保存。标注坐标来自真实 DOM/Control 或图像测量；不以生图重绘验收证据。实际尺度用于判断可读性和边缘，放大图用于定位像素原因。回复前查看最终版本，避免分析的图与交付的图不同。

多图索引用现有 Markdown/HTML 即可，注明状态、尺寸、改动与边界；不固定版式、图片数或标签表。可复用的采集脚本留在对应工具目录，一次性脚本和临时 profile 仅清理自己创建的对象。
