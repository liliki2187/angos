# 生图色彩：方向比较与精确匹配分开

2026-09-07 修订。颜色合同不是每次生图前的量化审批表。

## 方向探索

直接观察当前标杆和用户选定稿，描述背景、主要内容面、辅助色、重点与警示的角色，分析明度层级、冷暖、彩度和面积关系。色彩可以有灰度但不能失去清晰色相；不要把“去灰土”自动理解成调白地图、提高全屏饱和度或整体压暗。

用户要求配色变体时保留约定不变的构图、材质和内容，探索不同但同体系的色彩角色；不以“必须与原图 Delta E 相同”否决变体。无需在 prompt 前创建 ROI、Lab 或面积表。

## 精确延续已确认资产

只有同材质跨组件匹配、指定色值、批量生产或用户要求定量比较时，才选可比采样区，记录色彩空间、光照/阴影影响与容许差异。阈值来自该资产实际测试和用户要求，不使用统一 Delta E≤3、全屏亮度±3 或固定纸张面积比例。

保留局部调整范围，比较原图与新图。色值相近不等于材质一致；像素均值也不能代替宽块面、纹理密度、接触关系与整体气氛的目视判断。

## 分支隔离

clean-low-poly、高清微像素角色与其他分支分别使用自己的参考图。禁止把像素尺寸、半调、泛黄颗粒当成所有纸张的公共规则。当前运行资产的有效材质合同继续用于其消费者；新方向探索不会自动改写该合同。
