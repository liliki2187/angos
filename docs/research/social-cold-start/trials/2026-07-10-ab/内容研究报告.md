# 2026-07-10 Angus 社媒冷启动内容研究报告

> 本报告只整理本次试运行提取到的案例、内容规律和 Angus 可执行方向，不讨论模型能力评分。互动数据是 2026-07-10 的可见快照，不是实时值。

## 先说结论

1. **最能拉新注意的不是“独立游戏”身份，而是一个发生在熟悉生活里的具体异常。**“十年前停播的节目又出现”“洗衣机看不到底”“角色知道自己忘了最重要的事”，都比功能清单或“第几章上线”更容易让陌生人停下来。
2. **最能促成评论参与的是一个可以提交的任务。**有身份、资源限制、评分、二选一或明确后果的题目，比“大家觉得发生了什么”更容易把浏览者变成参与者。
3. **报纸、档案、聊天记录等形式容易获得点赞、收藏和工具需求，但不会自动带来游戏转化。**它们应承载矛盾证据或编辑判断，不能成为账号主线本身。
4. **真正接近转化的内容往往不高赞。**Demo、愿望单、攻略、答疑和里程碑帖更像漏斗下游，不能拿它们与怪谈爆款比较点赞规模，也不能把低赞直接判成失败。
5. **成熟传播不是一篇爆款，而是一条链。**异常情境获得注意，评论任务产生参与，网页微体验承接行动，攻略 / 答疑维持关系，统一入口和商店页再承接转化。
6. **Angus 最适合扮演“异常新闻编辑部 / 未解之谜投稿站”。**用户先做值班编辑、判断证据和决定报道口径，再逐渐理解这些行为来自一款主编经营游戏。

## 证据范围

- 两组分别执行同一套 12 组小红书查询、4 组通用网页查询和最多 6 条详情深挖；合并正文、历史参照及人工补看入口后，共涉及 44 个不同小红书链接。
- 本报告只选取能说明曝光、参与、关系、转化或失败边界的代表案例；相同链接只保留一次。
- 小红书接口没有返回可靠发布日期。本报告不采用笔记 ID 推定日期，因此以下内容只能叫“本次采集样本”，不能据此宣称“本月正在流行”。
- 大部分案例只有平台搜索摘要；已成功读取全文的条目会单独说明。愿望单、访问量等数字多为作者自报，Steam 公开页面只能验证作品和 Demo 存在，不能验证愿望单归因。
- 评论 / 点赞比只是参与结构信号，不是转化率。评论内容未抽样核验时，不能把全部评论视为有效推理。

《诡异广告调查事件》《寻找陈雨彤》《潜意识侦破》和 Exposure 等成熟案例来自本轮读取的正式历史基线，用来对照新采集样本；它们不计作 2026-07-10 新发现。

评论结构最强的案例通常包含四个条件中的三个：

1. 用户有一个具体身份，例如幸存者、考生、调查员或值班编辑。

## 成熟冷启动案例怎么运作

### 1. 《诡异广告调查事件》：生活叙述先行，再露出可玩入口

- **可见结果**：5310赞 / 852评。
- **内容链**：日常生活背景 -> 发现停播节目或异常广告 -> 线索越来越不对劲 -> 用户需要继续调查 -> 网页事件承接。
- **为什么成熟**：第一篇即使不知道作品名也能成立；网页入口不是孤零零的链接，而是解答当前疑问的下一步。
- **Angus迁移**：首篇写成“编辑部收到一份无法归档的材料”，结尾只要求一次报道判断；第二步再开放档案或搜索入口。

### 2. 《寻找陈雨彤》：第一人称求助把用户变成调查者

- **可见结果**：首发求助帖3961赞 / 351评；后续出现多篇游玩repo和保姆级攻略。
- **内容链**：人物失踪求助 -> 登录账号 / 搜索材料 -> 论坛、录音、小说和彩蛋 -> 玩家攻略和情感复述。
- **为什么成熟**：它同时有拉新情境、可玩入口和后续二创；玩家能够用自己的语言复述完整体验。
- **暴露的问题**：攻略反馈指出主线容易落入套路、关键线索依赖粗体。形式真实不等于玩法新鲜，引导也不能只靠视觉强调。
- **Angus迁移**：所有剪报、录音和人物稿都应服务于一个可复述的编辑结论；上线前准备无剧透提示和卡点兜底。

### 3. [《潜意识侦破》](https://www.xiaohongshu.com/explore/6a37de3d0000000008027edc)：评论参与与游戏结构高度同构

- **可见结果**：1074赞 / 732评。
- **内容链**：老报纸 / 警务档案 -> 关键词搜索 -> 审讯 -> 多结局 -> 作者答疑。
- **为什么成熟**：用户在社媒上做的“读材料、找关键词、讨论结论”，与进入游戏后的核心行为接近，评论不是与产品无关的热闹。
- **Angus迁移**：冷启动问题应尽量模拟主编行为，例如给报道可信度打分、选择派谁调查、决定刊登或压稿。

### 4. 《清河大学 ARG》：材料本身就是玩法

- **可见结果**：1477赞 / 202评。
- **内容链**：学校官网、邮箱、校园墙和门禁记录共同构成坠楼事件；用户直接判断相信谁并留言。
- **为什么成熟**：没有“先看宣传，再跳去玩”的断层；用户眼前的网页材料已经是产品体验。
- **Angus迁移**：首个网页微事件只需要一个主操作，例如搜索关键词或按时间排列材料；不必一次堆满邮箱、论坛、录音和人物系统。

### 5. Exposure：爆发后仍有清楚的玩法说明和社区管理

- **可见结果**：[新手玩法指引](https://www.xiaohongshu.com/explore/69c488cd0000000021010f7d)2706赞 / 209评；[录音文件](https://www.xiaohongshu.com/explore/69c3850d000000001a02097e)393赞 / 58评。
- **内容链**：异常笔记 -> 网页 / 关键词 -> 下一篇 -> 录音等载体轮换 -> 二创、攻略和作者回应。
- **为什么成熟**：它不只会制造谜面，还处理新手入口、内容预警、二创授权、冒充教程和重复问题。
- **Angus迁移**：正式拉新前就准备一篇不破坏沉浸感的“值班编辑须知”，以及内容预警、统一入口和二创边界。

### 6. “十年前停播的节目”为何有效、又为什么还不够

- **可见结果**：3732赞 / 190评。
- **优势**：标题是一件具体异常，“玩到后面有人敲门”提供现实越界瞬间，远强于“沉浸式、多结局、网页解谜”等抽象标签。
- **不足**：当前摘要没有入口点击、试玩和愿望单数据，只能证明曝光钩子。
- **Angus迁移**：可以学习具体瞬间，不能学习伪造现实骚扰或只靠惊吓；后续必须给用户一个编辑行动。

## 游戏宣发内容的具体规律

### 有效起手式

- **角色困境比背景设定更好理解。**同账号的“她知道自己忘了最重要的事”获得179赞 / 46评；另一篇“他只想当一个好人”是53赞 / 6评。两帖还有配图、发布时间等变量，不能归因角色性别，但信息缺口明显更可讨论。
- **让陌生人先看到情境，再看到作品名。**“十年前停播的节目”“空难唯一幸存者滞留孤岛”都比标题只写游戏名和章节更完整。
- **试玩入口必须回答当前疑问。**清河大学、黑室记录和短网页解谜都把搜索、解锁或找回角色作为自然下一步。
- **系列编号只有在每篇能独立成立时才有用。**“第六个网页解谜”有1317赞 / 257评；单纯的“《全网公敌》第一章：程序员之死（上）”只有2赞 / 0评。编号不能代替陌生人钩子。

### 开发日志怎么发

- 发“一个可感知变化”，不要发流水账。例如：本周取消粗体线索、补了搜索失败反馈、把30分钟流程压到15分钟。
- 角色故事后必须接一个节点，例如内测、Demo、试玩反馈或新品节；否则只能建立氛围，无法承接行动。
- 里程碑应同时写下一阶段承诺，而不是单独晒数字。愿望单数字要标明自报，不把累计结果归因某一篇帖子。
- 攻略和答疑属于关系维护。它们能暴露卡点、减少作者救火，但不适合做陌生人的第一篇入口。

### 明确反例

- [只写游戏名、章节和实况切片](https://www.xiaohongshu.com/explore/6a4e715000000000070245a3)：2赞 / 0评，陌生人不知道为什么要继续看。
- [只写“破不了案就死”](https://www.xiaohongshu.com/explore/6a32c8bd000000002103ee18)：341赞 / 0评，强后果句能获得注意，但没有可提交任务，参与链仍会中断。
- [只有档案编号和危险等级](https://www.xiaohongshu.com/explore/6a4e463c000000001702fb6d)：8赞 / 1评，机构感建立了，用户却没有行动。
- 只靠旧论坛、失踪、人体实验或邪神献祭：容易进入已经被2549赞 / 196评集中批评的同质化区域。

## 与游戏无关或弱关联的维护内容

### 值得做

1. **日常物件的单一异常**：洗衣机看不到底1341赞 / 365评。重点不是论坛体，而是“所有人都认识这个物件，却有一处无法解释”。
2. **证据判断题**：法医血痕测试183赞 / 289评。可迁移为报纸照片、时间戳、证词或版面错误判断，但现实刑侦知识必须有可靠来源。
3. **旧照片 / 录音共同辨认**：[60年前胶卷](https://www.xiaohongshu.com/explore/67450ddb0000000002018bd6)9赞 / 9评，规模小但天然具有协作调查结构；虚构素材比现实陌生人照片更安全。
4. **题材反思与征集**：[“现在的都市怪谈都没意思了”](https://www.xiaohongshu.com/explore/6a4a41970000000021015773)24赞 / 13评，通过批评同质化征集真正会发毛的故事。Angus 可以改成“本周编辑部拒收了哪些没有判断价值的投稿”。
5. **网页解谜推荐与攻略**：能维持同类受众活跃，也有机会让推荐账号和玩家成为扩散节点。必须控制比例，避免账号变成泛解谜资讯号。

### 只能少量做

1. **报纸 / 档案模板**：曝光很强，但容易吸引只想做OC、接委托或下载模板的人。若发，必须绑定一条异常线索或报道选择。
2. **聊天记录和证据整理工具**：需求真实，但现实伪造、诈骗和隐私风险高。只能做明确虚构、不可导出的编辑部材料。
3. **泛开发者宣发经验**：[独游发售宣传经验分享](https://www.xiaohongshu.com/explore/6a336200000000000f02ad8f)1044赞 / 27评，适合低频幕后内容；它吸引的是同行，不一定是未来玩家。
4. **纯梗与玩家反应**：可帮助二次传播，但[单独一条只有1赞 / 0评的样本](https://www.xiaohongshu.com/explore/6a4f95030000000021019e5b)说明，不能把可截取笑点当核心内容。

## Angus 建议的账号内容结构

以下比例是四周试运行建议，不是已经验证的稳定规律：

| 内容支柱 | 建议占比 | 主要目标 | 典型内容 |
| --- | ---: | --- | --- |
| 编辑部主线调查 | 40% | 拉新 + 参与 | 异常投稿、矛盾证据、报道口径选择 |
| 事件后续与微体验 | 20% | 关系 + 试玩 | 评论结果、网页搜索、录音、编辑批注 |
| 弱关联受众维护 | 20% | 保持活跃 | 日常异常、证据判断、旧照片、网页解谜推荐 |
| 开发与转化节点 | 15% | 信任 + 转化 | 可玩变化、Demo、商店页、愿望单、试玩反馈 |
| 答疑与社区秩序 | 5% | 降低摩擦 | 新手须知、内容预警、二创规则、常见卡点 |

每篇只能有一个主目标。拉新帖看停留与评论任务，关系帖看回访和旧线索引用，转化帖看入口点击和完成反馈；不要让一篇帖子同时承担世界观介绍、玩法说明、开发日志和愿望单请求。

## 前12篇冷启动排期草案

> 以下都是社媒实验母题，不是 Angus 世界观或剧情定案，不写入 GDD。

| 顺序 | 选题母题 | 用户动作 | 主要验证 |
| ---: | --- | --- | --- |
| 1 | **编辑部来件001：明天的报纸今天送到了** | 选择刊登、压稿或继续核验 | 具体异常能否让陌生人参与 |
| 2 | **同一事故出现了两份完全相反的头版** | 给两份报道打可信度分并写一条依据 | 可计算问题是否优于开放猜测 |
| 3 | **值班结果：我们按评论选择刊登后，城市里少了一个地名** | 对比上篇线索，提出下一调查方向 | 用户是否回访并引用旧线索 |
| 4 | **记者从地图上不存在的小镇发回录音** | 决定派谁接应，说明风险 | 角色身份与后果能否提升参与 |
| 5 | **编辑部所有钟都慢了7分钟，只有录音时间没变** | 找出最可能伪造的证据 | 日常物件异常能否作为维护内容 |
| 6 | **三张剪报里只有一张来自真实的昨天** | 证据判断题 | 知识 / 观察型参与质量 |
| 7 | **开放一个15分钟档案搜索页** | 输入关键词、提交最终报道 | 评论参与能否进入可玩微体验 |
| 8 | **搜索页结案批注与常见卡点** | 分享卡点或无剧透提示 | 攻略 / 答疑是否促成关系维护 |
| 9 | **一名调查员记得明天，却不记得自己** | 选择相信人物、材料或时间戳 | 角色信息缺口与系统说明的差异 |
| 10 | **编辑部拒稿：为什么“失踪 + 邪教”已经不够了** | 投稿一个真正需要编辑判断的异常 | 题材反思能否带来高质量投稿 |
| 11 | **这周只改了一件事：不再用粗体替玩家找线索** | 比较新旧搜索反馈 | 可感知开发日志是否建立信任 |
| 12 | **值班编辑入口开放** | 进入统一主页、试玩或添加愿望单 | 何时公开游戏身份和转化入口 |

更稳妥的首个三篇连载是：`异常来件 -> 评论决定报道 -> 报道造成可见后果并开放短网页事件`。它比一开始发完整世界观、团队介绍或Steam请求更贴近成熟案例的传播链。

## 单篇内容模板

1. **第一屏只放一件不可能发生的事**，不用“沉浸式、悬疑、多结局”等抽象形容词。
2. **中段提供2至4条可比较材料**，每条都应改变判断，而不是只补氛围。
3. **结尾只给一个动作**：二选一、0至100分、选择一名记者、指出一条伪证或决定刊登口径。
4. **预告反馈方式**：次日公布编辑部采取了什么行动，以及评论如何影响后续。
5. **入口只在能承接当前疑问时出现**。不要每篇都塞Steam链接，也不要为了沉浸永远隐藏入口。

## 下一轮四个单变量实验

1. **首句框架**：同一材料只对照“本周开发了一套调查玩法”与“编辑部收到一份无法归档的维修记录”。
2. **提问结构**：同一事件只对照开放推理与“可信度0至100分 + 一条依据”。
3. **入口时点**：同一微事件只对照首发即放入口与24小时后补入口。
4. **形式绑定**：同一异常只对照纯报纸模板与“报纸 + 一项报道判断”。

统一记录曝光、有效推理评论、回访评论、求入口、实际点击、完成反馈和愿望单表达。一次只比较一个变量，点赞只作为曝光旁证。

## 不应照搬的内容

- 不冒充真实失踪、真实执法档案或现实骚扰，不用“真实事件改编”制造真假混淆。
- 不把旧论坛、粗体关键词、编号档案和泛黄报纸当作玩法差异。
- 不让规则数量变成阅读考试，不在首个微事件堆叠所有载体。
- 不把模板收藏者、同行开发者或怪谈评论者直接换算为潜在玩家。
- 不把愿望单当销量，不把累计愿望单归因某一篇小红书帖子。
- 不因为高赞零评就宣布成功，也不因为低赞转化帖就宣布失败。

## 当前最值得执行的一件事

先不要做完整账号视觉包装或重型聚合站。优先制作一套三篇连续但每篇可独立阅读的冷启动实验：

1. 一份发生在熟悉生活中的异常材料。
2. 一个有后果、可提交的编辑判断。
3. 24小时后公布结果，并用一个15分钟以内的网页事件承接。

这套实验能同时验证 Angus 的账号定位、评论参与质量、连载回访和网页入口转化，是本次案例库中证据交集最大的起步方式。
