# Angus 社媒冷启动手册

> 当前版本：v0.1 历史基线  
> 状态：四周试运行假设，尚未经过连续周报验证

## 账号定位

Angus 的小红书账号优先扮演“异常新闻编辑部 / 未解之谜投稿站”，而不是纯开发日志账号。用户先参与调查、判断和报道选择，再逐渐知道这些行为可以在游戏里成为完整的主编体验。

## 当前传播链假设

1. 小红书发布第一人称异常投稿或编辑部求助。
2. 评论区完成猜测、调查方向、标题或报道口径选择。
3. 高价值事件进入网页微型档案、关键词搜索或短Demo。
4. 发布提示、攻略、编辑批注、录音、剪报和人物补充。
5. 鼓励玩家攻略、测评、二创和梗图，并建立内容预警与授权规则。
6. 用统一主页承接系列入口、Steam商店页和愿望单。

## 冷启动内容结构

- 核心内容：异常投稿、档案线索、报道判断、连续事件。
- 参与内容：投票、评论区调查、标题选择、可信度判断。
- 弱关联维护：网页解谜推荐、报纸模板、未解之谜素材、编辑部幕后。
- 转化内容：网页微体验、Demo、Steam商店页、愿望单和试玩反馈。

## 当前成功指标

- 曝光：赞、收藏和播放规模。
- 参与：有效推理评论数、评论 / 点赞比、投票与投稿。
- 关系：关注、系列追更、用户主动引用旧线索。
- 转化：求入口、实际试玩、愿望单和商店页相关表达。

点赞高但没有调查、追更或入口需求的内容，只能证明形式吸引力，不能证明游戏转化。

## 四周需要验证的问题

1. 第一人称“求助 / 投稿”是否持续优于直接游戏介绍。
2. 评论区选择题、开放推理和正式投票，哪种参与质量更高。
3. 报纸、录音、聊天记录、电脑桌面中，哪种载体更适合 Angus。
4. 弱关联内容能否带来同一受众，而不是吸引只想要模板的人。
5. 哪个节点公开游戏身份和Steam入口，既不破坏沉浸感又能形成转化。

## 修订门槛

- 单周爆款只能进入周报，不直接改写本手册。
- 同一模式至少在不同账号、不同周次或同账号对照中重复出现，才可升级为稳定建议。
- 与 Angus 核心体验冲突的高互动形式，只记为平台规律，不强行迁移。
- 每次修订保留旧结论、证据变化和修订日期。
