# Angus 社媒冷启动持续监测

## 目标

持续观察独立游戏及相邻内容在小红书、Steam、B站、抖音 / TikTok、TapTap、YouTube、Reddit 等平台的传播方式，为 Angus 的账号冷启动、日常活跃内容、Demo 与商店页转化提供可复查证据。

本目录不把单条爆款直接当作结论。监测必须同时区分：

- 曝光：点赞、播放、收藏等规模信号。
- 参与：评论密度、投票、推理、投稿、求助和二创。
- 转化：求入口、求试玩、愿望单、Demo 下载、商店页访问等信号。

## 自动化流水线

| 阶段 | 计划时间 | 模型 | 主要产物 |
| --- | --- | --- | --- |
| 原始扫描 | 每周五 10:00 | GPT-5.6 Luna / low | 原始扫描/日期.md |
| 周度归纳 | 每周五 17:00 | GPT-5.6 Terra / medium | 周报/年份-W周数.md |
| 周期复盘 | 每月第二个周六 10:00 | GPT-5.6 Sol / medium | 冷启动手册.md 与周期复盘 |

定时任务运行在 D:\angos 本地项目中。首次真实触发前，状态只能写“已配置、未验证”，不能宣称自动调度已经可用。

## 文件职责

- 检索词池.md：固定搜索轴、轮换词和低效关键词。
- 案例库.md：经筛选后的长期案例，不是原始搜索结果堆。
- 监测状态.md：覆盖窗口、最后成功运行、下次窗口和调度验证状态。
- 待人工补看.md：平台限制导致无法阅读全文、但值得用户补看的笔记。
- 原始扫描/：Luna 每周生成的候选样本。
- 周报/：Terra 根据原始扫描和历史基线形成的周度判断。
- 周期复盘/：Sol 合并近期周报后形成的证据摘要与策略修订记录。
- 冷启动手册.md：Sol 按周期修订的长期策略，不因单周热点随意改写。
- trials/：一次性模型、检索协议或提示词对照，不计作正式定时运行。2026-07-10 的案例与策略整理见 [`trials/2026-07-10-ab/内容研究报告.md`](./trials/2026-07-10-ab/内容研究报告.md)，模型配置结论见 [`trials/2026-07-10-ab/对照评分.md`](./trials/2026-07-10-ab/对照评分.md)。

## 证据规则

1. 平台内搜索和通用网页搜索必须分开标注；没有平台内证据时，不得写成“平台上没有案例”。
2. 点赞数不能单独代表成功；优先同时记录评论、收藏、发布时间、账号阶段和转化表达。
3. 每轮保留高互动、中位、低表现对照和“低赞高评论”异常样本，避免幸存者偏差。
4. 新发现与历史追踪分开；旧案例只有出现新数据、衍生内容、攻略、二创或转化进展时才重新进入重点。
5. 小红书全文受限时，不反复扫码或卡住任务；记录标题、链接、可见摘要、数据和“待人工补看原因”。
6. 所有结论都要区分事实、推断和 Angus 可迁移建议。
