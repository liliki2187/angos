## 2. 持续成立的模式：仅为重复机制观察，未升级为稳定策略

以下观察至少跨周重复，但没有足够的跨平台、同账号对照或可归因后续数据，仍停留在“高优先级验证”层：

1. **首发、帮助、玩家复述与承接入口承担不同职责。**W29 的灵异论坛 / 清河大学、W30 的毕业季失踪事件、W31 的桌面探索者、W32 的探案法均出现官方内容、提示 / 攻略、实况 / repo / 通关感想或商店承接中的多个节点。证据满足跨周和传播链后续观察，但发布日期、先后因果与归因不足，不能证明固定发布顺序有效。
2. **具体动作与体验边界反复成为可复述信息。**关键词核对、审稿、回看、保存、提交、完成状态，以及桌面端、时长、可中断、内容提示，在 W29—W32 多次出现。它们可作为内容和落地页的信息合同；尚无同一产品加 / 不加这些字段的完成率对照。
3. **点赞、评论、关系和转化必须分开。**四周都出现高赞 CTA、低赞高评、低量攻略 / 卡点等不同结构，但没有点击、试玩完成或愿望单后台。该模式支持继续分层计数，不支持把任何互动指标换算为转化。

## 3. 被削弱或推翻的判断

### 被削弱：报纸、档案或伪桌面外观本身足以驱动冷启动

- **证据**：W29 的质量争议与购买后摩擦，W30 的卡点 / 设备说明，W31 的回看、保存和提交问题，W32 的可认领完成状态都把注意力拉回具体动作和完成摩擦。
- **可迁移点**：视觉继续服务 Angus 的编辑部身份，但每件材料必须绑定一个明确动作和一个可见结果。
- **不可照搬点**：这些是跨作品机制样本，不足以否定 Angus 现有美术方向，也不能替代本项目可用性测试。
- **验证方式**：同一案件、同一视觉素材下，只改变“是否给出明确动作与结果反馈”，比较任务开始率、完成率和误读类型。

### 被推翻：泛“伪新闻 / 账号异常”适合作为稳定检索或标题入口

- **证据**：W32 中 `伪新闻` 18 条可见卡片有 17 条落入网警、谣言、时政或新闻讨论；`聊天记录 账号异常` 20/20 为现实服务噪声。
- **可迁移点**：改用“具体载体 + 异常动作”，如撤回的寻人帖、停播节目录音、查无此案编号。
- **不可照搬点**：这是当前小红书语义入口失效，不等于用户不接受伪媒介题材。
- **验证方式**：下一周期用同一事件分别测试具体载体标题与泛题材标题，只比较相关评论率、求入口率和误入类型。

## 4. 仍待验证的假设

1. 第一人称“编辑部求助 / 投稿”是否持续优于直接游戏介绍；当前缺同账号、同素材对照。
2. 三选一判断、开放推理和正式投票中，哪一种产生更高比例的有效参与；当前评论全文长期不可见。
3. 报纸、录音、论坛帖与伪桌面中，哪一种最适合 Angus；当前样本多为跨作品比较，不能归因载体。
4. 弱关联维护内容能否带来同一批调查型受众；高赞清单、模板与工具热度均无后续访问 / 试玩证据。
5. 网页微体验、Demo 与 Steam 商店页应在哪个节点接入；当前只确认“入口存在”，没有从社媒到点击、开始、完成和愿望单的链路数据。

## 5. 新出现的弱信号

- **可认领的完成状态可能是传播接力单位。**W32 出现“打完了”、repo、章节与通关感想并存；可尝试用“第 2 版勘误已核对”等 Angus 原生状态，但不得把单作品内容并列当作增长因果。
- **开始门槛与深入门槛可能需要两个入口。**短切片回答“现在能否开始”，长实况 / Demo 回答“是否值得投入”；证据跨平台、跨作品，暂不能比较效果大小。
- **图文索引可能更适合作为可玩内容后的补口。**目录、图文版和聚合清单反复出现，但收藏 / 点击 / 完成数据缺失，不能提前建设大社区或把模板热度当玩家关系。

## 9. 下一周期四个单变量内容实验

每个实验只改变一个变量；素材、发布时间段、版式、篇幅、账号和入口均尽量保持一致。曝光、参与、关系、转化分别计数，不以点赞替代完成或愿望单。

1. **标题载体实验**：具体载体标题“被撤回的寻人帖”对照泛题材标题“一条伪新闻”；唯一变量为标题框架，两版均保留相同的虚构标识。主指标为相关有效评论占比，次指标为误入 / 辟谣讨论占比。
2. **参与问题实验**：同一事件末尾使用“三选一：刊出 / 压下 / 继续查”对照开放问句“你会怎么处理”；唯一变量为提问形式。主指标为有效判断评论占比，另记理由完整度和灌水占比。
3. **体验边界实验**：同一网页微体验入口，有 / 无“桌面端、预计 5—15 分钟、可中断、内容提示”固定卡；唯一变量为边界卡。主指标为入口点击后的开始率与完成率，另记重复提问和误入反馈。
4. **承接位置实验**：同一微体验链接放在首帖正文对照完成一次评论判断后再由置顶评论承接；唯一变量为 CTA 位置。主指标为有效点击、开始和完成率。Demo / Steam 尚未真实可用时不得替换成空入口；真实可用后再沿用同一设计记录 UTM 与愿望单。
