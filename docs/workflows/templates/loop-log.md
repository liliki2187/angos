# Loop Log

> 自动触发：用户说“这次错在 / 为什么又 / 怎么避免 / 复盘 / 先别落地 / 不改文件 / 这个要进错题本 / 转成 eval case”，或父级自检发现产物类型、阶段、证据、agent、可读性或实现范围误判时，必须使用本模板。不能只道歉。

## 决策条 / Decision Strip

- **结论**：本轮哪里错；当前继续 / 降级 / 返工 / 停止 / 需要你裁决。
- **影响**：这个错会挡住什么，或为什么不能继续按原结果推进。
- **下一步**：本轮只复盘 / 降级 / 补证据 / 转 eval case / 更新 gate。

- **一句话结论**：这次问题的本质是什么，当前应继续、降级、返工、停止还是交给用户裁决。

## 不合格 Loop Log

- 只道歉或只解释，没有 `失败归因`。
- 没写本轮产物继续、降级、返工、停止还是交给用户裁决。
- 没写复发保护。
- 可迁移错误没判断是否沉淀。
- 用户要求不改文件时仍改文件。
