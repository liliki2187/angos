# Angus 验证与交接说明

验证力度按本次改动的后果和实际消费者选择。设计与权限入口见 [AGENTS.md](../../AGENTS.md)，角色路由见 [协作说明](../onboarding/subagent-collaboration-improvement.md)，此处不另设制作流程。

| 受影响范围 | 有用的检查 |
| --- | --- |
| 讨论、文案或规范 | 回答范围、真源与引用；改可执行工具时检查其实际行为 |
| 风格稿、配色或隔离 mock | 看原图与实际结果，核验本轮指定输出属性，说明未验证项 |
| 内容布局、状态或代表装配 | 真实常态与风险状态，图文组合、输入语义和对应消费者 |
| 正式替换、共享组件或批量资产 | 合同及迁移、受影响运行路径、必要回归与可恢复原件 |
| 外部发布、删除或不可逆操作 | 精确目标和实际授权；可先完成获授权的准备工作 |

文档改动不触发 Godot 或截图；运行实现改动不能只验文档。GDScript 改动检查解析与受影响运行行为；涉及入口、autoload、阶段切换或共享依赖时扩大至相关主流程。是否使用 [Godot 组合 smoke](godot-agent-smoke.md) 取决于它覆盖的路径，不取决于文件扩展名。可见运行改动按 [截图指引](../onboarding/功能改动截图指引.md) 给真实证据。

检查通过且依赖未变化的证据可以引用；新的修改、失败或未解决风险才需要重跑或扩测。说明检查证明了什么，不以断言数或角色名证明美术质量。完成当前请求即交付，不自动进入下个界面或下一批生成。

[workflow-gates.yml](workflow-gates.yml) 是产物身份与条件说明目录，不是自动执行引擎。`scripts/check_delivery_manifest.py` 仅在调用时检查交付记录字段与产物身份，不运行其中的 gate。正式调用某个验证工具时遵守其输入/输出约束，不能把未运行的声明写成通过。

长期任务更新原 STATUS；复杂交接才按需使用模板。重复失败、范围/证据误判或明确复盘时，在现有记录写原因、方法变化、证据和限制。普通反馈不自动形成永久门槛；用户要求不改文件时尊重范围，不自动写复盘。

Git 盘点、提交、推送和跨端交接仍执行 [git-cloud-submit](../../skills/git-cloud-submit/SKILL.md)，本次精简不改变权限、分类或远端保护。GUI 崩溃需要核验出错的精确可执行文件，headless 通过不能替代。
