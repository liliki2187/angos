### A42. 角色与概念风格参考采用“Q版主编 + 巨大周刊现实撕裂”方向
- **来源**：2026-06-10 角色设计与概念风格参考讨论；用户明确要求以当前提供的主编角色图与标题页图作为角色设计和概念风格参考。
- **机制**：后续主编 / 编辑角色与核心概念图应优先参考“高精度 Q 版黑色幽默编辑 + 巨大周刊头版 / 浏览器窗口 / 印刷物件撕开现实”的方向。角色可保留蓬乱黑发、厚框眼镜、风衣 / 编辑工装、工牌、报纸叠、印章 / 签批工具等职业符号；画面主视觉强调周刊版面作为现实改写机器，使用深蓝、红橙、米白、青色异常光、半调网点、像素城市剪影、套印错位和像素粒子。该方向是角色设计与概念风格参考，不等于把所有 UI 或角色全部像素化，也不等于回到旧报纸 / 旧档案 / 暖木复古路线。
- **应用范围**：主编 / 编辑角色设计、标题页 / 概念图、关键视觉、视觉 prompt、后续美术风格稿和宣传图方向。
- **状态**：已采纳为角色设计与概念风格参考；Riso 印刷风格与 `Nirvana Noir` 风格融合仍待本轮讨论后确认，不在本条直接写死。

### A45. 视觉风格稿生成后必须由 `@像素艺术` 复审颗粒度与标杆继承
- **来源**：2026-06-11 世界地图界面元素风格稿反馈；用户指出生成稿整体不错，但像素颗粒度不太像标杆界面的像素风，并追问生成后是否让 `@像素艺术` 看过。
- **机制**：后续 UI 风格稿、美术资源包、界面元素风格稿或生图结果，若要被称为生产标杆、资源标杆或真源候选，必须在生成后再交 `@像素艺术` 复审。复审不只看“整体是否好看”，还必须检查像素颗粒度、颗粒密度、半调 / 套印是否成为结构语言、是否继承当前标杆图、动态文字安全区是否可落地，以及是否滑向旧报纸、旧档案、泛黄纸噪点或高清摄影噪声。
- **应用范围**：世界地图 / 全球频道资源、所有 UI 视觉风格稿、生图 prompt、生成后验收、截图风格复核和后续美术资源生产。

### A65. 派遣签批台干净象牙纸与像素印刷约束（回链）
- **来源**：2026-06-16 派遣签批台整屏风格稿 v2 反馈与 `@像素艺术` 二次复审；主条目见 `ui-ux-decisions.md` A65。
- **美术判断**：v2 构图与三栏功能方向可保留，但当前不能作为生产标杆；纸边、红底板、折角、破损污渍、金属夹、掉漆按钮和摄影级纸纹会把 Angus 拉向旧案卷 / 泛黄档案 / 写实旧物件，与“现代异常周刊 + 印刷物质感 + 像素材质”的正式方向冲突。
- **执行约束**：派遣签批台及同源签批纸、任务纸、员工卡、CTA、状态章的纸面应使用干净暖白 / 浅象牙新印刷纸，允许轻微纸纤维、印刷压痕、套印错位、块状半调和 2-4px 像素颗粒，但不得出现脏污、茶渍、破败、撕裂、黄褐旧档案、旧报纸、sepia、随机摄影噪声、金属锈蚀或掉漆旧机器质感。正文安全区纹理强度应降到几乎不可见，装饰颗粒必须退到 `no_text_rects`。
- **状态**：作为 A65 的美术回链已采纳；后续派遣签批台风格稿若仍出现旧档案 / 脏旧纸 / 写实旧物件倾向，应判为未通过生产标杆复审。

### A67. 地区任务地图不得被程序化低保真地图替代（回链）
- **来源**：2026-06-16 地区任务地图资源返工反馈；主条目见 `ui-ux-decisions.md` A67。
- **美术判断**：用户认可的是上一套地区任务台中间地图的深海军蓝、低多边形纸质分面、红青半调、裁切线、像素颗粒和现代编辑部地图墙气质。程序化多边形地图、简化矢量大陆、白盒调试网格和低保真 PIL / Canvas / SVG 绘图即使尺寸正确，也不具备该视觉证据链，不能作为正式地图资源或生产标杆。
- **状态**：作为 A67 的美术回链已采纳；后续 `@像素艺术` 审地区任务地图时，必须检查候选图是否继承原地图视觉源，而不是只看“没有 pin / 标签”或“内容区干净”。

### A82. 地区任务台 v3 整屏图作为视觉锁定源（回链）
- **来源**：2026-06-17 地区任务台资产 UI 化返工继续推进；主条目见 `ui-ux-decisions.md` A82。
- **美术判断**：本轮用户明确认可的是整张地区任务台图的综合视觉效果，而不只是“地图质感”单点。后续美术与 UI 落地应保留深蓝工作台、中央低多边形纸质地图、暖白新鲜印刷纸、红青套印、半调网点、夹具 / 档案 / 票据物件关系和现代杂志社工作台气质。若为了拆功能而重画成低保真地图、普通后台面板、旧档案纸、脏旧报纸或另一套配色，应判定为跑偏。
- **执行约束**：`rt_artboard_full` 可以作为视觉锁定底图和高保真恢复参考，但动态文字与可点击状态仍需由 UI 动态层或独立组件承担；美术复审重点是“功能化之后是否仍像同一张图的生产版”，而不是只看局部文本是否没出框。
- **状态**：作为 A82 的美术回链已采纳；后续地区任务台截图复审应先确认中央地图与整屏气质未被替换，再检查按钮、任务卡、右侧详情和 CTA 是否进入同一视觉系统。

### A96. Color Contract Gate 作为像素艺术色彩硬闸门（回链）
- **来源**：2026-06-22 世界地图像素颗粒度分支实验；主条目见 `process-and-research-decisions.md` A96。用户指出 B5 虽被宽合同标为通过，但肉眼仍与参考图不同；`@像素艺术` 复盘判定 B5 只能作为宽合同误判案例。
- **美术判断**：颜色匹配不是“整体像 Angus”的主观判断，必须先过 `docs/onboarding/imagegen-color-contract-gate.md`。`@像素艺术` 复审 UI 风格稿、资源候选或生图结果时，应先确认颜色硬闸门是否通过，再审像素颗粒、半调 / 套印、纸面旧化和动态文字安全区。颜色未过时，不能继续升级为生产标杆、资源标杆或真源候选。
- **状态**：作为 A96 的美术回链已采纳；后续色彩问题默认先看 Color Contract Gate，不能只凭“没有明显偏黄 / 过白”或“整体风格不错”放行。

### A109. 世界地图右栏半调证据图体量控制（回链）

- **执行约束**：后续世界地图右栏证据图应保持中等体量，约占右栏有效高度 25%-30%，接近 B7 参考图比例；图样应使用蓝黑半调、红青套印、裁切标记和印刷颗粒，但不得遮挡标题、状态章、正文、摘要行或 CTA 安全区。若 `推进一天` 已移到左下，右侧释放出的垂直空间优先给地区详情、任务线索和判断摘要，不用于继续放大证据图。

### A110. 推进一天实体日程器物性（回链）
- **来源**：2026-06-23 世界地图 / 地区界面推进一天位置讨论；主条目见 `ui-ux-decisions.md` A110。
- **美术判断**：`推进一天` 是全局时间闸门，不应继续画成普通米白纸卡或地区 / 任务信息卡。它可以更特殊、更实体拟物，但实体感应来自 Angus 的现代编辑部纸品 / 印刷装置语法：深蓝主体、金色日期框、米白小票 / 日期窗、红橙警示、裁切线、套印错位、可按压 / 可拨动结构和克制的 2-4px 像素颗粒。它不是旧金属机器、锈蚀办公器具、蒸汽朋克拨杆、泛黄旧日历或厚重写实控制台。
- **执行约束**：左下日程器应保持为独立物件，视觉权重高于普通列表卡但低于右侧 `进入地区 / 进入派遣签批` 主 CTA；纸面只作为日期回执 / 小票 / 标签，不作为主按钮容器。生成后复审必须检查：旧纸卡语义是否残留、控件是否一眼读成全局时间推进、是否提供确认态空间、是否与右侧 CTA 分离、是否保持 B7 深蓝 / 象牙 / 红橙 / 青色合同。
- **状态**：作为 A110 的美术回链已采纳。`36-b7-left-entity-advance-day-device-v1.png` 因叠放过低、旧纸卡语义残留，作为覆盖错误对照；`37-b7-left-entity-advance-day-device-v2.png` 与裁切 `38-b7-left-entity-advance-day-device-v2-crop.png` 作为当前实体日程器结构方向稿，仍非生产 no-text 组件。

### A112. 图3/图4升级为新的干净低多边形周刊风格标杆
- **来源**：2026-06-23 新旧美术标杆对比讨论；用户明确表示目前希望图3和图4作为新的风格标杆，并指出新标杆同样使用低多边形作为图形视觉元素，但整体更干净、质感更轻。
- **机制**：后续 Angus 全局视觉与 UI 风格探索应把图3/图4视为新的阶段性标杆：以深色编辑部底板、干净低多边形神秘图形、周刊封面、照片 / snapshot、文件夹、贴纸、CD、回形针、图标与色板组成现代周刊资产系统。新方向的重点不是重纹理拟物，而是低多边形几何、清晰版式、大块负空间、克制纸张材质和资产分组感；像素、半调与印刷感应更轻、更干净，避免此前过重的纸纹、噪点、污损和厚重旧物质感。
- **应用范围**：全局视觉风格稿、世界地图 / 地区任务台 / 派遣签批台等资产化 UI 的视觉包装、Steam 截图风格、图标 / 贴纸 / 文件夹 / 周刊封面 / 证据照片资源包、生图 prompt 与后续 `@像素艺术` 复审。
- **执行约束**：图3/图4可作为风格标杆，但落到可交互 UI 时仍需遵守动态文字安全区、正交可写面、真实机制物件和可玩界面职责。`style guide`、`color palette`、`graphic elements` 等开发板式语言不得直接进入玩家实机截图；需要转译成玩家正在操作的周刊工作台、案件材料、任务档案、发刊稿件或签批物件。
- **状态**：已采纳为新的阶段性美术风格标杆；已同步到 `design/art-direction/angus-visual-style-guide.md` 的 2026-06-23 补充。旧图1/图2不再作为排斥图3/图4的理由，但仍可作为“可玩 UI 结构 / 动态界面承载能力”的对照参考。

### A113. 新标杆低多边形必须是大块概括与手绘裁纸感
- **来源**：2026-06-24 世界地图标杆落地复审；用户指出当前世界地图组件稿与新标杆差异在于：原图图形更概括，低多边形是大块面并有一定手绘感；当前图1/2/5 的地图与快照缺少标杆的大块多边形风格，图3/4 的票条和 ticker 细小点、孔洞、微线过多。
- **机制**：新标杆中的低多边形不是密集三角网、GIS 纹理或摄影噪声，而是“形状经济”：用少量大块面、概括轮廓、轻微不规则切边和干净色块形成视觉力量。世界地图、地区卡缩略图、dossier 快照、周刊图像和异常场景应优先使用大块低多边形 / 手绘裁纸式图形；票条、ticker、CTA、图标 atlas 应减少孔洞、条码、短刻度、刮痕、微线和点阵，保留更大的图形关系。
- **应用范围**：世界地图组件母版、右侧地区 dossier、地区文件夹卡、地图板、地图 pin / sticker、ticker 票据、CTA / task-intel 票条、dossier 快照、后续生图 prompt、生成后 `@像素艺术` 复审。
- **执行约束**：主图形在缩到 25% 预览时应先读出大块地图 / 文件 / 票据剪影，而不是细线、孔洞、点和条码；100% 局部看时，半调应是块状结构，文字区应干净。每个小组件同屏最多保留一种微细节语言（孔洞、条码、点阵、短刻度、微线或纸边磨损），且必须服务状态或结构；动态文字安全区不得被孔洞、斜纹、半调、强纸纹或装饰线穿过。
- **Prompt 约束**：正向使用 `large simplified low-poly planes`, `bold blocky polygon shapes`, `editorial cut-paper graphic design`, `slightly hand-drawn imperfect polygon edges`, `halftone as large structured patches`, `minimal micro-detail`, `strong negative space`；负向写死 `no dense triangulation mesh`, `no tiny polygon web`, `no small holes`, `no barcode clutter`, `no scattered speckle noise`, `no photographic grain`, `no GIS terminal map detail`, `no overly detailed coastlines`, `no decorative micro-lines`, `no texture covering text areas`。
- **状态**：已采纳为新标杆执行细则。`docs/screenshots/2026-06-24-world-map-benchmark-landing/01-world-map-component-motherboard-v0.png` 与 `02-right-dossier-component-sheet-v0.png` 降级为方向草稿 / 偏差案例，不得作为生产标杆；下一轮世界地图右侧 dossier 应先重做大块低多边形快照和低微细节票条，再进入无字底图、overlay 与中文填充。

### A114. 新标杆质感由低多边形色块明度塑造

- **执行约束**：生成提示必须把 `texture through polygon value blocks`、`large flat shaded planes`、`graphic hand-drawn abstraction` 作为正向目标，并明确禁止 `texture-heavy`, `paper grain as detail`, `photographic noise`, `surface scratches`, `many tiny UI marks`。验收时先问：去掉纸纹和噪声后，图形是否仍靠大块明暗成立；如果不成立，说明风格没有继承标杆。
