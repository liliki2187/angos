### A42. 角色与概念风格参考采用“Q版主编 + 巨大周刊现实撕裂”方向
- **来源**：2026-06-10 角色设计与概念风格参考讨论；用户明确要求以当前提供的主编角色图与标题页图作为角色设计和概念风格参考。
- **机制**：后续主编 / 编辑角色与核心概念图应优先参考“高精度 Q 版黑色幽默编辑 + 巨大周刊头版 / 浏览器窗口 / 印刷物件撕开现实”的方向。角色可保留蓬乱黑发、厚框眼镜、风衣 / 编辑工装、工牌、报纸叠、印章 / 签批工具等职业符号；画面主视觉强调周刊版面作为现实改写机器，使用深蓝、红橙、米白、青色异常光、半调网点、像素城市剪影、套印错位和像素粒子。该方向是角色设计与概念风格参考，不等于把所有 UI 或角色全部像素化，也不等于回到旧报纸 / 旧档案 / 暖木复古路线。
- **应用范围**：主编 / 编辑角色设计、标题页 / 概念图、关键视觉、视觉 prompt、后续美术风格稿和宣传图方向。
- **状态**：已采纳为角色设计与概念风格参考；Riso 印刷风格与 `Nirvana Noir` 风格融合仍待本轮讨论后确认，不在本条直接写死。

### A65. 派遣签批台干净象牙纸与像素印刷约束（回链）
- **来源**：2026-06-16 派遣签批台整屏风格稿 v2 反馈与 `@像素艺术` 二次复审；主条目见 `ui-ux-decisions.md` A65。
- **美术判断**：v2 构图与三栏功能方向可保留，但当前不能作为生产标杆；纸边、红底板、折角、破损污渍、金属夹、掉漆按钮和摄影级纸纹会把 Angus 拉向旧案卷 / 泛黄档案 / 写实旧物件，与“现代异常周刊 + 印刷物质感 + 像素材质”的正式方向冲突。
- **执行约束**：派遣签批台及同源签批纸、任务纸、员工卡、CTA、状态章的纸面应使用干净暖白 / 浅象牙新印刷纸，允许轻微纸纤维、印刷压痕、套印错位、块状半调和 2-4px 像素颗粒，但不得出现脏污、茶渍、破败、撕裂、黄褐旧档案、旧报纸、sepia、随机摄影噪声、金属锈蚀或掉漆旧机器质感。正文安全区纹理强度应降到几乎不可见，装饰颗粒必须退到 `no_text_rects`。
- **状态**：作为 A65 的美术回链已采纳；后续派遣签批台风格稿若仍出现旧档案 / 脏旧纸 / 写实旧物件倾向，应判为未通过生产标杆复审。

### A82. 地区任务台 v3 整屏图作为视觉锁定源（回链）
- **来源**：2026-06-17 地区任务台资产 UI 化返工继续推进；主条目见 `ui-ux-decisions.md` A82。
- **美术判断**：本轮用户明确认可的是整张地区任务台图的综合视觉效果，而不只是“地图质感”单点。后续美术与 UI 落地应保留深蓝工作台、中央低多边形纸质地图、暖白新鲜印刷纸、红青套印、半调网点、夹具 / 档案 / 票据物件关系和现代杂志社工作台气质。若为了拆功能而重画成低保真地图、普通后台面板、旧档案纸、脏旧报纸或另一套配色，应判定为跑偏。

### A110. 推进一天实体日程器物性（回链）
- **来源**：2026-06-23 世界地图 / 地区界面推进一天位置讨论；主条目见 `ui-ux-decisions.md` A110。
- **美术判断**：`推进一天` 是全局时间闸门，不应继续画成普通米白纸卡或地区 / 任务信息卡。它可以更特殊、更实体拟物，但实体感应来自 Angus 的现代编辑部纸品 / 印刷装置语法：深蓝主体、金色日期框、米白小票 / 日期窗、红橙警示、裁切线、套印错位、可按压 / 可拨动结构和克制的 2-4px 像素颗粒。它不是旧金属机器、锈蚀办公器具、蒸汽朋克拨杆、泛黄旧日历或厚重写实控制台。
- **执行约束**：左下日程器应保持为独立物件，视觉权重高于普通列表卡但低于右侧 `进入地区 / 进入派遣签批` 主 CTA；纸面只作为日期回执 / 小票 / 标签，不作为主按钮容器。生成后复审必须检查：旧纸卡语义是否残留、控件是否一眼读成全局时间推进、是否提供确认态空间、是否与右侧 CTA 分离、是否保持 B7 深蓝 / 象牙 / 红橙 / 青色合同。
- **状态**：作为 A110 的美术回链已采纳。`36-b7-left-entity-advance-day-device-v1.png` 因叠放过低、旧纸卡语义残留，作为覆盖错误对照；`37-b7-left-entity-advance-day-device-v2.png` 与裁切 `38-b7-left-entity-advance-day-device-v2-crop.png` 作为当前实体日程器结构方向稿，仍非生产 no-text 组件。

### A112. 图3/图4升级为新的干净低多边形周刊风格标杆
- **来源**：2026-06-23 新旧美术标杆对比讨论；用户明确表示目前希望图3和图4作为新的风格标杆，并指出新标杆同样使用低多边形作为图形视觉元素，但整体更干净、质感更轻。
- **机制**：后续 Angus 全局视觉与 UI 风格探索应把图3/图4视为新的阶段性标杆：以深色编辑部底板、干净低多边形神秘图形、周刊封面、照片 / snapshot、文件夹、贴纸、CD、回形针、图标与色板组成现代周刊资产系统。新方向的重点不是重纹理拟物，而是低多边形几何、清晰版式、大块负空间、克制纸张材质和资产分组感；像素、半调与印刷感应更轻、更干净，避免此前过重的纸纹、噪点、污损和厚重旧物质感。
- **应用范围**：全局视觉风格稿、世界地图 / 地区任务台 / 派遣签批台等资产化 UI 的视觉包装、Steam 截图风格、图标 / 贴纸 / 文件夹 / 周刊封面 / 证据照片资源包、生图 prompt 与后续 `@像素艺术` 复审。
- **执行约束**：图3/图4可作为风格标杆，但落到可交互 UI 时仍需遵守动态文字安全区、正交可写面、真实机制物件和可玩界面职责。`style guide`、`color palette`、`graphic elements` 等开发板式语言不得直接进入玩家实机截图；需要转译成玩家正在操作的周刊工作台、案件材料、任务档案、发刊稿件或签批物件。

### A113. 新标杆低多边形必须是大块概括与手绘裁纸感
- **来源**：2026-06-24 世界地图标杆落地复审；用户指出当前世界地图组件稿与新标杆差异在于：原图图形更概括，低多边形是大块面并有一定手绘感；当前图1/2/5 的地图与快照缺少标杆的大块多边形风格，图3/4 的票条和 ticker 细小点、孔洞、微线过多。
- **机制**：新标杆中的低多边形不是密集三角网、GIS 纹理或摄影噪声，而是“形状经济”：用少量大块面、概括轮廓、轻微不规则切边和干净色块形成视觉力量。世界地图、地区卡缩略图、dossier 快照、周刊图像和异常场景应优先使用大块低多边形 / 手绘裁纸式图形；票条、ticker、CTA、图标 atlas 应减少孔洞、条码、短刻度、刮痕、微线和点阵，保留更大的图形关系。
- **应用范围**：世界地图组件母版、右侧地区 dossier、地区文件夹卡、地图板、地图 pin / sticker、ticker 票据、CTA / task-intel 票条、dossier 快照、后续生图 prompt、生成后 `@像素艺术` 复审。
- **执行约束**：主图形在缩到 25% 预览时应先读出大块地图 / 文件 / 票据剪影，而不是细线、孔洞、点和条码；100% 局部看时，半调应是块状结构，文字区应干净。每个小组件同屏最多保留一种微细节语言（孔洞、条码、点阵、短刻度、微线或纸边磨损），且必须服务状态或结构；动态文字安全区不得被孔洞、斜纹、半调、强纸纹或装饰线穿过。
- **Prompt 约束**：正向使用 `large simplified low-poly planes`, `bold blocky polygon shapes`, `editorial cut-paper graphic design`, `slightly hand-drawn imperfect polygon edges`, `halftone as large structured patches`, `minimal micro-detail`, `strong negative space`；负向写死 `no dense triangulation mesh`, `no tiny polygon web`, `no small holes`, `no barcode clutter`, `no scattered speckle noise`, `no photographic grain`, `no GIS terminal map detail`, `no overly detailed coastlines`, `no decorative micro-lines`, `no texture covering text areas`。
- **状态**：已采纳为新标杆执行细则。`docs/screenshots/2026-06-24-world-map-benchmark-landing/01-world-map-component-motherboard-v0.png` 与 `02-right-dossier-component-sheet-v0.png` 降级为方向草稿 / 偏差案例，不得作为生产标杆；下一轮世界地图右侧 dossier 应先重做大块低多边形快照和低微细节票条，再进入无字底图、overlay 与中文填充。

### A114. 新标杆质感由低多边形色块明度塑造

### A185. 卡通感属于塑造方法，不能用卡通元素或写实低多边形替代

- **来源**：2026-07-13 区域任务元素板 v2 复审。用户指出 v2 的写实感和细节重新上升，并澄清此前所说的“卡通”更多指图片塑造：飞碟等对象不应画得那么真实、那么细，多边形应更大、更少、更概括；同时 v2 把黑色幽默的符号化表现一并删掉，整体变得过于严肃。
- **根因**：此前把两个独立维度错误绑在一起。维度一是**塑造抽象度**：轮廓、块面数量、明暗档位、透视和材质细节应有多概括；维度二是**题材符号强度**：是否使用问号、警示牌、荒诞章记、异常分类符号与冷面笑点。v1 用卡通题材元素冒充卡通塑造；v2 为删除卡通题材元素又恢复写实比例、细碎多边形、摄影光影与材质细节，并误删符号化黑色幽默。
- **标杆重读**：标杆中海怪使用阶梯状大块轮廓，金字塔 / 山体由少量大面和一束光构成，石像头像只保留几块头部结构，人物多为纯剪影；这些主体不是“真实物件加 low-poly 滤镜”，而是先删掉细节，再由大剪影和少数明暗面重新设计。标杆右侧部分 `SCENE MOOD / PHOTO & SNAPSHOT` 可包含较细场景，但它们是氛围样本与辅助层，不能反过来主导所有正式任务插图的颗粒度。
- **塑造合同**：单个核心主体通常只用 `4–8` 个主块面，极限不超过约 `10` 个可读面；天空、地面各压成 `2–4` 个大色带；建筑先归并成 `3–6` 个体块；飞碟不画舷窗列、面板缝、金属高光和精密环带，列车不逐扇画窗与轨道零件，信号塔不画完整钢架桁架，办公楼不逐格画窗。禁止均匀铺满细碎三角形、连续渐变、镜面反射和空气透视。
- **黑色幽默合同**：保留原标杆的问号警示牌、眼形章记、手绘便签、荒诞分类贴纸和“严肃机构处理荒谬事件”的反差；但这些是成人编辑图形，不是笑脸怪物或角色表情包。每张任务图允许一个强符号或一个冷面笑点，例如 `NO PARKING / AIRSPACE` 禁停标识、无限循环路线章、`SIGNAL: ANSWERED` 状态章；符号必须简短、图形化、远看可认。
- **目标组合**：高塑造抽象度 + 中等符号化 / 黑色幽默 + 低拟人 / 低萌化 + 低摄影写实。下一版不能在“拟人卡通”和“严肃写实”之间二选一，而要做到“造型卡通化、题材成人化、幽默符号化”。
- **状态**：已采纳为 A182 / A183 的上位纠偏。`02-region-task-element-art-style-board-v2-restrained.png` 降级为“写实细节回升、符号幽默丢失”的偏差案例，不作为下一轮正向图像参考。

### A186. 大多边形不等于极少纯色块，目标是现代且活跃的中粗颗粒塑造

- **来源**：2026-07-13 区域任务元素板 v3 复审。用户以三张局部图明确指出：排除第一版杂志右侧的可爱怪物等具体元素后，第一版的画面效果、概念与现代感总体可取；v3 则过于复古、土，尤其四张任务图缺少活跃色块变化，更像复古招贴画，地图也被压成过于简单的纯复古色块，整体滑向复古专业杂志。
- **关键纠偏**：A185 的“大块面、少细节”被机械执行成了“每张图只剩极少结构块 + 大面积单色 + 居中黑剪影”。这消除了写实，却同时消除了标杆最重要的色块活跃度、冷色现代感、场景层次与低多边形塑形，最终形成 WPA / 公共宣传画式的复古招贴语言。正确目标不是最少块面，而是**中粗颗粒、大小不均、同色 / 邻色色相活跃变化的大块面**。
- **第一版重新定级**：`01-region-task-element-art-style-board-v1.png` 不再整体作为失败图处理。其笑脸怪物、拟人独眼、张嘴报纸等具体元素仍是偏差；但它的深蓝底、冷青 / 钴蓝 / 紫蓝 / 芥末的色彩运动、不同尺寸多边形共同塑造体积、快照之间的昼夜 / 色相差异，以及现代周刊拼贴完成度，可作为下一轮的**塑造与色彩二级正向参考**。元素语义仍不得照搬。
- **任务插图合同**：主体保持大轮廓和低细节，但每个结构体块内部允许 `2–4` 个较大的明度 / 色相面；整张快照通常可由约 `15–30` 个不均匀的大中块面共同构成，而不是只有 `3–6` 个纯色形状。色块用于表现体积、光束、天空、地面和异常气氛；禁止均匀细三角，也禁止大片无变化的复古平涂。
- **现代感合同**：深海军蓝、钴蓝、青绿、紫蓝和清洁橄榄承担主色运动，芥末与锈红只作局部强调；纸边偏冷象牙 / 暖灰且薄，减少土黄、卡其、褐红、粗黑剪影、大圆日轮、居中徽章、复古路牌和编号教学卡。构图回到标杆的错落拼贴、局部裁切和场景深度，不做四张等权、同构、居中式宣传画。
- **地图合同**：地图保留 `4–6` 个宏观区域与清楚河流 / 路线，但每个区域内部再用 `3–5` 个较大的同色或邻色色块表现地势、异常气候和层次；水域也应有 `2–3` 档冷色变化。总体验证的是“宏观可读 + 中层活跃”，不能回到 GIS 细网，也不能停在纯扁平行政区色块。
- **黑色幽默合同**：黑色幽默优先嵌入场景关系和编辑部小物，例如飞碟下方散落的停车罚单、列车进入不可能缺口、信号月与塔形成暧昧眼形、异常影子；不要让大号复古标识牌成为画面主角。可爱怪物可替换为无表情、无萌化五官、轮廓更暧昧的神秘存在，但保留“普通世界认真面对荒谬事件”的概念。
- **目标句**：`现代神秘周刊拼贴 + 中粗颗粒低多边形色块塑形 + 活跃的冷色 / 邻色色块变化 + 场景内符号化黑色幽默 + 低剂量新怪谈`。明确排除 `minimal flat retro poster / WPA poster / propaganda graphics / vintage public-information sign / muted khaki-dominant palette`。
- **状态**：已采纳为 A185 的粒度与现代感修订。`03-region-task-element-art-style-board-v3-coarse-symbolic.png` 降级为“低多边形过度扁平化、复古招贴化、地图中层变化丢失”的偏差案例。

### A187. 符号不是统一矢量图标库，纸面色块也不是旧化噪声

- **来源**：2026-07-13 用户以标杆中的贴纸竖条、`DESIGN ELEMENTS`、CD、便签和软盘局部指出：标杆符号往往带手绘感，许多纸张上有赋予质感的色块，而不是年代感带来的脏旧；当前生图符号细节过多、线条清晰、结构完整，失去标杆感觉。用户同时说明该判断带有主观性，要求结合图片独立分析。
- **独立判断**：用户感受成立，但标杆不等于“所有符号都手绘”。它同时存在三种符号方言：一，眼、问号、怪物草图、手影等**手绘异常记号**；二，网格、轨道、globe、框线、CD 分区等**简化技术图形**；三，`TOP SECRET`、WMW、globe badge 等**贴纸字标 / 章记**。三者通过同一套受控印刷、色块与载体语言统一，而不是通过统一线宽、完美几何和同尺寸方框统一。
- **当前偏差**：v4 底部 globe、问号三角、eye、loop 和地图节点都结构闭合、居中对称、线宽一致，像一套成熟矢量 icon；右侧 `MISFILED DEPARTMENT` 纸条又包含完整标题、复选框和多行信息，读成精心设计的行政表单。符号因此过度解释、过度完成，缺少标杆“编辑部临时画下、剪下、印错、贴上”的受控不完整。
- **三种方言合同**：手绘异常记号允许轻微歪斜、断线、越界和线宽变化；简化技术图形可以较规整，但只保留少量结构线、允许裁切 / 缺口 / 非完整圆；贴纸字标使用一至两色粗块、轻微套印错位和不等宽剪纸边。三类符号不得全部做成同样的黑线方形 icon。
- **符号复杂度**：一个符号只讲一个概念，优先 `1` 个主剪影或主轮廓 + `0–3` 个内部记号；通常不超过两层嵌套结构。globe 可只保留一个略歪外圈、两条经线和一条纬线；eye 可用未闭合三角、单弧眼皮和偏心瞳点；signal 只用一个点与两道不对称波纹；route loop 只用一条断开的粗路线与一个箭头。删除装饰刻度、重复环、完整网格、对称辐射与说明性小字。
- **纸面色块合同**：标杆纸面质感来自平面色块的结构性分区，而非泛黄、污渍、随机噪声或磨损。每张便签 / 贴纸 / 文件夹可使用一个哑光基色加 `2–4` 个低对比的大块相邻色 / 明度面，再叠一至两色油墨；色块硬边、方向清楚，可像印刷底版、裁纸分面或遮罩压层。纸纹只作很轻的 print tooth，不负责塑造。
- **载体合同**：同一套符号应分布在不规则白边贴纸、彩色便签、文件夹直印、票条章记和裸印技术线图等不同载体上；尺寸、旋转、裁切与重叠关系不统一。禁止所有符号都居中放入同尺寸方框。
- **目标状态**：不是“画得更潦草”，而是**约 80% 清楚可信 + 20% 受控偏差**：线条自信但不完美，结构足够辨认但不解释完整，材质干净但有印刷分面。下一步应先做独立符号 / 纸面材质母板，不继续重生整张区域任务元素板。
- **状态**：已采纳为区域任务台下一阶段制作顺序与符号复杂度约束；v4 只保留场景色块与地图方向，符号区不得直接升级为母版。2026-07-13 经 A188 修订：本条的“三种方言”只描述二级画面特征，不再作为可跨载体任意分配的顶层分类；其中“技术图形可直印文件夹”须服从正式文书的机构语法。

### A188. 平面内容先按生产来源与载体分层，不能把画法任意印到所有纸品上

- **来源**：2026-07-13 用户以标杆中的粗线三角眼便签、方格草稿纸和贴纸竖条纠偏：草稿纸 / 便利贴需要手绘；文件夹、光盘、报刊等专业文书使用正体字与正式印刷；符号化贴纸是第三类独立平面内容。用户明确指出，上一版符号与纸面材质母板把手绘图形直接印在文件夹上，说明此前按“视觉方言”分类的理解不成立。
- **独立判断**：纠偏成立。顶层分类应依据**谁生产、承担什么功能、属于哪一层载体**，而不是只看线条规整或手绘。同一个眼睛母题可以分别成为个人草稿、机构徽记和贴纸，但必须经过对应系统重绘，三者不能直接互换。标杆的核心张力正是“混乱世界中的专业秩序”：荒诞事件与人的猜测可以混乱，编辑部的正式输出仍冷静、准确、有制度感；黑色幽默与身份感再由独立贴纸注入。
- **第一类——手稿 / 工作便签**：生产者是记者、编辑或研究者，承担临时记录、猜测、关联和未证实信息。载体白名单为便利贴、方格纸、散页草稿、夹入或贴附的独立批注纸。允许粗线或细线、偏心、断口、箭头、问号、潦草短注和未完成结构；粗线并不降低其手绘属性。禁止把这套手绘图形直接作为文件夹、光盘、报刊、正式表单或底图的基础印刷。

### A190. 地图低多边形应是少数有主次的大块面，整板颜色按面积分级

- **来源**：2026-07-14 用户审阅 `image_gen/2026-07-14/20260714-104602_wmw-region-selection-element-style-board-v5.png` 的地图裁切后指出：当前地图多边形太碎，失去原标杆的高级感；整板颜色也偏多，标杆没有让这么多颜色同时占据画面。

- **地图块面合同**：每个宏观区域先有一个清楚主色和大剪影，再用约 `3–5` 个真正可读的大块面塑造地势 / 光照 / 异常影响；这里的 `3–5` 是缩到 25% 仍能辨认的主结构面，不是底下再铺几十个小三角。最大块面应能占据区域显著面积，块面尺寸必须有明显主次，并混用大三角、梯形、斜四边形和不规则多边形；禁止等尺度三角镶嵌、Delaunay / Voronoi 纹理和全区低多边形滤镜。
- **块面语义**：每条主要分界线应能回答它表示什么——地势转折、光照面、气候带、异常污染或阴影；如果删除一条线不会损失任何结构信息，就不应存在。文字和路线所在区域优先留一块较大的安静色面，不让碎片穿过。
- **整板色彩合同**：执行“`1` 个深色背景 + `2` 个相邻主色家族 + `1` 个中性纸色 + `1` 个小面积强调色”。当前支线建议以深海军蓝为负空间，钴蓝 / 青绿 / 橄榄中的两组承担主体，冷象牙作为文书中性，只选择芥末或锈红之一作当版强调；紫色不得再与黄、红一起占据大面积。色票可以保留更多备选，但单张风格板 / 单张地图不能把全套色票等权铺开。
- **收色边界**：减少色相家族不等于回到灰暗、土黄或纯平复古招贴。活性改由同一主色家族内 `2–3` 档相邻色 / 明度大面、冷暖小偏移和面积节奏承担，贯彻“收色不收活性”。
- **当前产物裁决**：v5 的平面内容来源分层、正式文书与贴纸关系可以保留；地图块面尺度和整板颜色面积层级未通过，不得升级为区域选择元素风格基准。下一版只重做地图与全板配色统筹，不推翻 A188 已确认的载体语言。
- **状态**：已采纳为区域地图与后续总风格板的颜色 / 块面硬约束；2026-07-14 经 A191 补充，本条只能约束“地图已经成立之后怎么画”，不能代替地图对象身份与地理语义 Gate。

### A193. 地图身份不得靠写实制图密度换取，正式地图仍是低多边形编辑插画

- **来源**：2026-07-14 用户审阅 `image_gen/2026-07-14/20260714-111332_wmw-nyc-regional-map-structure-master-v1.png` 后强反馈：“这个太写实了”，并要求反思为何仍会生成明显不符合既有风格标杆规范的结果。
- **独立判断**：反馈成立，且不是轻微漂移。该图虽然通过了 A191 的“像地图”要求，却整体读成专业城市图册 / GIS 可视化：精细海岸线、连续城市肌理、密集道路与铁路、桥梁网络、比例尺、图例及定位图共同建立了写实制图权威感。它几乎没有双标杆的少数大块面、概括剪影、编辑部重绘感和现代拼贴活性，属于“地图身份成立，但支线风格完全失败”。
- **根因**：生成提示词把 `recognizable New York geography`、五区、道路 / 铁路 / 桥梁、比例尺、正式图例和定位图作为强正向要求；这些词共同指向真实地图册。末尾的 `no GIS / no realism` 只是较弱的负向修饰，无法抵消前面更具体、更可画的写实制图结构。更深层的误判是把“正式文书”误等同于“写实制图”，又把“像地图”误等同于“地理细节密度”。
- **地图身份的正确来源**：地图感来自空间层级，而不是街道数量。区域图只需在正式矩形纸面内建立：`1` 组可辨认的陆水关系、`4–6` 个概括次级地区、`3–5` 个大尺度地貌 / 城市剪影、`2–3` 条主交通走廊，以及少量地名或节点。纽约样例可以保留“狭长核心岛—两侧河流—港湾—东侧延伸陆地”的标志性关系，但不追求精确海岸、街区或桥梁复刻。
- **正式与插画的分工**：正体字、编号、边框、标题栏和克制对齐负责“机构输出”；纸面内部的地图仍必须是现代编辑插画——大剪影、少量中粗低多边形块面、有限冷色家族、图形化地貌和受控省略。方向标 / 比例尺 / 图例只作 `0–2` 个微型制图提示，不得成套堆满；定位小图默认删除。
- **正向提示词约束**：先正向锁定 `modern editorial cut-paper low-poly illustration`、`large shape economy`、`simplified iconic geography` 和 `flat graphic terrain silhouettes`，再写地图语义。禁止以 `accurate / exact geography / detailed roads / professional atlas / official cartography / locator map` 作为正向要求；仅写“不要写实”不构成有效保护。
- **双 Gate**：`Mapness Gate` 与“直接标杆 Gate”必须独立通过。前者检查遮掉文字 / 任务层后是否仍像区域地图；后者把成图与两张标杆并排，检查块面尺度、线密度、材质连续性和编辑插画感。若出现密集街网、航拍式连续城市纹理、精确曲折海岸、成套地图册附件，或第一眼像城市规划图 / 专业 atlas，即使地图身份成立也必须在发送前判废。
- **当前产物裁决**：`20260714-111332_wmw-nyc-regional-map-structure-master-v1.png` 降级为“为找回地图身份而过度补入写实制图密度”的偏差案例，不作为结构母版、风格候选或后续生产参考。
- **状态**：已采纳为 A191 的抽象度与交付 Gate 修订；下一轮不得继续沿该写实地图细化，只能在重新锁定双标杆塑造语言后，从极简空间骨架重建。
