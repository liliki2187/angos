## 条目

### C1. 派遣姿态：保守 / 标准 / 激进
- **来源**：2026-04-25 骰子机制讨论 → 借鉴自 Blades in the Dark 的 Position × Effect。
- **机制**：派遣前玩家选择本次姿态：
  - **保守**：成功档位低，但**反噬少**（公信稳）；
  - **标准**：基线；
  - **激进**：成功档位高，但**官方辟谣 / 反转事件触发概率提升**。
- **接入位置**：与现有 r1–r4 报道类型平行的"调查姿态"开关。
- **应用范围**：后期进阶，不在第一阶段实现。

### C2. 取材骰面 → 素材牌（与角色升级 / 临时构筑结合）
- **来源**：2026-04-25 骰子机制讨论 → 借鉴自 Sagrada / Cities of Splendor。
- **机制**：取材投出的骰面直接转换为**素材牌**进入合成台槽位，与现有现象/认知/情报体系无缝串联。
- **延伸**：作为**角色升级**方向 —— 角色升级或装备道具后，可解锁/添加新的骰面。
- **与 A2（临时人卡）结合**：临时人卡也可被视作一种"为本周构筑骰面池"的手段。
- **应用范围**：后期进阶，需先验证基础骰子层。

### C3. 员工特性 Hook（差异化判定规则）
- **来源**：2026-04-25 骰子机制讨论 → 借鉴自 Dicey Dungeons。
- **机制**：员工差异化不只是骰面分布，而是**读骰方式**也不同（按面值最大成功 / 按面图案触发额外 / 必须两颗同色才成功 等）。
- **状态**：方向上认同，**等待进一步具体方案**。
- **下一步**：拿出 3–5 个具体员工的"独特用骰规则"清单，再决定要不要落地。

### D1. 取材 3 次小掷骰（保留叙事面）
- **来源**：2026-04-25 骰子机制讨论 → 借鉴自 King of Tokyo / Yahtzee。
- **机制**：取材阶段做成 3 次小掷骰，每次玩家选保留某些"叙事面"（玄/实/混乱），最终凑成本场报道用的线索面集合。
- **状态**：先留着，回头想想怎么用。

### D2. 员工"汇报"带误差（隐藏取材结果）
- **来源**：2026-04-25 骰子机制讨论 → 借鉴自 Liar's Dice。
- **机制**：员工取材结果**只员工本人看见**，玩家只看到带角色性格误差的"汇报"（醉汉夸大、修女保守）。
- **状态**：方向有趣，加入待定区，后续再想怎么用。

### D7. 世界地图白色浮雕沙盘风格作为像素颗粒度分支实验
- **来源**：2026-06-22 世界地图风格稿颗粒度实验；用户表示喜欢 `docs/screenshots/2026-06-22-world-map-branch-pixel-grain-experiment/00-source-branch-style.png` 的效果，要求“把这个当分支实验”，并与 `@像素艺术` 合作先看不同像素风颗粒度。
- **机制 / 原则**：该方向仅作为世界地图视觉分支实验，不替代 A93 新世界地图标杆。可探索白色浮雕 / 实体地图、pin 与便签、左侧地区卡、右侧 dossier、底部卡片的物件感如何与 Angus 像素 / 半调 / 印刷语言结合；重点比较低颗粒、中颗粒、高颗粒三档对现代纸品感、地图可读性、UI 可落地性和旧档案 / 低清像素风险的影响。
- **当前实验产物**：源图与三版输出位于 `docs/screenshots/2026-06-22-world-map-branch-pixel-grain-experiment/`：`01-variant-a-fine-micro-pixel-grain.png`、`02-variant-b-medium-angus-pixel-halftone.png`、`03-variant-c-bold-coarse-pixel-print.png`。后续补充 `04-failed-b2-too-white.png` 作为过白失败边界，`05-variant-b3-color-locked.png` 作为 B 的确定性色彩锁定候选，三联对比为 `06-compare-source-b-b3-color-lock.png`；`07-variant-b4-ai-regenerated-color-contract.png` 为首次按 B3 色彩合同进行的 AI 细节再生图，对比图为 `08-compare-source-b3-b4-ai-regeneration.png`；`09-variant-b5-local-polish-accent-paper-noise.png` 是宽合同误判案例；`15-variant-b7-strict-color-match-pass.png` 是按 `Color Contract Gate` 修正后的严格色彩通过图，合同记录为 `color-contract-v1-b7-strict-pass.md`。
- **色彩流程补充**：B3 只用于锁定“源图色号 + B 的中颗粒 / 半调质感”这一中间状态，不代表生产标杆。后续继续 AI 生图时必须引用 `color-sampling-b-correction.md` 的色号合同，并先做颜色复采样，再讨论像素颗粒升级。
- **当前复审结论（2026-06-22 修订）**：用户并排比较后指出 B5 与源图仍有肉眼色差；复采样确认 B5 整体偏暗、深蓝底更重、红橙和青色偏沉。此前“B5 当前最佳候选”的结论撤回，B5 改列为宽合同误判 / 过暗失败边界。后续按 `docs/onboarding/imagegen-color-contract-gate.md` 建立严格 `Color Contract v1`，B7 已通过色彩硬闸门；但色彩通过不等于生产标杆，仍需继续审像素颗粒、纸面旧化、可写区和 UI 资产化。
- **边界**：三版都只能称为分支实验稿，不得作为生产标杆、生产真源或可直接切图母版。若后续要升级，必须先经用户确认，再经过 `@像素艺术` 生成后复审，明确解决白色浮雕沙盘、旧纸噪点、高清摄影质感、金属控制台和动态文字安全区问题。
- **状态**：待定 / 分支实验。下一步根据三档颗粒度对比决定是否继续迭代其中一档，或回收其中的局部手法到 A93 主线。

### M1. Arkham Horror LCG · Chaos Bag（混沌袋）
- **来源**：2026-04-25 骰子机制讨论。
- **当前状态（历史）**：用户曾表示「没看懂」，曾重新解释后入机制库备查。
- **简要原理**：判定时不投骰，从一个布袋摸 token；token 上是数字修正或特殊符号；袋的内容会随玩家行为/剧情变化；玩家可随时查看袋里"现在有什么"，但摸到什么仍是随机。
- **已撤回（2026-04-27）**：**不采用 Chaos Bag。** 用户理由：该机制本质是**跨轮积累的随机修正池**，与项目中已有 **四大势力（宏观维度：如公信、诡名、声望、守序/狂性等）的长期积累与事件释放**功能**重合**；避免两套「世界对你的态度」并行。  
  **替代承接**：环境修正、累积性风险与「世界回声」继续走 **`macro` + `weekEvent` + `staffEffects`**（及与势力挂钩的派遣/结算修正），不在工程上维护独立 token 袋数据结构。

### M2. 回收噪音线索 / 清理假料
- **来源**：早期全链 HTML Demo 的全球地图按钮；2026-05-13 讨论后从当前主干移出。
- **当前状态**：机制库备查，未采纳为当前正式流程。
- **简要原理**：玩家可主动清理博眼球假料或低质量线索，以换取宏观属性修正。旧 Demo 示例数值为 `诡名 -2，声望 +1`。
- **移出原因**：当前全球地图没有显示“噪音线索”对象，按钮却要求玩家理解自己在处理线索库存；实际效果只是宏观属性调节，和“选区域 -> 进入区域”的主流程语义不一致，容易干扰主操作。
- **后续若重启**：必须先有可见的噪音 / 假料对象、库存或事件来源，再决定回收成本、次数限制、收益与风险；不能只作为无条件宏观属性兑换按钮出现。

### M3. 解释路线气质候选（路线点子备查）
- **来源**：2026-05-14 核心乐趣、真相结构与科学 / 神秘路线差异讨论。
- **当前状态**：机制库备查，未采纳为正式路线规则。
- **使用前提**：路线应是软性长期倾向，由 `公信 / 诡名 / 声望 / 守序 / 狂性` 五项宏观属性组合承载，而不是硬分支按钮；正式结构原则见 A16。
- **候选气质**：
  - **科学解释**：确定感来自数据、复核、仪器、模型和误差排除；后期可通过模型过准、观测污染结果、科学边界走向不可知来崩塌。倾向公信、守序较高，狂性可在深层科学异常中上升。
  - **神秘解释**：确定感来自符号、仪式、梦境、旧文本和跨来源共鸣；后期可通过“解释越有效，越像被某种东西回应或认领”来崩塌。倾向诡名、狂性较高。
  - **阴谋解释**：确定感来自文件、线人、删改痕迹、资金流和失踪名单；后期可通过证据链本身被设计、玩家成为另一层解释的传播器来崩塌。声望、诡名或公信可并存，守序容易承压。
  - **猎奇 / 小报解释**：确定感来自标题、读者反馈、销量、传播热度和夸张包装；后期可通过原本为了流量编出的故事开始自证成真来崩塌。倾向声望、诡名较高，公信可能受损。
  - **民俗 / 地方记忆解释**：确定感来自旧闻、地方传说、家族记忆、口述传统和旧地图；后期可通过过去经由传说回流并改写现在来崩塌。倾向诡名、声望较高，守序和狂性视题材变化。
- **设计提醒**：各路线可以都通向不可知，但不可知的味道不能相同；路线差异应体现在确定感来源、崩塌方式、代价类型和宏观属性组合上。科学路线不等于安全路线，神秘路线也需要自己的证据感和内部秩序；猎奇路线不只是低质量路线，它适合承载“故事反过来制造现实”的魅力点。

### M4. 高危五档判定结果（由 B3 降级）
- **来源**：原 B3（2026-04-25 骰子机制讨论，借鉴 Dungeon World / Witcher RPG）；2026-07-14 用户明确降级为备选点子。
- **当前状态**：机制库备查，不再是危险任务的正式结算方向。
- **简要原理**：高危任务结果分五档——大成功 / 成功但反噬 / 部分成功 / 失败但有线索 / 大失败，每档配独立 deadpan 文案。
- **降级原因**：角色骰主干确定后，非黑骰任务口径统一为「只看是否达标」（黑骰任务才用大成功 / 成功 / 失败 / 大失败四档）；五档与主干口径并行会造成两套结果语法。2026-07-14 借骰子玩法诊断确认降级。
- **遗留实现提醒**：全链 HTML demo 的 `mapHighRiskTier` / `applyHighRiskOutcome`（危险任务仍走五档结算）成为历史遗留，后续应安排退役，让危险任务回到达标口径 + 危险后果（失败代价更重）表达；退役前新增机制（如 A195 暴露副轴）不得依赖五档结构。
- **后续若重启**：更适合作为个别脚本化特殊事件的局部结果语法（对应分层扩展第 8 档「改读数规则」的局部调味定位），不作为危险任务的默认结算。
