- 日期：2026-09-03
- 状态：已裁决
- 分类：UI / 美术 / 流程
- cross-read tags：`world-map`、`RegionCard`、`content-binding`、`visual-integration`、`assetization-gate`

## 用户反馈

当前三张地区卡依然有很强的拼凑感，应先由 AI 自行找出问题，不能继续把图文绑定正确当成视觉完成。

## 裁决

1. 保留上一轮三地区内容身份绑定与 `41/41` 机器校验的 PASS。
2. 撤回 RegionCard 玩家可见视觉通过结论，视觉整合状态为 FAIL。
3. 当前图片全部降级为合同诊断样本，不得进入 Godot、atlas、manifest 或正式组件资产化。
4. 下一候选必须整体重做 FrontCarrier、StateDecor 和纸层接触关系；不再用阴影、净距、断线或附加小装饰掩盖物件原型问题。
5. 运行时尺寸、动态文字槽、共享 `69:44` 图片、状态语义、0° FrontCarrier 与 hit 合同保持冻结。

## 推荐方向

- 主方向：一张连续的横向地区简报纸；照片是纸面内的印刷窗口，右侧是完成构图的无数据留白。
- 对照方向：编辑接触印样卡；照片与右侧区域共用一块深钴蓝/蓝灰印样承底。
- 暂不采用：栏目文件夹分隔页，因为容易重新滑向档案管理和官僚机构语言。
