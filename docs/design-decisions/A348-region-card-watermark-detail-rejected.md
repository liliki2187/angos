# A348：RegionCard 不使用精细白色地球水印

- 日期：2026-09-04
- 状态：已裁决
- 分类：UI / 美术
- cross-read tags：`world-map`、`RegionCard`、`clean-low-poly-weekly`、`watermark`、`wide-facets`

## 用户反馈

RegionCard A 右侧的白色地球水印细节过多，不像既有美术标杆。

## 裁决

1. 删除精细白色地球浮雕、水印、经纬网、大陆轮廓和机构徽章式图形。
2. 右侧无数据构图区改用三至五块宽大的冷蓝灰印刷色面完成构图。
3. 低多边形只作为宽块面的印刷色彩结构，不表现纸张褶皱。
4. 手绘批注最多保留一个粗线、低权重记号，不得成为第二主视觉。
5. 不以微型套准线、状态灯或按钮式短线填满留白。
6. 连续暖白地区简报纸仍是 RegionCard 下一轮唯一主方向。

## 功能边界

本裁决不改变 `340×170`、动态文字槽、`69:44` 图片槽、状态语义、0° FrontCarrier 和整卡 hit 合同。
