# 发刊中央双版现代异常周刊校样结构稿 v2

## 用途

本稿只验证中央双版是否重新建立报刊媒介身份与图文排版关系，不是最终美术包装，也不是生产资产。

## 本轮变化

- 保留 `1040×920` 中央区域、左右页壳、书脊、六个版位外矩形和真实内容。
- 用页头、栏网、开放式规则线、共同对齐轴和图注带替代旧程序卡框。
- 主头版采用标题先行的大头版；副头版采用横图＋右侧窄文字列，避免左右同构。
- 四个普通位继续使用 `160×160` 正方形图片：左页标题先行，右页图片先行。
- 2026-07-22 局部修正：右页普通位的 folio 侧轨由 `53px` 压缩为 `26px`；方图保持 `160×160`，图片相对坐标改为 `[26,22,160,160]`，全高竖线改为 `32px` 短规则。
- 结构稿只使用黑白灰和去饱和报道图，不验证颜色、材质、按钮或交互状态。

## 用户只需判断

1. 第一眼是否是正在排版的现代周刊，而不是相册。
2. 是否自然形成主头版 → 副头版 → 四篇普通报道的阅读顺序。
3. 每篇报道的标题、图片与 meta 是否属于同一编辑单元。
