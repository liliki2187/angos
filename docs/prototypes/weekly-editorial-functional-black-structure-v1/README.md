# 发刊编辑界面功能黑色结构稿 v1

> 产物类型：`structure_wireframe`
>
> 本稿只验证桌面 `1920×1080` 下的内容容量、三栏职责、六版位映射、候选选择 / 投放 / 替换 / 回流语义，以及签批阻断关系。它不是最终视觉包装、Godot 生产界面或美术真源。

## 本轮纠偏

- 左侧候选池按 `candidate_card v1.2.0` 使用 `288×92` 紧凑横卡，不再使用接近正方形的大图卡。
- 常态演示 `8` 篇未上版候选，首屏完整显示 `6` 张，另 `2` 张通过纵向滚动访问；不露半张第七卡。
- 选中卡不放大、不移位、不重排，只使用双线框、左括号与“已选稿”状态槽。
- 中央继续冻结双版常显与六版位，本稿展示 `3/6` 已上版、`3/6` 空位，以及一个合法投放目标。
- 右栏只有一个“签批送印”主按钮；发行预览待重算时保持禁用，不新增第二个 CTA。

## 交互范围

- 点击候选卡：建立 / 取消唯一候选来源。
- 滚动候选池：访问第七、八篇候选。
- 选中候选后点击版位：投入空位或原子替换占用稿；旧稿回到候选池。
- 将已上版稿拖回左侧候选池：退稿回流；回流过程中左栏整体显示临时接收框。
- 任一版面变化都会把发行预览标记为“待重算”，并禁用签批按钮。

入口：`index.html`
