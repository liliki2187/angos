# 发刊报道图片两规格合同黑白结构审阅板 v1

## 用途

本页用于裁决报道图片的两规格资产合同与双页内部排布，不是最终视觉包装，也不代表 Godot、组件合同或 GDD 已修改。

## 当前推荐

- 每篇报道以 `1024×1024` 方形母图作为唯一构图真源。
- 候选缩略图使用 `64×64`，普通版位使用 `189×189`，副头版使用 `210×210`；三者都直接读取方形母图。
- 主头版使用 `15:8` 横图，源尺寸 `1920×1024`，由方形母图左右各扩展 `448px`；运行显示约 `410×219`。
- 副头版在原 `442×342` 外槽内重排为左侧方图与右侧文字栏，不改变两张 `490×800` 周刊外框。
- 普通版位只压缩内部标题与间距，不增加外槽高度。
- 没有摘要字段时不虚构字段，右侧文字栏使用标题、元数据与留白。

## 冻结边界

桌面 `1920×1080`、`320 / 1040 / 360` 三栏、双页完整可见、8 卡常显、12 卡仅左栏滚动、定向替换、重算与签发状态机全部保持不变。

## 用户需要裁决

1. 是否正式采用主头版 `15:8`。
2. 是否正式采用副头版 `210×210` 方图；`224×224` 仅作为更激进但压缩文字栏的备选。
3. 是否确认无摘要字段时保留留白，不为版面新增字段。
