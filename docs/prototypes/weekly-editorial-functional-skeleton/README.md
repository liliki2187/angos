# 发刊编辑功能骨架 v0.2

> **历史原型（2026-07-14）**：本页验证过“双版总览＋单版聚焦”，但用户随后把当前范围修订为“双版常显”。现行实现与合同以 Godot `WeeklyRunEditorialPhase.gd` 和 `PAGE-CONTRACT-BOARD-v2-DUAL-PAGE.md` 为准；本页不得再作为当前交互真源。

这是两次整屏风格稿被拒收后的确定性纠错产物，只验证桌面 1920×1080 下的功能链、信息层级和页面尺度切换，不代表最终美术风格，也不得直接作为生产 UI 资产。

## 已验证结构

- 三大区：候选报道池、中央周刊、发刊复核。
- 默认“双版总览”：两张纵向页面并列，左页承载主头版，右页承载副头版，六个角色版位同时可见。
- “单版聚焦”：点击任一页放大编辑；另一页保留为可点击的上下文缩略页，避免失去跨页位置感。
- 总览与聚焦共享同一份 `slot_assignment`、拿稿、移位和退稿状态，不生成第二套排版数据。
- 聚焦态不直接签批；玩家必须返回双版总览，才能检查整期并进入双页确认。
- 六状态：未选择、已拿起、投放目标、已占用、空版位、硬阻断。
- 操作链：拿稿、投放、跨页换稿 / 移位、退稿、实时复核、返回总览、双页签批确认。

## 当前骨架映射

- 左页：主头版、专题 A、专题 B。
- 右页：副头版、内页 A、内页 B。

这只是 v0.2 用于检验双页容量与跨页操作的可运行映射；版位名称、权重及每页分配仍应由正式配置和 GDD 决定，不能从本骨架反推为最终规则。

## 暂定规则与已知出入

- 骨架暂把“主头版为空”表现为硬阻断，把“副头版为空”表现为风险提示。
- 现行 GDD 的边界情况仍写明“有稿件但头版空缺时允许尝试发刊，但后果必须显著”，与骨架硬阻断不一致。
- 其他空版位暂以“允许带风险送印”展示；`required_slots_filled` 的正式口径尚未锁定。
- 资产化或接入运行时前，必须择一修正文档或实现，不能把演示假设当作既定机制。

## 不在本轮范围

- 不引用两张标杆图的最终颜色、材质、造型或装饰。
- 不生成或切分美术资产，不接入 Godot 运行时。
- 预计触达、预计净利仅是交互演示值，不代表正式游戏公式。
- 不验证动态美术节奏；本轮 animated WebP 只展示真实交互状态切换。
