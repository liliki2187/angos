# 发刊编辑正式视觉包装候选 v2

## 产物定位

`filled_state_text_mock / formal_visual_packaging_candidate`

本版本在 v1 的视觉包装与 v4 的冻结功能结构上，只落实用户确认的报道图片两规格合同。它不是最终 UI，也不代表 Godot、正式组件合同或 GDD 已修改。

## 本轮冻结的图片体系

- 每篇报道以 `1024×1024` 方形母图作为唯一构图真源。
- 候选缩略图继续使用 `64×64` 方图。
- 四个普通版位的图片窗统一为 `189×189`。
- 副头版改为 `210×210` 左方图与右侧文字栏；没有摘要字段时保留留白。
- 主头版横图固定为 `15:8`，运行显示 `410×219`；生产源目标为 `1920×1024`，由方形核心左右各扩展 `448px`。
- 禁止第三种图片比例，禁止从横图反裁方图，禁止在扩图两翼新增关键主体、线索或文字。

## 保持不变

- 桌面 `1920×1080` 与 `320 / 1040 / 360` 固定三栏。
- 两张 `490×800` 周刊始终完整可见。
- 8 张候选卡完整可见；12 张时只滚动左栏。
- 类型筛选、等级 / 获得时间排序、定向替换、六个合法目标、单一局部换稿按钮。
- 替换后旧结果失效并重算、右栏连续证据链、固定阻断区、唯一主 CTA。
- 确认送印时冻结双页并保留返回修改。
- 不恢复报头交互、底部长条持稿栏、单页放大或第二个送印按钮。

## 当前资产边界

本版本没有重新生成正式方形母图。A01–A06 继续引用现有报道图作为版面框体与裁切压力预览，其中部分源图仍是旧横图或近方图，因此只能证明图片窗布局，不能证明新资产生产管线已经完成。

正式资产生产时必须先生成或重制 `1024×1024` 方形母图，再由它生成 `1920×1024` 主头版横图；不得把本候选中的旧素材居中裁切当作合同实现。

## 调试接口

页面保留 `window.editorialVisual` 与 `window.editorialWireframe` 调试接口，支持：

- `showState(name)`
- `setCandidateCount(count)`
- `clearFilters()`
- `getAuditState()`

URL 查询参数继续沿用 v4。
