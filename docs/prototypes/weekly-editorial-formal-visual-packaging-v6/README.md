# 发刊编辑正式视觉包装候选 v6

## 产物定位

`filled_state_text_mock / formal_visual_packaging_candidate`

本版本继承用户已冻结的 v4 主 / 副头版与主标题层级，只把中栏顶部操作条中的定向提示改为清楚的非按钮说明。它不是最终 UI，也不代表 Godot、正式组件合同或 GDD 已修改。

## 中栏顶部操作条

- 保持原有 `1010×48` 外框，不改变双页起点。
- “本期双版”与“已上版 N/6 · 空位 N”始终常驻。
- 选中来源且存在合法目标时显示“下一步：点击报纸中高亮的版位”，并隐藏“清空双版”。
- 定向提示不使用底色、描边、阴影、圆角或悬停反馈，不可聚焦也不接收鼠标事件，避免被误认为按钮。
- 重算时显示“版面已更新 · 正在重算”，确认送印时显示“版面已冻结”；两态均隐藏并禁用清空入口。
- 普通编辑 / 结果有效时隐藏情境提示，只显示低权重“清空双版”；悬停或键盘聚焦时才使用锈色危险反馈。
- 双版为空时不显示清空入口。

## 主头版标题层级

- 外槽、`410×219` 主图与 meta 保持不动。
- “头版主稿”与报道 ID 压为同一眉题行。
- 能完整容纳时使用 `28px / 34px / 800` 单行标题。
- 单行真实溢出时切换为 `24px / 26px / 800` 双行标题。
- 分类依据是真实运行字体的字形宽度，不按字符数猜测；双行仍溢出时记录容量失败，不静默缩字或省略。
- 副头版标题继续为 `18px / 23px / 700`，由字号、字重、图片面积与页面位置共同维持主副层级。

## 修订后的两规格图片体系

- 每篇报道仍以 `1024×1024` 方形母图作为唯一构图真源。
- `square`：用于候选缩略图与四个普通版位。
- `headliner_landscape`：由方形母图左右扩展成 `1920×1024 / 15:8`，由主头版与副头版共同使用。
- 主头版显示为 `410×219`。
- 副头版显示为 `375×200`，面积约为主头版的 `83.5%`，保留主副层级。
- 候选缩略图继续为 `64×64`，普通版位继续为 `189×189`。
- 仍然只有两种资产规格，不生成独立副头版构图，也不从横图反裁方图。

## 副头版排布

副头版外槽保持 `442×342`：

- 横图：`[33,14,375,200]`
- 角色：`[15,226,72,14]`
- 报道 ID：`[95,226,48,14]`
- 标题：`[15,248,411,48]`，最多两行
- meta：`[15,306,411,18]`，强制单行
- 局部换稿按钮：`[354,160,44,44]`

横图中央 `200×200` 对应方形核心，两侧各约 `87.5px` 为扩展翼。换稿按钮只落在右扩展翼的 action-safe zone，不遮挡中央主体。扩展翼不得包含唯一人物、异常符号、文字或关键线索。

## 保持不变

- 桌面 `1920×1080` 与 `320 / 1040 / 360` 固定三栏。
- 两张 `490×800` 周刊始终完整可见。
- 8 张候选卡完整可见；12 张时只滚动左栏。
- 类型筛选、等级 / 获得时间排序、定向替换、六个合法目标、单一局部换稿按钮。
- 替换后旧结果失效并重算、右栏连续证据链、固定阻断区、唯一主 CTA。
- 确认送印时冻结双页并保留返回修改。
- 不恢复报头交互、底部长条持稿栏、单页放大或第二个送印按钮。

## 当前资产边界

本版本没有重新生成正式方形母图或横向扩图。A01–A06 继续引用旧报道图作为版面框体与裁切压力预览，因此只能证明图片窗布局，不能证明 `1024×1024 → 1920×1024` 正式资产生产管线已经完成。

正式资产生产时必须先完成方形母图，再生成同源横图；主、副头版读取同一横图文件，候选与普通位读取同一方图文件。

## 调试接口

页面保留 `window.editorialVisual` 与 `window.editorialWireframe` 调试接口，支持：

- `showState(name)`
- `setCandidateCount(count)`
- `clearFilters()`
- `getAuditState()`

URL 查询参数继续沿用 v4。
