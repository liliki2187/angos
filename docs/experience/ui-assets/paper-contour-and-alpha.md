# 纸边：柔化覆盖率与修顺轮廓是两种问题

触发：透明纸件的长边、斜边、旋转或缩放出现重复台阶，或外缘改善后相邻纸层色界仍显锯齿。适用于概括手绘纸件；刻意像素化角色、撕纸缺口等不能直接套用。

## Angus 实例与原因

A364 的局部采样柔化改善了部分二值透明边，但用户再次指出右侧蓝衬纸仍有台阶。原轮廓本身不平滑时，alpha 柔化只改变台阶的锐度；相邻白纸边属于 PNG 内部不透明色界，也不由外部 alpha 单独决定。不能以“已开抗锯齿”判解决。

A365 将该底纸的蓝衬纸外缘及白纸内缘重建为连续轮廓，按屏幕像素控制覆盖率，保留原 PNG 纸纹。首个样本仍把旧描边取进边界，随后修正取色；尺寸验证也从逻辑纹理尺寸改为 GPU 读回图的实际像素。

## 用于当前判断的检查问题

- 源图轮廓是否已有台阶？半透明覆盖率是否被二值化？运行缩放/旋转是否又引入采样或几何锯齿？
- 问题在外部 alpha 还是内部纸层色界？软化后是否仍存在形状台阶、亮边、深色短线或主体发虚？
- 目标显示尺寸下是否改善，手绘的大形与层叠关系是否保留？放大观察只能定位原因，不能代替实际尺度判断。

按原因可以保留平滑 alpha、改善拆层/源素材、重建轮廓或使用局部渲染。没有统一的滤镜、采样核或强度处方；单纯全图模糊不能保证形状连续。

## 实现边界

[WorldMapDossierContour.gd](../../../gd_project/scenes/gameplay/weekly_run/components/WorldMapDossierContour.gd) 含 578×1078 来源和左侧范围假设，是该底纸实现，尚非通用 Paper 组件。[WorldMapPaperEdge.gdshader](../../../gd_project/scenes/gameplay/weekly_run/components/WorldMapPaperEdge.gdshader) 同样需核对使用条件。其他形状、四边、夹具与转角需要重新验证。

[证据脚本](../../../scripts/art/build_world_map_contour_evidence.py) 可参考真实多尺寸与带外像素差异的检查方法，但它的区域和阈值只适用于这个样本。先判断缺陷原因，再选择工艺；自动检查不判美术通过。
