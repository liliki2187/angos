# UI 资产经验索引

这里保存已发生问题的原因、证据与适用限制，供 UI、美术和工程共用。先从当前目标、原图和功能形成判断；在相关拆层、渲染或批量决定前检索命中项，不默认通读，也不照搬案例答案。

| 触发条件 / 检索词 | 问题 | 案例 |
| --- | --- | --- |
| 透明 PNG、纸边、长斜边、旋转、缩放、alpha、不透明纸层色界 | 软化边缘仍留下轮廓台阶；逻辑尺寸可能冒充真实显示尺寸 | [纸边与透明轮廓](paper-contour-and-alpha.md) |
| 真实可写面、任务纸、短内容、固定槽位、长标题、图文配合 | 容量不溢出但常态松散，装饰和文字分离 | [内容与承载面](content-and-surface.md) |

新增案例要有实际触发、原因或仍待验证的假设、试过的方法、证据和限制。单次反馈不自动成为项目硬规则；只把经多处验证的能力提炼成工具，不预建完整百科。运行参数保留在对应组件或合同。

本目录的两张 evidence 图片是原运行图的未修改副本，用于让关键经验不依赖本机忽略目录；原批次完整检查仍按案例中的来源查阅。它们不是新界面标杆，也不构成用户审美批准。
