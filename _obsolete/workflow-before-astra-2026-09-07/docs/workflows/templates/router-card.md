# Router Card

## 决策条 / Decision Strip

- **结论**：通过 / 部分通过 / 不通过 / 需要你裁决。
- **影响**：这意味着可以继续什么、会挡住什么，或对用户有什么风险。
- **下一步**：下一轮具体做什么。

## 详情 / Human Brief

- **一句话结论**：这轮能不能继续；如果能，继续到哪一步；如果不能，为什么。
- **我实际做了什么**：只完成路由判断 / 已读取必要 workflow gate / 其它。
- **现在卡在哪里**：无阻断 / 阶段不明 / 产物类型不明 / agent 路由不明 / 缺用户裁决。

- **下一步怎么验证**：
- **本轮不要做**：

## 进入下一步前自问

- 这个任务是否被我误判成了另一个载体或阶段？
- 是否有用户已确认的旧优点需要保护？
- 如果只做本轮范围，是否已经足够回答用户问题？
- 是否存在必须先交给用户裁决的冲突？
