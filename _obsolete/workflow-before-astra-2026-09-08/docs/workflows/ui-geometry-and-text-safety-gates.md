# UI 几何、文字与装配检查

适用实际内容装配、可复用资产和运行实现。风格探索只检查影响本轮判断的明显遮挡/失真，不要求先具备所有生产证据。

## 合同与检查对象

先确认正在使用哪一版页面/组件合同以及当前用户允许改变的范围。检测资产的实际可写区，不只检测 PNG 外框或 Control/DOM 矩形；正文、标题、状态和操作应各有清楚归属。

精确比例、正交角度、padding、热区、字号等来自当前实现需求与经验证的合同，不使用跨页面统一的 1px、1°、32px、IoU 或 facet 对称阈值。旧 B2 个案探针留在其脚本/合同及历史记录，不自动用于新风格稿。

## 实际装配重点

- 同一母图按约定等比缩放；不因选中/锁定就换图规格。检测图片实际内容区，而非只比较外框。
- 动态文字与图片不压夹具、折角或高对比装饰；足够对比和字号在目标显示尺寸目视验证。合理换行与扩展承载优于无条件缩字/裁字。
- alpha、色键残留、接缝、旧图泄漏、双重烘焙标识和叠加层归属，按素材路径有针对性检查。
- 状态层不改变共享内容身份；点击、焦点、hover 与可见对象对应，装饰层不拦截输入。
- 长内容、空态、锁定/已选、展开与边缘位置只覆盖实际适用项；修改共享组件应覆盖其受影响消费者。

## 证据

整屏检查整体关系；细节不清或局部问题才补目标尺寸裁图。声称像素级对齐、角度或比例通过时给测量方法与实际结果；图像看过才给视觉判断。不要用裁图数量或“存在 QA 文件”替代检查。

生产问题按用户影响处理：关键操作不可达、错误状态或数据损失是功能问题；局部纹理误差不自动升为 P0。重大装配缺陷未解决时不能宣称可生产，单纯审美候选也不因缺运行证据被误判不可探索。
