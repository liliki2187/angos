## 1. 为什么另开支线

这组标杆和项目之前的像素艺术记录差异较大：它不是角色高清微像素，也不是早期重纸纹、重半调、旧档案感的资产化 UI。它更像一套**干净现代周刊编辑部 + 大块低多边形图形设计 + 轻纸品物件**的 UI 视觉语言。

因此当前只作为世界地图视觉落地支线推进。不得因为局部效果成立，就直接覆盖角色美术、全局像素颗粒、正式 UI 真源或既有美术规范。

### 1.1 临时评审路由（2026-07-13）

`angus_art_director` 暂不参与本支线的自动生成前指导和生成后放行。它当前的启动壳与技能由旧像素 / 半调标杆训练，默认把像素颗粒、半调和套印是否成为结构语言列为核心门槛，与本支线的“大块低多边形明度面、干净现代周刊、轻纸品和低微细节”存在坐标系冲突。

本支线临时使用以下真值链：两张原始标杆图 → 本支线规范 → 纸张材质合同 / Color Contract → `ui_designer` 布局与安全区 → `ux_laoge` 可读性与操作链 → 父级逐项标杆对照。用户显式点名 `@像素艺术` 时仍可调用，但其结论不阻断本支线。只有在该 agent 完成支线专用真值源和失败样本校准，并经用户确认后，才恢复自动路由。

## 3. 核心理解

这条支线的关键词不是“质感丰富”，而是**图形概括准确**。

标杆的视觉力量来自：

- 大块低多边形色块的明度变化。
- 清晰剪影、硬边阴影和少量冷暖色块。
- 现代周刊版式、大标题、色票、标签、文件夹和纸件叠层。
- 轻微手绘 / 裁纸感的不规则边缘。
- 干净但不空洞的纸面。
- 贴纸式、概括式、轻微歪斜的符号系统。

标杆不依赖：

- 重纸纹、污渍、旧档案黄、旧报纸脏感。
- 摄影噪声、雾气、刮痕、随机颗粒。
- 密集三角网、GIS 终端纹理、过细海岸线。
- 规则软件 icon、统一线宽矢量图标、通用游戏按钮 bevel。

### 3.1 风格主语重新提炼（2026-07-13 · 区域任务台纠偏）

两张标杆的第一主语不是“写实纸品 UI”，也不是“深色低多边形场景”，而是：

> **现代图形周刊拼贴 + 哑光色块 + 概括剪影 + 平面裁纸式低多边形。**

纸张、文件夹、照片和夹子只是承载这套图形设计的物件，不是让画面变得真实、厚重、旧或像档案室的理由。低多边形也不是给写实地图、城市夜景或照片加一层 polygon filter，而是先删除写实信息，再用少量平面色块重建对象。

| 维度 | 两张标杆的真实读法 | 区域任务台 v2 的偏差 | 后续执行口径 |
| --- | --- | --- | --- |
| 色彩 | 深色底只是负空间；橄榄、钴蓝、青绿、芥末黄和暖纸形成大块中间色 | 灰蓝、灰绿和米纸占主导，颜色层级被压成同一沉闷区间 | 每个主列至少有一块明确的彩色中间调；颜色靠色相区分，不靠整体提亮 |
| 明度 | 少量离散明度层：深底、彩色中间调、暖纸、窄高光 | 连续灰阶、夜景和写实阴影让局部读成灰暗；即使整图均亮度更高也仍显沉 | 用 3–5 档平面明度块，不做写实光照、空气透视或渐进阴影 |
| 低多边形 | 平面海报式概括；缩到 25% 仍先读彩色剪影 | 地图和缩略图仍先读真实纽约、夜景照片或交通场景 | 先删地理 / 摄影信息，再用 3–8 个大面重画；禁止“写实对象 + low-poly 滤镜” |
| 材质 | 薄纸边、单层硬边错位阴影、轻 print tooth | 厚纸边、投影、夹子、案卷叠层共同强化拟真和旧档案感 | 纸面只做平面色块载体；边、影、夹具都减到最低，不表现纸张厚度和年代 |
| 构图 | 大小不一的彩色物件形成编辑版面节奏，留白与物件块面同等重要 | 三栏规整、同形卡重复，容易读成深色后台或写实任务软件 | 保留功能正交，但用不同色块尺寸、裁切关系和大标题建立周刊版式张力 |
| 图像题材 | 标杆快照更像编辑部重绘的海报图形，题材冷暖和昼夜有变化 | 四张任务图和右栏证据图集中使用灰蓝夜景，形成持续暗场 | 只允许选中异常图使用深夜；其他缩略图使用橄榄、钴蓝、青绿、芥末等不同色底 |

本轮量化只用于说明偏差，不直接当生产阈值：`benchmark-board-02` 的全图平均饱和度约 `0.59`、低饱和像素约 `8.5%`；区域任务台 v2 约为 `0.44` 与 `33.4%`。v2 的平均亮度其实更高，但仍被读成“更灰暗”，证明后续不能再用全图均亮度或“纸面更亮”替代彩色中间调、题材昼夜和局部明度层级检查。

后续生图 prompt 的主句应优先使用：

```text
modern graphic editorial collage, matte color-block UI, flat cut-paper low-poly poster, simplified colored silhouettes, front-facing screen-print composition, thin crisp offset shadow
```

不得再用下列词组担当主风格词；它们只能作为负面约束：

```text
realistic paper interface, vintage dossier, evidence photography, cinematic night scene, realistic city map, material rendering, thick paper edge, bevel, heavy cast shadow, desaturated gray-blue palette
```

新的直接标杆 Gate：

1. 缩到 25% 时，地图、缩略图和右栏图先读成彩色大块与剪影，不先读成真实场景细节。
2. 地图只允许河流 / 地区 / 主干路线等 5–8 个大色面；禁止街道网、真实地标群和写实地理纹理。
3. 选中异常图可使用深夜；其他缩略图不得全部使用夜景 / 灰蓝照片语法。
4. 纸边只做窄边，阴影只做一层硬边错位；若第一眼读成厚案卷、旧档案或写实桌面，直接失败。
5. 正交功能面仍然成立，但不能靠同形深色卡片和连续灰阶获得秩序；必须保留标杆的彩色块面节奏。
6. 颜色复核必须按语义 ROI 比较深底、彩色中间调、纸面和警示色，并同时报告饱和度 / 低饱和占比；不得只报告全图平均亮度。

### 3.2 题材气质与“先风格板、后界面”闸门（2026-07-13）

本支线不能只靠材质和配色接近标杆。区域任务台正式进入整屏界面前，先用一张**元素美术风格板**验证以下四个题材主语：

- **卡通化**：采用面向成人的编辑插画式概括、夸张比例和明确剪影；不是儿童绘本、萌系 Q 版，也不是写实照片的多边形滤镜。
- **黑色幽默**：让异常事件与日常周刊工作、票据、截止日期、停车罚单、办公室习惯发生冷面碰撞；幽默应干燥、克制、荒诞，不做热闹恶搞或血腥笑话。
- **符号化**：每个元素优先形成一个可在小尺寸识别的图形符号，例如眼睛月亮、收到罚单的飞碟、弯折天线、吞掉列车的纸洞；一图一梗，不靠文字说明和写实细节补语义。
- **新怪谈幻想**：熟悉地点和物件以安静、日常的方式违反现实逻辑；怪异来自“不可能但被当作正常工作处理”，不是传统罪案、警探、法证、硬科幻控制台或纯鬼屋恐怖。

四项不是等权叠加。**原标杆的现代周刊低多边形编辑插画始终是主画风；卡通、黑色幽默与新怪谈只作为低剂量题材暗味。**推荐的控制关系不是“每件物件都卡通、每张图都有梗”，而是：造型约八成保持克制、可信、成人编辑插画化；每个场景最多留一个轻微不可能点。异常关系可以荒诞，主体造型本身不要变成怪谈吉祥物。

卡通强度回收规则：

- 建筑、列车、飞碟、天线与地图地标使用较可信的比例和严肃剪影，只做低多边形概括与极轻微比例夸张。
- 禁止笑脸怪物、拟人月亮、萌系独眼、张嘴报纸、漫画动作线、成组表情贴纸和连续视觉笑点。
- 黑色幽默通过物件关系表达，例如异常物旁出现一张尺寸普通、样式严肃的罚单；不要给异常主体画表情来解释笑点。
- 新怪谈通过一个安静的逻辑错误表达，例如影子方向或形状略微不匹配、路线不可能地折回、远处地标悬浮少许；不要把整个画面变成怪物秀。
- 贴纸区以抽象符号、编辑部章记、路线记号和异常分类徽记为主，造型参考原标杆的克制图形，不做角色表情包。

区域任务台的首张元素板应覆盖：符号化地图碎片、四张不同色相 / 昼夜的任务插画、六枚左右贴纸符号、文件夹或任务卡壳、截止票条 / 日历记号、项目色票与少量回形针 / 胶带。它必须像两张标杆中的美术方向板，而不是可点击界面截图；不得出现三栏布局、完整任务列表、菜单按钮或大段动态文字。

放行到整屏界面的条件：

1. 缩到 25% 时，至少三种元素能先靠剪影和色块讲清一个荒诞异常，而不是先读成探案照片。
2. 画面能感到卡通概括、黑色幽默、符号化和新怪谈幻想，但四者不得压过原标杆的克制周刊低多边形主画风；若第一眼读成怪谈漫画或卡通贴纸包，直接失败。
3. 深海军蓝只作为负空间；钴蓝、青绿、橄榄、芥末、暖纸与锈红形成活跃而受控的中间色块。
4. 不出现红线证据板、警徽、犯罪现场、法证标签、写实侦探照片、黑色电影光照、厚旧卷宗或泛黄档案。
5. 用户明确认可风格板后，才能把元素关系转译成区域任务台的正交功能布局。

### 3.3 塑造卡通化与题材符号化必须分轴控制（2026-07-13）

“卡通”在本支线首先是**怎么画**，不是**画什么卡通元素**。正确组合为：

| 控制轴 | 目标强度 | 正确表现 | 失败表现 |
| --- | --- | --- | --- |
| 塑造抽象度 | 高 | 大剪影、少块面、离散明暗、删材质细节 | 真实场景上均匀铺细碎 low-poly 三角形 |
| 符号化 / 黑色幽默 | 中 | 问号警示牌、荒诞章记、异常分类符号、严肃文书处理荒谬事件 | 全部删掉后只剩严肃 UFO / 建筑照片 |
| 拟人 / 萌化 | 低 | 极少使用；主体无表情、无角色化五官 | 笑脸怪物、独眼萌物、张嘴报纸、贴纸角色包 |
| 摄影写实 | 低 | 平面海报式重画、物体只保留身份特征 | 真实透视、金属高光、汽车反射、完整桁架和逐窗细节 |

标杆内部也有层级，不能平均取样：

- **主造型锚点**：海怪、金字塔 / 山体、石像头像、剪影人物、雷达与眼形标记。它们决定正式插图的轮廓经济、块面颗粒和符号强度。
- **辅助氛围层**：`SCENE MOOD / PHOTO & SNAPSHOT` 中较细的办公室或场景照片。它们只提供冷暖、环境与题材气氛，不能作为主体细节密度和写实度上限。
- **版式物件层**：文件夹、便签、票条、CD、夹具与色票。它们负责周刊编辑部拼贴关系，不负责把插图拉回写实档案照片。

对象级塑造预算：

- 一个飞碟：先读一个略不规则的扁椭圆大剪影，归并为 `3–6` 个结构体块；每个体块仍可用 `2–3` 个较大的冷暖 / 明暗面塑造体积。禁止舷窗列、面板缝、金属反射和精密机械环。
- 一列火车：车头、车身、窗带、底盘与阴影归并为 `5–8` 个结构体块；允许在大体块上增加少量不均匀色面，但禁止逐窗、轨枕、架空线零件和真实摄影透视细节。
- 一座塔：主体先读为强剪影，再用几块青黑 / 紫蓝 / 橄榄面和信号光塑造；禁止只剩纯黑徽标，也禁止完整钢架桁架和设备零件。
- 一栋楼：先合并成 `3–6` 个建筑体块，每个体块可有 `2–3` 档大色面，窗只做一两条明暗带；禁止逐格窗户、汽车、路灯和停车场写实细节。
- 天空与地面：分别由若干大小不均的大中块面组成，保留色相与明度的活跃变化；既不用几十个均匀小三角模拟空气透视，也不能退化为一块纯色背景和一个纯色地台。

符号化黑色幽默不靠表情，而靠严肃图形与荒谬语义的碰撞：

- 飞碟旁使用简化禁停标识或 `NO PARKING / AIRSPACE` 章，不画飞碟表情。
- 列车路线使用一枚无限折返路线章或矛盾到站时间，不增加卡通乘客。
- 信号塔使用 `SIGNAL: ANSWERED` 章、反向波纹或问号警示，不把月亮画成眼球角色。
- 办公楼使用“多出来的影子部门”式分类符号或错误楼层章，不画完整笑脸巨怪。

直接放行 Gate：

1. 遮掉所有贴纸和文案后，主体插图仍必须是粗颗粒、大块面、低细节的标杆式塑造；否则属于“符号遮掩写实底图”。
2. 遮掉所有主体插图后，剩余符号仍应能传达神秘周刊的荒诞分类感；若只剩通用定位、信号、箭头软件 icon，则黑色幽默 / 符号化不足。
3. 缩到 25% 时先读主体剪影和几组活跃的大色块；若能读出车窗、塔架、汽车、飞碟面板或建筑逐格窗，细节过量；若只剩一个黑剪影、一块圆形背景和两三块平涂，则又过度扁平。
4. prompt 主句使用 `modern editorial collage / medium-coarse faceted color modeling / varied large polygon planes / active cool adjacent-color shifts / symbolic tabloid absurdity`；同时负向排除 `photograph converted to low poly / dense uniform triangulation / micro facets / minimal flat retro poster / WPA poster / vintage public-information sign`。

### 3.4 现代活跃色块与复古招贴的边界（2026-07-13）

大多边形不等于“极少纯色块”。标杆与区域任务元素板 v1 的可取之处，是大小不均的低多边形面在同一对象内部继续发生冷暖、色相和明度变化，从而既概括又有体积与活力。v3 的失败是把对象压成居中黑剪影、纯色大圆、单色地台和大号复古路牌，形成公共宣传画 / 复古专业杂志气质。

现代感的正向特征：

- 深海军蓝作为干净负空间，钴蓝、青绿、紫蓝和清洁橄榄承担主要色彩运动，芥末与锈红只作局部强调。
- 同一主体或背景内部有 `2–4` 档相邻色 / 明度大面，块面大小不均、方向有节奏，不使用统一尺寸三角网。
- 快照保留前中后关系、光束、地面、异常物与少量环境线索，仍像编辑部重绘的场景，而不是图标放进方框。
- 纸边偏冷象牙 / 暖灰、薄且干净；胶带和夹具作现代拼贴节奏，不制造年代感。
- 构图大小错落、局部裁切、色相轮换；避免四张等权、同构、居中、编号式教学图板。

复古招贴的负向特征：

- 卡其、土黄、褐红、米纸和粗黑剪影同时占据大面积。
- 大圆日轮、中心徽章、复古路牌、粗红描边、编号标题和公共信息标识成为每张图的主要构图。
- 场景被压成一个主体图标加一块纯色背景，几乎没有内部色块变化。
- 颗粒、旧纸、磨损和印刷褪色成为画面高级感来源。

整板颜色必须有面积层级，而不是把色票全部铺开：

- 单张风格板 / 单张地图采用“`1` 个深色背景 + `2` 个相邻主色家族 + `1` 个中性纸色 + `1` 个小面积强调色”。
- 深海军蓝负责负空间；钴蓝 / 青绿 / 橄榄中选两组承担大面积主体；冷象牙负责文书；芥末或锈红每版只选一个作为明显强调。
- 色票表可以展示更多备选，但不能让橄榄、青绿、紫、芥末、锈红和钴蓝同时成为等权大色块。
- “收色不收活性”：减少色相家族后，仍用同色系内 `2–3` 档相邻色 / 明度大面和少量冷暖偏移维持现代感；禁止重新变成灰暗、卡其主导或纯平复古招贴。

地图必须同时具有两级结构：

- **宏观层**：`4–6` 个可读区域、主河流 / 路线和少量异常节点，缩小后仍一眼可读。
- **中层色块层**：每个区域内部用 `3–5` 个在 25% 缩放下仍能辨认的**主结构面**表现地势、气候、光照或异常影响；底下不得再铺几十个小三角。水域使用 `2–3` 个大冷色面，并允许少量地形剪影 / 路线穿插。
- **尺度主次**：最大块面应占区域显著面积；混用大三角、梯形、斜四边形和不规则多边形，不使用等尺度 Delaunay / Voronoi 镶嵌。块面分界必须对应地势、光照、气候或异常语义，不能只是纹理。
- **安静承载面**：地区名、说明和路线附近至少保留一个较大的低变化色面，禁止文字压在细碎三角网之上。
- 失败两端分别是：细密 GIS / 均匀三角网，以及 v3 式纯扁平行政区色块。目标是“宏观清楚、少数中层大面活跃、没有微观碎屑”。

### 3.5 区域地图的对象身份与 Mapness Gate

区域地图不是“带路线的异形色块”。它是玩家从世界地图进入某一地区后看到的近尺度地图，必须先具备制图对象身份，再讨论低多边形块面。

正式载体：

- 区域地图属于“正式文书 / 机构输出”，默认承载在矩形或展开式地图纸、地图册页面或正式报告附图上。
- 地图纸以正体标题、边框和克制对齐建立机构感；方向标、比例尺、图例三者只选 `0–2` 个极简提示，不得成套堆成专业图册。定位小图默认不使用。
- 土地 / 水域位于纸面视窗内，不把整块陆地模切成悬浮贴纸；但纸面内部仍是编辑部重绘的低多边形插画，不是 GIS、航拍底图或专业测绘图。
- 手写箭头、问号和贴纸标记只能作为后贴 / 后夹层出现，不能融进正式地图底图。

五层语义：

1. **地图载体 / 视窗**：正式地图纸与可读边界。
2. **地理上下文**：海岸、湖泊、河谷、邻区边缘或其它能说明“这里位于哪里”的关系。
3. **内部地区 / 地貌**：`4–6` 个次级地区，以及山地、森林、平原、城区、工业带等差异。
4. **聚落 / 交通骨架**：城镇、站点、地标、主路、铁路或航线，数量克制但足以形成空间网络。
5. **任务 / 异常层**：路线、节点、警示、贴纸和手写批注；它们建立在前四层之上，不能替代前四层。

直接 Gate：

- 遮掉路线、任务节点和所有文字后，仍能凭海岸 / 水系、内部地区、地貌、聚落与交通骨架认出“区域地图”。
- 去掉深色桌面背景后，地图仍凭正式纸张载体、边框、比例尺和制图结构成立。
- 若第一眼读成徽章、岛形贴纸、双叶图形、抽象拼块或任务路径示意，直接失败，不进入块面 / 配色评审。
- A190 的大块面只塑造地貌、城市密度、光照和异常影响，不能把整个地区切成无地理语义的放射面或色带。

Mapness 不等于写实制图：

- 地图身份来自**空间层级和邻接关系**，不是地理细节密度。单张区域图的正向信息预算为：`1` 组概括陆水关系、`4–6` 个次级地区、`3–5` 个大尺度地貌 / 城市剪影、`2–3` 条主交通走廊与少量地名 / 节点。
- 真实城市样例只提炼标志性关系，不复刻精确海岸、街区和桥梁。纽约可保留“狭长核心岛—两侧河流—港湾—东侧延伸陆地”的识别骨架，但不得生成街道网、密集铁路、连续桥梁网络或航拍式城市肌理。
- 正式的是**字体、编号、边框和层级**；插画化的是**地理内容**。二者并存才是“混乱世界里的专业秩序”，不能用写实地图的权威感代替正式文书语言。
- 提示词顺序固定为：先锁 `modern editorial cut-paper low-poly illustration`、`large shape economy`、`simplified iconic geography`、`flat graphic terrain silhouettes`，再写上述地图语义。避免把 `accurate`、`exact geography`、`detailed roads`、`professional atlas`、`official cartography`、`locator map` 写成正向要求。
- `Mapness Gate` 通过后仍必须过**直接标杆 Gate**。将成图与两张支线标杆并排：若出现密集线网、精细曲折海岸、连续写实材质、成套图册附件，或第一眼像城市规划图 / 专业 atlas，直接判废，不得以“至少像地图”发送给用户。

黑色幽默优先融进场景关系，而不是做成大号复古标识牌：飞碟与停车罚单、列车与不可能缺口、信号塔与暧昧眼形月、建筑与异常影子都可保留；罚单、章记和问号只作第二阅读层。v1 中可爱笑脸怪物应替换为无表情、轮廓暧昧、没有萌化五官的神秘存在，但场景的色块塑造和概念张力可以继承。

## 4. 低多边形规则

低多边形必须是“大块概括”，不是“细密三角网”。

通过标准：

- 一个主体先读出大剪影，再用 3-8 个主要明暗面塑造体积。
- 场景 / 快照在缩到 25% 时先读出大色块和主物体，不读成纹理。
- 天空、山体、地图大陆、异常物件优先使用大三角、大梯形、大斜四边形。
- 轮廓可以有手绘式轻微不规则，但不要写实细边。

失败表现：

- 全图被均匀三角面切满。
- 各区内部铺满尺寸近似的小三角，即使区域轮廓很大，仍读成 low-poly filter / 程序化 Delaunay 纹理。
- 大陆、小岛、海岸线过细，读成 GIS / 雷达底图。
- 快照像照片加 low-poly 滤镜，而不是编辑部重绘的图形插图。
- 为了“高级感”增加雾、纸纹、颗粒、刮痕。

## 5. 纸件和票条规则

纸件应是现代周刊工作物件，不是旧档案。

票条和 CTA 的正确方向：

- 中心 `content_rect` 必须干净，能承载动态中文。
- 但中心区域不应纯平空白，可保留极轻的 4-7 个大块色面或印刷压层。
- 彩色框体内应有低多边形明度变化，避免变成 SaaS 表单条。
- 票条边缘应像纸签 / 印刷切片 / sticker-cut，轻微不规则。
- 红橙只给 danger、alert、primary CTA。

票条和 CTA 的失败方向：

- 完全纯平矩形，失去标杆色块起伏。
- 过度 bevel、高光、阴影，读成通用手游按钮。
- 孔洞、条码、短刻度、细线、点阵全部堆在一个组件里。
- 斜纹、箭头、角切、描边、高光同时出现，导致图形过忙。

## 6. 平面内容的生产来源、载体与叠层规则

顶层分类不按“看起来手绘还是规整”，而按**谁生产、承担什么功能、属于哪一层载体**。同一个 eye / globe 母题可以跨类出现，但必须在各自系统中重新设计，不能复制同一图形后任意换纸。三类内容共同制造的张力是：异常世界与个人猜测可以混乱，编辑部的正式输出仍保持冷静秩序，贴纸再注入身份和冷面幽默。

### 6.1 手稿 / 工作便签

- **生产者与功能**：记者、编辑、研究者；记录临时线索、猜测、关联、问题和未证实结论。
- **载体白名单**：便利贴、方格纸、散页草稿、剪下的小纸片，以及夹入 / 胶带贴在正式文书上的独立批注纸。
- **画法**：粗线与细线都允许；重点是手部书写留下的偏心、断口、箭头、越界、局部重描和未完成结构。图 1 式粗线三角眼是合格手稿，不需要全部变成细密速写。
- **禁止项**：不得把手绘标题、手绘 globe、草绘轨道、准星或问号直接印成文件夹、光盘、报刊、正式表单、正式地图的基础图形。

### 6.2 正式文书 / 机构输出

- **生产者与功能**：WMW 的编辑、出版、归档或技术系统；负责命名、编号、分类、校验和可信度。
- **载体**：报刊封面、文件夹、档案页、光盘标签、表格、票据、正式地图和元数据页。
- **文字与图形**：使用清楚的正体无衬线 / 窄体 / Slab 字形、直线对齐、期号、条码、网格、少量规范化 globe / seal / technical mark。线图可以简化，但必须像机构设计，不像个人草图。
- **色块与材质**：载体可使用哑光基色加 `2–4` 个低对比或邻色的大块分面、彩色底版和轻微套印。色块负责让专业文书不那么官僚、更加现代高级；不能靠手写化、泛黄、污渍或随机磨损“放松”。

### 6.3 符号化贴纸

- **生产者与功能**：编辑部文化、现场分类习惯或周刊品牌；负责快速识别、态度、身份和冷面玩笑。
- **载体**：独立模切贴纸，必须看得见白边 / 色边、贴附关系、轻微旋转或局部翘起，不能与文书底图熔成同一印刷层。
- **画法**：`1` 个主剪影 / 主轮廓 + `0–3` 个内部记号，通常不超过两层嵌套；使用一至两色粗块、轻微套印错位和不等宽剪纸边。WMW、`TOP SECRET`、eye badge、globe badge、黑手与异常分类图形均可使用这套语法。
- **区别**：贴纸比手稿更凝练、更可复制；比正式徽记更放松、更具态度。不能把手稿加白边就自动当贴纸，也不能把正式 seal 做歪就自动当贴纸。

### 6.4 叠层与同母题转译

默认物理层序为：

1. **正式文书基底**：正体字、编号、规范图形、结构色块。
2. **独立贴纸 / 标签**：后贴上的分类、品牌或态度层。
3. **夹入 / 贴上的手稿批注**：最临时、最私人、最不确定的一层。

便签可以贴在文件夹上，贴纸可以贴在光盘盒上，但必须看出它们是后来附着的独立物理层；文件夹本身仍保持正式文书语法。比如同一个 eye：便签版表示“我怀疑有人在看”；正式 seal 版表示“机构定义的观察类编号”；贴纸版表示“快速标记 / 黑色幽默”。三者需分别绘制。

### 6.5 共用材质与复杂度约束

- 质感来自哑光基色上的结构色块，而非旧化。纸纹只保留很轻的 print tooth；禁止用泛黄、污渍、随机噪声、磨损、折痕和脏边制造年代感。
- 色块像印刷底版、裁纸分面或遮罩压层：硬边、方向清楚、大小不均。正式文书尤其需要靠它软化制度感，而不是靠潦草化。
- 一个符号只讲一个概念。删除装饰刻度、重复环、完整网格、说明性小字和不服务功能的多层嵌套。
- 白色剪纸边、贴纸边和套印错位应硬边、可读、受控，不做模糊彩边。

失败方向：

- 把三类当成可互换的“视觉方言”，将个人手稿直接印上文件夹 / 光盘 / 报刊。
- 为所有载体统一使用完美圆、完美三角、同线宽、居中对称的标准 icon set。
- 为了“手绘”只添加统一抖动、脏边或噪点，而没有明确的个人书写载体。
- 正式文书为了“不严肃”而改用手写标题，或反过来做成纯灰、纯平、无结构色块的政府表格。
- 贴纸没有独立模切边和贴附关系，直接与正式文书底图熔成一层。

直接标杆 Gate：

1. **来源 Gate**：不看画法，只看载体，能否判断这是个人记录、机构输出还是独立贴纸；无法判断即失败。
2. **载体 Gate**：文件夹、光盘、报刊和正式表单的基础层是否全部使用正体字与机构图形；出现直接印刷的个人手稿即失败。
3. **叠层 Gate**：便签或贴纸贴到文件夹上时，是否仍能看出独立纸边、遮挡、旋转和附着关系；融合成底纹即失败。
4. **复杂度 Gate**：转成纯黑剪影后，至少一半贴纸符号仍能凭主轮廓识别；必须依赖内部细线和文字说明即过度完成。
5. **材质 Gate**：去掉纸纹后，正式文书仍应靠 `2–4` 个结构色块显得现代高级；若先读到污渍、泛黄、磨损或纯复古色块，失败。

## 7. 已踩坑记录

1. **把标杆误读成重质感。**  
   结果会加纸纹、污渍、摄影颗粒和刮痕。正确做法是用低多边形色块明度塑造质感。

2. **把低多边形做成细密三角网。**  
   世界地图、快照和地区卡会变成 GIS / 雷达终端，而不是周刊图形设计。

3. **为了 UI 可读性把票条做成纯平表单。**  
   文字区变安全了，但标杆味丢失。正确做法是文字区干净但仍有极轻的大块色面压层。

4. **把图标做成规整软件 icon。**  
   规则图标削弱标杆的贴纸、手绘、周刊物件感。

5. **直接生成整屏概念图。**  
   整屏图容易好看但不可落地。必须拆成无字底图、动态文字、安全区 overlay、状态 atlas 和 1920 截图验证。

6. **右栏尺寸未先验证。**  
   右侧 dossier 单独好看，但放入 1920x1080 后会压中央地图。正式布局需要右栏固定列或缩窄到约 520-580px。

7. **小组件变土、变暗、变厚。**  
   v0.5 找回了手绘贴纸和低多边形色块，但纸边太厚、暗部太黑、颜色偏泥、整体像土黄色手工贴纸，缺少远标杆里的干净高级感。正确方向应更轻、更清透、更现代：纸边薄而白、阴影克制、暗部不死黑、橄榄和青绿更干净、红橙更清爽，保留概括手绘但不要滑向民俗 / 手账 / craft paper。

8. **整屏验证时又回到低多边形渲染。**  
   v0.17 把 v0.16 小组件放回世界地图后，票条语言能成立，但中心地图、右侧快照和左侧缩略图又出现细碎三角、场景插画和 GIS 感。整屏验证不能只看“有 low-poly”，必须继续检查块面颗粒度：标杆是大块剪纸式概括，不是低多边形 3D 渲染或细密三角网。

9. **信息承载面被纸件感带斜。**  
   v0.18 虽然减少了碎三角和微细节，但右侧 dossier、左侧地区卡、底部票据整体倾斜，违反“承载信息的 UI 面必须正交”的硬规则。后续 prompt 和验收必须先锁定：凡有动态文字、可点击热区、缩略图框、状态条、按钮文案或真实中文填充的正面区域，一律 0 度水平 / 垂直；斜切、胶带、夹子、背后纸张露边只能存在于 no-text 装饰层。

10. **为了修正交把风格修平。**  
    v0.54 这类正交约束稿虽然改善了功能面倾斜，但中央世界地图多边形变成更碎的细密三角网，左侧卡片、右侧 dossier、CTA 和底部票据上的低多边形平面色块被抹平，结果从“低多边形周刊纸品”滑向“干净软件 UI”。后续必须双闸门验收：先看功能面是否正交，再看同一批功能面是否仍保留大块平面色块、4-8 个主要明度块面、块状阴影和手绘贴纸张力。不能用扁平空白矩形解决文字安全区。

11. **把色块误写成褶皱。**  
    v0.55 的 prompt 把标杆文字组件上的平面明度色块误写为 `folds / 褶皱 / 折痕`，导致文本槽出现纸张折起感。原标杆的文字组件不是折纸纹理：它们只有低对比、平面的低多边形色块和明度块面，不应有明显 crease / wrinkle 线穿过可写区。后续 prompt 必须写 `flat low-poly color-value blocks`，并负向排除 `creases / wrinkles across text slots`。

12. **右侧 dossier 轻斜仍然一票否决。**  
    v0.55 虽然找回了一部分大色块，但右侧 dossier / CTA stack 仍有可见倾斜。该图降级为“色块恢复但正交失败”的偏差样本，不得作为生产候选或下一步切图源。后续生成后必须先裁切右侧 dossier、CTA stack、底部 receipt 并叠水平 / 垂直参考线；只看整屏观感或说“基本正”都不算验收。

13. **QA 框不能替代真实边线。**  
    v0.56 暴露两个复发问题：底部 receipt 右侧出现高对比白色折角 / 撕裂状痕迹，仍然把“平面低多边形色块”误生成为纸张 fold / tear；右侧 CTA stack 的真实生成边线仍有可见倾斜。`111-world-map-wmw-flat-color-orthogonal-v0-56-qa.png` 与 `112-world-map-wmw-flat-color-orthogonal-v0-56-right-qa-crop.png` 只能证明手动画的参考框是正的，不能证明图本身正交。后续 QA 线必须贴住真实生成边缘；只要真实边缘斜，即使参考框水平也失败。

14. **把组件校正误扩成整屏重生。**  
    用户的原始诉求是把标杆中的组件改成能承载真实游戏 UI 的组件语言，而不是持续重生整张世界地图。整屏生图每次都会重新解释地图、配色、纸张、按钮、材质和构图，导致旧优点被冲掉、新问题不断出现。后续应先做组件校正板：地区卡、右侧 dossier、CTA、底部 receipt、贴纸图标、标题条等逐类转译；只修正正交、可写区、状态矩阵和符号嵌合问题，其它标杆味道尽量不动。组件板通过后，再把组件放回世界地图做单状态验证。

15. **不能靠 prompt 形容词复刻纸张。**  
    纸张是这条支线的基础材质，不能每轮让生图模型重新理解 `warm beige / advanced gray / paper texture`。后续必须先引用 `clean-lowpoly-weekly-paper-material-contract.md`：从标杆裁切 token 锁定纸色和纸纹，再做组件形状、生图、后处理或回填验证。v0.5 只能作为色彩方向候选，不是纸张材质真源；纸张真源来自标杆 crop board。

## 7.5 高级感 / 舒适度闸门

小组件必须同时满足“手绘概括”和“干净高级”。不能只因为符号不规整、色块回来了，就放行。

通过标准：

- 纸边是干净暖白 / 象牙白，不是厚黄纸板。
- 色彩清透，橄榄绿、青绿、红橙之间有层级，不灰、不脏、不糊。
- 暗部用深海军蓝 / 深墨绿控制，不大面积死黑。
- 阴影轻，只表达叠层，不制造笨重贴纸块。
- 符号粗犷但自信，像现代周刊贴纸，不像廉价手账贴纸。
- 留白充足，组件之间有空气感。

失败表现：

- 整体偏土黄、偏棕、偏脏绿、偏黑。
- 纸边过厚，像硬纸板或手工剪贴。
- 组件阴影厚重，显得笨、沉、廉价。
- 为了手绘感把图标画得幼稚、民俗或低龄。
- 票条虽然有低多边形，但低对比泥色让画面发闷。

v0.6 方向样本：

- `docs/screenshots/2026-06-24-world-map-benchmark-landing/11-ticket-symbol-atlas-v0-6-premium-light.png`

v0.6 修正了 v0.5 的“土暗厚”，但不能作为色彩通过样本：纸边 / 高亮纸面被推到 `#F3E8D9`，明显高于标杆贴纸裁图约 `#C2BAAC`；橄榄绿也从标杆约 `#4E623D` 漂到 `#747945`；警示红橙从低饱和锈色漂到 `#BD4F26`。下一轮不能整体压暗或整体提亮，必须按 token 色号回到标杆，同时重新加入更像 `premium-sticker-reference-crop.png` 的概括、歪斜和黑色图形张力。

## 8. 落地验证链

每个组件进入生产候选前，至少通过以下验证：

1. **无字底图**：没有烘死中文、数字、按钮文案和任务数据。
2. **安全区 overlay**：明确 `content_rects / no_text_rects / hit_rects`。
3. **真实中文填充**：使用当前游戏字段，不用占位假字。
4. **状态 atlas**：至少 default / hover / selected / locked / warning。
5. **1920x1080 截图**：确认在真实桌面界面比例中可读、可点、风格不掉。
6. **直接标杆复审**：若要升级为生产标杆 / 真源候选，必须完成两张原始标杆的逐项对照、纸张 / 色彩合同、UI / UX 与真实内容回填复审；临时不经过 `angus_art_director`。

## 9. 当前阶段结论

已阶段性成立：

- v0.3 的“色块塑形”方向大致对。
- v0.4 右侧 dossier 单组件能承载真实中文。
- v0.5 票条 / 符号方向修正了“过平”和“过规整”的问题。
- v0.6 票条 / 符号方向修正了“土暗厚”的问题，但颜色过亮、过白，不能作为色彩通过样本；下一轮必须按 `12-ticket-symbol-color-contract-v0-1.md` 复采样。
- v0.8 票条 / 符号候选解决了 v0.6 的过亮白和 v0.5 的泥厚问题，可进入小范围真实 UI 验证。
- v0.16 是当前较干净的小组件候选，适合进入真实 UI 验证，但仍不是 exact 色号通过。
- v0.18 在“大块色面、低微细节”上比 v0.17 有进步，但因信息面倾斜，降级为偏差样本。
- v0.19 是当前世界地图局部落地验证候选：在保持 v0.18 大块面方向的同时，恢复了信息承载面的正交硬规则。
- 2026-07-01 的 `02-wmw-component-correction-sheet-v0-2-no-text.png` 是组件转译候选：相比继续整屏重生，它更符合“先修可复用组件、其它不动”的流程；但尚未经过真实中文填充、逐组件安全区、色号复采样和直接标杆复审，不能升级为生产候选。
- 2026-07-01 的 `07-wmw-component-correction-sheet-v0-5-balanced-advanced-gray.png` 是当前“高级灰但不土”的色彩方向候选：比 v0.3 少黄褐土味，比 v0.4 少旧档案感。它仍不是生产候选；warning / rust 的饱和度和纸面高光还需在真实世界地图单状态里继续压测。

仍未通过：

- 中央世界地图 v0.18 已明显减少碎片，但正式底图仍需继续删小岛、删细海岸、删密集切面。
- 快照和缩略图仍略偏场景插画 / low-poly render，不够手绘概括。

- 尚未完成左侧地区卡、任务派遣、地区界面的铺量验证。

## 10. 转正条件

这条支线只有满足以下条件，才可考虑并入正式 Angus 美术风格：

- 世界地图：右侧 dossier、左侧地区卡、中央地图、底部票条、pin / sticker atlas 全部通过真实界面验证。
- 地区界面：能保持同样的色块塑形和手绘贴纸符号，不退回普通面板。
- 任务派遣：角色、任务卡、签批票条、CTA 不与当前角色高清微像素方向冲突。
- 多屏截图放在一起时，仍像同一套游戏，而不是一张独立漂亮风格稿。
- 父级直接对照两张标杆确认它继承大块低多边形、干净周刊纸品和低微细节语言，且没有滑向旧像素、重半调、旧档案、重纸纹、纯科幻终端或通用手游 UI；同时 UI / UX 与材质 / 色彩合同通过。
