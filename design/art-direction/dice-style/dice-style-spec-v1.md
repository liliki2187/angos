## 美术方向判断

普通角色骰应像“低多边形证据方块”，不是赌场骰、白色塑料骰或奇幻骨骰。材质方向：

- 主体：深海军蓝 / 绿黑 / 蓝黑低多边形实体。
- 顶面：干净纸品或荧光信号色嵌片，承载属性和点数。
- 边缘：短高光、硬切面、轻微纸品 / 印刷颗粒。
- 字：必须是骰面贴图的一部分，跟随顶面投影和遮挡。

黑骰先按 330 公交的真实规则表达：

- 初始不是一颗显眼坏骰，而是“鬼附身在真实角色骰面之上”。
- 重投后只提示刚刚重投的未锁定骰组是否出现鬼迹。
- 提交时若带入鬼，取消优秀结果或造成角色临时污染。

本轮解决的问题：v0.12 进入真实运行尺寸后，为了躲避顶面图案，`理性` 和 `+2` 在透视与缩小后读成互相挤压。v0.13 改为三层信息合同：

- `title_rect`：属性汉字，最高优先级。
- `value_rect`：点数 / 异常符号徽章，独立槽位，不和标题共用空间。
- `watermark_rect`：图案只做低优先级水印，不得迫使标题或点数让位。

该版本仍不是最终美术师精修资产，但可作为后续骰面信息密度的工程合同：凡是顶面同时承载汉字、点数和图案，都必须先证明三者在 1920x1080 真实运行尺寸下不重叠、不抢读。图案优先降为水印；不要用缩小文字或硬塞中心区来解决。

## 2026-07-07 运行资产记录：v0.14 数字优先 GLB / UV

v0.14 产物路径：

- GLB / UV 资源：`gd_project/Assets/dice_models/v0_14/`
- 生成脚本：`scripts/build_dice_glb_v0_14_assets.py`
- 数字优先审查图：`dice-face-layout-v0-14-number-priority-review.png`
- Godot 动态预览：`docs/screenshots/2026-07-07-dice-3d-v014-number-priority-glb-uv-godot/`

本轮回应用户反馈：“数字太小，可以图标小点数字大点。”v0.14 保留 v0.13 的 `title_rect / value_rect / watermark_rect` 三层合同，但调整信息权重：

- `value_rect` 是玩法读数，字号和明度必须高于水印图标，停住后要能在真实 1920x1080 游戏视角下直接读到 `+2` / `!`。
- `watermark_rect` 只承担属性联想，不承担主要读数；图标应缩小、降低不透明度，并避免占据标题和数值之间的中心注意力。
- 小尺寸 3D 骰子不追求“汉字、数字、图标三者同等显眼”。优先级固定为：属性汉字 > 点数 / 异常符号 > 图标水印 > 装饰纹理。

后续若继续做正式骰面，不能再用“为了露出图标而压小数字”的方案。图标需要让位给规则读数；如果二者仍互相抢读，应继续降低图标面积 / 对比度，而不是牺牲 `+2` 或黑骰警示符号。

## 2026-07-07 临时收敛：常态骰面先取消图标

用户进一步确认：暂时先考虑只有属性文字和数字的骰面，直接不要图像 / 图标。该方向用于解决 v0.13-v0.16 持续暴露的信息拥挤问题：即使图标缩小、移角落或做底层水印，常态小尺寸骰面仍会分走注意力，导致 `理性 +2` 的排版空间不足。

当前临时合同：

- 常态小尺寸顶面只保留 `属性名 + 点数 / 异常符号`，例如 `理性` + `+2`。
- 顶面不放属性图标、头像图标、水印图案或角落小章。
- 属性名不能压到 v0.18 F 那种小标题体量；当前按 v0.18 E 的标题字号感推进，但去掉标题框 / 标题牌。
- `属性名` 和 `+2` 应直接丝印 / 压印在骰面材料上，中间留足呼吸，不用独立文字容器解决可读性。
- 属性识别由颜色、材质和外部角色槽 / 骰槽标题共同承担。
- 图标只保留为可选的 hover / 放大详情 / 结算截图 / 教程说明层，不进入常态小尺寸骰面。
- 下一轮验证重点从“图标怎么放”改为“中文和数字如何在斜俯视 3D 小骰面上松弛、稳定、好读”。

新增硬约束：

- 骰子不能像卡牌游戏组件：避免独立矩形卡框、牌面底板、集换式卡牌边框和“把卡贴在立方体上”的读法。
- 骰面信息应像丝印、压印、证据标签或直接印在低多边形材料上，而不是放进独立卡牌面板。
- 图3 / 图4 的关键不是“给每个元素加框”，而是周刊资产板里的低多边形道具、贴纸、文件夹、CD、照片和图标系统；骰子应更像这一套物件系统里的可投掷道具。
- 下一轮高保真图应在 v0.5 基础上减重：减少石块感，增加轻巧印刷物 / 桌面游戏道具 / 周刊证据贴片质感。

颜色语义修订：

- `探索`：橄榄绿 / 信号绿为主，可有少量深海军蓝阴影。
- `理性`：青蓝 / 象牙白为主，读作校核、逻辑、档案整理。
- `诡思`：紫、深紫、灰紫和象牙白丝印为主，不应混入大面积黄色 / 琥珀块；黄色会把它误读成另一类骰面。
- `生存`：黄色 / 琥珀 / 防护色归这里，适合盾牌、防毒面具、撤离、现场安全等面。
- `黑骰 / 鬼迹 / 污染`：黑紫、炭黑、红橙异常色；红橙只做危险边缘和符号，不铺满普通面。
- 任一单颗角色骰应以一个主属性色为主，侧面可显示任务外面符号，但不得让第二属性色在主视觉上喧宾夺主。
