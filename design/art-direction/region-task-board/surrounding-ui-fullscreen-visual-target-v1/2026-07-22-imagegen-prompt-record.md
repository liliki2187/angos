## 最终有效提示词

生成一张且仅一张 `1920×1080` 桌面 16:9 Angus《世界怪闻周刊》区域任务台整屏外围美术目标；不是组件 atlas、拆分套件或多方案。画面正交、正视、无透视、无倾斜。严格保留顶部刊头、左侧事件索引、右侧 dossier、底部行动 / 日程 / 后果票据的职责与现有间距；中央 `x=420, y=96, w=1040, h=804` 必须是完全干净、均匀深海军蓝的地图回填区，任何外围物件不得侵入。

视觉采用 clean-lowpoly weekly：现代成年怪新闻编辑设计，深海军蓝舞台、青绿与蓝绿中间色、低饱和橄榄、暖白纸和极少量锈红风险色；使用大片哑光色块、扁平裁纸低多边形语言、清晰切角、薄纸边、每个主要纸件 4–8 个低对比大折面与轻微丝网印刷颗粒。顶部、左、右、下必须像同一期刊物，不能像装饰过的游戏 HUD。

左侧建立一个完整索引文件夹和两张真实任务纸条；selected 通过纸层与色块关系表达，不靠软件描边。右侧是一张连续 dossier：标题、7–9 行摘要、metadata、风险 / 依据 / 建议与唯一底部主 CTA 具有不同编辑角色，不能变成三个同形内嵌矩形。底部是连接票据构图，包含低权重推进票、周日程回条和后果预览，不是米色软件状态栏。

全图禁止任何可读文字、伪字、数字、图标、照片、印章、问号、pin、徽章、箭头、条码或 baked CTA；只保留干净、水平、可回填真实中文的 carrier。禁止旧档案泛黄、脏污、证物墙、写实厚纸、软投影、浮雕、高光、金属道具、赛博 HUD、通用手游与摄影质感。

## 生成后的处理

模型生成尺寸为 `1672×941` 且宏观坐标有偏差，因此没有将其伪装成可直接落地资产。合成脚本只重排生成图中的完整纸件区域，回填冻结地图 / pin、既有 kind icon 和真实中文，并另外导出 25% 与几何 QA 证据。
