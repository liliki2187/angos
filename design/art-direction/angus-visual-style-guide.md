# Angus 视觉风格指南

> **状态**：美术风格真源  
> **创建时间**：2026-06-09  
> **用途**：给后续 AI、美术、UI、宣传图、生图 prompt 与视觉实验提供统一方向。  
> **关系**：本文不替代 `design/gdd/` 的玩法真源；它负责解释 Angus 的视觉语言。若视觉方向影响产品定位、支柱或系统边界，仍需同步对应 GDD。
> **角色美术真源**：自 2026-06-11 起，角色 / 主编 / 编辑的正式视觉方向以 [`角色设计风格规范-AI包`](../../角色设计风格规范-AI包) 及其四人标杆图 [`reference/01-原始基准图.png`](../../角色设计风格规范-AI包/reference/01-原始基准图.png) 为准：高清微像素 Q 版角色、深蓝夜色、低能量都市怪谈群像。旧的“角色不做像素角色”规则废止。

---

## 1. 一句话方向

Angus 的视觉方向是：

> **现代图形设计的电影海报冲击力 + 像素作为高端氛围材质 + 印刷品物质感 + 深蓝与红橙的极限对比。**

玩家第一眼应读到：这是一份新鲜刊发、带黑色幽默和异常新闻设计感的未解之谜周刊；玩家不是在翻旧案，而是在通过周刊版面、解释和传播影响现实。

### 2026-06-23 补充：干净低多边形周刊风格标杆

当前阶段的全局视觉探索以用户确认的图3 / 图4 新标杆为重要参考：它们把低多边形从“地图质感”推进为更通用的图形语言，用在周刊封面、神秘照片、场景快照、文件夹、贴纸、CD、图标和版式资产中。该方向强调更干净的现代资产板、更轻的纸张质感、更少随机脏噪、更明确的版式分组和更强的品牌整理感。

这条补充不是把 Angus 推回旧档案或复古报纸，而是把“异常周刊”从重质感拟物转向更克制的低多边形编辑视觉：深色底板保留为主场，纸张和文件保持干净，绿色 / 蓝绿色可以作为神秘信号与扫描色更积极使用，红橙继续保留给危险、异常升级、不可逆动作或强 CTA。

---

## 2. 不是什么

Angus 不应被做成：

- 旧报纸 / 旧档案 / 泛黄历史案件。
- 暖木桌面、台灯、咖啡色办公室和温馨编辑部。
- 全画面复古像素游戏。
- 纯恐怖调查、纯科幻终端、纯赛博全息界面。
- 通用手游按钮、玻璃 SaaS 面板或素材包卡牌。

早期“复古报刊 + 档案感”只能作为历史探索和少量印刷隐喻参考，不再作为当前主视觉方向。

## 3. 色彩系统

| 角色 | 推荐 |
| --- | --- |
| 基底 | 深海军蓝 `#0F1A2E` |
| 能量 / 异常 / 紧迫 / 主 CTA | 烈焰红橙 `#E84B2C` |
| 内容 / 纸面 / 周刊实体 | 暖米白 `#F5EDD8` |
| 系统信息 / 追踪 / 低频信号 | 少量青色，必须克制 |

禁止大面积使用暖木色、灰褐旧纸、灰银金属、霓虹粉紫、高饱和绿和平均灰蓝。颜色必须服务“异常新闻设计”和“周刊品牌”，不是单纯区分控件。

---

## 4. 媒介混合

| 元素 | 风格 |
| --- | --- |
| 主编 / 编辑 / 角色 | 高清微像素 Q 版角色，以 `角色设计风格规范-AI包/reference/01-原始基准图.png` 为视觉标杆；不是 8-bit / FC / 体素低清像素 |
| 城市 / 环境远景 | 像素剪影、颗粒、氛围材质 |
| 报道图 / 周刊插图 | 半调网点、低细节剪影、异常符号、像素边缘 |
| UI / 字体 / 排版 | 现代图形设计，粗标题、强层级、明确负空间 |
| 纸张 / 档案 / 票据 | 印刷品物质感，不做泛黄怀旧 |

像素在本项目中不是“复古游戏风格”。角色使用高清微像素插画；UI、字体和排版仍保持现代图形设计；城市远景、半调、信号噪点和异常粒子继续承担数字化材质。

## 5. 核心情绪

### 要保留

- 酷。
- 自信。
- 紧迫。
- 黑色幽默。
- 带商业周刊 / tabloid / magazine 的版式冲击。
- 日常编辑部工作与异常现实回响之间的错位。

### 要避免

- 温馨怀旧。
- 安静克制。
- 厚重写实。
- 旧案考古。
- 普通报社经营后台。
- 过度恐怖化或科幻化。

---

## 6. 关键视觉母题

- 巨大的周刊头版、打开的厚纸杂志、版位槽。
- 签批夹、红笔、印章、印刷机按钮、裁切标记。
- 半调网点、套印错位、红青轻微偏移。
- 城市远景像素剪影、异常粒子、信号干扰条。
- 主编 / 编辑 / 角色作为高清微像素 Q 版黑色幽默角色，角色设定、比例、表情和禁忌以 `角色设计风格规范-AI包` 为准。

物件必须承担工作职责：签批纸用于确认，印章用于状态，版位槽用于组稿，印刷按钮用于不可逆送印。不能只把物件当装饰。

---

## 7. UI 包装原则

Angus 的 UI 优先读作“编辑部工作物件”，而不是后台软件界面。

- 功能放入黑板、便签、电视、窗、印刷机、地图墙、索引册、剪报、签批文件、印章、档案夹和桌面器具。
- 线条来自纸边、夹板、物件边缘、套印错位和压层，而不是层层等粗矩形框。
- 主 CTA 应像场景内动作入口，例如签批、盖章、印刷机开关、频道切入条。
- 动态文字、数值和按钮文案由 UI 渲染，不能被生图烙死。
- 纸纹、半调、污点和折痕不能穿过正文或按钮文案。

## 8. 生成与验收

任何视觉 prompt 或生图结果都要先回答：

1. 它是否仍像 Angus，而不是旧档案 / 普通探案 / 视觉小说 / 纯恐怖？
2. 它是否保留深蓝、红橙、米白的品牌结构？
3. 角色是否符合四人标杆图的高清微像素密度、Q 版比例、深蓝夜色和低能量表情？
4. UI、字体和正文是否仍是现代图形设计，而不是被角色高清微像素带成低清复古游戏界面？
5. 主物件是否足够大，是否承担玩法或职业幻想？
6. 删掉 20% 装饰后是否更清楚？
7. 如果是 UI，文字和点击区是否仍由可控 UI 承担？

若视觉稿要作为生产标杆、资源标杆或真源候选，生成后必须由 `@像素艺术` 复审。复审不仅看整体好不好看，还要检查像素颗粒度与标杆继承：颗粒应是有意的 2-4px 方块簇、块状半调、套印错位和清晰图形边缘；不得退成高清摄影噪点、细碎纸脏、泛黄旧档案或旧报纸纹理。世界地图 / 全球频道类资源默认对照 `docs/screenshots/2026-06-07-global-channel-style-board/05-global-channel-style-board-reference-clean-modern-pixel.png` 与 `docs/screenshots/2026-06-07-global-channel-style-board/07-global-channel-full-interface-style-draft-flat-magazine-ui.png`。

若截图第一眼与目标读法冲突，以截图为准；不能用 prompt 意图或实现解释当作通过。

## 9. 与协作 agent 的分工

- `angus_art_director` / `@像素艺术`：判断美术资源、界面视觉风格和视觉 prompt 是否像 Angus，指导参考转译、像素 / 半调 / 印刷材质用法和风格跑偏修正。
- `angus_character_pixel_director`：`@像素美术` 触发；判断角色是否符合四人标杆图和角色设计风格规范，指导角色 prompt、真值源选择和生成后验收。
- `ui_designer`：把界面 brief 转成布局、控件、组件 spec。
- `ux_laoge`：检查玩家是否看懂、是否能点、是否被遮挡或误读。
- `steam_indie_appraiser`：判断 Steam 第一眼、头图、宣传片和 demo 吸引力。
- `game_producer`：判断美术资产范围、成本、人月和里程碑风险。
- `openrouter-image-gen`：执行图像生成；不替代风格判断。

父级 Codex 负责合并意见。若美术指导与 UI / UX / SIA 冲突，必须说明冲突和取舍，不能把所有建议堆进同一张图或同一个界面。
