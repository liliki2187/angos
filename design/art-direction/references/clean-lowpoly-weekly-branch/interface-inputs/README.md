# Clean Low-Poly Weekly 界面输入图

本目录保存 2026-07-22 至 2026-07-29 期间由用户在对话中提供、并实际参与世界地图、区域地图与报刊填入风格校准的输入图。它们不是生成结果，也不自动升级为生产标杆。

## 功能稿

- `world-map-functional-wireframe.png`：世界地图黑白功能稿。
- `region-map-functional-wireframe.png`：区域地图黑白功能稿。
- `newspaper-editorial-functional-wireframe.png`：报刊填入 / 发刊编辑台黑白功能稿。

## 符号与偏差证据

- `sticker-symbol-crop-a.png`、`sticker-symbol-crop-b.png`：用户从标杆中指出的贴纸、手绘标志与品牌符号裁片。
- `component-drift-ufo-sticker.png`：贴纸滑向光滑矢量商品图的偏差证据。
- `component-drift-station-prop.png`：站台 / 时钟 / 日程器滑向写实拟物的偏差证据。
- `region-illustration-over-realistic-crop.png`：区域任务配图滑向低多边形微缩模型的偏差证据。

## 使用边界

- 功能稿约束信息结构、栏位与交互职责，不约束最终塑造方法。
- 两张正式 benchmark 仍负责美术塑造语言；本目录符号裁片只帮助识别其手绘、拼贴与黑色幽默层。
- 偏差证据只用于反例与 Loop Log，不得作为下一轮正向生图参考。
