# 报刊填入界面风格稿提示词

## 参考图职责

- 黑白功能稿：唯一功能几何真源，固定桌面 16:9、顶栏、`320 / 1040 / 360` 三栏、中央双页六版位与右侧发刊复核顺序。
- 世界地图 A / 区域地图 R-21 并排图：跨界面视觉合同，约束深夜蓝桌面、明亮暖白纸、烟熏钴蓝、青绿、橄榄、少量芥末黄 / 锈红、粗颗粒低多边形和冷幽默剂量。
- `benchmark-board-01.png`、`benchmark-board-02.png`：美术内核真源，约束现代怪异周刊、拟物纸张层、夹具、印章、符号和时髦品牌感。

## 首轮生成

用途：高保真桌面 16:9 游戏 UI 风格稿，一张完整界面截图，不是情绪板。

生成“截稿前最后一篇”状态：

- 顶栏保留 `WORLD MYSTERY WEEKLY`、`ISSUE 018`、`DEADLINE TONIGHT`。
- 左栏是八篇候选稿件匣；A04 被选中并略微抽出，以烟熏钴蓝索引边和 `SELECTED` 标签提示状态。候选稿件是有组织的编辑部稿纸，不是圆角 SaaS 卡片。
- 中央是全屏最亮的暖净白双页校样，两张竖版页面始终同时可见。保留六个固定版位：左页上方主头条、左页下方两个专题、右页上方副头条、右页下方两个内页位置。当前完成 5/6，右下为空。两页共用纸张、栏网、页码、裁切线和刊头节奏；即使移除角色标签，也必须仅凭标题、图片面积和跨栏关系看出主副层级。禁止把六个位置做成六张封闭 UI 卡。
- 右栏是夹在深蓝底板上的主编签批纸，顺序呈现当前头条、传播 / 收益预览、公开立场冲突、同题疲劳、硬阻断；硬阻断突出 `EMPTY SLOT 1`，底部只有一个禁用的 `SIGN & PRINT`。
- 五张配图分别概括：不存在站台前停车的 M330、播报明日潮汐的港口塔、51 区路障、市政厅影子部门、拒绝蓝色电话亭的猫。每张图只用少量大结构面和清楚剪影，避免写实微缩景观与密集三角网。
- 版式使用印刷无衬线刊头、标题—图片—图注耦合、共同栏线、条码和校样标；动态小字以整洁横线代替不可读伪文本。
- 背景使用深墨海军蓝 / 夜幕板岩色；纸张保持明亮暖净白；辅色使用旧牛仔钴蓝、灰蓝、低饱和青绿和橄榄；芥末黄与锈红总面积低于 5%，钴蓝不可电光。
- 黑色幽默控制为：一枚 `LACKS NEWS VALUE` 小印章、一处红铅笔圈、页脚 `NO REALITY COMPLAINTS AFTER PRINT`、最多一至两枚 WMW 眼睛 / 地球符号。
- 禁止旅行社、旅游剪贴簿、侦探软木板、泛黄旧档案、蒸汽朋克、赛博霓虹、玻璃拟态、圆角后台卡片、单色、照片写实、密集 Delaunay、像素风、重污损、贴纸雨、角色和额外功能。

## 定向校准

以首轮图为编辑目标，只修改三项：

1. 在候选稿件匣和签批纸背后补充克制的旧牛仔钴蓝、灰蓝、青绿、橄榄纸板层、两三枚小索引签和一张芥末黄校样便签；保持中央校样纸为全屏最亮区域。
2. 将五张新闻配图进一步压成更平、更像印刷海报的宽面低多边形：强调 5–8 个大结构面、轮廓和钴蓝 / 青绿 / 橄榄色块，避免写实 3D。
3. 把趣味度提升到世界地图 A 同档，但只增加最多一枚 WMW 符号和一处编辑手绘符号，不新增文案、功能或装饰噪声。

严格保持三栏几何、六版位、A04 选中、5/6、空位硬阻断、右栏信息顺序与禁用签批按钮。
