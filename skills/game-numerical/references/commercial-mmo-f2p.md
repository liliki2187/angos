## R1 · 商业手游 vs 独立游戏数值哲学差异

| 维度 | 商业手游 | 独立游戏 |
|------|---------|---------|
| **核心目标** | 最大化 LTV（用户终身价值） | 最大化单次体验质量 |
| **时间维度** | 纵向（100+ 天持续成长） | 横向（30 分钟-5 小时一局内平衡） |
| **成长模型** | 永续（等级/战力/装备无限追） | 有限（单局结束/通关结束） |
| **经济目标** | 制造"差距感"驱动付费 | 制造"公平感"保证体验 |
| **通胀态度** | 主动制造（让旧内容贬值推新卡池） | 天然避免（每局重置） |
| **平衡标准** | "大R碾压小R但小R还想玩" | "所有玩家同等条件下公平" |

**核心启示**：如果你的独立游戏要加"长线运营"要素（如赛季/Battle Pass/每日奖励），才需要本资料库的内容。纯买断制单次体验 → 不需要。

## R2 · 付费阶层模型（F2P 专用）

### R2.1 标准三阶层

| 阶层 | 定义 | 月付费 | 资源获取效率 | 设计目标 |
|------|------|--------|------------|---------|
| 免费（零氪） | 不花钱 | ¥0 | 1× 基准 | "能玩、不无聊、但看得到天花板" |
| 小R（月卡/通行证） | 小额固定支出 | ¥30-98 | 1.5-3× | "花一点钱体验明显提升，性价比高" |
| 大R（鲸鱼） | 重度付费 | ¥500-5000+ | 5-20× | "花钱=变强=碾压，满足控制欲" |

### R2.2 阶层差距控制

```
大R vs 免费的战力差距 ≤ {{MAX_WHALE_GAP=300%}}
  → 超过 300% = 免费玩家流失（"打不过就走"）
  → 低于 150% = 大R觉得"花了钱没用"

关键：差距必须"可见但不绝望"
  → 免费通过时间投入可追赶 大R 1个月前的水平（永远差一步但不是天壤之别）
```

### R2.3 付费点嵌入公式

```
每次付费的心理驱动 =
  "我距离下一个体验跃升还差 X"  ← 成长断点
  × "不花钱要磨 Y 天"            ← 时间成本
  × "花 Z 元直接到达"            ← 付费捷径

设计原则：让 Y 略高于玩家"日耐心阈值"（通常 3-7 天），Z 在 ¥6-30 冲动购买范围内
```

## R3 · 经济防通胀体系

### R3.1 Source-Pool-Sink 完整模型

```
Source（产出源）
├── 日常：每日任务 / 体力刷本 / 挂机
├── 周常：周副本 / 竞技场结算
├── 活动：限时活动 / 节日 / 版本庆典
└── 付费：直购 / 抽卡 / 月卡 / Battle Pass

Pool（玩家持有）
├── 通货：金币 / 钻石 / 体力
├── 材料：升级石 / 突破材料 / 碎片
└── 资产：角色 / 装备 / 卡牌

Sink（消耗池，防通胀关键）
├── 永久消耗：强化消耗 / 合成消耗 / 升星消耗
├── 周期重置：赛季重置 / 淘汰机制
├── 税收：交易行手续费 / 修理费
└── 随机消耗：强化失败 / 附魔失败（争议大）
```

### R3.2 日产出效率公式

```
单次产出 = 全局日产出效率 × (单次行为时长 / 每日预期总时长) × 难度系数

全局日产出效率 = 当前等级预期日获取量（表配）

约束：
  - 每日产出 × 30 天 = 当月可升级 1-2 个重要档位（不是所有）
  - 大R日产出 = 免费日产出 × 付费效率倍率（1.5-3×）
  - 活动日产出 ≤ 常规日产出 × 2（否则"不打活动=浪费"焦虑感过强）
```

### R3.3 通胀预警指标

| 指标 | 健康范围 | 危险信号 |
|------|---------|---------|
| 头部玩家资源囤积量 | 可消耗 7-14 天 | >30 天 = 通胀 |
| 新玩家追赶速度 | 2-4 周追到大部队 80% | >8 周 = 新手流失 |
| 版本间战力膨胀率 | 15-30% / 大版本 | >50% = 老装备废纸化 |
| 最强 vs 最弱玩家差距 | 3-5× | >10× = 生态崩溃 |

## R4 · 长线成长曲线

### R4.1 标准等级曲线

```
升级所需经验 = {{BASE_EXP}} × level^{{EXP_EXPONENT=1.5-2.0}}

推荐：
  - 前 20 级（新手期）：快速（每日升 2-3 级），制造"在进步"的感觉
  - 20-50 级（成长期）：中速（每 2-3 天升 1 级），核心玩法展开
  - 50-80 级（中期）：慢速（每周升 1 级），开始需要社交/付费
  - 80-100 级（末期）：极慢（每 2-4 周升 1 级），维持目标感
  - 100+ 级（终局）：象征性（月级），身份标识而非实际提升
```

### R4.2 战力膨胀曲线

```
PowerCurve(level) = BASE_POWER × (1 + GROWTH_RATE)^level

商业手游推荐 GROWTH_RATE：
  - PVE 主导：3-5% / 级（平滑，老玩家不碾压太多）
  - PVP 主导：1-3% / 级（更平，避免新手体验崩塌）
  - 付费驱动：5-8% / 级（大R快速拉开，制造付费欲望）

⚠️ 独立游戏绝不能用这套——这是为了"让玩家觉得昨天的自己弱，今天需要变强"而设计的心理操控曲线。
```

## R5 · 抽卡/Gacha 数值

### R5.1 标准概率分布

| 稀有度 | 单抽概率 | 保底次数 | 体验设计 |
|--------|---------|---------|---------|
| N（普通） | 70-80% | — | 填充 + 分解素材 |
| R（稀有） | 15-20% | — | 有用但不稀缺 |
| SR（超稀有） | 3-5% | 30-50 抽 | "每月稳定获取" |
| SSR（极稀有） | 0.5-1.5% | 80-180 抽 | "版本核心角色 → 付费驱动力" |
| UR（传说） | 0.1-0.3% | 200-300 抽 | "鲸鱼身份象征" |

### R5.2 保底体系（Pity）

```
硬保底 = {{HARD_PITY=90-180}} 抽必出最高稀有度
软保底 = 从第 {{SOFT_PITY_START=60-75}} 抽开始概率线性递增
概率递增公式：P(n) = base_rate + (n - SOFT_PITY_START) × {{PITY_INCREMENT=0.05}}

50/50 机制（部分游戏）：
  首次保底 50% 概率 UP 角色 / 50% 概率常驻
  歪了 → 下次保底 100% UP
```

### R5.3 付费成本换算

```
每次十连 ≈ ¥98-128（标准手游定价）
获取一个 SSR 的期望花费 = 保底次数 × 单抽价格 = 90 × ¥10 = ¥900
获取满破 SSR = ¥900 × 7 = ¥6,300

⚠️ 这套系统本质是"用概率制造需求 → 用保底制造安全感 → 用付费缩短等待"。
   独立游戏如果用这套 → 玩家会骂"独立游戏还搞氪金"→ 口碑崩塌。
   独立游戏的正确做法 = 买断解锁全部内容，或用 Roguelite 随机性替代 Gacha 感。
```

## R6 · 赛季/重置机制

### R6.1 赛季重置目的

```
1. 压缩头尾差距（让新/老玩家重新接近）
2. 刺激消费（赛季限定 → 再氪一波）
3. 延长生命周期（每 2-3 个月一次"新鲜感"）
4. 淘汰旧资产（让旧卡池贬值 → 推新卡池）
```

### R6.2 重置幅度

```
软重置 = 战力保留 60-80%，排名清零
硬重置 = 战力保留 30-50%，装备/等级部分回收
赛季通行证 = 保留"战力"但重置"进度条"（Battle Pass 体验重来）

⚠️ 对独立游戏的启示：
  如果你做"赛季制"独立游戏（如每月一个新 chapter）→ 可参考软重置
  但绝大多数独立游戏 → 不需要赛季机制
```

## R7 · LTV / 商业化公式

### R7.1 核心指标

```
LTV（用户终身价值）= ARPU × 用户生命周期天数
ARPU（每用户平均收入）= 总收入 / DAU
ARPPU（每付费用户平均收入）= 总收入 / 付费用户数
付费率 = 付费用户 / 总用户 = 通常 2-8%

ROI 盈亏线 = LTV > CPI（获客成本）
  → CPI 通常 $3-30/人（取决于品类和地区）
  → LTV 必须 > CPI × 1.3 才有安全边际
```

### R7.2 商业化漏斗

```
             安装
              ↓ 50-70% 次日留存
            Day 1
              ↓ 20-40% 7日留存
            Day 7   ← 第一个付费窗口（新手礼包 ¥6）
              ↓ 10-20% 30日留存
           Day 30   ← 月卡窗口（¥30）
              ↓ 5-10% 90日留存
           Day 90   ← 大R窗口（限定池 / 赛季通行证）
```

### R7.3 独立游戏 vs 手游商业化对比

| 模式 | 独立游戏 | 商业手游 |
|------|---------|---------|
| 收入来源 | 一次性买断 $10-30 | 持续付费 $3-30/月/人 |
| 用户量需求 | 5-50 万份即可盈利 | 需要 100 万+ DAU |
| 成功标准 | 好评率 > 85% → 长尾口碑 | 30 日留存 > 10% → 持续运营 |
| 失败风险 | 做完没人买（一锤子没锤中）| 运营成本烧完前没回本 |
| 数值设计核心 | 单次体验平衡 | 长线付费驱动 |

## R8 · PVE/PVP 数值隔离

### R8.1 为什么要隔离

```
PVE 需要：玩家变强 → 碾压怪物 → 爽快感
PVP 需要：玩家对等 → 技术/策略决定胜负 → 公平感

如果用同一套数值：
  - 大R 在 PVP 里碾压 → 小R 不玩 PVP → PVP 生态死
  - 为了 PVP 公平削弱属性 → PVE 没有变强感 → 成长感消失
```

### R8.2 常见隔离方案

```
方案 A：PVP 场景属性缩放
  PVP_伤害 = PVE_伤害 × {{PVP_SCALE=0.3-0.5}}
  PVP_HP = PVE_HP × {{PVP_HP_SCALE=2.0-3.0}}
  → 拉长 TTK，增加操作空间

方案 B：PVP 固定基础值 + 装备加成上限
  PVP_ATK = 固定值 + min(装备加成, {{PVP_GEAR_CAP}})
  → 大R有优势但有天花板

方案 C：完全独立数值（PVP 专属属性/装备）
  → 最公平但开发成本最高
```
