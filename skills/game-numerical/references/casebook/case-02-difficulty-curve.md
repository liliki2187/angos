# Case 02 · Roguelite 难度曲线设计

> **场景**：Roguelite 卡牌游戏，10 层 + 1 Boss，需要设计从第 1 层到 Boss 的难度递增曲线。
> **演示重点**：难度曲线公式 → 敌人配表 → Boss 锚定 → 休息节奏 → 边界测试。

---

## 用户输入

> 接上一次的卡牌游戏。我设计了 10 层普通战斗 + 第 5 层精英 + 第 10 层 Boss。
> 每 3 层有一次休息/商店。帮我设计难度曲线和敌人数值表。

---

## Agent 标准响应

### Phase 1 · 体验目标确认

**Q1**：你希望难度体感是什么样的？
- A) 前松后紧（前 5 层轻松练手，后 5 层才有压力）
- B) 匀速递增（每层都比上一层难一点点）
- C) 波浪形（每 3 层一个压力峰 → 休息 → 再上升）

**Q2**：第 1 层和第 10 层的体感差距？
- A) "第 10 层明显比第 1 层难，但不至于绝望"（1.5-2× 难度）
- B) "第 10 层是地狱，必须有好 build 才能过"（3-4× 难度）
- C) "每层差不多，Boss 才是真正的挑战"（层间平坦，Boss 跳跃）

**Q3**：玩家第一次玩（无升级/无解锁）的预期通关率？
- A) 30-40%（有挑战但不打击新手）
- B) 15-25%（难，需要学习和好运气）
- C) 5-10%（极难，核心向 Roguelite）

---

### [假设用户回答：C 波浪形 / B / B]

体验锚定：
- 波浪形难度（每 3 层一个峰 → 休息 → 再上升）
- 第 10 层 ≈ 第 1 层的 3-4× 难度
- 首次通关率 15-25%

---

### Phase 2 · 难度曲线公式

**基础增长公式**：

```
enemy_power(floor) = BASE_POWER × (1 + GROWTH_RATE)^floor × wave_modifier(floor)

参数：
  BASE_POWER = 1.0（基准化，具体数值在 Phase 3 展开）
  GROWTH_RATE = 0.18（每层增长 18%）

  // 18% × 10 层 ≈ 总增长 4.4×，对应"第10层=第1层的3-4×难度"（Boss 额外加成）
```

**波浪调节器（wave_modifier）**：

```
wave_modifier(floor):
  floor 1: 0.85  // 第一层偏简单（教学）
  floor 2: 1.00  // 正常
  floor 3: 1.15  // 小峰值（休息前的压力）
  --- 休息/商店 ---
  floor 4: 0.95  // 休息后稍松一口气
  floor 5: 1.30  // ⭐ 精英层（大峰值）
  floor 6: 1.00  // 精英后回落
  --- 休息/商店 ---
  floor 7: 1.05  // 稍有压力
  floor 8: 1.10  // 递增
  floor 9: 1.20  // Boss 前夕（紧张感）
  --- 无休息，直接进 Boss ---
  floor 10: BOSS（独立公式，见 §Boss 锚定）
```

**人话翻译**：
- "第 1 层是教学，让玩家找到节奏"
- "第 3 层是小考，提醒你'该认真了'"
- "第 5 层精英是期中考，考你前 4 层攒的 build"
- "第 6 层故意放松，给你'打赢精英好爽'的奖励感"
- "第 7-9 层稳步爬升，制造'Boss 要来了'的紧张感"
- "第 10 层 Boss 是期末考"

### Phase 3 · 敌人数值配表

**基准**（基于 case-01 的玩家数值：回合 EV ≈ 12-15 伤害输出）：

```
第 1 层标准敌人 HP = 玩家回合输出 × TTK 目标回合数
  = 13 × 3 = 39 ≈ 40 HP

第 1 层标准敌人 ATK = 玩家 HP / 存活回合目标
  = 70 / 8 = 8.75 ≈ 8 ATK（玩家能扛 8 回合不治疗）
```

### Boss 锚定（第 10 层）

```
Boss HP = 玩家完整 build 期望 DPS × BOSS_TTK
  = 15 伤害/回合 × 12 回合 = 180 HP

Boss ATK = 玩家完整 build HP / BOSS_KILL_PLAYER_TURNS
  = 70 / 5 = 14 基础（阶段性提升）

Boss 三阶段设计：
  Phase 1（HP 100-66%）：ATK 14，无特殊
    → "热身，找节奏"
  Phase 2（HP 66-33%）：ATK 18 + 每 2 回合全体 AOE 8
    → "开始施压，需要护甲/回复"
  Phase 3（HP < 33%）：ATK 22 + 狂暴（每回合行动 2 次）
    → "DPS 竞速：拼命输出或被反杀"

Boss 特殊机制预算 = HP × 25% = 45 点
  → 用 "破盾机制" 消耗：Boss 每 3 回合获得 15 护甲，玩家必须先破盾
  → 体验意图："不是纯堆数字比大小，有操作/策略要素"
```

### 休息节奏验证

```
休息点分布：第 3 层后 / 第 6 层后（第 9 层后无休息直面 Boss）

到达休息时的预期状态：
  - 第 3 层后：HP 损耗约 20-35%（小峰值后需要补血）
  - 第 6 层后：HP 损耗约 40-60%（精英后严重消耗）
  - Boss 前：HP 约 50-70%（第 6 层休息补过 + 第 7-9 层消耗）

休息恢复量 = 已损失 HP × 40%
  → 第 3 层后恢复：损失 20 → 回 8 → HP 约 90%（足够继续）
  → 第 6 层后恢复：损失 35 → 回 14 → HP 约 75%（有余力打 Boss）

验证：Boss 前 HP ≈ 50-70%（不满血 → 有紧迫感；不残血 → 不绝望）→ ✅ 合理
```

```markdown
## 数值验证报告

### 体验对齐检查
| 设计意图 | 对应数值 | 达成 |
|---------|---------|------|
| "波浪形难度" | wave_modifier 在 [0.85, 1.30] 间波动 | ✅ |
| "第10层≈第1层3-4×难度" | Boss 180HP/18ATK vs 第1层 34HP/7ATK = 5.3×HP 2.6×ATK | ✅ 综合约 3.5× |
| "首次通关率 15-25%" | 需模拟验证 | [待测] |
| "Boss 战 10-14 回合" | 180HP / 15DPS = 12 回合 | ✅ |
| "精英是期中考" | 精英 95HP vs 前 4 层平均 42HP = 2.3× | ✅ |

### 平衡性检查
- [✅] 每层 TTK 在 2-8 回合（不拖沓也不秒杀）
- [✅] 波浪节奏清晰（峰值 → 休息 → 峰值）
- [✅] Boss 三阶段 DPS check + 机制 check
- [✅] 休息后 HP 充足但不满（保持紧张感）
- [待验证] 纯防 build 是否能在 Boss P3 前输出够

### 边界测试
| 极端场景 | 预期结果 | 应对方案 |
|---------|---------|---------|
| 纯攻 build 遇精英 | 快速击杀但自己也掉很多血 | 精英反伤 3 惩罚纯攻，但不致命 |
| 纯防 build 遇 Boss P3 | 扛得住但 DPS 可能不够 → 超时 | Boss P3 每 5 回合叠一次 ATK+5（soft enrage） |
| 运气极差（前 5 层全选垃圾卡） | 精英层可能过不去 | 精英前必给 1 次商店 → 保底有 1 次补强机会 |
| 运气极好（第 2 层拿到传说卡） | 后面可能太简单 | 传说卡出现率 ≤ 1%，属于奖励性体验，不影响整体 |

### 模拟验证方案
- 方法：Python / 手动 30 局
- 分组：A组（随机选卡）/ B组（纯攻 build）/ C组（纯防 build）/ D组（combo build）
- 每组 30 局
- 通过条件：
  - 总通关率 15-25%
  - 最强 build（D组）通关率 40-60%
  - 最弱 build（C组）通关率 ≥ 10%
  - 精英通过率 50-70%
  - Boss 到达率（打到第 10 层）40-60%

### 可调旋钮指南
| 旋钮 | 调大效果 | 调小效果 |
|------|---------|---------|
| GROWTH_RATE (0.18) | 后期更难，通关率下降 | 后期更平，通关率上升 |
| Boss HP (180) | Boss 战更长，考验续航 | Boss 战更快，考验爆发 |
| 休息恢复比 (40%) | 更宽松，通关率上升 | 更紧凑，需要精打细算 |
| 精英 wave_modifier (1.30) | 精英更难，检查更严 | 精英更软，更像普通怪 |
| Boss P3 触发线 (33% HP) | P3 更早来，紧迫感更强 | P3 更晚来，更多缓冲 |
```
