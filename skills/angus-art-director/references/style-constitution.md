# Angus 视觉风格宪法

> 用途：供 `angus-art-director` 在审查截图、参考图、视觉 prompt 和美术方向时使用。若本文与 `design/art-direction/angus-visual-style-guide.md` 冲突，以后者和用户最新确认优先。

## 1. 一句话风格定义

Angus 的视觉核心是：

> 现代图形设计的电影海报冲击力 + 像素作为高端氛围材质 + 印刷品物质感 + 深蓝与红橙的极限对比。

它不是复古像素游戏，不是旧报纸档案游戏，也不是通用赛博 UI。玩家应感到自己在经营一份新鲜刊发、会影响现实的未解之谜周刊。

## 2. 色彩系统

### 主色

| 角色 | 色彩 |
| --- | --- |
| 基底 | 深海军蓝 `#0F1A2E` |
| 能量 / 紧迫 / 异常 / 主行动 | 烈焰红橙 `#E84B2C` |
| 内容 / 纸面 / 周刊实体 | 暖米白 `#F5EDD8` |
| 系统信息 / 追踪 / 低频信号 | 少量青色，必须克制 |

### 禁止倾向

- 暖木色、咖啡色、灰褐旧档案色。
- 灰色 / 银色 3D 金属渐变。
- 霓虹粉紫、大面积高饱和绿。
- 平均灰蓝、灰土、泛黄纸张占主导。
- 多色彩虹式图标系统。

## 3. 混合媒介规则

| 元素 | 方向 |
| --- | --- |
| 角色 / 主编 / 编辑 | 高清微像素 Q 版角色，以 `角色设计风格规范-AI包/reference/01-原始基准图.png` 为标杆；不是 8-bit / FC / 体素低清像素 |
| 环境 / 城市远景 / 异常粒子 | 像素渲染、剪影、颗粒、信号噪点 |
| 报道图 / 周刊插图 | 低细节场景剪影 + 异常符号 + 半调 / 像素边缘 |
| UI / 排版 / 字体 | 现代图形设计，粗标题、强层级、清晰负空间 |
| 纸张 / 档案 / 票据 | 印刷品物质感，不是泛黄怀旧感 |

核心判断：角色使用高清微像素插画；UI、字体和正文仍保持现代图形设计；城市远景、半调、信号噪点和异常粒子继续承担材质与隐喻。

## 4. 情绪目标

### 要

- 酷。
- 自信。
- 紧迫。
- 黑色幽默。
- 新鲜刊发的异常新闻设计感。
- 现代周刊 / tabloid / magazine 的版式冲击。
- 玩家正在定义解释权的职业感。

### 不要

- 温馨。
- 怀旧。
- 安静。
- 纯恐怖。
- 纯科幻。
- 旧档案。
- 旧报纸。
- 暖光办公室。
- 普通报社经营后台。

## 5. UI 面板与物件规范

- 底色：比背景亮半阶的深色面，带极克制微噪点。
- 边框：可用双层边、纸边、套印错位、压层阴影暗示厚度。
- 文字层级：标题纯白最大；正文约 70% 白；辅助约 50% 白。
- 红 / 青标记：使用小型徽章、短条、压章、数字框，不整行染色。
- CTA：红橙底 + 白字 + 像素级凸起或印刷机 / 印章式动作感。
- 纸面：动态文字必须有干净安全区，纸纹不能穿过正文。

## 6. 8 大陷阱

1. **复古温馨**：暖木色、台灯、泛黄纸、咖啡桌面会把项目拉成怀旧办公室。
2. **低清复古像素化**：把角色、字体、主 UI 做成 8-bit / FC / Pico-8 / 体素低清，会误读为复古像素游戏；角色应按四人标杆图的高清微像素执行。
3. **3D 金属**：灰银金属渐变会拉向廉价科幻或手游界面。
4. **廉价扁平**：只剩大色块会丢失印刷材质和视觉密度。
5. **搜索词偏差**：不要用 `beautiful pixel art` 这类泛词；优先找 atmosphere、visual language、brand system、editorial design。
6. **小物件化**：重要物件必须尺度戏剧化，不能全变成小图标和碎纸片。
7. **赛博通用**：霓虹边框、全息 UI、玻璃卡片不是 Angus 主语。
8. **手游素材包**：通用胶囊按钮、圆角发光标签和模板化卡牌会破坏品牌感。

## 7. 冲突处理

如果用户要求和当前风格冲突，先给出两条路：

- 在现有风格内找替代方案。
- 正式修改风格定义，并同步 `design/art-direction/angus-visual-style-guide.md` 与相关文档。

美术指导不能自行改风格宪法；只能指出冲突、提出替代和等待用户确认。
