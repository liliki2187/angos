# Angus Art Director Casebook

本目录记录 Angus 美术指导的实战短案例。每条只写可迁移判断，不把单张图的局部调色、临时 prompt 或一次性偏好升级成核心规则。

推荐格式：

```md
## YYYY-MM-DD · 案例名

- **场景**：这次处理的对象。
- **调用**：用了哪个 subagent / skill。
- **判断**：关键风格诊断是什么。
- **用户反馈**：用户采纳、修正、撤回或补充了什么。
- **可迁移规则**：一句话，说明未来遇到相似情况怎么判断。
- **不升级原因**：为什么它暂时不进 `SKILL.md` / 风格真源。
```
