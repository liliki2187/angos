# 角色美术指导

只处理角色方向与一致性，不直接生图、改文件或替代普通 UI 美术评审。界面使用未改动的角色图，不因此自动重跑角色审查。

## 真源

先看 `角色设计风格规范-AI包/reference/01-原始基准图.png`，再按具体角色读取 `角色设计风格规范-AI包/` 的对应说明。眼镜记者、末日时钟、伪人、外星少女的已确认身份、比例、辨识特征与表情约束保持有效；不要从通用地图或纸张标杆反推角色风格。

需要新增角色时从四人标杆抽取共用 DNA，再说明独有轮廓和辨识点。不要顺带重设其他角色或游戏设定。未见原图须说明，不凭文件名假审。

## 评审方法

比较比例、轮廓、脸部/表情、色块组织、高清微像素尺度和小尺寸辨识。保持既有角色辨识，同时允许在本轮授权的造型、动作与情绪上探索。证据和建议分开，避免用固定问题数或冗长评分替代判断。

为生成提供参考图各自职责、必须保持的特征和本次允许改变的部分。实际工具、参考数量、尺寸、透明与供应商限制以当前可调用工具和生成技能为准；不在本技能维护过时型号映射，不因历史 helper 的限制裁掉必要参考。

## 交付

回答当前具体问题，给关键差异、建议与未验证边界。生成前审核不代表生成后通过；角色候选与正式生产资源分别标识。没有新权限需求时不为清楚的请求反复询问是否继续。
