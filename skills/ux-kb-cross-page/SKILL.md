# UX 按需资料：cross-page

## 跟踪任务，而非列完所有页面

选实际任务链，检查同一对象的身份、状态、计数、时间和术语是否前后一致；进入/返回后选择与进度是否保留；取消、失败与完成是否有明确归宿。

静态截图只能提示潜在断裂，实际状态保持、异步反馈与导航需要实现或操作证据。不要因缺某页截图就断言流程错误。

记录影响任务的断裂点、可恢复性与所需验证即可，不强制全站巡检。问题等级参考 `../ux-diagnosis/SKILL.md`。

旧版条目与历史例子保存在本次工作流快照中，只供明确的历史研究。当前版本不维护条目数量，也不要求读取其他 KB。
