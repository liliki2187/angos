# 2026-06-09 · 全球频道右侧面板容器审计

- **场景**：Godot 世界地图 / 全球频道中，右侧区域详情面板虽然信息齐全，但用户贴出外部 AI 诊断后指出其更能说明问题。
- **调用**：父级 Codex 同时调用 `ux_laoge` 与 `ui_designer`，对比外部诊断与当前 agent 输出。
- **判断**：外部诊断更好，是因为它没有停在“层级不清 / 风格不统一”，而是把右侧面板拆成可落地组件：容器底色、边框厚度、文字金字塔、语义色面积、密度节奏和 CTA 锚定。
- **用户反馈**：用户认为外部诊断“感觉更好”，要求研究原因并补全我们的 UX agent。
- **可迁移规则**：详情面板、签批夹、弹窗和右侧从属信息栏必须先过“容器是否成立”审计；若容器和背景黏在一起、边框职责混乱、标题 / 正文 / 状态 / CTA 没有金字塔，即使没有遮挡，也应判为 UX 问题。
- **不升级原因**：本案例已经把上位判断器同步进 `system-prompt-v2.2.md`；本文件保留 Angus 全球频道的具体实例，供类似“右侧面板 / 签批夹 / 详情栏”任务按需回看。
