# UX 按需资料：principles

## 可用的解释角度

清楚的反馈帮助理解状态；空间与视觉归组帮助归属判断；一致术语降低转换成本；可恢复操作降低试错风险；渐进披露可降低首屏负荷，但不能藏住当前决定必需的信息。

设计应帮助完成用户目标，不是消除所有思考。策略权衡、探索未知与编辑判断可能正是游戏乐趣。不要仅因“多一个选项/多走一步”否定它。

Fitts/Hick 等模型只在适用假设下提供方向，不以模型名推导本项目未经实测的毫秒、像素或转化率。需要量化、平台标准或当前规范时查原始权威来源并说明适用尺度。

先解释证据与机制，再提出改变。数量与严重度参考 `../ux-diagnosis/SKILL.md`，不重复维护。

旧版条目与历史例子保存在本次工作流快照中，只供明确的历史研究。当前版本不维护条目数量，也不要求读取其他 KB。
