# UX 按需资料：symptoms

## 常见模式

- 幽灵热区：可见对象和可点击范围不一致。
- 状态幻影：视觉显示成功/可用，但实际状态不同。
- 反馈黑洞：操作已发出，结果、进度或失败没有可感知反馈。
- 决策断链：做选择所需信息与操作范围无法对应。
- 归属模糊：数值、图片、说明或装饰不清楚属于哪个对象。
- 复用断裂：同一内容因状态或位置变化需要不必要的多份资产。
- 噪音竞争：次要装饰与关键内容抢注意，或风格被过度简化而失去身份。

这些是观察线索，不是固定诊断。选择时间不按自造指数公式估算；数量、距离和耗时需实际情境验证。机制解释见 `../ux-kb-principles/SKILL.md`，表达模板见 `../ux-kb-templates/SKILL.md`。
