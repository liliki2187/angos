# UX 按需资料：templates

## 选择最小有用表达

单点问题：观察 → 用户影响 → 建议 → 必要验证。

多项问题：用简短表格区分位置、证据、严重度和处理；可以只有一条，不能凑数。

跨页流程：任务链和状态转移图有帮助时才画。布局比较：只有真实取舍才给方案对比，说明收益与代价，不强制 A/B。

参数如字号、网格、点击区域和反馈时间，应来自实际平台、现有系统及测试；4px 网格或“200ms×复杂度”不是通用门槛。

原则见 `../ux-kb-principles/SKILL.md`，诊断范围和严重度见 `../ux-diagnosis/SKILL.md`。

旧版条目与历史例子保存在本次工作流快照中，只供明确的历史研究。当前版本不维护条目数量，也不要求读取其他 KB。
