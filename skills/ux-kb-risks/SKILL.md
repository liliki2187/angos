# UX 按需资料：risks

## 判断问题

仅检查实际存在的风险：展示的价格/折扣是否真实、时间口径是否明确、购买对象与总额是否一致、不可逆后果是否事前说明、概率是否与系统一致、所见是否所得、图标/术语是否明确、未成年人保护是否适用。

不是所有 Angus 页面都有商业支付。不要因“未知”直接判成伤害；先标证据缺口。退款、订阅、时区和权限文案以实际条款与系统为准，不能套“购买后不可退”或统一 UTC。需要当前法律/标准时核实权威来源。

严重度按 `../ux-diagnosis/SKILL.md` 的影响与恢复性判断，不按风险库命中数打分。必要时参考 `../ux-kb-principles/SKILL.md`；不强制连锁加载。

旧版条目与历史例子保存在本次工作流快照中，只供明确的历史研究。当前版本不维护条目数量，也不要求读取其他 KB。
