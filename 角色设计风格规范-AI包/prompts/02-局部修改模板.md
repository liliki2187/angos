# Prompt 模板 02 · 局部修改（在已通过版本上微调）

> 适用：已有一张基本通过的图，只需要改某个角色的某个属性。例如"把伪人的领带改成红色"、"把末日时钟的姿势改成蹲下"等。

---

## 使用步骤

1. **必须传入的参考图**：
   - **基准图**：用户已通过的那张图（主参考，作为"未改动部分"的真值）
   - **方向参考图**：如果有，传入"正确"和"错误"两端的对照图

2. **修改原则**：
   - 一次只改一处（不要批量改多个角色多个属性）
   - 显式列出"不动"清单
   - 关键易丢失属性（如伪人灰肤）⚠️ 单独强调

3. **必须使用的模型**：`gemini-3-pro-image`

---

## Prompt 模板

```
任务类型：局部修改，不是重新创作。

基准图：[传入已通过的版本] —— 这是"未改部分"的唯一真值源，请像素级保留。

【本次仅修改】
角色：[明确指定要改的角色，如"角色C·伪人"]
部位：[具体到哪个部位，如"领带颜色"、"姿势"、"嘴型"]
方向：[具体到肌肉/属性的描述，如"领带从黑色改为深红色 #8C2C2C"、"姿势从看手表改为双手插兜"]

✅ 正确参考：[如有，传入正确示例图]
❌ 错误反例：[如有，传入错误示例图，告诉模型"不要画成这样"]

【保持不变（必须与基准图完全一致）】
- 其他 3 个角色的所有细节（脸 / 服装 / 道具 / 姿势 / 表情）
- 被修改角色除修改部位外的所有细节
- 整体构图、站位、比例
- 背景、夜空、城市剪影、粒子
- 整体色调、像素质感、风格

【⚠️ 易丢失属性单独强调（即使本次不修改）】
- 伪人的灰白苍白肤色 #7C7D75~#828180（绝对不可漂移到正常人类肤色）
- 伪人的红色圆瞳
- 末日时钟必须低头看时钟，不要直视观众
- 末日时钟必须闭嘴放空，不要画痛苦表情

【本次特别要避免】
[列出本次特别要避免的常见错误，如"不要把伪人嘴型也改了"、"不要把末日时钟改成痛苦表情"]
```

## 修改场景示例

### 示例 1：改伪人服装颜色

```
任务类型：局部修改，不是重新创作。

基准图：[已通过的四人合影]

【本次仅修改】
角色：左3 伪人
部位：领带颜色
方向：从黑色 #0F0F0E 改为深酒红色 #6C2C2C

【保持不变】
- 其他 3 个角色完全一致
- 伪人除领带外所有细节不变：
  * ⚠️ 灰白苍白肤色 #7C7D75
  * 红色圆瞳
  * 小幅度上抿露上排小牙的嘴型（等级 3）
  * 眉头微蹙
  * 黑西装、白衬衫、看手表姿势
- 背景、夜空、构图全部不变

【本次特别要避免】
- 不要改动伪人的嘴型 / 眼神 / 肤色
- 不要把伪人的笑容画夸张
- 不要影响其他角色
```

### 示例 2：改末日时钟姿势

```
任务类型：局部修改，不是重新创作。

基准图：[已通过的四人合影]

【本次仅修改】
角色：左2 末日时钟
部位：姿势
方向：从站立抱时钟改为蹲下放时钟在地上、双手抱膝。表情保持"放空发呆"不变（仍然是低头看时钟、半睁眼、闭嘴）。

【保持不变】
- 其他 3 个角色完全一致
- 末日时钟除姿势外所有细节不变：
  * 长黑发凌乱长刘海
  * 破洞黑T + 军绿工装裤 + 军靴
  * 齿轮电路板时钟（外观不变，只是从抱着变成放地上）
  * ⚠️ 表情仍然是"低头放空闭嘴"，绝对不要改成痛苦
- 背景、构图（左1、右1 站位不变）

【本次特别要避免】
- 不要把末日时钟改成痛苦表情或抬头看人
- 不要改动其他 3 个角色
- 不要把伪人肤色画成正常人类肤色（即使本次不改伪人）
```

### 示例 3：改伪人嘴型程度（最易出错场景）

```
任务类型：局部修改，不是重新创作。

基准图：[当前版本，伪人嘴型偏大（等级 4），需要收一点]

【本次仅修改】
角色：左3 伪人
部位：嘴型
方向：从当前的"嘴角大幅平拉露牙"（等级 4）改为"小幅度上抿露上排一排小牙齿"（等级 3）。
- 嘴宽从 0.18h 缩到 0.14h
- 牙齿可见但只露上排一排小牙，不露下排
- 嘴角向上抿一个小角度，不是平拉

✅ 正确参考：[传入 examples/伪人嘴型对照/01-正确-小幅度上抿露上排小牙.png]
❌ 错误反例 1：[传入 examples/伪人嘴型对照/02-错误-嘴太大露牙过多.png] —— 当前就是这样，不要画成这样
❌ 错误反例 2：[传入 examples/伪人嘴型对照/03-错误-嘴过小几乎闭嘴.png] —— 也不要矫枉过正改成这样

【保持不变】
- 其他 3 个角色完全一致
- 伪人除嘴型外：⚠️ 灰白肤色 / 红圆瞳 / 眉头微蹙 / 黑西装 / 看手表姿势 全部不变

【本次特别要避免】
- 不要矫枉过正改成完全闭嘴或几乎不露牙
- 不要把肤色改成正常人类肤色
- 不要影响其他角色
```

## 修改后必做的自检

按 `风格规范-v2.0.md` §8 验收 Checklist 核查，**额外重点**：

- [ ] 修改的部位是否达到目标？
- [ ] **未修改的部位是否仍与基准图一致**？
- [ ] 其他 3 个角色是否完全没动？
- [ ] 易丢失属性（伪人灰肤、末日时钟表情）是否还在？
