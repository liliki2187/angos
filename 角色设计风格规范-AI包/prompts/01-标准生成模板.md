# Prompt 模板 01 · 标准生成（全新场景）

> 适用：全新场景，没有现成的"正确版本"可参考。例如"画 4 人在便利店门口"、"画末日时钟单人新姿势"等。

---

## 使用步骤

1. **必须传入的参考图**：
   - `reference/01-原始基准图.png`（构图/风格/未出场角色的形象）
   - 涉及末日时钟时：必须传入 `examples/末日时钟表情对照/01-正确-放空发呆.png`
   - 涉及伪人时：必须传入 `examples/伪人嘴型对照/01-正确-小幅度上抿露上排小牙.png`

2. **必须使用的模型**：
   - 优先 `gemini-3-pro-image`
   - 备选 `gpt-image-2`（设置 `quality: high`，但多图模式可能超时）

3. **必须填入的 prompt 模板**（见下）

---

## Prompt 模板

```
风格：像素风 Q 版 chibi 角色，弱描边（深棕单像素），块面平涂为主（70%）+ 少量明暗渐变（30%），像素颗粒质感，整体色调深蓝夜色基底 #000A19，复古都市怪谈氛围，风格锚定参考 Eastward / Omori 的现代高清像素风（不要画成 8-bit FC 风、不要画成 Minecraft 体素风）。

背景：深蓝夜空 #000A19~#010B1A + 远处城市剪影（暖灰棕 #1F1A18）+ 散落的橙色 #B36833 暖灯粒子 和 青色 #0098B3 冷灯粒子。整体色调暗调都市怪谈氛围。

【本次场景】：
[在此填入具体场景描述，如"4 人站在便利店门口"、"末日时钟单人在废墟上"等]

【出场角色】：
[按下方角色卡逐个列出涉及的角色]

---

【左1 眼镜记者】中长黑发，黑框圆眼镜，卡其风衣 #5D5853 + 黑高领 #0F0F0E，蓝色 #2C5A8A 工牌挂胸前，左手抱报纸，右手持麦克风，肩挂橙色 #B36833 帆布包，正常人类暖肤色。
表情：警惕微抿，眉略蹙，嘴抿平，不要画笑容。

---

【左2 末日时钟】长黑发凌乱长刘海垂落，破洞黑T #0F0F0E + 军绿工装裤 #4F5837 + 军靴 #3A2E22，怀里抱齿轮电路板焊成的破旧时钟（铜色 #6E5A3A + 电路板绿 #3A5028 + 外露铜线），正常人类暖肤色。

表情严格按以下肌肉描述，并参考传入的"末日时钟正确特写"图：
- 头部明显低垂看怀里时钟（不要直视观众）
- 半睁眼眼神向下无神
- 眉完全放松平直，眉尾微微下垂
- 嘴完全闭合平直一条短线，嘴宽 0.08h
- 不要画汗珠

气质：放空、麻木、温和的丧，低能量抽离感（不是痛苦）。

🔴 严禁：痛苦表情、皱眉、张嘴、汗珠、直视观众、哭、咬牙、咧嘴。

---

【左3 伪人】⚠️⚠️⚠️ 这是一个"想低调融入打工族的温和伪人"，不是经典恐怖谷诡异伪人。

⚠️ 关键：必须使用灰白色苍白非人类肤色 #7C7D75~#828180（绝对不可改为正常人类肤色！这是非人化的核心识别符）。

短乱黑发 #0F0F0E，红色圆瞳 #C8302A 稍微睁大，眉头微微紧蹙。

表情严格按以下肌肉描述，并参考传入的"伪人正确特写"图：
- 嘴角小幅度向上抿起 0.14h 嘴宽（等级 3 标尺，不是等级 1/2/4/5）
- 露出上排一排小牙齿（不要露下排牙、不要露满口大牙）
- 呈现"打工人陪笑"的克制状态
- 嘴眼错位：嘴在做笑的动作但眼睛保持紧绷局促

服装：黑西装 #050504 + 白衬衫 #B0B0A8（夜景下偏灰）+ 黑窄领带 #0F0F0E + 手表，双手交叠看手表姿势。

气质：温和、拘谨、局促的打工人陪笑，像第一天上班被介绍给同事时勉强挤出的客气微笑。

🔴 严禁：
- 经典恐怖谷的咧嘴大笑（参考传入的"错误案例 02"，不要画成那样）
- 嘴角向两侧大幅平拉
- 完全闭嘴或几乎不露牙（参考传入的"错误案例 03"，不要画成那样）
- 呆滞空洞瞪大眼
- 正常人类肤色

---

【右1 外星少女】黑齐刘海齐肩短发 #0F0F0E，UFO 飞碟造型帽子（灰色 #7E7770 碟身 + 顶部雷达天线 + 帽檐绿色外星人 #5FB84A 和白色幽灵 #D8D8D2 图案），黑长风衣 #0A0A09（衣摆绿色外星人图案 + 锁链装饰）+ 黑长靴，双手分别抱白色幽灵玩偶和绿色外星人玩偶，正常人类暖肤色。
表情：平静冷淡，嘴抿平，不要画笑容。

---

【构图】：[根据场景填写，如"四人横向排列站立，3:2 横版"、"单人居中，1:1 正方"等]

【整体氛围】：低能量、内敛、都市疏离感，不要画戏剧化高情绪。

⚠️ 最后再次强调关键点：
1. 伪人必须是灰白苍白肤色 #7C7D75~#828180，不是正常肤色
2. 伪人嘴型必须是等级 3（小幅度上抿露上排小牙），不要画成等级 1/2/4/5
3. 末日时钟必须是低头放空闭嘴，绝对不要画痛苦表情
4. 所有角色情绪必须温和克制，不要戏剧化
5. 风格必须是现代高清像素风（参考 Eastward），不是 8-bit FC 风
```

## 工具调用示例（伪代码）

```python
generate_image(
    model="gemini-3-pro-image",
    prompt=<上面的完整 prompt>,
    image_urls=[
        "reference/01-原始基准图.png",                          # 风格/构图基准
        "examples/末日时钟表情对照/01-正确-放空发呆.png",       # 末日时钟脸部真值
        "examples/伪人嘴型对照/01-正确-小幅度上抿露上排小牙.png",  # 伪人脸部真值
        "examples/伪人嘴型对照/02-错误-嘴太大露牙过多.png",     # 伪人错误案例（让模型知道边界）
        "examples/伪人嘴型对照/03-错误-嘴过小几乎闭嘴.png",     # 伪人错误案例
    ],
    aspect_ratio="3:2"  # 根据场景调整
)
```

## 生成后必做的自检

按 `风格规范-v2.0.md` §8 验收 Checklist 逐项核查，**任何一项不通过则必须重生**。

特别注意：

- ⚠️ 伪人灰肤是否还在
- ⚠️ 伪人嘴型是不是等级 3（上排小牙整排可见、嘴宽适中）
- ⚠️ 末日时钟是不是低头放空（不是痛苦）
