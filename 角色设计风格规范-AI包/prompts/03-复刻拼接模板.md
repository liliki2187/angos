# Prompt 模板 03 · 复刻拼接（已有正确特写）⭐ 推荐

> 适用：当部分元素的"正确版本"已经存在于不同的图中，需要拼接组合时。这是**经验证最稳定**的工作流。

---

## 为什么推荐这个模板

经过 8 轮迭代验证：
- "重生成" 即使 prompt 描述再精确，每次都会有细微漂移
- "复刻拼接" 把已有的正确图当作真值源，模型只需要"组装"而非"想象"
- 漂移率：重生成 ~40%，复刻拼接 ~5%

---

## 使用步骤

1. **明确每个角色 / 部位的"真值源"图**：
   - 整体构图、风格、背景 → 来自基准图
   - 末日时钟脸部 → 来自 `examples/末日时钟表情对照/01-正确*.png`
   - 伪人脸部 → 来自 `examples/伪人嘴型对照/01-正确*.png`
   - 记者、外星少女 → 来自基准图

2. **必须使用的模型**：`gemini-3-pro-image`（多图复刻能力较好）

3. **关键句必须出现**：
   - "这是严格的图像复刻任务，不是创作任务"
   - "图 X 是 Y 的唯一真值源，必须像素级复刻"
   - "不要再创作、不要优化、不要根据图 Z 的同一部位调整"

---

## Prompt 模板

```
这是一个严格的图像复刻任务，不是创作任务。

提供的图：
- 图 1 = [基准图/标杆图]，定义整体构图、像素美术风格、背景、未改动的角色
- 图 2 = [末日时钟脸部正确特写]，作为左2脸部的唯一真值源
- 图 3 = [伪人脸部正确特写]，作为左3脸部的唯一真值源
- 图 4（可选）= 其他需要复刻的特写

要求：

【整体】
- 保留图 1 的整体构图、像素美术风格、夜空粒子背景、像素颗粒质感、所有色调
- 图 1 中的左1眼镜记者和右1外星少女的脸和身体所有细节必须与图 1 完全一致（不要重新设计、不要"优化"）

【左2 末日时钟脸部 - 像素级精确复刻图 2】
- 头部朝向：低头看怀里时钟（按图 2 的角度）
- 长刘海垂落位置：按图 2
- 眼神：半睁眼眼神向下无神（按图 2）
- 眉毛：完全放松平直眉尾下垂（按图 2）
- 嘴：完全闭合平直一条短线（按图 2）
- 整体表情：放空温和的丧（按图 2）

左2 的身体、服装、道具、姿势保持图 1 原样（破洞黑T + 军绿工装裤 + 军靴 + 抱齿轮电路板时钟）。

【左3 伪人脸部 - 像素级精确复刻图 3】
- ⚠️ 灰白色苍白非人类肤色（按图 3，不要画成正常人类肤色）
- 短乱黑发（按图 3）
- 红色圆瞳稍微睁大（按图 3）
- 眉头微微紧蹙（按图 3）
- ⚠️ 嘴型：嘴角小幅度向上抿起，露出上排一排小牙齿，呈现"打工人陪笑"的克制状态（按图 3 的嘴宽和露牙程度）
- 整体表情：温和、拘谨、局促（按图 3）

左3 的身体、服装、道具、姿势保持图 1 原样（黑西装 + 白衬衫 + 黑窄领带 + 看手表姿势）。

【强制约束】
- 图 2 和图 3 是脸部唯一真值源，像素级复刻，不要再创作
- 不要"优化"任何细节
- 不要根据图 1 的同一角色的脸做任何调整
- 不要把图 2/图 3 的元素揉到不该出现的角色身上

【场景调整（如有）】
[如本次复刻同时需要调整场景，如"把背景从夜空改为便利店内"，在此说明]
```

### 示例 2：单人新场景（如"末日时钟一个人坐在天台"）

```
这是一个严格的图像复刻任务，不是创作任务。

提供的图：
- 图 1 = [基准图]，定义末日时钟的所有视觉元素（服装/道具/像素风格/色调）
- 图 2 = [末日时钟脸部正确特写]，作为脸部唯一真值源

要求：

【场景调整】
- 单人构图：仅末日时钟一个人
- 背景：从城市夜景改为高楼天台夜景（保持深蓝夜色 + 远处城市剪影 + 橙蓝粒子）
- 姿势：坐在天台栏杆边，怀里仍然抱着齿轮电路板时钟

【角色 - 末日时钟】
- 脸部像素级复刻图 2：低头看怀里时钟、半睁眼无神、闭嘴平直、放空温和的丧
- 服装、发型、道具按图 1 中的左2 完全一致：长黑发凌乱长刘海、破洞黑T、军绿工装裤、军靴、齿轮电路板时钟
- 姿势：坐姿，双腿可自然伸直或一只腿曲起

【风格】
- 严格保持图 1 的像素美术风格、Q 版比例、像素颗粒质感

【禁忌】
- 不要画痛苦表情（按图 2 的放空状态）
- 不要直视观众
- 不要画汗珠
```

### 示例 3：互动场景（如"伪人递咖啡给记者"）

```
这是一个严格的图像复刻任务，不是创作任务。

提供的图：
- 图 1 = [基准图]，定义所有角色的服装/道具/像素风格/色调
- 图 2 = [伪人脸部正确特写]，伪人脸部唯一真值

要求：

【场景】
- 两人互动：伪人面向左侧，正在递一杯咖啡给记者
- 记者面向右侧，伸手接咖啡
- 背景：保持深蓝夜色 + 城市剪影

【左·伪人】
- 脸部像素级复刻图 2：⚠️ 灰白苍白肤色、红圆瞳、小幅度上抿露上排小牙、眉头微蹙
- 服装、发型按图 1：黑西装 + 白衬衫 + 黑窄领带
- 姿势：身体面向左侧 30°，右手前伸递咖啡

【右·记者】
- 完全按图 1 的左1 记者：黑发、黑框眼镜、卡其风衣、黑高领、蓝工牌、橙包
- 表情：警惕微抿（按图 1）
- 姿势：身体面向右侧 30°，右手前伸接咖啡

【风格】
- 严格保持图 1 的像素美术风格、像素颗粒质感、整体色调

【禁忌】
- 不要画伪人成正常人类肤色
- 不要画两人笑容（按各自的表情基线）
- 不要画亲密接触
```

## 复刻后必做的自检

按 `风格规范-v2.0.md` §8 验收 Checklist 核查，**额外重点**：

- [ ] 复刻的脸部是否与真值特写图一致？
- [ ] 没有出现"再创作"的细节漂移？
- [ ] 风格、色调、像素质感与基准图一致？
- [ ] 各角色的服装、道具、配饰完整？
- [ ] ⚠️ 伪人灰肤还在？
- [ ] ⚠️ 末日时钟表情没变成痛苦？

## 复刻失败时的兜底策略

如果模型仍然出现漂移（典型表现：伪人嘴型变大、末日时钟变成痛苦表情、伪人肤色变正常）：

1. **第一次重试**：在 prompt 末尾追加更强的反刻板化语句
2. **第二次重试**：传入更多错误反例图作为"边界提示"
3. **第三次重试**：用 `prompts/02-局部修改模板.md` 在已生成的"半对"版本上做精修
4. **仍然失败**：停下来，用文字向用户报告漂移情况，让用户决定下一步

**不要无限重试 —— 5 次以内必须停下来对齐策略。**
