## 1. 整体美术风格

### 1.1 风格锚定（最高优先级）

模型必须按以下锚定理解风格，**不要把"像素风"理解成 8-bit FC 风**：

| 维度 | 锚定参照 | 错误参照 |
|---|---|---|
| 整体像素密度 | **现代高清像素风**（参考 Eastward / Omori / Octopath Traveler 角色立绘） | ❌ 8-bit FC 风 / Minecraft 体素 / Pico-8 |
| 角色比例 | **Q 版 chibi**（参考 To the Moon、A Short Hike 的小人） | ❌ 写实比例 / 头身比 1:7 以上 |
| 色调氛围 | **暗调都市怪谈**（参考 Disco Elysium 夜景 / Signalis / Omori 暗章） | ❌ 糖果色 / 高饱和卡通 / 阳光明亮 |
| 质感 | **CRT 扫描线轻噪点 + 块面平涂 + 偶尔像素抖动** | ❌ 厚涂 / 矢量平滑 / 写实光影 |

### 1.2 量化技术指标

| 项目 | 规则 |
|---|---|
| 图像分辨率 | 1536×1024 或 1024×1024 |
| 像素颗粒大小 | 视觉上等效约 3-4 真实像素/单元 |
| 描边 | 弱描边，单像素深色边（深棕/深蓝），**不使用纯黑边**；部分角色边缘可不描边 |
| 平涂占比 | 整体颜色 70-80% 为块面平涂，20-30% 为简化阴影 |
| 阴影方向 | 默认右上光源，阴影在角色左下侧 |
| 颗粒纹理 | 全图叠加轻微 CRT 噪点（透明度 5-10%） |

#### 1.3.3 伪人（角色 C）灰白苍白肤色（核心识别符）

> **这是整个项目最关键的色值之一，绝对不可漂移到正常人类肤色。**

| 用途 | Hex | 备注 |
|---|---|---|
| 亮部 | `#C8BCAE` ~ `#CDC4B5` | 极浅冷灰白 |

- 人类肤色饱和度 8-15%，偏暖（R > G > B）
- **伪人肤色饱和度 <5%，几近无饱和度**，偏中性冷灰

## 2. 角色通用规则

### 2.1 头身比例量化

- 全身高度 H = 角色总高度
- 头部高度：0.30H ~ 0.35H（Q 版大头）
- 躯干高度：0.30H ~ 0.35H
- 腿部高度：0.30H ~ 0.35H
- 头宽：约等于躯干宽度的 0.9 倍

### 2.2 面部五官比例（基于头部高度 h）

- 眼睛纵向位置：从头顶往下 0.55h（中下偏中）
- 眼睛大小：宽 0.20h × 高 0.15h
- 瞳孔大小：眼睛内部的 60-70%
- 双眼间距：约 0.15h（窄于真实人脸）
- 眉眼间距：0.05h
- 眉毛粗细：单像素 ~ 1.5 像素
- 嘴位置：从头顶往下 0.78h
- 嘴默认宽度：0.12h（伪人小笑时 0.15h，最大不超过 0.18h）
- 鼻子：省略或单像素点（在 0.68h 位置）
- 耳朵：通常被头发遮住，不画

### 2.3 通用面部规则

| 项目 | 规则 |
|---|---|
| 眼睛形状 | 圆形 / 椭圆瞳孔（**伪人为正圆**），瞳色作为角色识别色 |
| 眉毛 | 极简两笔，眉形决定情绪 70% 信号 |
| 嘴巴 | 默认极小（一两个像素短线），张嘴必须有节制 |
| 鼻子 | 通常省略或仅一个像素点 |
| 皮肤 | 人类角色为正常暖肤色；非人类角色必须使用**灰白/灰青色苍白肤色**作为视觉区隔 |
| 描边 | 面部不使用纯黑描边，使用深棕/深灰描边 |

### 2.4 道具规则

- 每个角色必须持有 1-2 个标志性道具，作为人设识别符
- 道具风格统一为像素风，颗粒感与角色一致
- 道具颜色不能脱离整体色调（不要画亮色道具破坏氛围）

#### 3.3.1 伪人嘴型五级精确标尺（最易翻车点）

| 等级 | 描述 | 嘴宽 | 露牙 | 评价 |
|---|---|---|---|---|
| 1 | 闭嘴一条线 | 0.08h | 0 颗 | ❌ 太冷漠 |
| 2 | 抿嘴露一道细缝 | 0.10h | <1 行牙 | ❌ 太收敛 |
| 3 | **小幅度上抿 + 露出上排一排小牙齿** | **0.13~0.15h** | **上排小牙整排可见** | ✅ **正确** |
| 4 | 嘴角向两侧大幅平拉露牙 | 0.18h | 上下排都露 | ❌ 太恐怖 |
| 5 | 咧嘴大笑露满口牙 | 0.22h+ | 满口大牙 | ❌ 完全错误 |

#### 3.3.2 伪人的"打工人陪笑"心理模型

伪人不是想吓人，他是**第一天上班被介绍给同事时**勉强挤出来的客气微笑：
- **嘴**：想笑得得体，但肌肉不熟练 → 等级 3
- **眼**：想看又不敢直视，微微紧绷 → 视线略微回避或正视但发僵
- **眉**：略微紧蹙透出不自信 → 眉头微皱
- **整体**：克制 + 局促 + 想合群，而不是夸张 + 诡异 + 想吓人

#### 3.3.3 伪人"嘴眼错位"的核心识别符

**伪人是 4 个角色中唯一允许嘴眼情绪不匹配的**：
- 嘴在做"笑"的动作（等级 3）
- 眼睛保持紧绷局促，没有笑意
- 这种"嘴笑眼不笑"的肌肉分离感是伪人非人化的体现

## 4. 表情设计核心原则

### 4.1 三层情绪信号

角色情绪通过**眉 + 眼 + 嘴**三层组合表达，三者必须协调（伪人除外）：

| 情绪类型 | 眉 | 眼 | 嘴 |
|---|---|---|---|
| 放空 / 丧（B 末日时钟） | 平直、眉尾微垂 | 半睁低垂 | 闭合平直 |
| 警惕 / 观察（A 记者） | 略蹙 | 微眯或正视 | 抿平 |
| 局促 / 陪笑（C 伪人） | 微蹙 | 微睁 + 视线略避 | 小幅度上抿露小牙（等级 3） |
| 冷淡 / 神秘（D 少女） | 平直 | 半睁正视 | 闭合平直 |

### 4.2 情绪强度上限

- 所有角色情绪默认**温和、克制**，避免戏剧化
- 不画：放声大笑、痛哭、惊恐尖叫、愤怒咆哮等高强度情绪
- 即便"开心"也只是"嘴角微抿"；即便"难过"也只是"放空发呆"
- **整组角色的情绪基调统一为：低能量、内敛、都市疏离感**

### 4.3 嘴眼匹配规则

- **普通角色**（A、B、D）：嘴笑则眼也要带笑意；嘴抿则眼也要冷淡
- **伪人（C）唯一例外**：嘴在做"笑"的动作，眼睛保持紧绷局促 —— "嘴眼错位"是伪人的核心识别符

### 4.4 表情描述必须具体到肌肉

❌ 抽象描述（模型每次理解都不同）：
- "温和的微笑"
- "局促的表情"
- "丧的感觉"

✅ 具体到肌肉的描述（可稳定复现）：
- "嘴角小幅度向上抿起 + 露出上排一排小牙齿 + 眉头微微紧蹙 + 视线略微回避"
- "头部低垂 + 半睁眼眼神向下无神 + 眉尾微微下垂 + 嘴完全闭合平直"

## 5. 构图规则

### 5.1 标准多人合影

- 角色**横向排列**，正面或微侧朝向观众
- 角色之间**留有空隙**（约 0.5 个角色身宽），不重叠
- 角色脚下高度对齐
- 背景为远景城市夜空，角色与背景之间用模糊远景过渡
- 整体比例 3:2（横版）

### 5.2 单人立绘

- 角色居中，占画面纵向 60% ~ 80%
- 背景简化或纯色 `#000A19`，突出角色

### 5.3 镜头距离

- 默认**全身镜头**（脚到头）
- 半身（腰以上）/ 头肩特写需求需另行说明

### 5.4 互动场景

- 角色之间可有动作互动，但保持人物之间至少 1/4 身宽空隙
- 不要画拥抱、亲吻等近距离亲密互动（与项目疏离基调不符）

## 6. AI 生成方法论

### 6.1 任务前必做的 3 件事

1. **读完本文档 + README + 4 个角色的图片**（reference + examples）
2. **判断任务类型**（新生成 / 局部修改 / 复刻拼接），选择 `prompts/` 中的对应模板
3. **先用文字向用户复述理解**，确认后再生成

### 6.2 生成时的硬性要求

| 要求 | 说明 |
|---|---|
| **必须传入图像参考** | 至少传入 `reference/01-原始基准图.png`；涉及末日时钟和伪人必须传入对应正确特写 |
| **必须标注真值源** | 在 prompt 中明确"图 X 是脸部唯一真值，必须像素级复刻" |
| **必须列出禁忌** | "不要画 X / Y / Z"作为硬性约束 |
| **必须 ⚠️ 标记关键属性** | 易丢失属性（如伪人灰肤）单独反复强调 |
| **必须显式反刻板化** | "这个伪人不是经典恐怖谷伪人" |

### 6.3 复刻 vs 重生成的决策树

```
用户给出的需求
    │
    ├─ 全新场景（无已有正确版本）
    │      → 走"标准生成"流程
    │      → 参考图：原始基准图 + 涉及角色的正确特写
    │
    ├─ 已有图，要改某个角色某个属性
    │      → 走"局部修改"流程
    │      → 参考图：已通过版 + 修改方向描述
    │      → 强调"未改部分保持原样"
    │
    └─ 已有正确部件（如某角色脸 OK 但身体在另一张图）
           → 走"复刻拼接"流程（推荐）
           → 明确告诉模型"这是复刻任务不是创作任务"
           → 把所有正确部件作为"唯一真值源"传入
```

### 6.4 不同模型的选择建议

| 模型 | 适用场景 |
|---|---|
| `gemini-3-pro-image` | 多图参考 + 复刻任务的首选，对"严格按参考"指令响应较好 |
| `gpt-image-2` | 适合带 mask 的局部编辑；多参考图模式可能超时 |

## 7. 经验教训详细版（8 条避坑原则）

### 7.1 原则 1：先理解人设，再画表情

**踩坑实例**：模型把"末日时钟"画成**痛苦扭曲表情**（皱眉 + 张嘴 + 汗珠），把"伪人"画成**夸张大笑**。

**根本原因**：模型默认按"角色名"字面发挥 —— "末日时钟"听起来很痛苦、"伪人"听起来很恐怖，于是画得很戏剧化。

**正确做法**：在 prompt 中**明确告诉模型角色的内核**：
- "末日时钟"是**放空发呆的低能量丧**，不是痛苦
- "伪人"是**温和打工人的局促陪笑**，不是恐怖谷的吓人怪物

**规则**：任何带情绪色彩的角色名，**必须在 prompt 中提供"反直觉"的人设澄清**。

### 7.2 原则 2：表情描述要"具体到肌肉位置"

**踩坑实例**：用"局促表情"、"温和微笑"等抽象词时，模型每次理解都不同，反复横跳。

**正确做法**：用**具体到面部肌肉位置**的描述：
- ❌ 抽象：「温和的笑容」
- ✅ 具体：「嘴角小幅度向上抿起 + 露出上排一排小牙齿 + 眉头微微紧蹙 + 视线略微回避」

**规则**：表情提示必须**逐项写明眉 / 眼 / 嘴 / 视线 / 头部朝向**，每一项给一个动作描述。

### 7.3 原则 3：避免"越改越极端"的螺旋

**踩坑实例**：用户说"嘴改小一点" → 模型改成"完全闭嘴" → 用户又说"露牙没了" → 模型又改成"咧嘴大笑"。

**根本原因**：模型对"程度词"理解为开关式跳变，不是渐变。

**正确做法**：
- 给出**具体参照标尺**（如本文档 §3.3.1 中的"伪人嘴型五级标尺"）
- 修改时同时给出"对的样子"和"错的样子"两端，让模型在中间定位
- 在提示词中加："不要超出 / 不要不到"的双向边界

### 7.4 原则 4：保持正确的部分不要动

**踩坑实例**：每次修改一个角色的表情，**其他角色的脸或肤色也会一起被重画**。

**典型表现**：
- 修对了伪人嘴型，但伪人皮肤变成了正常肤色
- 修对了皮肤，但末日时钟的姿势又变了

**正确做法**：
- 把"通过的版本"作为**主参考图**传入
- 在 prompt 中**逐角色逐部位列出"保持不变"清单**
- 关键属性（如伪人的灰肤）单独用 ⚠️ 标记反复强调

**规则**：每次修改时，**未修改的部分必须显式列出"保持原样"**，不要假设模型会自动保留。

### 7.5 原则 5：拼接 > 重生成

**踩坑实例**：当两个角色的"正确版本"分别存在于两张不同的历史图中，反复用 prompt 描述去"重生成"两个角色，每次都会有细微漂移。

**正确做法**：
- 直接把两张正确的特写当作**唯一真值源**传入
- 明确告诉模型："这是复刻任务，不是创作任务"
- 用"像素级复刻"、"照搬"、"不要重新设计"等强制性指令

**规则**：当部分元素已经画对时，**优先用拼接模式，不要再走重生成路径**。

### 7.6 原则 6：先确认理解，再动手生成

**踩坑实例**：用户提需求 → 模型立刻生图 → 错了 → 再生 → 再错。一轮浪费 5-10 次生成。

**正确做法**：
- 收到模糊需求时，**先用文字描述自己理解的方向**，让用户确认
- 用户确认后再动手
- 复杂修改前可以列出"要改什么 / 不改什么"的清单先对齐

**规则**：宁可多花一轮文字对齐，也不要靠生图来试错。

### 7.7 原则 7：警惕"角色刻板印象"对模型的污染

**踩坑实例**：每次说"伪人"，模型都默认往"经典 SCP / 都市传说式恐怖伪人"方向画。

**正确做法**：
- 在提示词中**明确否定刻板印象**：「这个伪人不是经典恐怖谷伪人，是温和的打工人伪人」
- 给出**反例对比**：「不要咧嘴大笑、不要露满口牙、不要呆滞瞪眼」
- 用类比锚定：「像第一天上班被介绍给同事时的客气微笑」

**规则**：所有带类型 / 标签的角色名（伪人、吸血鬼、忍者等），都要在 prompt 中**显式反刻板化**。

### 7.8 原则 8：渲染独立属性时单独标红

**踩坑实例**：伪人的灰白肤色每隔几轮就会丢失，被画回正常人类肤色。

**正确做法**：
- 把"易丢失但关键"的属性（如非人类肤色、特殊瞳色、独特配饰）**单独抽出来用 ⚠️ 标记**
- 在 prompt 末尾**再次强调一次**
- 在验收 checklist 中作为必查项

### 7.9 原则 9：避免"中间产物像素粒度污染"

**踩坑实例（发生于新角色生成实战）**：
- Step 1：生成新角色的"单人立绘"作为后续真值源
- Step 2：把单人立绘和现有基准图一起传入，生成多人合影
- 结果：新角色的像素颗粒明显比现有 4 人粗糙，画面像"4+1 拼贴"而非整体群像

**根本原因**：
- 中间产物（单人立绘）的像素密度本身就漂移了
- 当作真值源传入后，"像素级复刻"指令把这个漂移也复刻到了最终图
- 即使在 prompt 中要求"风格一致"，模型仍会优先复刻图像而不是文字描述

**正确做法**：
- ⭐ **用现有基准图作为像素密度的唯一锚**，不引入未经验证的中间产物
- 新角色优先**用文字描述生成**（基于详尽的人设卡），不依赖单人立绘
- 如果必须先生成单人立绘，**生成后人工对比像素密度**，不通过则禁止用作后续真值源
- 在 prompt 中**显式锚定像素密度**：「整张图保持基准图相同的像素颗粒密度」

**规则**：每次有新元素（新角色、新道具、新场景）加入时，**用基准图作为风格锚，不要让中间产物成为新的真值源**。

### 7.10 原则 10：画幅变化 = 必然重绘，不要试图"扩展画幅同时保留原图"

**踩坑实例（发生于新角色加入合影实战）**：
- 任务：把基准图（1536×1024，3:2，4 人）扩展为 16:9 的 5 人合影
- 期望：现有 4 人完全按基准图保留，仅在右侧添加新角色
- 结果：现有 4 人也被重新绘制了，与基准图对不上

**根本原因**：
- gemini-3-pro-image / gpt-image-2 等模型本质是"按描述整图生成"，不是"图像编辑器"
- 当画幅尺寸/比例发生变化时，模型必须重新构图（每个角色的位置/大小/姿势都要重新计算）
- 即使在 prompt 中说"完全按图1"，模型仍会重画，因为它没有"局部锁定"能力

**正确做法**：
- ⭐ **不要试图通过单次 prompt 完成"扩展画幅 + 保留原图 + 添加新元素"**
- 改用以下三种工作流之一：

  **方案 A：物理拼接（推荐）**
  ```
  1. 单独生成新元素（如新角色单人立绘），严格匹配基准图像素密度
  2. 人工验证像素密度 OK
  3. 用 Python/PIL 把基准图和新元素强行拼接
  4. 必要时用模型做边缘衔接修复
  ```

  **方案 B：保持画幅不变**
  ```
  在原画幅内重新构图（如把 4 人挤紧给新角色腾位）
  接受现有角色会被轻微重画
  优势：画幅不变，重画偏差最小
  ```

  **方案 C：mask 局部编辑**
  ```
  1. 用 PIL 先扩展画布（基准图保留 + 右侧填空白）
  2. 给空白区域加 mask
  3. 用支持 mask 的模型（gpt-image-2）只在 mask 区域生成新元素
  优势：左侧像素完全不动；劣势：边缘衔接需调试，可能超时
  ```

**规则**：
- 任何涉及"画幅扩展"或"添加新角色到现有合影"的任务，**必须事先决定走哪个方案**，不要默认走"prompt 直接扩展"
- 对用户说明这个限制：单次 prompt 无法完美做到"扩展+保留+添加"

## 8. 验收 Checklist

每次生成后，按此清单逐项检查。**有任何一项不通过则必须重生**。

### 8.1 整体风格
- [ ] 像素风、Q 版、像素颗粒质感
- [ ] 深蓝夜色背景（`#000A19~#010B1A`）+ 城市剪影 + 橙蓝粒子
- [ ] 色调统一，无糖果色 / 无写实光影 / 无矢量平滑

### 8.2 角色完整性
- [ ] 所有要求的角色都在场
- [ ] 角色站位、构图正确
- [ ] 每个角色的标志性道具齐全

### 8.3 角色 A（眼镜记者）
- [ ] 黑框圆眼镜 + 工牌（蓝底）+ 报纸 + 麦克风 + 橙包齐全
- [ ] 表情警惕、嘴抿平、无笑容
- [ ] 卡其风衣 + 黑高领

### 8.4 角色 B（末日时钟）
- [ ] **头部低垂、看向怀里时钟**
- [ ] **半睁眼 + 闭嘴 + 无汗珠**
- [ ] 抱着齿轮电路板时钟（铜色 + 绿电路板 + 外露铜线）
- [ ] 破洞黑T + 军绿工装裤 + 军靴
- [ ] **❌ 没有画成痛苦表情**（无皱眉 / 无张嘴 / 无汗珠 / 无哭）

### 8.5 角色 C（伪人）⭐ 重点核查
- [ ] ⚠️ **灰白色苍白肤色**（`#7C7D75~#828180` 区间，不是正常人类肤色）
- [ ] **红色圆瞳**（`#A82A2A~#C8302A`）
- [ ] **嘴小幅度上抿 + 露出上排一排小牙齿**（嘴宽 0.13~0.15h，等级 3）
- [ ] 眉头微蹙，有局促感
- [ ] 视线略微回避或正视但发僵
- [ ] 黑西装 + 白衬衫 + 黑窄领带 + 看手表姿势
- [ ] **❌ 没有画成经典恐怖谷的咧嘴大笑**
- [ ] **❌ 没有画成完全闭嘴**
- [ ] **❌ 没有画成呆滞瞪大眼**

### 8.6 角色 D（外星少女）
- [ ] UFO 帽子完整（碟身 + 天线 + 帽檐图案）
- [ ] 抱着白色幽灵 + 绿色外星人玩偶
- [ ] 黑长风衣 + 衣摆外星人图案 + 锁链
- [ ] 表情冷淡平静

### 8.7 一致性
- [ ] 修改后未改的角色与基准图保持一致
- [ ] 未要求改变的属性（肤色、瞳色、服装等）全部保留
- [ ] 整组色调一致，没有某个角色突兀
