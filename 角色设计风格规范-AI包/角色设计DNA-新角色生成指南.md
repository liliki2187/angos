# 角色设计 DNA 与新角色生成指南

> 本文档是「角色设计风格规范-AI 包」的**宏观方法论篇**。v2.0 是"既有角色的档案库"，本文档是"新角色的生成蓝图"。两者配合使用：v2.0 告诉你"怎么画现有 4 个角色"，本文档告诉你"如何设计第 5、第 6、第 N 个新角色，并让他们与现有 4 人组风格一致"。

---

## 0. 本文档解决的问题

| 场景 | v2.0 能解决吗 | 本文档能解决吗 |
|---|---|---|
| 画现有 4 个角色的新场景 | ✅ | — |
| 在已通过版本上微调 | ✅ | — |
| **设计一个全新的第 5 个角色** | ❌ | ✅ |
| **替换某个现有角色** | ❌ | ✅ |
| **为系列扩展新原型** | ❌ | ✅ |
| **判断一个新角色提案是否符合本项目调性** | ❌ | ✅ |

## 1. 项目世界观与调性 DNA（最高层抽象）

### 1.1 一句话定位

> **"现代都市夜色背景下，一群与超自然相关的边缘个体，以低能量、克制、疏离的姿态共处一帧。"**

### 1.2 必须遵守的 5 条世界观铁律

1. **时空锚定 - 现代都市 + 夜晚**
   - 不画古代、未来、白天、自然原野
   - 所有场景默认在城市内/边缘，夜色背景

2. **氛围基调 - 末日感 / 都市怪谈**
   - 不是温馨日常，不是热血战斗，不是浪漫爱情
   - 是"末班车之后无人的城市"那种空寂

3. **角色身份 - 边缘个体而非主流市民**
   - 不画上班族、学生、警察、医生等"正常职业"形象
   - 即使有"职业"，也是边缘的、灰色的、与异常相关的（记者-调查异常；伪人-伪装人类；外星少女-信徒）

4. **情绪能量 - 低、克制、内敛**
   - 不画放声大笑、痛哭、咆哮等高情绪
   - 所有角色情绪默认在 "低能量光谱"（详见 §3.4）

5. **超自然成分 - 必须有，但不能太显**
   - 每个角色都与"异常"有关，但不画明显的特效（不发光、不悬浮、不召唤）
   - 异常通过**道具、装饰、肤色、瞳色**等细节暗示

## 2. 角色设计 DNA（所有角色必须满足的共性）

### 2.1 视觉 DNA

| 维度 | 规则 | 为什么 |
|---|---|---|
| **比例** | Q 版头身比 1:1.5~1:2，大头小身 | 项目美术统一锚定 |
| **媒介** | 现代高清像素风（参考 Eastward / Omori） | 风格识别符 |
| **主色** | 70-80% 黑色 / 深暗色调（黑、深棕、深绿、深蓝） | 与都市夜色一致 |
| **识别色** | 10-20% 高饱和"跳色"（每个角色 1-2 个） | 让角色在合影中可辨识 |
| **发色** | 黑色（项目内 4 个角色全部黑发，强烈建议新角色也保持） | 群像统一性 |
| **描边** | 弱描边，深棕/深灰单像素，不用纯黑 | 风格一致性 |

### 2.2 人设 DNA

| 维度 | 规则 |
|---|---|
| **必须有 1 个"异常元素"** | 通过道具/本体/装饰之一暗示角色与超自然的关联 |
| **必须有 1-2 个"标志道具"** | 作为人设核心识别符，合影中道具不可省略 |
| **必须有完整的"着装语言"** | 服装反映其身份/职业/亚文化归属，不能随便穿 T 恤短裤 |
| **必须有"低能量情绪基线"** | 默认表情在 §3.4 的低能量光谱中 |
| **不允许"普通市民"设定** | 每个角色都必须是边缘个体 |

### 2.3 调性 DNA

| 维度 | 规则 |
|---|---|
| **疏离感** | 角色之间不亲密、不嬉闹，保持 0.5 身宽空隙 |
| **克制感** | 即使做动作，也是"刚好够"的最小幅度 |
| **不笑** | 默认所有角色嘴抿平，唯一例外是"伪人式陪笑" |
| **不直视观众**（部分）| 一些角色视线略偏，加强疏离感 |

## 3. 角色原型分类系统（4 维度坐标）

> 现有 4 个角色 = 在这 4 个维度上的 4 个不同坐标。新角色应该**选择一个新坐标**或**补充某个空白维度**。

### 3.1 维度 A：异常类型（角色"非人"在哪里）

| 类型 | 含义 | 现有案例 | 视觉表现 |
|---|---|---|---|
| **道具异常** | 角色本身正常，但持有的道具异常 | A 记者（50 年代麦克风）<br>B 末日时钟（自制怪钟） | 道具的形态、材质偏离常规 |
| **本体异常** | 角色本身是非人/半人 | C 伪人（灰肤 + 红瞳） | 肤色/瞳色/比例脱离人类 |
| **装饰异常** | 角色本体正常，但装饰物超出常规 | D 外星少女（UFO 帽 + 外星人玩偶） | 服饰造型偏离常规审美 |
| **行为异常**（待开发） | 角色姿势/动作不寻常 | 暂无 | 长时间凝视墙壁、倒退走等 |
| **环境异常**（待开发） | 角色总伴随某种异常环境元素 | 暂无 | 周身一直有蝴蝶/雾气 |

### 3.2 维度 B：与超自然的关系

| 类型 | 含义 | 现有案例 |
|---|---|---|
| **调查者** | 主动接触和记录超自然 | A 记者 |
| **见证者** | 被动遭遇超自然，被改变 | B 末日时钟 |
| **化身** | 自身就是超自然存在的化身 | C 伪人 |
| **信徒** | 主动追随/崇拜超自然 | D 外星少女 |
| **拒绝者**（待开发） | 知道超自然但拒绝接触 | 暂无 |
| **利用者**（待开发） | 把超自然当工具利用 | 暂无 |
| **逃亡者**（待开发） | 被超自然追逐 | 暂无 |

### 3.3 维度 C：服装语言（亚文化归属）

| 类型 | 含义 | 现有案例 |
|---|---|---|
| **职业装** | 反映其"工作"身份 | A 记者（风衣）<br>C 伪人（西装） |
| **实用装/废土装** | 反映其"生存"状态 | B 末日时钟（破洞 T + 工装裤） |
| **亚文化装** | 反映其"信仰/兴趣" | D 外星少女（哥特长风衣） |
| **学生装**（待开发） | 校服 / 学院风 | 暂无 |
| **运动装**（待开发） | 街头 / 滑板 / 跑酷 | 暂无 |
| **古典装**（待开发） | 和服 / 旗袍 / 民国风 | 暂无 |
| **军事装**（待开发） | 战术背心 / 制服 | 暂无 |

### 3.4 维度 D：情绪能量光谱（低能量带）

> 所有角色情绪必须落在这条"低能量光谱"中，**不允许超出**。

```
   ←—— 更内敛                              更外显 ——→
   
   神游   冷漠   放空   疏离   警惕   局促   忧郁   出神
    │     │     │     │     │     │     │     │
                                    │
   [D]   [TBD] [B]   [TBD] [A]   [C]   [TBD] [TBD]
   外星  待用  末日  待用  记者  伪人  待用  待用
   少女        时钟        
```

| 情绪基线 | 含义 | 眉 | 眼 | 嘴 |
|---|---|---|---|---|
| 神游 | 灵魂出窍/恍惚 | 微微下垂 | 半睁向上无神 | 微张呼吸 |
| 冷漠 | 不关心一切 | 平直 | 半睁直视 | 抿平 |
| 放空 | 大脑停转 | 完全放松 | 半睁低垂 | 闭合平直 |
| 疏离 | 与人有距离 | 平直 | 半睁视线略偏 | 抿平 |
| 警惕 | 时刻观察 | 略蹙 | 微眯 | 抿紧 |
| 局促 | 不自在/陪笑 | 微蹙 | 微睁略避 | 上抿小笑 |
| 忧郁 | 内心阴沉 | 眉尾下垂 | 半睁低垂 | 嘴角微下垂 |
| 出神 | 看向远方 | 平直 | 半睁远眺 | 微张 |

**禁止情绪**：放声大笑、痛哭、惊恐、咆哮、狰狞、暴怒、热情、欢呼等所有"高能量情绪"。

## 4. 新角色 5 步设计法

### Step 1：定原型坐标（在 4 维度中选一个新位置）

填写以下表格：

```
新角色坐标：
- 异常类型：[选 §3.1 中的一种]
- 与超自然关系：[选 §3.2 中的一种]
- 服装语言：[选 §3.3 中的一种]
- 情绪基线：[选 §3.4 中的一种]
```

**关键原则**：至少有 2 个维度与现有 4 个角色**不同**，否则会和现有角色重复。

### Step 2：定异常元素（让角色"非人化"的具体表现）

根据 Step 1 选的"异常类型"，具体设计：

- **道具异常**：什么道具？形态/材质如何偏离常规？
- **本体异常**：哪个身体部位异常？颜色/质感/比例如何？
- **装饰异常**：什么装饰？为什么这个装饰反常？
- **行为异常**：什么姿势/动作？为什么让人不安？
- **环境异常**：伴随什么环境元素？

**质量自检**：
- [ ] 这个异常是否"细微但持久"（不是一次性特效）？
- [ ] 普通观众一眼能看出"哪里不对劲"，但说不出具体是什么？
- [ ] 这个异常是否避免了"明显的超自然特效"（不发光、不悬浮）？

### Step 3：选识别色（在调色板中给角色定 1-2 个跳色）

参考 `风格规范-v2.0.md` §1.3 的整体色板。

**规则**：
- 每个新角色应有 **1 个主识别色**（饱和度 50%+）+ **1 个副识别色**（饱和度 30%+）
- 识别色不能与现有 4 个角色冲突：
  - ❌ 不要选橙色（记者占了）
  - ❌ 不要选军绿（末日时钟占了）
  - ❌ 不要选血红 + 灰白组合（伪人占了）
  - ❌ 不要选草绿（外星少女占了）
- 推荐扩展色域：
  - 紫色 `#5A3A7C` ~ `#8A5AB8`（神秘 / 信仰）
  - 青蓝色 `#2C6A8A` ~ `#4A9AC8`（科技 / 冷感）
  - 酒红 `#6C2C2C` ~ `#9C3C3C`（古典 / 悲剧）
  - 金黄 `#8A6B3A` ~ `#C8A05A`（贵族 / 颓废）
  - 苍青 `#3A6C5A` ~ `#5C8A78`（药剂 / 病态）
  - 暗粉 `#7C4A5A` ~ `#A87890`（少女 / 暧昧）

### Step 4：设计服装语言

根据 Step 1 的"服装语言"维度具体设计：

- **服装类型**：上衣/下装/外套/鞋 各是什么？
- **材质**：棉、麻、皮、金属、合成纤维？
- **完整度**：完好 / 破损 / 改装 / 拼接？
- **装饰物**：项链、戒指、徽章、绑带、链条等？
- **特征细节**：补丁、刺绣、涂鸦、磨损痕迹？

**色彩配比强制规则**：
- 主色 70-80% 必须是黑色或深暗色
- 识别色 10-20%（来自 Step 3）
- 中间灰色 / 阴影 10%

### Step 5：定情绪基线 + 姿势基线

- **情绪基线**：在 §3.4 光谱中选一个位置（不能超出光谱外）
  - 眉怎么样？
  - 眼怎么样？
  - 嘴怎么样？
- **姿势基线**：默认站姿是什么样？
  - 双手位置？
  - 头部朝向？
  - 视线方向？
- **不可越界**：
  - 不能笑（伪人式陪笑除外）
  - 不能直接看观众（部分可正视，但要"冷漠地正视"）
  - 不能与其他角色亲密互动

## 5. 新角色 Checklist（设计完成后必查）

### 5.1 世界观一致性
- [ ] 角色是"现代都市夜色"中的边缘人物？
- [ ] 角色与超自然有明确关联？
- [ ] 角色不是"普通市民"形象？

### 5.2 视觉 DNA
- [ ] 头身比 Q 版（1:1.5~1:2）？
- [ ] 黑色 / 深暗色占主色 70%+？
- [ ] 有 1-2 个高饱和识别色？
- [ ] 识别色不与现有 4 角色冲突？
- [ ] 发色为黑色（保持群像统一性）？

### 5.3 人设 DNA
- [ ] 有明确的"异常元素"（道具/本体/装饰/行为/环境之一）？
- [ ] 有 1-2 个不可省略的标志道具？
- [ ] 有完整的着装语言（反映身份/职业/亚文化）？
- [ ] 情绪基线在低能量光谱内？

### 5.4 原型独立性
- [ ] 在 4 维坐标中至少有 2 维度与现有角色不同？
- [ ] 不与现有 4 角色的设定重复或近似？

### 5.5 集成兼容性
- [ ] 站在现有 4 人合影中不会显得突兀？
- [ ] 与现有 4 人的高度比例协调？
- [ ] 不会"抢镜"破坏群像平衡？

## 6. 现有 4 个角色在原型系统中的定位（参考案例）

| 角色 | 异常类型 | 与超自然关系 | 服装语言 | 情绪基线 |
|---|---|---|---|---|
| A 眼镜记者 | 道具异常（老麦克风） | 调查者 | 职业装（风衣） | 警惕 |
| B 末日时钟 | 道具异常（自制怪钟） | 见证者 | 实用装/废土 | 放空 |
| C 伪人 | 本体异常（灰肤红瞳） | 化身 | 职业装（西装） | 局促 |
| D 外星少女 | 装饰异常（UFO 帽） | 信徒 | 亚文化装（哥特） | 冷漠 |

### 6.1 当前 4 角色的空白维度

观察上表，现有 4 角色**没有覆盖**的维度位置：

- **异常类型**：行为异常 / 环境异常 ← 新角色可填
- **与超自然关系**：拒绝者 / 利用者 / 逃亡者 ← 新角色可填
- **服装语言**：学生装 / 运动装 / 古典装 / 军事装 ← 新角色可填
- **情绪基线**：神游 / 疏离 / 忧郁 / 出神 ← 新角色可填

## 7. 新角色示例：第 5 个角色"灵媒少女"

> 用 §4 的 5 步法走一遍，作为方法论的演示。
### Step 1：原型坐标
- 异常类型：**本体异常 + 装饰异常**（双异常）
- 与超自然关系：**利用者**（新维度）
- 服装语言：**古典装**（新维度）
- 情绪基线：**神游**（新维度）

→ 至少 3 维度与现有 4 角色不同 ✅

### Step 2：异常元素
- **本体异常**：右眼是浑浊的乳白色（左眼正常黑色），象征"看见另一边"
- **装饰异常**：脖子挂一串小铜铃 + 手腕缠绕泛黄符纸，符纸边角写着褪色朱砂字

### Step 3：识别色
- 主识别色：**朱砂红 `#9C3C3C`**（符纸朱砂字）
- 副识别色：**暗金 `#8A6B3A`**（铜铃）
- 不与现有 4 角色冲突 ✅

### Step 4：服装语言（古典装 - 改良和服 / 民国风混搭）
- 上身：长袖白色（夜景下偏灰 `#A8A8A0`）改良立领衬衫，袖口绑暗红绑带
- 下身：黑色 `#0F0F0E` 中长马面裙，裙摆有暗金 `#8A6B3A` 云纹刺绣
- 外套：黑色 `#0A0A09` 无袖长马甲，背后绣朱砂红 `#9C3C3C` 八卦图案
- 鞋：黑色 `#0F0F0E` 平底布鞋
- 装饰：脖子小铜铃 + 手腕符纸 + 头上一枚银色 `#A8A8A0` 发簪
- 配比自检：黑/深色 75% + 红+金跳色 15% + 中间灰 10% ✅

### Step 5：情绪基线 + 姿势
- **眉**：微微下垂
- **眼**：半睁，右眼乳白色，视线略向上无神
- **嘴**：微张（呼吸感），不抿
- **姿势**：双手自然垂落，左手轻握符纸，头部微微仰起约 10°
- **气质**：似醒非醒，灵魂半离身的"神游"

### 集成兼容性
- 站在 4 人合影右侧或左侧均可
- 高度与外星少女接近
- 识别色（朱砂红 + 暗金）不与现有角色冲突
- 情绪（神游）与整体低能量基调一致

### 一句话人设
> "白色右眼能看到另一边的少女，靠卖符纸和铜铃驱赶游荡的怪谈生物为生。"

## 8. 给 AI 生成新角色的 Prompt 模板

### 8.0 ⚠️ 必读：避免"粗糙立绘传染像素粒度"陷阱

这是新角色生成最容易踩的坑，**实战中已踩过一次**。

#### 错误流程（不要这样做）

```
Step 1：先生成新角色的"单人立绘"作为后续合影的真值源
    └─ 问题：单人立绘可能本身像素密度就漂移了（比基准图粗糙或细腻）

Step 2：把单人立绘作为"真值源"传入，生成 5 人合影
    └─ 问题：因为要求"像素级复刻"，模型把单人立绘的错误像素密度也复刻进合影
    └─ 结果：合影中的新角色像素颗粒明显比其他 4 角色粗糙，画面像"4+1 拼贴"
```

#### 正确流程

```
Step 1：跳过"单人立绘"环节（除非单人立绘本身就是任务目标）

Step 2：直接在合影任务中：
    - 传入【现有基准图】作为像素密度/颗粒/描边/色调的唯一锚定标准
    - 传入【现有角色的脸部正确特写】作为现有角色的真值源
    - 用【纯文字描述】生成新角色（包括外观、服装、道具、表情）
    - 在 prompt 中显式强调：「新角色的像素密度必须与基准图完全一致」
```

#### 必须包含的 prompt 关键句

```
【⚠️ 最高优先级 - 像素密度统一】
- 整张图必须保持基准图完全相同的像素颗粒密度
- 整张图必须保持基准图完全相同的描边粗细
- 整张图必须保持基准图完全相同的色调饱和度
- 新角色的像素质感必须与现有角色完全一致，不要更细腻、不要更粗糙
- 不要让画面中出现"两种不同分辨率/像素密度"的角色
```

#### 何时可以使用单人立绘作为真值源

只有当**单人立绘本身已经验证过像素密度匹配基准图**时，才能用它作为后续真值源。否则一律用文字描述 + 基准图风格锚定。

## 9. 新角色集成到现有 4 人组的方式

### 9.1 三种集成模式

| 模式 | 含义 | 适用 |
|---|---|---|
| **替换** | 用新角色替换某个现有角色 | 现有角色不再使用时 |
| **补位** | 加入第 5 个角色，与现有 4 人共存 | 扩展群像 |
| **客串** | 在某场景中临时出现，不进 4 人合影 | 单次场景 |

### 9.2 5 人合影构图建议

如果加入第 5 人，构图调整建议：
- 横向排列拉长为 4:3 或 16:9
- 第 5 人插在合影中间（如 A B 新 C D）或两端
- 保持角色间距 0.5 身宽
- 整体调色仍然 70% 暗 + 跳色点缀
