> **本包是给 AI 看的，不是给人看的。** 请 AI 在开始任何角色绘图任务前**必读本 README**，理解包内每个文件的用途，并严格按 §4 的工作流执行。

## 0. 你（AI）正在做什么

你正在为「**末日都市怪谈像素风群像**」这个项目生成角色图。

本项目有 **4 个固定角色**（眼镜记者 / 末日时钟 / 伪人 / 外星少女）+ **一套统一的美术风格**。无论用户给你什么场景（合影、单人、互动、新姿势、**或新角色**），你必须保证：

1. **风格统一**：像素风、Q 版、深蓝夜色基调
2. **角色一致**：4 个角色的服装、道具、表情基线、识别色不能漂移
3. **表情克制**：所有情绪都是低能量、内敛的都市疏离感
4. **遵守禁忌**：每个角色都有"绝对不能画"的清单（见 §3）
5. **新角色必须符合项目 DNA**：见 `角色设计DNA-新角色生成指南.md`

## 3. 4 个角色的极简卡片

> 完整设定见 `风格规范-v2.0.md` §3。这里只列**最易出错的红线**。

### 角色 A · 眼镜记者
- 黑框圆眼镜 + 卡其风衣 + 蓝色工牌 + 橙色帆布包
- 表情：警惕观察、不笑

### 角色 B · 末日时钟
- 长黑发凌乱、破洞黑T、军绿工装裤、抱齿轮电路板大钟
- 🔴 **红线**：表情必须是**低头看时钟+闭嘴放空**，绝对不要画痛苦/张嘴/汗珠/直视观众
- 看 `examples/末日时钟表情对照/01-正确*.png`

### 角色 C · 伪人 ⭐ 最易出错
- ⚠️ **灰白苍白肤色**（不是人类肤色！）
- 红圆瞳 + 短乱黑发 + 黑西装 + 黑领带 + 看手表
- 🔴 **红线**：嘴型必须是**小幅度上抿露出上排一排小牙齿**的"打工人陪笑"，绝对不要画：
  - ❌ 经典恐怖谷的咧嘴大笑（看 `examples/伪人嘴型对照/02-错误*.png`）
  - ❌ 完全闭嘴或几乎不露牙（看 `examples/伪人嘴型对照/03-错误*.png`）
- ✅ 看 `examples/伪人嘴型对照/01-正确*.png`

### 角色 D · 外星少女
- UFO 飞碟造型帽子（顶部雷达天线 + 帽檐外星人/幽灵图案）
- 黑长风衣（衣摆绿色外星人图案+锁链）+ 抱白幽灵和绿外星人玩偶
- 表情：冷淡神秘、不笑

## 4. 工作流（必须按顺序执行）

### Step 1：判断任务类型

| 用户需求 | 走哪个文档/模板 |
|---|---|
| **设计一个全新的角色**（第5、6、N 个）| ⭐ **`角色设计DNA-新角色生成指南.md`**（核心方法论） |
| 全新场景但用现有 4 角色（如"画 4 人在便利店门口"）| `prompts/01-标准生成模板.md` |
| 在已有图上调表情/动作 | `prompts/02-局部修改模板.md` |
| 已有正确的脸部/部件需要拼接 | `prompts/03-复刻拼接模板.md` ⭐ |
| 评估某个新角色提案是否符合调性 | `角色设计DNA-新角色生成指南.md` §1-3 |

### Step 2：读取必要参考图

无论哪种任务，**至少要读**：
- `reference/01-原始基准图.png`（风格 / 构图 / 色调基准）
- 涉及末日时钟 → 必读 `examples/末日时钟表情对照/01-正确*.png`
- 涉及伪人 → 必读 `examples/伪人嘴型对照/01-正确*.png`
- 涉及伪人 → **必读** `examples/伪人嘴型对照/02-错误*.png` 和 `03-错误*.png`，理解边界

### Step 3：先用文字确认理解

⚠️ **重要**：在调用图像生成 API 之前，**先用文字向用户复述你的理解**：
- 这个任务涉及哪些角色？
- 每个角色的表情/动作应该是什么状态？
- 哪些是用户没说但你打算保留的？

**用户确认后再生成**。生图是昂贵的，文字对齐是廉价的。

### Step 4：生成

按选定模板的 prompt 结构调用，**严格遵循**：
- 把"真值源"图作为图像输入传入
- 在 prompt 中明确告诉模型："这是复刻任务，不是创作任务"
- 列出"不要画 X / Y / Z"的禁忌项
- 关键易丢失属性（如伪人灰肤）用 ⚠️ 单独标记

### Step 5：自检

按 `风格规范-v2.0.md` §8 的 Checklist 逐项核对，**不通过则重生**。

## 5. 避坑原则（精简版）

> 详细版见 `风格规范-v2.0.md` §7

| # | 原则 | 一句话 |
|---|---|---|
| 1 | 反刻板化 | 名字带情绪色彩的角色（末日时钟/伪人）必须显式反直觉澄清 |
| 2 | 表情具体到肌肉 | 不说"温和微笑"，说"嘴角小幅度上抿+露上排小牙+眉头微蹙" |
| 3 | 避免螺旋 | 给五级标尺让模型在中间定位，不要单向"再大点/再小点" |
| 4 | 保持正确不动 | 修改时显式列出"不改"清单 |
| 5 | 拼接 > 重生成 | 已对的部分用真值源复刻，不要再描述生成 |
| 6 | 先文字确认 | 复杂修改前文字对齐一次，比生图试错三次便宜 |
| 7 | 反刻板印象污染 | 「这个伪人不是经典恐怖伪人」必须明说 |
| 8 | 关键属性标红 | 易丢失属性（伪人灰肤）用 ⚠️ 反复强调 |
| 9 | 避免中间产物像素粒度污染 ⭐ | 用基准图作像素密度锚，不要让粗糙的中间产物成为新真值源 |
| 10 | 画幅变化 = 必然重绘 ⭐⭐ | 不要试图通过单次 prompt 完成"扩展画幅+保留原图+添加新元素"，要走物理拼接/mask 编辑 |

## 6. 不要做的事

- ❌ **不要**只看 README 就开始生图，必须先读 `风格规范-v2.0.md`
- ❌ **不要**把 `reference/角色B-末日时钟-*.png` 和 `reference/角色C-伪人-*.png` 当作脸部真值（它们的脸是错的）
- ❌ **不要**忽略 `examples/` 里的错误案例，那些是模型最容易踩的坑
- ❌ **不要**在没有用户确认的情况下做"自由发挥"
- ❌ **不要**改动用户没要求改的角色 / 属性 / 配色

---

## 7. 紧急情况

如果遇到以下情况，**立刻停下来询问用户**，不要自行决策：

- 用户要求的场景中需要新增 4 角色之外的新角色 → 询问新角色的人设
- 用户要求的姿势或动作可能违反角色禁忌 → 列出冲突让用户取舍
- 用户的描述模糊到有多种合理理解 → 列出 2-3 个理解请用户选
- 生成 3 次仍未达到用户要求 → 停下来用文字重新对齐，不要继续盲生
